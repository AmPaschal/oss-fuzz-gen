
	
<description>
The function ssh_dispatch_run_fatal is a wrapper for ssh_dispatch_run, which reads and processes incoming SSH packets. The mode argument determines whether the function blocks waiting for a packet or polls for one. The done argument is a pointer to a flag that, if set, will cause the dispatch loop to terminate.
</description>
<requirements>
<requirement>
The first argument, a pointer to a struct ssh, must be initialized. The ssh_init function is a good candidate for this, as it is used by callers of the target function to initialize this struct.
</requirement>
<requirement>
The second argument, mode, must be either DISPATCH_BLOCK (0) or DISPATCH_NONBLOCK (1). Other values will lead to undefined behavior in the packet reading loop.
</requirement>
<requirement>
The third argument, done, can be NULL. If it is not NULL, it must point to a valid sig_atomic_t variable.
</requirement>
<requirement>
The function ssh_dispatch_init should be called to initialize the dispatch table in the ssh struct. This is necessary to properly handle incoming packets.
</requirement>
</requirements>

// Dummy log handler to suppress output.
static void fuzz_log_handler(LogLevel level, int force, const char *msg, void *ctx) {}

// The fuzzer entry point must have C linkage.
extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider stream(data, size);

  // Basic logging setup to avoid fatal errors on logging attempts.
  log_init("fuzz", SYSLOG_LEVEL_ERROR, SYSLOG_FACILITY_USER, 1);
  set_log_handler(fuzz_log_handler, NULL);

  struct ssh *fuzz_ssh = NULL;

  // Initialize ssh struct. Pass NULL for kex_params as it's optional
  // and avoids complex initialization that causes build failures.
  if (ssh_init(&fuzz_ssh, stream.ConsumeBool(), NULL) != 0) {
    return 0;
  }

  // Initialize dispatch table.
  ssh_dispatch_init(fuzz_ssh, NULL);

  // Feed fuzzer data into the ssh input buffer.
  std::vector<uint8_t> input_data = stream.ConsumeRemainingBytes<uint8_t>();
  if (ssh_input_append(fuzz_ssh, input_data.data(), input_data.size()) != 0) {
    ssh_free(fuzz_ssh);
    return 0;
  }

  // Fuzz the mode and done flag.
  int mode = stream.PickValueInArray({DISPATCH_BLOCK, DISPATCH_NONBLOCK});
  volatile sig_atomic_t done_flag = 0;
  volatile sig_atomic_t *done_ptr = NULL;
  if (stream.ConsumeBool()) {
    done_ptr = &done_flag;
  }

  // Call the target function.
  // ssh_dispatch_run_fatal is designed to not return on error,
  // but it might if the input buffer is exhausted.
  ssh_dispatch_run_fatal(fuzz_ssh, mode, done_ptr);

  // Cleanup.
  ssh_free(fuzz_ssh);

  return 0;
}
