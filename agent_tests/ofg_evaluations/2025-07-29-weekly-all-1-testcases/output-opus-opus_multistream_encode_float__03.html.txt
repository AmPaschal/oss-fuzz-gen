
	
<description>
The function `opus_multistream_encode_float` encodes a multistream Opus frame from float input. It is a wrapper around the native function `opus_multistream_encode_native`. The first argument, `st`, is a pointer to an `OpusMSEncoder` state that must be created by `opus_multistream_encoder_create` or `opus_multistream_surround_encoder_create` and initialized with valid parameters. The second argument, `pcm`, is a pointer to the input audio data, and `frame_size` is the number of samples per channel. The `data` and `max_data_bytes` arguments specify the output buffer and its size.
</description>
<requirements>

<requirement>
The `st` argument, a pointer to an `OpusMSEncoder` struct, must be initialized by calling `opus_multistream_encoder_create`. This is because `opus_multistream_encode_float` operates on an existing encoder state.
</requirement>
<requirement>
The `frame_size` argument must be a valid frame size supported by the library for the sample rate provided to `opus_multistream_encoder_create`. Using an invalid frame size will cause the function to return `OPUS_BAD_ARG`.
</requirement>
<requirement>
The `max_data_bytes` argument must be large enough to hold the encoded output. A value less than `st->layout.nb_streams * 2 - 1` will result in an `OPUS_BUFFER_TOO_SMALL` error.
</requirement>
<requirement>
The `pcm` argument must be a buffer of at least `frame_size * st->layout.nb_channels` float values. Accessing elements beyond this size will lead to a buffer over-read.
</requirement>
<requirement>
The `data` argument must be a buffer of at least `max_data_bytes` bytes. A smaller buffer will lead to a buffer overflow when writing the encoded data.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <vector>

#include "opus.h"
#include "opus_multistream.h"

// Fuzzer for opus_multistream_encode_float.
extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Parameters for opus_multistream_encoder_create
  const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  opus_int32 Fs = provider.PickValueInArray(sample_rates);

  int channels = provider.ConsumeIntegralInRange<int>(1, 8);
  if (channels == 0) return 0; // Avoid division by zero later
  int streams = provider.ConsumeIntegralInRange<int>(1, channels);
  int coupled_streams = provider.ConsumeIntegralInRange<int>(0, streams);

  std::vector<unsigned char> mapping =
      provider.ConsumeBytes<unsigned char>(channels);
  if (mapping.size() != channels) {
    return 0;
  }

  const int applications[] = {OPUS_APPLICATION_VOIP, OPUS_APPLICATION_AUDIO,
                              OPUS_APPLICATION_RESTRICTED_LOWDELAY};
  int application = provider.PickValueInArray(applications);

  int error;
  OpusMSEncoder *st = opus_multistream_encoder_create(
      Fs, channels, streams, coupled_streams, mapping.data(), application, &error);
  if (error != OPUS_OK || st == nullptr) {
    return 0;
  }

  // Parameters for opus_multistream_encode_float
  const int frame_sizes[] = {120, 240, 480, 960, 1920, 2880};
  int frame_size = provider.PickValueInArray(frame_sizes);

  const size_t pcm_size = frame_size * channels;
  if (provider.remaining_bytes() < pcm_size * sizeof(float)) {
      opus_multistream_encoder_destroy(st);
      return 0;
  }
  
  std::vector<float> pcm(pcm_size);
  for (size_t i = 0; i < pcm_size; ++i) {
      pcm[i] = provider.ConsumeFloatingPoint<float>();
  }

  opus_int32 max_data_bytes = provider.ConsumeIntegralInRange<opus_int32>(128, 4000);
  std::vector<unsigned char> out_data(max_data_bytes);

  opus_multistream_encode_float(st, pcm.data(), frame_size, out_data.data(),
                                max_data_bytes);

  opus_multistream_encoder_destroy(st);
  return 0;
}
