
	
<description>
The function `symbolic_compressed_block::get_color_quant_mode` is an inline function that returns the `quant_mode` member of a `symbolic_compressed_block` object. This object represents a symbolically-decoded ASTC block. The `quant_mode` itself is an enum of type `quant_method`, which determines the quantization level used for the color endpoints in the block. To correctly obtain a meaningful `quant_mode`, the `symbolic_compressed_block` object must first be properly initialized by decoding a physical ASTC block.
</description>
<requirements>
<requirement>
The `symbolic_compressed_block` object (`scb`) must be initialized by calling `physical_to_symbolic` before calling `get_color_quant_mode`. The `physical_to_symbolic` function populates the `quant_mode` member of the `scb` which is returned by `get_color_quant_mode`.
</requirement>
<requirement>
The `physical_to_symbolic` function requires a valid `block_size_descriptor` instance as its first argument. The `init_block_size_descriptor` function must be called to initialize the `block_size_descriptor` before it is used.
</requirement>
<requirement>
The `init_block_size_descriptor` function must be called with a valid `astcenc_profile` enum value and valid block dimensions (x, y, z). These parameters define the block's properties, which are essential for the correct execution of the `physical_to_symbolic` function.
</requirement>
<requirement>
The second argument to the `physical_to_symbolic` function is a pointer to a 16-byte buffer representing the physical ASTC block data. This buffer must contain valid ASTC block data, as it is read and decoded by the function.
</requirement>
</requirements>

#include "/src/astc-encoder/Source/astcenc_internal.h"

#include <array>
#include <fuzzer/FuzzedDataProvider.h>
#include <vector>

struct BlockSizes {
  int x;
  int y;
  int z;
};

std::array<BlockSizes, 3> testSz{{
    {4, 4, 1},   // Highest bitrate
    {12, 12, 1}, // Largest 2D block
    {6, 6, 6}    // Largest 3D block
}};

std::array<block_size_descriptor, 3> testBSD;

/**
 * @brief Utility function to create all of the block size descriptors needed.
 */
bool bsd_initializer() {
  for (size_t i = 0; i < testSz.size(); i++) {
    init_block_size_descriptor(testSz[i].x, testSz[i].y, testSz[i].z, false, 4,
                               1.0f, testBSD[i]);
  }

  return true;
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  // Preinitialize the block size descriptors we need
  static bool init = bsd_initializer();

  // Must have enough data to select a block size and provide a 16 byte payload
  if (size < 1 + 16) {
    return 0;
  }

  FuzzedDataProvider stream(data, size);

  // Select a block size to test
  int i = stream.ConsumeIntegralInRange<int>(0, testSz.size() - 1);

  // Populate the physical block
  uint8_t pcb[16];
  std::vector<uint8_t> buffer = stream.ConsumeBytes<uint8_t>(16);
  if (buffer.size() != 16) {
    return 0;
  }
  std::memcpy(pcb, buffer.data(), 16);

  // Create the symbolic block from the physical
  symbolic_compressed_block scb;
  physical_to_symbolic(testBSD[i], pcb, scb);

  // Call the function under test
  (void)scb.get_color_quant_mode();

  return 0;
}
