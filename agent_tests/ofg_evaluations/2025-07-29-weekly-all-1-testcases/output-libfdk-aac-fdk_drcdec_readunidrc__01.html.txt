
	
<description>
The function FDK_drcDec_ReadUniDrc reads DRC information from a bitstream. It is a wrapper around the function drcDec_readUniDrc. It first checks if the decoder handle is valid and ready. Then, it calls drcDec_readUniDrc to read the UniDrc config, loudness info, and gain from the bitstream. Finally, it starts the selection process and updates the decoder status.
</description>
<requirements>
<requirement>
The first argument, hDrcDec, should be a valid handle obtained from FDK_drcDec_Open. This is because the function checks if the handle is NULL and accesses its members.
</requirement>
<requirement>
The status member of the hDrcDec handle must be non-zero. The function explicitly checks this and returns an error if it is zero, so it is a necessary precondition.
</requirement>
<requirement>
The hGainDec member of the hDrcDec handle must be a valid handle. This is because it is used to call drcDec_GainDecoder_GetFrameSize and drcDec_GainDecoder_GetDeltaTminDefault.
</requirement>
<requirement>
The second argument, hBitstream, must be a valid bitstream handle. This handle is passed to drcDec_readUniDrc to read data from.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <vector>

#include "FDK_drcDecLib.h"
#include "FDK_bitstream.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider provider(data, size);

    HANDLE_DRC_DECODER hDrcDec = NULL;
    if (FDK_drcDec_Open(&hDrcDec, DRC_DEC_ALL) != DRC_DEC_OK) {
        return 0;
    }
    if (hDrcDec == NULL) {
        return 0;
    }

    /* Initialize the decoder with fuzzed parameters. This is required for the
     * decoder to be in a valid state for processing. */
    const int frameSize = provider.ConsumeIntegralInRange<int>(1, 8192);
    const int sampleRate = provider.ConsumeIntegralInRange<int>(8000, 192000);
    const int baseChannelCount = provider.ConsumeIntegralInRange<int>(1, 16);
    if (FDK_drcDec_Init(hDrcDec, frameSize, sampleRate, baseChannelCount) != DRC_DEC_OK) {
        FDK_drcDec_Close(&hDrcDec);
        return 0;
    }

    /* Use the remaining data for the bitstream */
    std::vector<uint8_t> bitstream_data = provider.ConsumeRemainingBytes<uint8_t>();
    if (bitstream_data.empty()) {
        FDK_drcDec_Close(&hDrcDec);
        return 0;
    }

    /* FDKcreateBitStream is an inline function that takes a non-const buffer.
     * The vector's data() provides a suitable pointer. */
    HANDLE_FDK_BITSTREAM hBitstream = FDKcreateBitStream(bitstream_data.data(), (UINT)bitstream_data.size());
    if (hBitstream == NULL) {
        FDK_drcDec_Close(&hDrcDec);
        return 0;
    }

    /* Call the target function */
    FDK_drcDec_ReadUniDrc(hDrcDec, hBitstream);

    /* Cleanup */
    FDKdeleteBitStream(hBitstream);
    FDK_drcDec_Close(&hDrcDec);

    return 0;
}
