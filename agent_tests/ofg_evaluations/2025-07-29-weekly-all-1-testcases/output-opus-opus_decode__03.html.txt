
	
<description>
The `opus_decode` function decodes an Opus packet. It takes a previously created `OpusDecoder` state, the compressed data packet, and a buffer for the decoded PCM audio. It can also be used to handle lost packets by passing NULL as the data pointer. The function returns the number of decoded samples per channel or an error code.
</description>
<requirements>

<requirement>
The `OpusDecoder *st` argument must be initialized by calling `opus_decoder_create()`. This is because `opus_decode` operates on a decoder state that is set up by `opus_decoder_create`.
</requirement>
<requirement>
The `channels` argument provided to `opus_decoder_create` must be 1 or 2. This is to prevent an assertion failure `celt_assert(st->channels == 1 || st->channels == 2);` in `opus_decode`.
</requirement>
<requirement>
The `Fs` argument provided to `opus_decoder_create` must be one of 8000, 12000, 16000, 24000, or 48000. `opus_decoder_create` will return an error and a NULL decoder if `Fs` is not one of these supported sampling rates.
</requirement>
<requirement>
The `frame_size` argument must be greater than 0. The function returns `OPUS_BAD_ARG` for non-positive values.
</requirement>
<requirement>
The `pcm` buffer must be allocated to be at least `frame_size * st->channels * sizeof(opus_int16)` bytes. A smaller buffer will lead to a heap buffer overflow when the decoded audio is written.
</requirement>
<requirement>
If `decode_fec` is 0, `data` is not NULL, and `len` is positive, the `data` buffer must contain a valid Opus packet. `opus_decode` uses `opus_decoder_get_nb_samples` to validate the packet, and will return `OPUS_INVALID_PACKET` if it's invalid.
</requirement>
<requirement>
When decoding a lost packet (i.e., when `data` is NULL and `len` is 0), the `frame_size` should be determined by calling `opus_decoder_ctl` with the `OPUS_GET_LAST_PACKET_DURATION` request. This ensures the decoder has the correct frame size information for packet loss concealment.
</requirement>

</requirements>

#include <vector>
#include <cstdint>

#include "/src/opus/include/opus.h"

// Define from tests/test_opus_api.c
#define MAX_FRAME_SAMP (960 * 6)

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  if (size < 1) {
    return 0;
  }

  const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  opus_int32 Fs = provider.PickValueInArray(sample_rates);
  int channels = provider.ConsumeIntegralInRange<int>(1, 2);

  int error;
  OpusDecoder *decoder = opus_decoder_create(Fs, channels, &error);
  if (error != OPUS_OK || decoder == nullptr) {
    return 0;
  }

  int frame_size = provider.ConsumeIntegralInRange<int>(1, MAX_FRAME_SAMP);
  int decode_fec = provider.ConsumeBool();

  std::vector<opus_int16> pcm(frame_size * channels);
  std::vector<uint8_t> packet_data = provider.ConsumeRemainingBytes<uint8_t>();

  opus_decode(decoder, packet_data.data(), packet_data.size(), pcm.data(), frame_size, decode_fec);

  opus_decoder_destroy(decoder);

  return 0;
}
