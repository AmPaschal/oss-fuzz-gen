
	
<description>
The SafeUint32Mult function safely multiplies three unsigned 32-bit integers. It checks for arithmetic overflow at each intermediate multiplication step. If an overflow is detected, a 'dng_exception' is thrown, which is caught by the function, causing it to return 'false'. If the multiplication is successful, the result is stored in the 'result' output parameter, and the function returns 'true'.
</description>
<requirements>

<requirement>
The 'result' parameter must be a valid pointer to a uint32_t variable. The function writes the multiplication result to this pointer, so a NULL or invalid pointer will cause a crash.
</requirement>
<requirement>
The product of 'arg1' and 'arg2' should not exceed the maximum value for a 32-bit unsigned integer (UINT32_MAX). An intermediate overflow will cause an exception to be thrown and the function to return false.
</requirement>
<requirement>
The final product of 'arg1', 'arg2', and 'arg3' must not exceed UINT32_MAX. The function is designed to prevent this overflow, and will return false if it occurs.
</requirement>

</requirements>
