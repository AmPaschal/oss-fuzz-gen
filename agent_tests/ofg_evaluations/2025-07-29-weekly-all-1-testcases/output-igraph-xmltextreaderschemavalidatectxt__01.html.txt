
	
<description>
The function `xmlTextReaderSchemaValidateCtxt` is a wrapper around `xmlTextReaderSchemaValidateInternal`. It is used to set the schema validation context for an XML text reader. The primary purpose is to either activate validation by providing a valid schema validation context (`ctxt`) or to deactivate validation by passing `NULL` as the context.
</description>
<requirements>

<requirement>
The first argument, `reader`, must be a valid `xmlTextReaderPtr`. This is because the function dereferences this pointer to access and modify its members. A NULL pointer will cause a crash.
</requirement>
<requirement>
The `reader`'s `ctxt` member must not be NULL if the second argument `ctxt` is not NULL. The `xmlNewTextReaderFilename` function can be used to create a reader with an initialized context.
</requirement>
<requirement>
If the second argument `ctxt` is not NULL, the `reader`'s `mode` must be `XML_TEXTREADER_MODE_INITIAL`. This is the default mode when a reader is created using `xmlNewTextReaderFilename`.
</requirement>
<requirement>
The second argument, `ctxt`, can be a NULL pointer. If it is not NULL, it must be a valid `xmlSchemaValidCtxtPtr` created by `xmlSchemaNewValidCtxt`. An invalid pointer can lead to a crash.
</requirement>
<requirement>
The third argument, `options`, is unused. Any integer value can be provided for this argument.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <string>
#include <vector>

extern "C" {
#include "libxml/parser.h"
#include "libxml/xmlreader.h"
#include "libxml/xmlschemas.h"
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Split data for XML and Schema
  const size_t xml_size = provider.ConsumeIntegralInRange<size_t>(0, size);
  const std::string xml_data = provider.ConsumeBytesAsString(xml_size);
  const std::string schema_data = provider.ConsumeRemainingBytesAsString();

  // It's recommended to initialize and cleanup the parser for each fuzz input
  xmlInitParser();

  xmlTextReaderPtr reader = xmlReaderForMemory(
      xml_data.c_str(), xml_data.length(), NULL, NULL, 0);
  if (reader == NULL) {
    xmlCleanupParser();
    return 0;
  }

  xmlSchemaParserCtxtPtr parser_ctxt =
      xmlSchemaNewMemParserCtxt(schema_data.c_str(), schema_data.length());
  if (parser_ctxt == NULL) {
    xmlFreeTextReader(reader);
    xmlCleanupParser();
    return 0;
  }

  xmlSchemaPtr schema = xmlSchemaParse(parser_ctxt);
  xmlSchemaFreeParserCtxt(parser_ctxt);

  xmlSchemaValidCtxtPtr valid_ctxt = NULL;
  if (schema != NULL) {
    valid_ctxt = xmlSchemaNewValidCtxt(schema);
  }

  const int options = provider.ConsumeIntegral<int>();

  // Call the function under test
  xmlTextReaderSchemaValidateCtxt(reader, valid_ctxt, options);

  // Reading the document triggers the validation
  while (xmlTextReaderRead(reader) == 1) {
  }

  // Cleanup
  if (valid_ctxt != NULL) {
    xmlSchemaFreeValidCtxt(valid_ctxt);
  }
  if (schema != NULL) {
    xmlSchemaFree(schema);
  }
  xmlFreeTextReader(reader);
  xmlCleanupParser();

  return 0;
}
