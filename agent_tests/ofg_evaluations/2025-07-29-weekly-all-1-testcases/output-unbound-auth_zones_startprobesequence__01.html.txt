
	
<description>
The function `auth_zones_startprobesequence` starts a probe sequence for a given domain name within the authentication zones. It finds the appropriate transfer structure (`auth_xfer`) for the domain and initiates the notification process. The function is called by `do_auth_zone_transfer` in `daemon/remote.c`, which handles remote control commands.
</description>
<requirements>

<requirement>
The `az` parameter, a pointer to `struct auth_zones`, must be a valid, initialized structure. The function accesses the `lock` member of this struct, so `az` cannot be NULL.
</requirement>
<requirement>
The `nm` and `nmlen` parameters should represent a valid domain name. These are used to find the corresponding `auth_xfer` structure; an invalid domain name will likely cause `auth_xfer_find` to fail.
</requirement>
<requirement>
The `dclass` parameter should be a valid DNS class. In the only observed call site, this is hardcoded to `LDNS_RR_CLASS_IN`, suggesting that this is the expected value.
</requirement>

</requirements>
