
	
<description>
The function `ogs_gtp_context_parse_config` is responsible for parsing GTP-C and GTP-U configuration from a YAML document stored in the global application context (`ogs_app()->document`). It uses the `local` parameter as a key to find the relevant configuration section. The function then extracts server addresses, ports, and other options, and uses them to configure the GTP context. It is essential to properly initialize the application context and load a valid configuration file before calling this function.
</description>
<requirements>

<requirement>
The `ogs_app_initialize` and `ogs_app_parse_local_conf` functions must be called before `ogs_gtp_context_parse_config`. This is because the function depends on the global application context and the parsed YAML document, which are initialized by these functions.
</requirement>
<requirement>
The `ogs_gtp_context_init` function must be called before `ogs_gtp_context_parse_config`. This is to initialize the GTP context that this function configures.
</requirement>
<requirement>
The `local` parameter must be a non-null, null-terminated string that corresponds to a top-level key in the YAML configuration file. This is because it is used to find the correct configuration section in the YAML document.
</requirement>
<requirement>
The `remote` parameter must be a non-null, null-terminated string. Although it is not used in the provided source of `ogs_gtp_context_parse_config`, it is passed by all callers and might be used in `ogs_gtp_context_validation`.
</requirement>
<requirement>
The `ogs_app()->document` global variable must be a valid YAML document. The YAML document should contain `gtpc` and `gtpu` sections under the key provided by the `local` parameter to avoid assertion failures and to ensure proper configuration.
</requirement>

</requirements>

#include <stdio.h>
#include <stdint.h>
#include <unistd.h>
#include <stdlib.h>

#include "fuzzing.h"
#include "ogs-app.h"
#include "ogs-gtp.h"

#define FUZZ_LOCAL_KEY "smf"
#define FUZZ_REMOTE_KEY "upf"

extern int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    if (size == 0) {
        return 0;
    }

    char filename[] = "/tmp/fuzz-XXXXXX.yaml";
    int fd = mkstemp(filename);
    if (fd < 0) {
        return 0;
    }

    ssize_t written = write(fd, data, size);
    close(fd);

    if (written != (ssize_t)size) {
        unlink(filename);
        return 0;
    }

    if (ogs_app_initialize(NULL, filename, NULL) != OGS_OK) {
        unlink(filename);
        return 0;
    }

    ogs_gtp_context_init(16);

    ogs_app_parse_local_conf(FUZZ_LOCAL_KEY);

    ogs_gtp_context_parse_config(FUZZ_LOCAL_KEY, FUZZ_REMOTE_KEY);

    ogs_app_terminate();
    unlink(filename);

    return 0;
}
