
	
<description>
The `JS_NewTypedArray` function creates a new JavaScript TypedArray. It is a wrapper around the internal `js_typed_array_constructor` function, which handles the actual creation of the TypedArray. The function's behavior depends on the arguments passed in the `argv` array. It can create a new TypedArray of a specified length, or it can create a view over an existing ArrayBuffer.
</description>
<requirements>
<requirement>
A valid `JSRuntime` and `JSContext` must be created before calling this function. This is because the function and its callees dereference the `ctx` pointer, which is initialized by `JS_NewContext`, which in turn requires a `JSRuntime` created by `JS_NewRuntime`.
</requirement>
<requirement>
The `type` argument must be an integer within the range of the `JSTypedArrayEnum`, specifically between 0 (JS_TYPED_ARRAY_UINT8C) and 12 (JS_TYPED_ARRAY_FLOAT64), inclusive. The function performs an explicit check on this range and will throw a `RangeError` for invalid values.
</requirement>
<requirement>
To create a TypedArray of a specific length, `argc` should be 1 and `argv[0]` should be a `JSValue` representing a non-negative integer length. This is because `js_typed_array_constructor` will treat a non-object `argv[0]` as the length for a new underlying `ArrayBuffer`.
</requirement>
<requirement>
To create a TypedArray from an existing `ArrayBuffer`, `argv[0]` should be a `JSValue` pointing to an `ArrayBuffer` object. The `ArrayBuffer` can be created using `JS_NewArrayBufferCopy`. `argv[1]` (offset) and `argv[2]` (length) can also be provided, and they must specify a valid region within the buffer to avoid a `RangeError`.
</requirement>
</requirements>
