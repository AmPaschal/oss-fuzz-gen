
	
<description>
The `nts_ke_setup_send` function constructs an NTS-KE (Network Time Security Key Exchange) message to be sent from a server to a client. This message includes negotiated parameters like the AEAD (Authenticated Encryption with Associated Data) algorithm, as well as cookies for the client to use in subsequent NTP requests. The function takes a buffer control structure (`buf`), the chosen `aead` algorithm, client-to-server (`c2s`) and server-to-client (`s2c`) keys, and the `keylen`. It appends several records to the buffer, including the next protocol negotiation, the AEAD algorithm negotiation, and a series of cookies generated by `nts_make_cookie`.
</description>
<requirements>
<requirement>
The `nts_cookie_init()` function must be called before `nts_ke_setup_send`. This is because `nts_cookie_init()` initializes the `cookie_ctx` which is used by `nts_make_cookie` which is called by the target function. A failure to do so will result in a crash.
</requirement>
<requirement>
The `nts_cookie_init2()` function must be called before `nts_ke_setup_send`. This is because `nts_cookie_init2()` reads the cookie keys from a file or generates new ones, populating the `nts_keys` global array that is used by `nts_make_cookie`.
</requirement>
<requirement>
The `buf` argument, which is a pointer to a `BufCtl_t` struct, must be initialized with a buffer large enough to hold the generated NTS-KE message. A buffer of size 2048 is recommended, as seen in the `nts_ke_request` function.
</requirement>
<requirement>
The `aead` argument should be a valid AEAD algorithm identifier. For example, `AEAD_AES_SIV_CMAC_256`, as used in the caller function `nts_ke_request`.
</requirement>
<requirement>
The `c2s` and `s2c` arguments must point to valid key buffers. These keys are used by `nts_make_cookie` to generate cookies.
</requirement>
<requirement>
The `keylen` argument must be the correct length for the chosen `aead` algorithm. For example, if `aead` is `AEAD_AES_SIV_CMAC_256`, `keylen` should be 32.
</requirement>
</requirements>

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#include "ntpd.h"
#include "nts.h"

/* The enum aead_ciphers and its macros are defined in nts.h */

bool nts_ke_setup_send(struct BufCtl_t *, int, uint8_t *, uint8_t *, int);

extern int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size) {
	const int aead = AEAD_AES_SIV_CMAC_256;
	const int keylen = AEAD_AES_SIV_CMAC_256_KEYLEN;

	if (Size < (size_t)(keylen * 2)) {
		return 0;
	}

	/* These are required to initialize the cookie context used by the target function. */
	if (!nts_cookie_init()) {
		return 0;
	}
	if (!nts_cookie_init2()) {
		return 0;
	}

	uint8_t nts_message_buffer[2048];
	struct BufCtl_t buf;
	buf.next = nts_message_buffer;
	buf.left = sizeof(nts_message_buffer);

	uint8_t c2s_key[keylen];
	uint8_t s2c_key[keylen];
	memcpy(c2s_key, Data, keylen);
	memcpy(s2c_key, Data + keylen, keylen);

	nts_ke_setup_send(&buf, aead, c2s_key, s2c_key, keylen);

	return 0;
}
