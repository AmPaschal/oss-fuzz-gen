The `utf8proc_errmsg` function translates an error code of type `utf8proc_ssize_t` into a human-readable, null-terminated string. It is typically used when a function from the `utf8proc` library, such as `utf8proc_map`, returns a negative value indicating an error. The function implements a switch statement to map specific negative error codes (e.g., `UTF8PROC_ERROR_NOMEM`, `UTF8PROC_ERROR_OVERFLOW`) to their corresponding descriptive strings. For any unrecognized error code, a generic "unknown error" message is returned. This function is self-contained, does not rely on global state, and performs no memory allocation.
</description>
