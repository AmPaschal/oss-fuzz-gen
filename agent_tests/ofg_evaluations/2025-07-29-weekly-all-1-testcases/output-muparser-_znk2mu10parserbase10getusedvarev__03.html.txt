
	
<description>
The function `GetUsedVar` returns a map of the variables used in the expression. It does this by first creating a reverse polish notation (RPN) of the expression and then extracting the variables from the token reader.
</description>
<requirements>
<requirement>
The `SetExpr` method must be called with a valid expression string before calling `GetUsedVar`. This is because `GetUsedVar` internally calls `CreateRPN` which will throw an `ecUNEXPECTED_EOF` error if the expression string is not set.
</requirement>
<requirement>
The expression string provided to `SetExpr` should not be empty. An empty expression string will cause an `ecUNEXPECTED_EOF` error within the `CreateRPN` function, which is called by `GetUsedVar`.
</requirement>
</requirements>
