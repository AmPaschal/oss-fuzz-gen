
	
<description>
The `usbredirparser_send_iso_packet` function is a wrapper around the `usbredirparser_queue` function. It is used to send ISO packets. The function takes a parser, an ID, an ISO packet header, and a data buffer as input. The `usbredirparser_queue` function then queues the packet to be sent.
</description>
<requirements>
<requirement>
The `parser` argument must be a valid pointer to a `usbredirparser` struct. This is because it is dereferenced in the `usbredirparser_queue` function.
</requirement>
<requirement>
The `iso_header` argument must be a valid pointer to a `usb_redir_iso_packet_header` struct. This is because it is dereferenced in the `usbredirparser_queue` function.
</requirement>
<requirement>
If `data_len` is greater than 0, the `data` argument must be a valid pointer to a buffer of at least `data_len` bytes. This is to prevent a buffer over-read in the `usbredirparser_queue` function.
</requirement>
<requirement>
The `data_len` argument should be equal to the `length` field of the `iso_header` struct. This is to ensure consistency between the header and the data.
</requirement>
</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  InitializeParser();
  if (!parser) {
    return 0;
  }

  FuzzedDataProvider fdp(data, size);

  // Generate arguments for usbredirparser_send_iso_packet
  const uint64_t id = fdp.ConsumeIntegral<uint64_t>();
  
  struct usb_redir_iso_packet_header iso_header;
  if (fdp.remaining_bytes() < sizeof(iso_header)) {
      return 0;
  }
  fdp.ConsumeData(&iso_header, sizeof(iso_header));

  const int data_len = iso_header.length;
  std::vector<uint8_t> packet_data = fdp.ConsumeBytes<uint8_t>(data_len);
  
  // Ensure the data buffer has the expected size.
  if (packet_data.size() != data_len) {
    return 0;
  }
  
  uint8_t* data_ptr = (data_len > 0) ? packet_data.data() : nullptr;

  usbredirparser_send_iso_packet(parser.get(), id, &iso_header, data_ptr, data_len);

  // Try to write out any queued data to exercise more code paths
  while (usbredirparser_has_data_to_write(parser.get())) {
    if (usbredirparser_do_write(parser.get()) < 0) {
      break;
    }
  }

  return 0;
}
