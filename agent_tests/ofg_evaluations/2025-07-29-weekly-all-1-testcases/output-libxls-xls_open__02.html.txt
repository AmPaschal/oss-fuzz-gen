
	
<description>
The `xls_open` function opens an XLS file and prepares it for reading. It is a wrapper around the `xls_open_file` function, which in turn calls `ole2_open_file` to open the OLE2 container and then `xls_open_ole` to parse the workbook data. The function takes a file path and a character set as input and returns a `xlsWorkBook` structure that can be used to access the data in the XLS file.
</description>
<requirements>

<requirement>
The first argument, `file`, must be a path to a regular file that can be opened for reading. This is because the function eventually calls `fopen` on this path, and if the file does not exist or cannot be opened, the function will fail and return `NULL`.
</requirement>
<requirement>
The second argument, `charset`, should be a valid, null-terminated string representing the character encoding of the strings in the XLS file. "UTF-8" is a commonly used and safe value for this argument, as seen in the project's test cases.
</requirement>

</requirements>
