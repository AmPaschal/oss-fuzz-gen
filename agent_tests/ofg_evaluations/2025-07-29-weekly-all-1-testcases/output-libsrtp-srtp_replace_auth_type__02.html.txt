
	
<description>
The function `srtp_replace_auth_type` is used to replace an existing authentication type in the srtp crypto kernel with a new implementation. It is a wrapper around `srtp_crypto_kernel_do_load_auth_type` with the `replace` parameter set to true. The function first performs some sanity checks on the input parameters, then runs a self-test on the new authentication type. If the self-test passes, it replaces the old authentication type with the new one in the kernel's list of authentication types.
</description>
