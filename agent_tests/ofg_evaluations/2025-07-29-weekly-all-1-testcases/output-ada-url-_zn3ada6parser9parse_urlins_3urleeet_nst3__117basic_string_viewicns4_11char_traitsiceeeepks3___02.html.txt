
	
<description>
The function `ada::parser::parse_url` parses a URL string `user_input` into a `ada::url` object. It can handle both absolute and relative URLs. If a relative URL is provided, the `base_url` argument is used to resolve it. The function implements the WHATWG URL parsing standard, which is a complex state machine. The parsing process involves multiple steps, including scheme identification, authority parsing (username, password, host, and port), path parsing, and query and fragment parsing. The function is designed to be robust and handle various edge cases and malformed URLs gracefully, marking them as invalid when necessary. The `user_input` string is first sanitized by removing tabs, newlines, and leading/trailing C0 control characters. The fragment part of the URL (if present) is handled separately at the end of the parsing process. The function can be instantiated for different result types, but the analysis focuses on `ada::url`.
</description>
