
	
<description>
The function `checkDynamicTestMessage` is a test utility used to verify that a `DynamicStruct::Builder` object contains a specific set of test data. It is part of the capnproto test suite and is not intended for general use. The function itself is a wrapper around `dynamicCheckTestMessage`, which performs the actual checks. The `dynamicCheckTestMessage` function reads various fields (primitive types, lists, structs, etc.) from the provided `DynamicStruct::Builder` and asserts that they have the expected values. For the function to execute correctly without assertion failures, the `DynamicStruct::Builder` must be initialized with the exact data that `dynamicCheckTestMessage` expects. The project provides the `initDynamicTestMessage` function for this purpose. Therefore, any call to `checkDynamicTestMessage` should be preceded by a call to `initDynamicTestMessage` on the same `DynamicStruct::Builder` instance.
</description>
<requirements>

<requirement>
The `DynamicStruct::Builder` argument must be initialized by calling `initDynamicTestMessage` before being passed to `checkDynamicTestMessage`. This is because `checkDynamicTestMessage` contains a large number of assertions that check for specific values in the `DynamicStruct::Builder`, and `initDynamicTestMessage` sets up the builder with precisely these expected values.
</requirement>
<requirement>
The `DynamicStruct::Builder` should be created from a `MallocMessageBuilder` and the `TestAllTypes` schema. The fields being set and checked correspond to the `TestAllTypes` schema defined in the project's test files, and using a different schema would result in missing fields and cause the program to crash.
</requirement>
