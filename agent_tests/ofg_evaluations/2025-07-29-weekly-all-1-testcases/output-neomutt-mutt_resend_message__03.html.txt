
	
<description>
The `mutt_resend_message` function is used to resend an email. It takes a file pointer to the raw message, the mailbox containing the message, the email entry to resend, and a configuration subset. It constructs a new email based on the old one, and then calls `mutt_send_message` to send it. The function is called from `mutt_attach_resend` when resending a message from an attachment context.
</description>
<requirements>
<requirement>
The `fp` argument must be a valid, seekable file pointer. This is because the function calls `mutt_prepare_template`, which seeks to a specific offset in the file to read the message content.
</requirement>
<requirement>
The `e_cur` argument must be a valid pointer to a `struct Email`. The `offset` field of this struct is used to determine where to start reading in the file pointed to by `fp`.
</requirement>
<requirement>
The `m` argument should be a valid pointer to a `struct Mailbox`. This is passed to both `mutt_prepare_template` and `mutt_send_message` and provides context for the email being resent.
</requirement>
<requirement>
The `sub` argument must be a valid pointer to a `struct ConfigSubset`. This is used to retrieve configuration options, such as those for S/MIME and PGP encryption.
</requirement>
<requirement>
The global variable `WithCrypto` should be initialized. It is used to control whether encryption-related logic is applied to the resent message.
</requirement>
<requirement>
The `NeoMutt` global variable and its `sub` member must be initialized. The caller `mutt_attach_resend` passes `NeoMutt->sub` as the `sub` argument to `mutt_resend_message`.
</requirement>
</requirements>
