
	
<description>
The opus_decode function decodes an Opus packet. It takes an OpusDecoder state, the compressed data packet, its length, and a buffer for the decoded PCM audio as input. The frame_size argument specifies the size of the output buffer. The decode_fec argument is a flag to indicate whether to decode forward error correction data. The function returns the number of decoded samples per channel or an error code.
</description>
<requirements>
<requirement>
The first argument, `st`, must be a valid pointer to an `OpusDecoder` struct initialized by `opus_decoder_create`. This is because the function dereferences this pointer to access decoder state information like the number of channels.
</requirement>
<requirement>
The `data` and `len` arguments can be fuzzed to explore different decoding paths and error conditions. The function contains checks for `data` being NULL and `len` being positive, which should be tested.
</requirement>
<requirement>
The `pcm` buffer must be large enough to hold the decoded audio, which is `frame_size * st->channels` samples. Failing to provide a large enough buffer can lead to buffer overflows.
</requirement>
<requirement>
The `frame_size` argument must be greater than zero. The function returns an `OPUS_BAD_ARG` error if `frame_size` is not positive.
</requirement>
<requirement>
The `decode_fec` argument should be either 0 or 1. This argument is used as a boolean flag within the function.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <vector>

#include "/src/opus/include/opus.h"

// Maximum frame size from documentation (120ms at 48kHz)
constexpr int kMaxFrameSize = 5760;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Parameters for opus_decoder_create
  const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  opus_int32 Fs = provider.PickValueInArray(sample_rates);
  int channels = provider.ConsumeIntegralInRange<int>(1, 2);

  // Create the decoder
  int error;
  OpusDecoder *decoder = opus_decoder_create(Fs, channels, &error);
  if (error != OPUS_OK || decoder == nullptr) {
    return 0;
  }

  // Parameters for opus_decode
  const int frame_size = provider.ConsumeIntegralInRange<int>(1, kMaxFrameSize);
  const int decode_fec = provider.ConsumeBool();

  // Allocate PCM buffer
  std::vector<opus_int16> pcm(frame_size * channels);

  // Get input packet from fuzzer
  std::vector<uint8_t> input_packet = provider.ConsumeRemainingBytes<uint8_t>();

  // Call opus_decode with fuzzed data
  opus_decode(decoder, input_packet.data(), input_packet.size(), pcm.data(), frame_size, decode_fec);

  // Also test the packet loss concealment case
  if (provider.ConsumeBool()) {
    opus_decode(decoder, nullptr, 0, pcm.data(), frame_size, decode_fec);
  }

  // Cleanup
  opus_decoder_destroy(decoder);

  return 0;
}
