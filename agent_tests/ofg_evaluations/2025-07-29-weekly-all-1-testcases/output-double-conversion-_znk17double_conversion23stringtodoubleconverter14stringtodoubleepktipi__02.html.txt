
	
<description>
The function `double_conversion::StringToDoubleConverter::StringToDouble` converts a string of 16-bit characters to a double-precision floating-point number. The conversion behavior is highly configurable through the `StringToDoubleConverter` object's properties, which are set during its construction. The function itself is a simple wrapper around the `StringToIeee` function, where the core conversion logic resides. The `StringToIeee` function parses the input string, handling various formats like decimal, hexadecimal (if enabled), and special values like "infinity" and "NaN". It also supports various options for handling whitespace and trailing characters. The outcome of the conversion (the returned double and the number of characters processed) depends on the provided input string and the configuration of the `StringToDoubleConverter` object.
</description>
<requirements>

<requirement>
The `length` argument must be less than or equal to the actual size of the `buffer`. This is to prevent out-of-bounds memory access when the function iterates through the buffer.
</requirement>
<requirement>
The `processed_characters_count` argument must be a pointer to a valid, writable integer. This is because the function writes the number of processed characters to this location.
</requirement>
<requirement>
An instance of the `StringToDoubleConverter` class must be constructed before calling the target function. The constructor arguments should be fuzzed to explore different parsing behaviors.
</requirement>
<requirement>
The `flags` argument of the `StringToDoubleConverter` constructor should be a bitwise OR of the `Flags` enum values. This is to test all possible parsing options like `ALLOW_HEX`, `ALLOW_OCTALS`, `ALLOW_TRAILING_JUNK`, etc.
</requirement>
<requirement>
The `infinity_symbol` and `nan_symbol` arguments of the `StringToDoubleConverter` constructor should not start with a sign ('+' or '-'), a digit, or have the same first character. This is to avoid ambiguity during parsing.
</requirement>
<requirement>
The `separator` character in the constructor should not be a digit or part of the number's exponent. The fuzzer should test various valid and invalid separator characters.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <string>
#include <vector>

#include "/src/double-conversion/double-conversion/string-to-double.h"
#include "/src/double-conversion/double-conversion/utils.h"

using double_conversion::StringToDoubleConverter;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Fuzz the constructor parameters for StringToDoubleConverter.
  const int flags = provider.ConsumeIntegral<int>();
  const double empty_string_value = provider.ConsumeFloatingPoint<double>();
  const double junk_string_value = provider.ConsumeFloatingPoint<double>();
  
  const std::string infinity_symbol = provider.ConsumeBytesAsString(10);
  const std::string nan_symbol = provider.ConsumeBytesAsString(10);

  // Per documentation, symbols must not start with a sign, digit, or have the
  // same first character.
  if (!infinity_symbol.empty() && (isdigit(infinity_symbol[0]) ||
                                    infinity_symbol[0] == '+' ||
                                    infinity_symbol[0] == '-')) {
    return 0;
  }
  if (!nan_symbol.empty() && (isdigit(nan_symbol[0]) ||
                              nan_symbol[0] == '+' ||
                              nan_symbol[0] == '-')) {
    return 0;
  }
  if (!infinity_symbol.empty() && !nan_symbol.empty() &&
      infinity_symbol[0] == nan_symbol[0]) {
    return 0;
  }

  const uc16 separator = provider.ConsumeIntegral<uc16>();

  StringToDoubleConverter converter(flags,
                                    empty_string_value,
                                    junk_string_value,
                                    infinity_symbol.c_str(),
                                    nan_symbol.c_str(),
                                    separator);

  // Fuzz the input for the StringToDouble function.
  std::vector<uint8_t> byte_buffer = provider.ConsumeRemainingBytes<uint8_t>();
  if (byte_buffer.empty()) {
    return 0;
  }
  
  const uc16* buffer = reinterpret_cast<const uc16*>(byte_buffer.data());
  const int length = byte_buffer.size() / sizeof(uc16);

  if (length == 0) {
    return 0;
  }

  int processed_characters_count;
  converter.StringToDouble(buffer, length, &processed_characters_count);

  return 0;
}
