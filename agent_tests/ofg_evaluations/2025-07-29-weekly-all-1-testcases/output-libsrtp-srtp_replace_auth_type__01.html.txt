
	
<description>
The function `srtp_replace_auth_type` is used to replace an existing authentication algorithm implementation with a new one. It is a wrapper around the internal function `srtp_crypto_kernel_do_load_auth_type`, and it allows library users to extend SRTP with custom authentication mechanisms. The function takes a pointer to a constant `srtp_auth_type_t` structure, which defines the new authentication type, and an ID that specifies which existing authentication type to replace. For the replacement to be successful, the new authentication type must pass its own self-tests and the self-tests of the authentication type it is replacing. The function relies on the `crypto_kernel` global variable being initialized, which is done by calling `srtp_crypto_kernel_init`.
</description>
