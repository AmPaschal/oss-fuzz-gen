
	
<description>
The `sf_open` function is the primary entry point for reading and writing sound files with the libsndfile library. It takes a file path, an I/O mode, and a pointer to an `SF_INFO` structure. When opening a file for reading, the function populates the `SF_INFO` struct with information from the file's header. When opening for writing, the caller must pre-populate the `SF_INFO` struct with the desired file format, sample rate, and number of channels. The function returns a handle to the opened file, or NULL on error.
</description>
<requirements>
<requirement>
The `path` argument must be a null-terminated string. The function relies on string operations that require a null terminator to prevent buffer overflows.
</requirement>
<requirement>
The `mode` argument must be one of `SFM_READ` (0x10), `SFM_WRITE` (0x20), or `SFM_RDWR` (0x30). Other values will lead to undefined behavior as the function's internal logic is controlled by these specific flags.
</requirement>
<requirement>
The `sfinfo` argument must be a non-NULL pointer to a valid `SF_INFO` struct. The function dereferences this pointer, and a NULL value will cause a segmentation fault.
</requirement>
<requirement>
When opening a file in write mode (`SFM_WRITE` or `SFM_RDWR`), the `format`, `samplerate`, and `channels` fields of the `SF_INFO` struct must be initialized. These fields dictate the properties of the created sound file, and uninitialized values will lead to errors.
</requirement>
<requirement>
The `format` field of the `SF_INFO` struct must be a valid combination of a major format type (e.g., `SF_FORMAT_WAV`) and a subtype (e.g., `SF_FORMAT_PCM_16`). An invalid combination will be rejected by the library, preventing file creation.
</requirement>
<requirement>
It is recommended to call `sf_format_check()` on the `SF_INFO` struct before calling `sf_open()` in write mode. This preliminary check ensures that the provided format information is valid and supported, preventing runtime errors.
</requirement>
</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  const int modes[] = {SFM_READ, SFM_WRITE, SFM_RDWR};
  int mode = provider.PickValueInArray(modes);

  SF_INFO sfinfo;
  memset(&sfinfo, 0, sizeof(sfinfo));

  if (mode == SFM_WRITE || mode == SFM_RDWR) {
    const int major_formats[] = {
        SF_FORMAT_WAV,       SF_FORMAT_AIFF,        SF_FORMAT_AU,
        SF_FORMAT_RAW,       SF_FORMAT_PAF,         SF_FORMAT_SVX,
        SF_FORMAT_NIST,      SF_FORMAT_VOC,         SF_FORMAT_IRCAM,
        SF_FORMAT_W64,       SF_FORMAT_MAT4,        SF_FORMAT_MAT5,
        SF_FORMAT_PVF,       SF_FORMAT_XI,          SF_FORMAT_HTK,
        SF_FORMAT_SDS,       SF_FORMAT_AVR,         SF_FORMAT_WAVEX,
        SF_FORMAT_SD2,       SF_FORMAT_FLAC,        SF_FORMAT_CAF,
        SF_FORMAT_WVE,       SF_FORMAT_OGG,         SF_FORMAT_MPC2K,
        SF_FORMAT_RF64};
    const int sub_formats[] = {
        SF_FORMAT_PCM_S8,    SF_FORMAT_PCM_16,      SF_FORMAT_PCM_24,
        SF_FORMAT_PCM_32,    SF_FORMAT_PCM_U8,      SF_FORMAT_FLOAT,
        SF_FORMAT_DOUBLE,    SF_FORMAT_ULAW,        SF_FORMAT_ALAW,
        SF_FORMAT_IMA_ADPCM, SF_FORMAT_MS_ADPCM,    SF_FORMAT_GSM610,
        SF_FORMAT_VOX_ADPCM, SF_FORMAT_G721_32,     SF_FORMAT_G723_24,
        SF_FORMAT_G723_40,   SF_FORMAT_DWVW_12,     SF_FORMAT_DWVW_16,
        SF_FORMAT_DWVW_24,   SF_FORMAT_DWVW_N,      SF_FORMAT_DPCM_8,

        SF_FORMAT_ALAC_16,   SF_FORMAT_ALAC_20,     SF_FORMAT_ALAC_24,
        SF_FORMAT_ALAC_32};
    const int endian_formats[] = {SF_ENDIAN_FILE, SF_ENDIAN_LITTLE,
                                  SF_ENDIAN_BIG, SF_ENDIAN_CPU};

    sfinfo.samplerate = provider.ConsumeIntegralInRange<int>(1, 192000);
    sfinfo.channels = provider.ConsumeIntegralInRange<int>(1, 16);
    sfinfo.format = provider.PickValueInArray(major_formats) |
                    provider.PickValueInArray(sub_formats) |
                    provider.PickValueInArray(endian_formats);

    sf_format_check(&sfinfo);
  }

  const std::string filename = "fuzz.wav";
  std::vector<uint8_t> file_data =
      provider.ConsumeRemainingBytes<uint8_t>();
  FILE *fp = fopen(filename.c_str(), "wb");
  if (!fp) {
    return 0;
  }
  fwrite(file_data.data(), 1, file_data.size(), fp);
  fclose(fp);

  SNDFILE *sndfile = sf_open(filename.c_str(), mode, &sfinfo);

  if (sndfile) {
    sf_close(sndfile);
  }

  remove(filename.c_str());

  return 0;
}
