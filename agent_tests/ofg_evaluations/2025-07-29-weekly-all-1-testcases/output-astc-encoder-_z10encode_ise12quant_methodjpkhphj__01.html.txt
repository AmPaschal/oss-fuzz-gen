
	
<description>
The `encode_ise` function encodes a sequence of integers using the Integer Sequence Encoding (ISE) method. It supports different quantization levels, which determine the number of bits, trits, and quints used for encoding. The function takes an input array of 8-bit integers and writes the encoded bitstream to an output buffer, starting at a specified bit offset.
</description>
<requirements>
<requirement>
The `quant_level` parameter must be a value between 2 and 20 (inclusive). This is to avoid an out-of-bounds access on the `btq_counts` array, which has a size of 21 and is indexed by `quant_level`.</requirement>
<requirement>
The `character_count` parameter must be greater than 0. The function includes a `promise(character_count > 0)` check, and a value of 0 would lead to undefined behavior.</requirement>
<requirement>
The `input_data` buffer must be allocated with a size of at least `character_count` bytes. This is to prevent out-of-bounds reads when accessing elements of `input_data` within the loops.</requirement>
<requirement>
The `output_data` buffer must be large enough to hold the encoded data. The required size in bits can be determined by `get_ise_sequence_bitcount(character_count, quant_level)`, so the buffer should be at least `(bit_offset + get_ise_sequence_bitcount(character_count, quant_level) + 7) / 8` bytes.</requirement>
<requirement>
The values in the `input_data` array should be within the valid range for the chosen `quant_level`. The values are used to index the `integer_of_trits` and `integer_of_quints` tables, and out-of-range values will cause a crash.</requirement>
</requirements>

#include "/src/astc-encoder/Source/astcenc_internal.h"

#include <fuzzer/FuzzedDataProvider.h>
#include <vector>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
	FuzzedDataProvider stream(data, size);

	// Consume parameters for the function under test
	auto quant_level_val = stream.ConsumeIntegralInRange<unsigned int>(2, 20);
	quant_method quant_level = static_cast<quant_method>(quant_level_val);

	// Character count must be > 0. Limit to a reasonable size to avoid OOM.
	unsigned int character_count = stream.ConsumeIntegralInRange<unsigned int>(1, 100);

	// Consume the input data buffer
	std::vector<uint8_t> input_data = stream.ConsumeBytes<uint8_t>(character_count);
	if (input_data.size() != character_count) {
		return 0;
	}

	// Consume a bit offset, up to one byte
	unsigned int bit_offset = stream.ConsumeIntegralInRange<unsigned int>(0, 7);

	// Determine the size needed for the output buffer
	unsigned int output_bits = get_ise_sequence_bitcount(character_count, quant_level);
	size_t output_buf_size = (bit_offset + output_bits + 7) / 8;
	std::vector<uint8_t> output_data(output_buf_size, 0);

	// Call the function under test
	encode_ise(quant_level, character_count, input_data.data(), output_data.data(), bit_offset);

	return 0;
}
