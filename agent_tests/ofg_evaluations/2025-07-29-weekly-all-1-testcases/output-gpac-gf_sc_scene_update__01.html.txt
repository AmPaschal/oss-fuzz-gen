
	
<description>
The function `gf_sc_scene_update` updates a compositor's scene. It takes a `GF_Compositor` object, a `type` string specifying the type of update, and a `com` string containing the update command. The function's behavior varies based on the `type` and `com` arguments. If `type` indicates javascript ("js" or "application/ecmascript"), it executes the `com` string as a script. If `type` is NULL and `com` starts with "gpac ", it handles special gpac commands like adding content, splicing media, or selecting objects. Otherwise, it treats `com` as scene data (e.g., BT, XMTA, SVG, X3D) to be loaded, with the format potentially indicated by `type`. The function can create a new scene within the compositor if one doesn't exist. It is used in the gpac command-line player to apply updates from user input or command-line arguments.
</description>
