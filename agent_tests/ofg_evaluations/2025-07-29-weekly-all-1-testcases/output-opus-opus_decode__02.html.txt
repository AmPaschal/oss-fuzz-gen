
	
<description>
The `opus_decode` function decodes an Opus packet. It takes a previously created `OpusDecoder` state, a buffer `data` containing the compressed packet of length `len`, and an output buffer `pcm` of size `frame_size`. The `decode_fec` flag indicates whether to decode the packet normally or to perform forward error correction for a lost packet. The function returns the number of decoded samples per channel or an error code. It is essential to initialize the decoder state correctly using `opus_decoder_create` and to provide a sufficiently large output buffer.
</description>
<requirements>
<requirement>
The `st` argument, a pointer to an `OpusDecoder` struct, must be initialized by `opus_decoder_create`. This is because `opus_decoder_create` allocates and initializes the decoder state required by `opus_decode`.
</requirement>
<requirement>
The `opus_decoder_create` function must be called with a supported sample rate (8000, 12000, 16000, 24000, or 48000) and channel count (1 or 2). This is to prevent `opus_decoder_create` from returning null and to satisfy an assertion within `opus_decode` that checks for 1 or 2 channels.
</requirement>
<requirement>
The `frame_size` argument must be greater than zero. The function returns `OPUS_BAD_ARG` if `frame_size` is less than or equal to zero.
</requirement>
<requirement>
The `pcm` output buffer must be allocated to be at least `frame_size * st->channels * sizeof(opus_int16)` bytes. This is to prevent a buffer overflow, as the function writes up to `frame_size * st->channels` samples into `pcm`.
</requirement>
<requirement>
The `data` and `len` arguments should be fuzzed to explore various encoded data inputs. This will test the function's ability to handle valid, invalid, and malformed Opus packets.
</requirement>
<requirement>
The `decode_fec` argument should be fuzzed with values 0 and 1. This allows testing both normal decoding (`decode_fec=0`) and packet loss concealment (`decode_fec=1`), which is a distinct and important execution path.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <vector>

#include "/src/opus/include/opus.h"

// From the Opus documentation, the maximum frame size is 120ms at 48kHz.
// 48000 * 0.120 = 5760 samples.
constexpr int kMaxFrameSize = 5760;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);

  // Requirement: opus_decoder_create must be called with a supported
  // sample rate and channel count.
  const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  const opus_int32 sample_rate = fdp.PickValueInArray(sample_rates);
  const int channels = fdp.ConsumeIntegralInRange(1, 2);

  // Requirement: The st argument must be initialized by opus_decoder_create.
  int err;
  OpusDecoder *decoder = opus_decoder_create(sample_rate, channels, &err);
  if (err != OPUS_OK || decoder == nullptr) {
    return 0;
  }

  // Requirement: The decode_fec argument should be fuzzed.
  const int decode_fec = fdp.ConsumeBool();

  // Requirement: The pcm output buffer must be allocated to be at least
  // frame_size * st->channels * sizeof(opus_int16) bytes.
  // We use a fixed maximum frame_size to avoid trivial buffer-too-small
  // errors and focus fuzzing on the packet data.
  std::vector<opus_int16> pcm(kMaxFrameSize * channels);

  // Requirement: The data and len arguments should be fuzzed.
  const std::vector<uint8_t> packet_data = fdp.ConsumeRemainingBytes<uint8_t>();
  const opus_int32 len = packet_data.size();

  // Call the function under test.
  opus_decode(decoder, packet_data.data(), len, pcm.data(), kMaxFrameSize,
              decode_fec);

  // Cleanup.
  opus_decoder_destroy(decoder);

  return 0;
}
