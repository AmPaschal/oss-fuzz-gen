
	
<description>
The `onig_scan` function repeatedly searches for a regular expression pattern in a string and calls a callback function for each match. It takes a compiled regular expression (`regex_t*`), the string to search (`str` and `end` pointers), a region object to store match data (`OnigRegion*`), search options (`OnigOptionType`), a callback function (`scan_callback`), and a callback argument (`callback_arg`). The function iterates through all matches in the string, from the start to the end. For each match found by `onig_search`, it invokes the provided `scan_callback` with the match number, the match result, the region data, and the user-provided `callback_arg`. The scan can be stopped prematurely if the callback returns a non-zero value. The function returns the total number of matches found, or a negative error code if an error occurs.
</description>
<requirements>

<requirement>
The `reg` argument must be a valid `regex_t` object created by `onig_new`. This is because `onig_scan` internally uses the compiled pattern from the `regex_t` object to perform the search.
</requirement>
<requirement>
The `str` and `end` arguments must define a valid memory range. `end` must be greater than or equal to `str`, otherwise the scan loop may not behave as expected.
</requirement>
<requirement>
The `region` argument must be a valid `OnigRegion` object, initialized with `onig_region_new()`. This is because `onig_scan` passes this region to `onig_search` to store the results of the match.
</requirement>
<requirement>
The `scan_callback` argument must be a valid function pointer. The function will be called for each match, and a NULL pointer would lead to a crash.
</requirement>
<requirement>
The `scan_callback` function should return 0 to continue the scan. A non-zero return value will cause `onig_scan` to terminate and return that value.
</requirement>
<requirement>
`onig_initialize()` must be called before calling `onig_scan`. This is to ensure the Oniguruma library is properly initialized.
</requirement>
<requirement>
After the `onig_scan` call, `onig_region_free()` and `onig_free()` should be called for the `region` and `reg` objects respectively. This is to prevent memory leaks.
</requirement>

</requirements>
