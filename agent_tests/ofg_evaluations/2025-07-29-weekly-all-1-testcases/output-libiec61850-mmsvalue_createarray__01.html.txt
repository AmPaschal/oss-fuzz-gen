
	
<description>
The `MmsValue_createArray` function is responsible for creating a new MMS value of type array. It allocates memory for an `MmsValue` structure representing the array and then allocates memory for the components of the array based on the provided `size`. Each element of the array is then initialized with a default value corresponding to the `elementType` by calling the `MmsValue_newDefaultValue` function. This process involves a recursive call to `MmsValue_createArray` if the `elementType` itself is an array, allowing for the creation of multi-dimensional arrays. The function ensures that all memory allocations are successful and performs cleanup by deleting the partially created `MmsValue` and freeing allocated memory if any allocation fails.
</description>
<requirements>
<requirement>
The `elementType` argument must be a valid pointer to a fully initialized `MmsVariableSpecification` structure. This is because the function passes this argument to `MmsValue_newDefaultValue`, which dereferences it to determine the type of the array elements to create.
</requirement>
<requirement>
The `size` argument must be a non-negative integer. This is because it is used as the size parameter for memory allocation with `GLOBAL_CALLOC` and as the upper bound for a loop, and a negative value could lead to memory allocation errors or other undefined behavior.
</requirement>
<requirement>
The `MmsVariableSpecification` passed as `elementType` should not have a deeply nested structure. Because `MmsValue_createArray` is called recursively by `MmsValue_newDefaultValue` for array types, a deeply nested `elementType` can lead to excessive recursion and a stack overflow.
</requirement>
</requirements>
