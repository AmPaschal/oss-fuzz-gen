
	
<description>
The function `is_legal_3d_block_size` checks if a given 3D block size, represented by the dimensions `xdim`, `ydim`, and `zdim`, is one of the legally supported block sizes in the ASTC encoder. It does this by combining the three dimensions into a single 32-bit integer and comparing it against a list of hardcoded valid combinations. It returns `true` if the block size is legal, and `false` otherwise. This function is used as a precondition check before performing more complex operations that assume a valid block size.
</description>
<requirements>
<requirement>
The input parameters `xdim`, `ydim`, and `zdim` must be one of the 10 allowed combinations: (3,3,3), (4,3,3), (4,4,3), (4,4,4), (5,4,4), (5,5,4), (5,5,5), (6,5,5), (6,6,5), (6,6,6). This is because the function will otherwise return false, and subsequent processing may fail if it expects a valid block size.
</requirement>
<requirement>
The input parameters `xdim`, `ydim`, and `zdim` should be fuzzed with values from the set of allowed combinations. Exploring values outside this set is not necessary for covering the function's logic and may trigger errors in downstream code that assumes block sizes are valid.
</requirement>
</requirements>

#include "/src/astc-encoder/Source/astcenc_internal.h"
#include <fuzzer/FuzzedDataProvider.h>

#include <cstdint>
#include <vector>

// Forward declare the function to be fuzzed.
bool is_legal_3d_block_size(unsigned int, unsigned int, unsigned int);

struct BlockSize3D {
  unsigned int x;
  unsigned int y;
  unsigned int z;
};

// The 10 legal 3D block sizes supported by the ASTC standard.
static const BlockSize3D legal_3d_block_sizes[] = {
    {3, 3, 3}, {4, 3, 3}, {4, 4, 3}, {4, 4, 4}, {5, 4, 4},
    {5, 5, 4}, {5, 5, 5}, {6, 5, 5}, {6, 6, 5}, {6, 6, 6}};

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider stream(data, size);

  unsigned int xdim, ydim, zdim;

  // Decide whether to test a known legal size or a random size.
  if (stream.ConsumeBool()) {
    // Test one of the 10 known legal block sizes.
    BlockSize3D block = stream.PickValueInArray(legal_3d_block_sizes);
    xdim = block.x;
    ydim = block.y;
    zdim = block.z;
  } else {
    // Test a random block size.
    xdim = stream.ConsumeIntegral<unsigned int>();
    ydim = stream.ConsumeIntegral<unsigned int>();
    zdim = stream.ConsumeIntegral<unsigned int>();
  }

  is_legal_3d_block_size(xdim, ydim, zdim);

  return 0;
}
