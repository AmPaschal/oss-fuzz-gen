The `HlslGrammar::acceptPostDecls` function is a crucial component of the glslang HLSL parser, responsible for handling post-declaration qualifiers. These qualifiers include HLSL semantics (e.g., `SV_Position`), register assignments, packoffset, and layout qualifiers. The function operates on a token stream provided by the `HlslGrammar` object, consuming tokens and populating the `TQualifier` object with the parsed information. To effectively test `acceptPostDecls`, the parser's state must be properly initialized with an input string containing HLSL post-declaration syntax. This allows for the exploration of various parsing paths within the function. The `TQualifier` argument serves as an output parameter, accumulating the results of the parsing process. Therefore, a default-initialized `TQualifier` object is sufficient for invoking the function. The core of fuzzing this function lies in providing a diverse range of input strings that mimic valid or near-valid HLSL syntax, thereby ensuring comprehensive test coverage.
</description>

#include <fuzzer/FuzzedDataProvider.h>

#include "glslang/Public/ShaderLang.h"
#include "glslang/Public/ResourceLimits.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider provider(data, size);
    std::string fuzzer_string = provider.ConsumeRemainingBytesAsString();

    glslang::InitializeProcess();

    EShMessages messages = EShMsgReadHlsl;
    glslang::TShader shader(EShLangVertex);

    const char *shaderStrings[] = { fuzzer_string.c_str() };
    const int lengths[] = { (int)fuzzer_string.length() };
    shader.setStringsWithLengths(shaderStrings, lengths, 1);

    shader.setEntryPoint("main");
    shader.setSourceEntryPoint("main");

    // The parse method will internally create the HlslGrammar and call acceptPostDecls
    // when it encounters post-declaration qualifiers in the fuzzer-provided string.
    shader.parse(GetDefaultResources(), 100, false, messages);

    glslang::FinalizeProcess();
    return 0;
}
