
	
<description>
The `opus_encode_float` function encodes a frame of floating-point audio data into the Opus format. The first argument is a pointer to an `OpusEncoder` state that must be initialized by `opus_encoder_create`. The `pcm` argument is a buffer of audio samples to be encoded. The `analysis_frame_size` argument specifies the number of samples per channel in the input audio buffer. The `data` argument is a buffer where the encoded Opus data will be written, and `max_data_bytes` specifies the maximum size of this output buffer.
</description>
<requirements>
<requirement>
The `OpusEncoder` state `st` must be initialized by `opus_encoder_create`. This is because `opus_encoder_create` allocates and initializes the encoder state with the necessary settings for encoding.
</requirement>
<requirement>
The `analysis_frame_size` argument must be a valid frame size supported by Opus. This is because an invalid frame size will cause `frame_size_select` to return an error, which will in turn cause `opus_encode_float` to return `OPUS_BAD_ARG`.
</requirement>
<requirement>
The `pcm` buffer must have a size of at least `analysis_frame_size * st->channels` floats. This is to prevent buffer overflows when the function reads from the `pcm` buffer.
</requirement>
<requirement>
The `data` buffer must be large enough to hold the encoded data, and `max_data_bytes` should be set to its size. A recommended size for this buffer is 4000 bytes to avoid buffer overflows.
</requirement>
<requirement>
The `opus_encoder_destroy` function should be called on the `OpusEncoder` state after it is no longer needed. This is to free the memory allocated by `opus_encoder_create`.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <stdint.h>
#include <stdlib.h>
#include <vector>

#include "/src/opus/include/opus.h"

// Frame sizes in samples per channel.
const int kFrameSizes[] = {120, 240, 480, 960, 1920, 2880};
const int kSampleRates[] = {8000, 12000, 16000, 24000, 48000};
const int kApplications[] = {OPUS_APPLICATION_VOIP, OPUS_APPLICATION_AUDIO, OPUS_APPLICATION_RESTRICTED_LOWDELAY};
const int kMaxChannels = 2;
const int kMaxPacketOutput = 4000;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);

  const int sample_rate = fdp.PickValueInArray(kSampleRates);
  const int channels = fdp.ConsumeIntegralInRange<int>(1, kMaxChannels);
  const int application = fdp.PickValueInArray(kApplications);
  const int frame_size = fdp.PickValueInArray(kFrameSizes);

  int error;
  OpusEncoder *encoder = opus_encoder_create(sample_rate, channels, application, &error);
  if (error != OPUS_OK) {
    if (encoder) {
      opus_encoder_destroy(encoder);
    }
    return 0;
  }

  const size_t pcm_size = frame_size * channels;
  const size_t pcm_size_in_bytes = pcm_size * sizeof(float);
  std::vector<float> pcm(pcm_size);
  size_t consumed_bytes = fdp.ConsumeData(pcm.data(), pcm_size_in_bytes);

  if (consumed_bytes != pcm_size_in_bytes) {
    opus_encoder_destroy(encoder);
    return 0;
  }

  unsigned char output_data[kMaxPacketOutput];
  opus_int32 encoded_len = opus_encode_float(encoder, pcm.data(), frame_size, output_data, kMaxPacketOutput);
  (void)encoded_len;

  opus_encoder_destroy(encoder);

  return 0;
}
