
	
<description>
The function `cmsCreateDeviceLinkFromCubeFileTHR` creates a device link profile from a .cube file. It opens and parses the given file to extract lookup tables (both 1D and 3D) and other metadata, then constructs a `cmsHPROFILE` object. The function relies heavily on the `ParseCube` function to interpret the file format. The caller `cmsCreateDeviceLinkFromCubeFile` passes a NULL context, indicating that a specific context is not strictly necessary.
</description>
<requirements>

<requirement>
The `cFileName` argument must be a non-NULL pointer to a null-terminated string representing a valid file path. The function asserts that this pointer is not NULL and attempts to open the file for reading.
</requirement>
<requirement>
The file specified by `cFileName` must be a valid Adobe .cube file. The function uses the `ParseCube` internal function to parse the file, which expects specific keywords and data structures.
</requirement>
<requirement>
The `.cube` file must contain either `LUT_1D_SIZE` or `LUT_3D_SIZE` (or both), followed by the corresponding number of data points. A mismatch between the declared size and the actual data will lead to a parsing failure.
</requirement>
<requirement>
The `TITLE` keyword in the `.cube` file is optional, but if present, its value should be a string. This string is used as the profile description.
</requirement>
<requirement>
The `DOMAIN_MIN` and `DOMAIN_MAX` keywords, if present, must be followed by three numeric values. These define the input domain of the lookup tables.
</requirement>
<requirement>
The `LUT_1D_INPUT_RANGE` and `LUT_3D_INPUT_RANGE` keywords, if present, must be followed by `0` and `1.0`. Any other values will result in a parsing error.
</requirement>
<requirement>
The `ContextID` argument can be NULL. The only existing caller in the codebase, `cmsCreateDeviceLinkFromCubeFile`, passes NULL for this argument.
</requirement>

</requirements>

#include <stdint.h>
#include <stdio.h>
#include "lcms2.h"

#define CUBE_FILENAME "fuzz.cube"

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {

    FILE *fp = fopen(CUBE_FILENAME, "wb");
    if (!fp) {
        return 0;
    }
    fwrite(data, 1, size, fp);
    fclose(fp);

    cmsHPROFILE hProfile = cmsCreateDeviceLinkFromCubeFileTHR(NULL, CUBE_FILENAME);

    if (hProfile) {
        cmsCloseProfile(hProfile);
    }

    return 0;
}
