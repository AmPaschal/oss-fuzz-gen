
	
<description>
The `decNumberLog10` function calculates the base-10 logarithm of the input `decNumber` `rhs` and stores the result in the `decNumber` `res`. The `decContext` `set` provides the context for the operation, including precision and rounding modes. The function handles special cases: if `rhs` is NaN, it propagates the NaN. If `rhs` is a negative non-zero number, it returns a NaN and sets the `DEC_Invalid_operation` status. If `rhs` is zero, it returns negative infinity and sets the `DEC_Division_by_zero` status. For a positive `rhs`, it computes the natural logarithm and divides it by the natural logarithm of 10.
</description>

</requirement>

<requirement>
The `res` parameter, a pointer to a `decNumber` struct, must be allocated by the caller. This is necessary because the function writes the result of the logarithm operation into this struct.
</requirement>
<requirement>
The `rhs` input should be created using `decNumberFromString` with fuzzed string data. The fuzzer should be constrained to generate strings that represent non-negative decimal numbers to avoid the invalid operation error.

#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "qemu/osdep.h"
#include "libdecnumber/decNumber.h"
#include "libdecnumber/decContext.h"

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    // decNumberFromString requires a null-terminated C-string.
    // Limit size to prevent excessive memory allocation and long execution times.
    if (size == 0 || size > 512) {
        return 0;
    }

    char *fuzzed_string = (char *)malloc(size + 1);
    if (fuzzed_string == NULL) {
        return 0;
    }
    memcpy(fuzzed_string, data, size);
    fuzzed_string[size] = '\0';

    decNumber res;
    decNumber rhs;
    decContext set;

    // Initialize the context for the operation.
    // DEC_INIT_BASE provides a default context.
    decContextDefault(&set, DEC_INIT_BASE);
    
    // Set a reasonable precision for the fuzzer.
    set.digits = 34; // Corresponds to decimal128

    // Create a decNumber from the fuzzed string.
    // This function will handle various string formats, including malformed ones.
    decNumberFromString(&rhs, fuzzed_string, &set);

    // Call the function under test.
    // The function has its own checks for negative numbers, NaNs, etc.
    // which we want to exercise with the fuzzer.
    decNumberLog10(&res, &rhs, &set);

    free(fuzzed_string);
    return 0;
}
