The `mutt_send_message` function is a core component of neomutt responsible for sending emails and newsgroup articles. It is a large and complex function that handles various aspects of message composition and delivery. The function's behavior is controlled by the `SendFlags` argument, which allows for different modes of operation such as composing a new message, replying, forwarding, resending, or handling postponed messages.

The function can either create a new email from scratch or use a provided template (`e_templ`). It manages temporary files for message bodies, interacts with the user for input and confirmation through dialogs, and processes various configuration settings from the `ConfigSubset` argument. It also has extensive support for PGP and S/MIME encryption and signing, controlled by the `WithCrypto` global variable and related configuration options. Finally, it invokes the MTA (Mail Transfer Agent) to actually send the message.

The callers of `mutt_send_message` are diverse, ranging from simple mail sending operations to more complex scenarios involving attachments and replies. The function is highly flexible and configurable, making it a critical part of the neomutt application.
</description>
