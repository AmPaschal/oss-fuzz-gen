
	
<description>
The function `clib_package_install_development` installs the development dependencies of a `clib_package_t`. It takes a pointer to a `clib_package_t` object, a directory path, and a verbosity flag. It checks if the package and directory are valid, and if the package has development dependencies. If so, it calls the `install_packages` function to handle the installation of each dependency. `install_packages` iterates through the list of development dependencies, creates a package object for each, and then installs it using `clib_package_install`.
</description>
<requirements>

<requirement>
The first argument `pkg` must be a non-null pointer to a `clib_package_t` struct. This is because the function dereferences this pointer to access the `development` field.
</requirement>
<requirement>
The `pkg->development` field must be a valid pointer to a `list_t` struct. The function passes this field to the `install_packages` function which expects a valid list.
</requirement>
<requirement>
The list `pkg->development` should be populated with `clib_package_dependency_t` pointers. This is because the `install_packages` function casts each element of the list to a `clib_package_dependency_t` pointer and accesses its members.
</requirement>
<requirement>
The second argument `dir` must be a non-null, null-terminated string representing a valid and writable directory path. This is because `install_packages` and its callees will attempt to create subdirectories and write files within this directory.
</requirement>
<requirement>
The `pkg` object should be created using `clib_package_new` with a JSON string that contains a "development" object. This is because `clib_package_new` is responsible for parsing the JSON and populating the `pkg->development` list.
</requirement>
