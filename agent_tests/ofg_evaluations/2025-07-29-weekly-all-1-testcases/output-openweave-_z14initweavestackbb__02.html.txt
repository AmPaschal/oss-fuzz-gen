
	
<description>
The InitWeaveStack function initializes the Weave stack, including the system layer, network layer, message layer, exchange manager, and security manager. Its behavior is controlled by two boolean parameters and several global configuration objects. The `listen` parameter determines whether the stack listens for incoming connections, and the `initExchangeMgr` parameter controls the initialization of the exchange and security managers. The function relies on global options objects `gWeaveNodeOptions` and `gNetworkOptions` for configuration details such as fabric and node IDs, and local IP addresses.
</description>
<requirements>

<requirement>
The `listen` parameter should be set to `true`. This ensures that the Weave stack initializes its TCP and UDP listeners, allowing it to receive incoming connections and messages, which is essential for testing the full functionality of the stack.
</requirement>
<requirement>
The `initExchangeMgr` parameter should be set to `true`. This is necessary to initialize the Weave Exchange Manager and Security Manager, which are crucial components for managing communication sessions and handling security protocols.
</requirement>
<requirement>
The `InitToolCommon` function must be called before `InitWeaveStack`. This function initializes essential platform components, such as the secure random number generator, which are required for the proper operation of the Weave stack.
</requirement>
<requirement>
The `InitSystemLayer` and `InitNetwork` functions must be called before `InitWeaveStack`. These functions initialize the system and network layers, which are foundational dependencies for the Weave message layer and other higher-level components initialized by `InitWeaveStack`.
</requirement>
<requirement>
The `gWeaveNodeOptions.FabricId` and `gWeaveNodeOptions.LocalNodeId` global variables must be initialized. These values are used to configure the `FabricState`, which is a critical component for identifying the Weave node and its fabric.
</requirement>
<requirement>
The `gNetworkOptions.LocalIPv4Addr` and `gNetworkOptions.LocalIPv6Addr` global variables should be initialized with valid IP addresses. These addresses are used by the Weave stack to bind its listeners and enable network communication.
</requirement>
