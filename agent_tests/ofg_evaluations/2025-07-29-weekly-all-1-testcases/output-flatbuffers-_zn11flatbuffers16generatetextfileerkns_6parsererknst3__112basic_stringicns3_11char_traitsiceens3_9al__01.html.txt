
	
<description>
The function `GenerateTextFile` is a wrapper around `GenTextFile`, which generates a text file from a `Parser` object. The `Parser` object contains the parsed flatbuffer data. The generation logic depends on the `use_flexbuffers` option in the parser's options. If `use_flexbuffers` is true, it generates a JSON representation from the flexbuffer root. Otherwise, it generates text from the flatbuffer builder's buffer.
</description>
<requirements>

<requirement>
The `parser` object should be initialized and have its data set. This is because the function's logic depends on the state of the `parser` object, including its options and data.
</requirement>
<requirement>
If `parser.opts.use_flexbuffers` is false, `parser.builder_.GetSize()` must be greater than 0 and `parser.root_struct_def_` must not be null. This is to ensure the function does not return early and attempts to generate the output file.
</requirement>
<requirement>
The `path` and `file_name` arguments should be valid path strings. These are used to construct the output file path, so they must be valid for file creation.
</requirement>

</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
  if (size == 0) {
    return 0;
  }

  FuzzedDataProvider provider(data, size);

  flatbuffers::IDLOptions opts;
  opts.strict_json = provider.ConsumeBool();
  opts.skip_unexpected_fields_in_json = provider.ConsumeBool();
  opts.allow_non_utf8 = provider.ConsumeBool();
  opts.use_flexbuffers = provider.ConsumeBool();
  opts.output_default_scalars_in_json = provider.ConsumeBool();
  opts.indent_step = provider.ConsumeIntegralInRange<int16_t>(-1, 10);

  flatbuffers::Parser parser(opts);

  // The function attempts to write to a file, so provide a safe path.
  const std::string path = "/tmp";
  const std::string file_name = provider.ConsumeRandomLengthString(128);
  if (file_name.empty()) {
    return 0;
  }

  const std::string schema_and_json_data = provider.ConsumeRemainingBytesAsString();
  if (schema_and_json_data.empty()) {
    return 0;
  }

  // Parse the schema/json. This populates the parser object.
  if (parser.Parse(schema_and_json_data.c_str())) {
    // If parsing succeeds, the parser is in a valid state to generate text.
    // This fulfills the requirement that the parser has data.
    flatbuffers::GenerateTextFile(parser, path, file_name);
  }

  return 0;
}
