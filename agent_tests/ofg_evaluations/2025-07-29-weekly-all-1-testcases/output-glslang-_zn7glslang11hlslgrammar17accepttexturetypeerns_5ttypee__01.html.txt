The `HlslGrammar::acceptTextureType` function is responsible for parsing HLSL texture type declarations. Its execution is primarily driven by the token stream provided by the `peek()` and `advanceToken()` methods of the `HlslGrammar` class. The function parses the texture type, its dimensions, whether it's an array or multisampled, and its data type. It then populates the `TType` reference argument with the parsed information.

The function is called from within `HlslGrammar::acceptType`, which is a general-purpose type parsing function. `acceptType` acts as a dispatcher, and based on the current token, it calls the appropriate specialized parsing function. In this case, when a token corresponding to a texture type is encountered, `acceptTextureType` is invoked.

For the fuzzer to effectively test `acceptTextureType`, it needs to provide a stream of tokens that simulates valid (and invalid) HLSL texture declarations. The core of the fuzzer's input should be a string that is fed into the `HlslGrammar`'s parsing context. This string will be tokenized and consumed by the parsing functions. By crafting different strings, the fuzzer can explore the various execution paths within `acceptTextureType`. This includes testing all the supported texture types from the initial `switch` statement, exercising the logic for template-like texture declarations (e.g., `Texture2D<float4>`), and handling optional parts like the multisample count. The `TType` argument is an output parameter, so it does not have any specific initialization requirements. The key is to control the token stream to guide the parsing logic.
</description>

#include "glslang/Public/ResourceLimits.h"
#include "glslang/Public/ShaderLang.h"
#include "/src/glslang/glslang/HLSL/hlslGrammar.h"
#include <fuzzer/FuzzedDataProvider.h>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size == 0) {
    return 0;
  }

  glslang::InitializeProcess();

  FuzzedDataProvider stream(data, size);

  // Pick a shader stage
  const EShLanguage stage = stream.PickValueInArray({
      EShLangVertex,
      EShLangTessControl,
      EShLangTessEvaluation,
      EShLangGeometry,
      EShLangFragment,
      EShLangCompute,
  });

  glslang::TShader shader(stage);
  EShMessages messages = EShMsgDefault;
  messages = (EShMessages)(messages | EShMsgHlslLegalization | EShMsgKeepUncalled);

  const std::string shader_string = stream.ConsumeRemainingBytesAsString();
  const char *shader_strings[] = {shader_string.c_str()};
  const int shader_lengths[] = {(int)shader_string.length()};

  shader.setStringsWithLengths(shader_strings, shader_lengths, 1);

  // Set the environment to HLSL
  shader.setEnvInput(glslang::EShSourceHlsl, stage, glslang::EShClientVulkan, 100);
  shader.setEnvClient(glslang::EShClientVulkan, glslang::EShTargetVulkan_1_1);
  shader.setEnvTarget(glslang::EShTargetSpv, glslang::EShTargetSpv_1_3);
  shader.setHlslIoMapping(true);
  shader.setEntryPoint("main");

  // The call to parse will internally use HlslGrammar and potentially call
  // acceptTextureType if the input contains a texture declaration.
  shader.parse(GetDefaultResources(), 110, false, messages);

  glslang::FinalizeProcess();
  return 0;
}
