The function `gnutls_record_recv_seq` is used to receive data from a TLS/DTLS session. It is a wrapper around the internal function `_gnutls_recv_int`. This function will receive and decrypt a record from the peer and return the application data. It also returns the sequence number of the record, which is useful in DTLS to handle out-of-order packets. Before calling this function, a GnuTLS session must be initialized and a handshake must be successfully completed. The function takes a session handle, a buffer to store the received data, the size of the buffer, and a pointer to store the sequence number. It returns the number of bytes received, or a negative error code on failure.
