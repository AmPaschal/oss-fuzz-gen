
	
<description>
The function `avahi_string_list_add_pair` adds a key-value pair to an `AvahiStringList`. It takes a pointer to an `AvahiStringList`, a key, and a value as input. If the value is not `NULL`, it formats the string as "key=value" and adds it to the list using `avahi_string_list_add_printf`. If the value is `NULL`, it adds only the key to the list using `avahi_string_list_add`. The function can be used to create a new list by passing `NULL` as the first argument.
</description>
<requirements>
<requirement>
The first argument `l` can be a `NULL` pointer. If it is `NULL`, a new string list is created.
</requirement>
<requirement>
The second argument `key` must be a non-NULL C-string. The function has an assertion to check for this and will crash if the condition is not met.
</requirement>
<requirement>
The third argument `value` can be a `NULL` pointer. If it is not `NULL`, it must be a C-string.
</requirement>
<requirement>
The return value of this function should be used as the new head of the list for subsequent calls. This is because a new list may be allocated if the original list is `NULL` or needs to be reallocated, and the caller needs to use the updated pointer.
</requirement>
</requirements>

#include <stddef.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

#include "avahi-core/log.h"
#include "avahi-common/malloc.h"
#include "/src/avahi/avahi-common/strlst.h"

AvahiStringList * avahi_string_list_add_pair(AvahiStringList *, const char *, const char *);

/* Dummy log function to avoid noisy output during fuzzing */
void log_function(AvahiLogLevel level, const char *txt) {}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    avahi_set_log_function(log_function);

    /* The key must be a non-NULL C-string. To ensure this, we require
     * at least one byte of input to create a null-terminated string. */
    if (size == 0) {
        return 0;
    }

    /* Split the input data into a key and a value.
     * This allows the fuzzer to control the content of both. */
    const size_t key_len = size / 2;
    const uint8_t *value_data = data + key_len;
    const size_t value_len = size - key_len;

    /* Create a null-terminated C-string for the key.
     * The function asserts that the key is not NULL. */
    char *key = (char *)avahi_malloc(key_len + 1);
    memcpy(key, data, key_len);
    key[key_len] = '\0';

    /* Create a null-terminated C-string for the value. */
    char *value = (char *)avahi_malloc(value_len + 1);
    memcpy(value, value_data, value_len);
    value[value_len] = '\0';

    AvahiStringList *l = NULL;

    /* Test case 1: Create a new list with a key-value pair. */
    l = avahi_string_list_add_pair(NULL, key, value);

    /* Test case 2: Add another pair to the existing list.
     * The return value must be used as the new head of the list. */
    l = avahi_string_list_add_pair(l, key, value);

    /* Test case 3: Add a pair with a NULL value to the list. */
    l = avahi_string_list_add_pair(l, key, NULL);

    /* Clean up the allocated string list. */
    if (l) {
        avahi_string_list_free(l);
    }

    /* Clean up the allocated key and value strings. */
    avahi_free(key);
    avahi_free(value);

    return 0;
}
