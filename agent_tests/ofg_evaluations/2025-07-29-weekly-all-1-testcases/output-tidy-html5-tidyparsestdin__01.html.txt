
	
<description>
The `tidyParseStdin` function parses input from standard input. It is a wrapper around the `tidyDocParseStdin` function, which performs the actual parsing. The `tidyDocParseStdin` function creates a file input stream from `stdin`, and then calls `DocParseStream` to parse the stream. The input `TidyDoc` object is used to configure the parsing, for example, to determine the input character encoding.
</description>
<requirements>

<requirement>
The `tidyCreate` function must be called to create a `TidyDoc` object. This is because the `TidyDoc` object holds the configuration and state for parsing.
</requirement>
<requirement>
The `tidyRelease` function should be called on the `TidyDoc` object after parsing is complete. This is to free the memory and resources allocated for the `TidyDoc` object.
</requirement>
<requirement>
The fuzzer should provide input to standard input. The `tidyParseStdin` function reads from stdin to get the content to be parsed.
</requirement>

</requirements>

#include <stddef.h>
#include <stdint.h>
#include <stdio.h>
#include <unistd.h>

#include "fuzzer_temp_file.h"
#include "/src/tidy-html5/include/tidy.h"

int tidyParseStdin(TidyDoc);

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    TidyDoc tdoc = tidyCreate();
    if (!tdoc) {
        return 0;
    }

    char* tmpfile = fuzzer_get_tmpfile(data, size);
    if (!tmpfile) {
        tidyRelease(tdoc);
        return 0;
    }

    // Redirect stdin to the temporary file.
    if (freopen(tmpfile, "rb", stdin) == NULL) {
        fuzzer_release_tmpfile(tmpfile);
        tidyRelease(tdoc);
        return 0;
    }

    tidyParseStdin(tdoc);

    // No need to restore stdin since the process will exit.
    // The fuzzer harness creates a new process for each input.

    fuzzer_release_tmpfile(tmpfile);
    tidyRelease(tdoc);
    return 0;
}
