The type of the new `MmsValue` is determined by the `type` field of the `typeSpec` argument. The function handles various MMS types, including primitive types like INTEGER, UNSIGNED, FLOAT, etc., as well as complex types like ARRAY and STRUCTURE. For complex types, it recursively calls itself to create the elements of the array or structure.
</description>
