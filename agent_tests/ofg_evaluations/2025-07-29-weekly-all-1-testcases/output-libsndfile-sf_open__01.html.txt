
	
<description>
The sf_open function is used to open a sound file for reading, writing, or both. It takes a path to the file, a mode, and a pointer to an SF_INFO structure. If the file is opened for reading, the SF_INFO structure is filled in by the function. If the file is opened for writing, the SF_INFO structure must be filled in by the caller before calling sf_open. The function returns a pointer to a SNDFILE object on success, and NULL on error.
</description>
<requirements>
<requirement>
The `path` argument must be a null-terminated string representing a valid file path, or "-" to use stdin/stdout. This is because the function will attempt to open the path, and an invalid path will cause an error.
</requirement>
<requirement>
The `mode` argument must be one of `SFM_READ`, `SFM_WRITE`, or `SFM_RDWR`. These are the only modes supported by the function.
</requirement>
<requirement>
The `sfinfo` argument must be a valid pointer to an `SF_INFO` structure. This is because the function will read from or write to this structure.
</requirement>
<requirement>
If the `mode` is `SFM_WRITE` or `SFM_RDWR`, the `sfinfo` structure must be initialized with a valid `format`, `channels`, and `samplerate`. The `format` should be a bitwise OR of a major format (e.g. `SF_FORMAT_WAV`) and a minor format (e.g. `SF_FORMAT_PCM_16`). This is because this information is required to create the file header.
</requirement>
<requirement>
Before calling `sf_open` in write mode, the `sf_format_check` function can be used to validate the `SF_INFO` structure. This will prevent errors from invalid format combinations.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <vector>

extern "C" {
#include "/src/libsndfile/include/sndfile.h"

extern "C" SNDFILE * sf_open(const char *, int, SF_INFO *);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // We need some data to work with.
  if (provider.remaining_bytes() < 1) {
    return 0;
  }

  const int mode = provider.PickValueInArray({SFM_READ, SFM_WRITE, SFM_RDWR});

  SF_INFO sfinfo;
  memset(&sfinfo, 0, sizeof(sfinfo));

  if (mode == SFM_WRITE || mode == SFM_RDWR) {
    // For write modes, SF_INFO must be filled by the caller.
    const int major_formats[] = {SF_FORMAT_WAV,  SF_FORMAT_AIFF, SF_FORMAT_AU,
                                 SF_FORMAT_RAW,  SF_FORMAT_PAF,  SF_FORMAT_SVX,
                                 SF_FORMAT_NIST, SF_FORMAT_VOC,  SF_FORMAT_IRCAM,
                                 SF_FORMAT_W64,  SF_FORMAT_MAT4, SF_FORMAT_MAT5,
                                 SF_FORMAT_PVF,  SF_FORMAT_XI,   SF_FORMAT_HTK,
                                 SF_FORMAT_SDS,  SF_FORMAT_AVR,  SF_FORMAT_WAVEX,
                                 SF_FORMAT_SD2,  SF_FORMAT_FLAC, SF_FORMAT_CAF,
                                 SF_FORMAT_OGG};
    const int minor_formats[] = {
        SF_FORMAT_PCM_S8,    SF_FORMAT_PCM_16,   SF_FORMAT_PCM_24,
        SF_FORMAT_PCM_32,    SF_FORMAT_PCM_U8,   SF_FORMAT_FLOAT,
        SF_FORMAT_DOUBLE,    SF_FORMAT_ULAW,     SF_FORMAT_ALAW,
        SF_FORMAT_IMA_ADPCM, SF_FORMAT_MS_ADPCM, SF_FORMAT_GSM610,
        SF_FORMAT_VOX_ADPCM, SF_FORMAT_G721_32,  SF_FORMAT_G723_24,
        SF_FORMAT_G723_40,   SF_FORMAT_DWVW_12,  SF_FORMAT_DWVW_16,
        SF_FORMAT_DWVW_24,   SF_FORMAT_DWVW_N,   SF_FORMAT_DPCM_8,
        SF_FORMAT_DPCM_16,   SF_FORMAT_VORBIS,   SF_FORMAT_OPUS};
    const int endian_formats[] = {SF_ENDIAN_FILE, SF_ENDIAN_LITTLE,
                                  SF_ENDIAN_BIG, SF_ENDIAN_CPU};

    sfinfo.samplerate = provider.ConsumeIntegralInRange<int>(1000, 192000);
    sfinfo.channels = provider.ConsumeIntegralInRange<int>(1, 16);
    sfinfo.format = provider.PickValueInArray(major_formats) |
                    provider.PickValueInArray(minor_formats) |
                    provider.PickValueInArray(endian_formats);

    // Call sf_format_check to test its handling of fuzzed SF_INFO.
    sf_format_check(&sfinfo);
  }

  // The rest of the data is the file content.
  std::vector<uint8_t> file_content =
      provider.ConsumeRemainingBytes<uint8_t>();

  // Write the fuzzed content to a temporary file.
  const char *tmp_filename = "/tmp/fuzz_sf_open.wav";
  FILE *fp = fopen(tmp_filename, "wb");
  if (!fp) {
    return 0;
  }
  fwrite(file_content.data(), 1, file_content.size(), fp);
  fclose(fp);

  // Call the function under test.
  SNDFILE *sndfile = sf_open(tmp_filename, mode, &sfinfo);
  if (sndfile) {
    sf_close(sndfile);
  }

  // Clean up the temporary file.
  remove(tmp_filename);

  return 0;
}
