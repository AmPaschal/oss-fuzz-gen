
	
<description>
The function `stage2_next` is the second stage of the simdjson parsing process. It takes a `dom::document` object, which has been previously processed by the `stage1` function, and completes the parsing, building the document object model (DOM) in the `doc` object. It iterates through the structural indexes identified in `stage1` and builds the tape, which is a compact representation of the JSON document's structure and values. The function is called by `dom_parser::parse` and `document_stream::next`.
</description>
<requirements>

<requirement>
The `dom_parser_implementation::stage1` function must be called before calling `stage2_next`. This is because `stage1` populates the structural indexes and other data structures in the `dom_parser_implementation` object that are required by `stage2_next`.
</requirement>
<requirement>
The `doc` argument passed to `stage2_next` must be the same `dom::document` object that was passed to `stage1`. This is to ensure that `stage2_next` has access to the correct tape and string buffer for the document being parsed.
</requirement>
<requirement>
The `doc.tape` and `doc.string_buf` buffers must be allocated with sufficient capacity to hold the parsed JSON data. The `dom_parser::allocate` function should be used to allocate a parser with enough capacity for the expected document size.
</requirement>

</requirements>

#include "simdjson.h"
#include "simdjson/internal/dom_parser_implementation.h"

#include <cstddef>
#include <cstdint>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  // 1. Get the fallback implementation from the list of available implementations.
  const simdjson::implementation* fallback_impl = simdjson::get_available_implementations()["fallback"];
  if (!fallback_impl) {
    // This should not happen in a normal environment.
    return 0;
  }

  // 2. Set the fallback implementation as the active one for this thread of execution.
  simdjson::get_active_implementation() = fallback_impl;

  // 3. Create a parser. It will now use the globally-set active (fallback) implementation.
  simdjson::dom::parser parser;

  // 4. Allocate memory for the parser. This single call is sufficient to prepare
  // both the parser's internal implementation and its internal document (`parser.doc`).
  if (parser.allocate(size, size) != simdjson::SUCCESS) {
    return 0;
  }

  // 5. Get a pointer to the now-initialized low-level implementation object.
  simdjson::internal::dom_parser_implementation* implementation = parser.implementation.get();
  if (!implementation) {
      return 0;
  }

  // 6. Call stage1. Polymorphism will ensure the fallback version is called.
  auto error = implementation->stage1(data, size, simdjson::stage1_mode::regular);
  if (error) {
    return 0;
  }

  // 7. Call the function under test, passing the parser's own internal document,
  // which was prepared by the `parser.allocate()` call.
  implementation->stage2_next(parser.doc);

  return 0;
}
