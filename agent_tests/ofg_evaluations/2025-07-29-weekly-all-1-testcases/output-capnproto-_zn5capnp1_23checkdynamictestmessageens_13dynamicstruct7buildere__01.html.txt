
	
<description>
The function `capnp::_::checkDynamicTestMessage(DynamicStruct::Builder)` is a test utility function that verifies the content of a message built using a `DynamicStruct::Builder`. It is a wrapper around the templated function `dynamicCheckTestMessage`, which performs the actual checks. The `dynamicCheckTestMessage` function reads various fields from the provided `DynamicStruct::Builder` (or `DynamicStruct::Reader`) and asserts that they have specific, hard-coded values. These values are set by the corresponding `initDynamicTestMessage` function. Therefore, for `checkDynamicTestMessage` to execute without triggering assertion failures, the `DynamicStruct::Builder` passed to it must have been previously initialized by `initDynamicTestMessage`. Any other message content will likely cause the test to fail. The intended use is to first build a message with `initDynamicTestMessage`, then serialize and deserialize it, and finally use `checkDynamicTestMessage` to verify that the process was successful. For fuzzing purposes, one could mutate the message after initialization and before checking, to explore how the parser handles corrupted data.
</description>
<requirements>

<requirement>
A `capnp::MallocMessageBuilder` must be created. The `MallocMessageBuilder` is used to allocate memory for the message that will be checked.
</requirement>
<requirement>
The `initRoot<DynamicStruct>(TestAllTypes::schema)` method of the `MallocMessageBuilder` must be called to obtain a `DynamicStruct::Builder`. This `DynamicStruct::Builder` instance is the required argument for the `checkDynamicTestMessage` function.
</requirement>
<requirement>
The function `capnp::_::initDynamicTestMessage` must be called with the `DynamicStruct::Builder` as an argument before calling the target function. This is because `initDynamicTestMessage` populates the builder with the exact data that `checkDynamicTestMessage` expects to find.
</requirement>
<requirement>
The `DynamicStruct::Builder` argument should be initialized with the schema for `TestAllTypes`. This is because the fields checked by `checkDynamicTestMessage` correspond to the fields defined in the `TestAllTypes` schema.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <capnp/message.h>
#include <capnp/dynamic.h>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size < 1) {
    return 0;
  }

  FuzzedDataProvider provider(data, size);

  // Create a message builder.
  capnp::MallocMessageBuilder builder;

  // Initialize the root as a dynamic struct based on the TestAllTypes schema.
  capnp::DynamicStruct::Builder root =
      builder.initRoot<capnp::DynamicStruct>(capnp::Schema::from<capnp::_::TestAllTypes>());

  // Populate the message with the standard test data.
  capnp::_::initDynamicTestMessage(root);

  // Get the raw memory segments of the message.
  auto segments = builder.getSegmentsForOutput();
  if (segments.size() == 0) {
    return 0;
  }

  // Calculate the total size of all segments in words.
  size_t total_size_words = 0;
  for (const auto& segment : segments) {
    total_size_words += segment.size();
  }
  if (total_size_words == 0) {
    return 0;
  }

  // Pick a random offset to start corrupting.
  size_t offset_words = provider.ConsumeIntegralInRange<size_t>(0, total_size_words - 1);
  std::vector<uint8_t> fuzz_data = provider.ConsumeRemainingBytes<uint8_t>();
  
  // Find the target segment and apply the corruption.
  size_t current_pos_words = 0;
  for (auto& segment : segments) {
    if (offset_words < current_pos_words + segment.size()) {
      size_t segment_offset_words = offset_words - current_pos_words;
      capnp::word* segment_data = const_cast<capnp::word*>(segment.begin()) + segment_offset_words;
      size_t remaining_words = segment.size() - segment_offset_words;
      size_t bytes_to_copy = std::min(fuzz_data.size(), remaining_words * sizeof(capnp::word));
      if (bytes_to_copy > 0) {
        memcpy(segment_data, fuzz_data.data(), bytes_to_copy);
      }
      break;
    }
    current_pos_words += segment.size();
  }
  
  // Call the function under test with the (potentially corrupted) builder.
  // Wrap in runCatchingExceptions to handle assertion failures gracefully.
  kj::runCatchingExceptions([&]() {
    capnp::_::checkDynamicTestMessage(root);
  });

  return 0;
}
