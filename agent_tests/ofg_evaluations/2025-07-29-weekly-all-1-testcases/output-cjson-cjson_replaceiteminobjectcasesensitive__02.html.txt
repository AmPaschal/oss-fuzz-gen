
	
<description>
The function `cJSON_ReplaceItemInObjectCaseSensitive` replaces an item in a cJSON object. It is a case-sensitive version of `cJSON_ReplaceItemInObject`. The function is a wrapper around `replace_item_in_object` which in turn calls `cJSON_ReplaceItemViaPointer` and `get_object_item`. The function first finds the item to be replaced using `get_object_item` and then replaces it with the new item using `cJSON_ReplaceItemViaPointer`.
</description>

The `string` argument must be a null-terminated string. It represents the key of the item to be replaced in the object. A NULL value will cause the function to fail.

</requirement>
<requirement>
The `object` should contain an item with a key matching the `string` argument for a successful replacement to occur. An item can be added to the object using `cJSON_AddItemToObject`.
</requirement>
