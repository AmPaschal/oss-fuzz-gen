
	
<description>
The function `ogs_nas_esm_decode` decodes an EPS Session Management (ESM) message from a packet buffer (`ogs_pkbuf_t`). It first extracts the ESM header to identify the message type. Based on the message type, it calls a specific decoding function to parse the rest of the packet buffer and populate the `ogs_nas_eps_message_t` structure. The callers typically receive the `ogs_pkbuf_t` from underlying network layers and pass it to this function for parsing.
</description>
<requirements>
<requirement>
The `pkbuf` argument must be a valid, non-NULL pointer to an `ogs_pkbuf_t` struct. This is because the function dereferences this pointer without a prior null check.
</requirement>
<requirement>
The `pkbuf->data` pointer must be a valid, non-NULL pointer to a data buffer. The function asserts this condition, and a NULL pointer would lead to a crash.
</requirement>
<requirement>
The `pkbuf` must contain at least `sizeof(ogs_nas_esm_header_t)` bytes. This is because the function pulls this many bytes to decode the message header before proceeding.
</requirement>
<requirement>
The content of the buffer pointed to by `pkbuf->data` should be fuzzed. This buffer represents the NAS message, and its content, particularly the `message_type` field, dictates the control flow of the function.
</requirement>
<requirement>
The `message` argument must be a valid, non-NULL pointer to an `ogs_nas_eps_message_t` struct. This is because the function writes the decoded message into the memory pointed to by this argument.
</requirement>
</requirements>

#include <stdio.h>
#include <stdint.h>

#include "fuzzing.h"
#include "ogs-nas-eps.h"

#define kMinInputLength 3
#define kMaxInputLength 1024

extern int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size)
{
    if (Size < kMinInputLength || Size > kMaxInputLength) {
        return 1;
    }

    if (!initialized) {
        initialize();
        ogs_log_install_domain(&__ogs_nas_domain, "nas", OGS_LOG_NONE);
        ogs_log_install_domain(&__ogs_tlv_domain, "tlv", OGS_LOG_NONE);
    }

    ogs_pkbuf_t *pkbuf;
    pkbuf = ogs_pkbuf_alloc(NULL, OGS_MAX_SDU_LEN);

    if (pkbuf == NULL) {
        return 1;
    }
    ogs_pkbuf_put_data(pkbuf, Data, Size);

    ogs_nas_eps_message_t message;
    ogs_nas_esm_decode(&message, pkbuf);

    ogs_pkbuf_free(pkbuf);

    return 0;
}
