
	
<description>
The evhttp_start function creates a new HTTP server and makes it listen on the specified address and port. It returns a pointer to a new evhttp object on success, or NULL on failure. The address and port arguments are used to create a listening socket for the HTTP server.
</description>
<requirements>
<requirement>
The `address` argument can be a NULL pointer, but only if the `port` argument is 0. This is because `bind_socket` will create an unbound socket if both `address` and `port` are NULL or 0.
</requirement>
<requirement>
If the `address` argument is not NULL, it must be a valid hostname or IP address string. This is because `make_addrinfo` (called by `bind_socket`) will fail if the address is not a valid hostname or IP address.
</requirement>
<requirement>
The `port` argument must be a valid port number. An invalid port number will cause `make_addrinfo` to fail.
</requirement>
</requirements>

  std::string address_str = provider.ConsumeRandomLengthString();

  if (provider.ConsumeBool()) {

    address = nullptr;
    port = 0;

  if (http) {

  return 0;
