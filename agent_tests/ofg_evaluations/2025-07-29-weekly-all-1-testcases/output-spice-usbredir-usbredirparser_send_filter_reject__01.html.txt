
	
<description>
The function `usbredirparser_send_filter_reject` sends a filter reject message to the peer. It first checks if the peer has the `usb_redir_cap_filter` capability using `usbredirparser_peer_has_cap`. If the peer has the capability, it queues a `usb_redir_filter_reject` message to be sent to the peer using `usbredirparser_queue`. The `parser` argument must be a valid pointer to a `usbredirparser` struct that has been initialized by `usbredirparser_new`.
</description>

</requirement>

</requirement>

static int parser_write(void *priv, uint8_t *data, int count) {

  return count;

  // Call the target function. We cannot set peer capabilities via the public

  while (usbredirparser_has_data_to_write(parser)) {

  }

  usbredirparser_destroy(parser);
