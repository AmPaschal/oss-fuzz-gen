
	
<description>
The function `cmsCreateProofingTransform` creates a proofing transform. It is a wrapper around `cmsCreateProofingTransformTHR`, which in turn calls `cmsCreateExtendedTransform` or `cmsCreateTransformTHR`. The function takes input, output, and proofing profiles, along with formats, intents, and flags to create a color transform that simulates the output of one device on another.
</description>
<requirements>

<requirement>
The `InputProfile`, `OutputProfile`, and `ProofingProfile` arguments should be valid `cmsHPROFILE` handles. These can be created by calling `cmsOpenProfileFromMem` with fuzzer-provided data, or `cmsCreateProfilePlaceholder(NULL)` for an empty profile.
</requirement>
<requirement>
The `nIntent` and `ProofingIntent` arguments must be one of the defined intent values (0-3, 10-15). This is because these values are used to index internal arrays and select rendering intents.
</requirement>
<requirement>
The `InputFormat` and `OutputFormat` arguments must be valid pixel type specifiers. These are constructed using macros like `PT_RGB` and specify bits per sample and other colorimetric details.
</requirement>
<requirement>
The `dwFlags` argument should be a valid combination of `cmsFLAGS_` values. The function's behavior changes based on flags like `cmsFLAGS_SOFTPROOFING`, `cmsFLAGS_GAMUTCHECK`, and `cmsFLAGS_BLACKPOINTCOMPENSATION`.
</requirement>

</requirements>

#include "/src/lcms/include/lcms2.h"
#include <stdint.h>

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    // We need at least 20 bytes for the five uint32_t parameters.
    if (size < 20) {
        return 0;
    }

    uint32_t InputFormat    = *(const uint32_t*)(data + 0);
    uint32_t OutputFormat   = *(const uint32_t*)(data + 4);
    uint32_t nIntent        = *(const uint32_t*)(data + 8);
    uint32_t ProofingIntent = *(const uint32_t*)(data + 12);
    uint32_t dwFlags        = *(const uint32_t*)(data + 16);

    const uint8_t *profile_data = data + 20;
    size_t profile_data_size = size - 20;

    // Sanitize intent values to be within the valid ranges (0-15).
    nIntent %= 16;
    ProofingIntent %= 16;

    // Split the remaining data into three parts for the profiles.
    size_t each_profile_size = profile_data_size / 3;
    const uint8_t *in_profile_data = profile_data;
    const uint8_t *out_profile_data = profile_data + each_profile_size;
    const uint8_t *proof_profile_data = profile_data + 2 * each_profile_size;

    cmsHPROFILE hInProfile = cmsOpenProfileFromMem(in_profile_data, each_profile_size);
    cmsHPROFILE hOutProfile = cmsOpenProfileFromMem(out_profile_data, each_profile_size);
    cmsHPROFILE hProofProfile = cmsOpenProfileFromMem(proof_profile_data, each_profile_size);

    // If creating a profile from memory fails, use a placeholder.
    // This ensures the function is always called with valid handles.
    if (!hInProfile) hInProfile = cmsCreateProfilePlaceholder(NULL);
    if (!hOutProfile) hOutProfile = cmsCreateProfilePlaceholder(NULL);
    if (!hProofProfile) hProofProfile = cmsCreateProfilePlaceholder(NULL);

    // Proceed only if all profile handles are valid.
    if (hInProfile && hOutProfile && hProofProfile) {
        cmsHTRANSFORM hTransform = cmsCreateProofingTransform(
            hInProfile, InputFormat,
            hOutProfile, OutputFormat,
            hProofProfile,
            nIntent, ProofingIntent, dwFlags
        );

        if (hTransform) {
            cmsDeleteTransform(hTransform);
        }
    }

    // Clean up all resources. cmsCloseProfile handles NULL gracefully.
    cmsCloseProfile(hInProfile);
    cmsCloseProfile(hOutProfile);
    cmsCloseProfile(hProofProfile);

    return 0;
}
