
	
<description>
The function `MmsValue_newDefaultValue` creates a new `MmsValue` object and initializes it with a default value according to the provided `MmsVariableSpecification`. It handles various MMS data types, including primitive types like integers, floats, and booleans, as well as complex types like arrays and structures. For complex types, it recursively calls itself to create default values for the individual elements. The function returns a pointer to the newly created `MmsValue` object, or NULL if memory allocation fails or the type is unsupported.
</description>
