
	
<description>
The `mg_hello` function initializes a mongoose manager, and starts an HTTP listener on the provided URL. It then polls the manager until a termination condition is met.
</description>
<requirements>
<requirement>
The `url` parameter must be a valid, null-terminated string. This is to prevent memory access violations when the string is processed by functions like `strlen` and `strcpy`.
</requirement>
<requirement>
The `url` parameter must be a valid URL string that can be parsed by `mg_url_port`, `mg_url_host`, and `mg_aton`. An invalid URL will cause `mg_open_listener` to fail, which in turn will cause `mg_hello` to fail.
</requirement>
<requirement>
The host part of the `url` must be a valid IP address or a resolvable hostname. The `mg_aton` function, which is used to parse the host, will fail if the host is not a valid address.
</requirement>
</requirements>

#else
int LLVMFuzzerTestOneInput(const uint8_t *, size_t);
#endif

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size == 0 || size > 2048) {
    return 0;
  }

  char *url = (char *) malloc(size + 1);
  if (url == NULL) {
    return 0;
  }
  memcpy(url, data, size);
  url[size] = '\0';

  // mg_hello contains an infinite loop, but with the current setup
  // (MG_ENABLE_SOCKET=0 or sandbox restrictions), mg_http_listen is
  // expected to fail, causing mg_hello to return. If not, the fuzzer
  // timeout will handle termination.
  mg_hello(url);

  free(url);

  return 0;
}
