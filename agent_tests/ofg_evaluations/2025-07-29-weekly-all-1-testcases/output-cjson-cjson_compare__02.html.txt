
	
<description>
The function cJSON_Compare compares two cJSON objects for equality. It recursively compares nested objects and arrays. The comparison is case-sensitive for object keys if the case_sensitive argument is true. The function returns true if the objects are identical, and false otherwise.
</description>

</requirement>

</requirement>
<requirement>
For `cJSON_Object` types, the `string` member of each child should not be NULL. The function uses this member to look up corresponding items in the other object and will crash if it is NULL.
</requirement>
