
	
<description>
The function `YaHTTP::operator<<` serializes a `YaHTTP::Response` object to an output stream. It is a wrapper around the `HTTPBase::write` method, which handles the formatting of the HTTP response, including the status line, headers, cookies, and body. The behavior of the function is highly dependent on the values of the `Response` object's members.
</description>
<requirements>

<requirement>
The `kind` member of the `Response` object must be initialized to `YAHTTP_TYPE_RESPONSE`. This is correctly handled by the `Response` class constructor and ensures that the object is treated as a response, not a request.
</requirement>
<requirement>
The `version` member of the `Response` object should be set to 9, 10, or 11. Any other value will cause a `YaHTTP::Error` to be thrown, so it is important to test these specific values.
</requirement>
<requirement>
If the `statusText` member of the `Response` object is empty, the `status` member must be a valid HTTP status code. This is because the `Utility::status2text` function will be called, and an invalid status code could lead to unexpected behavior.
</requirement>
<requirement>
The `headers` map of the `Response` object should be populated with various key-value pairs. Special attention should be given to the "Content-Length" and "Transfer-Encoding" headers as they affect how the response body is written.
</requirement>
<requirement>
The `jar` member of the `Response` object, which is a `CookieJar`, should be populated with cookies. This is necessary to test the cookie serialization logic in the `write` method.
</requirement>
<requirement>
The `renderer` member of the `Response` object should be a valid function pointer. The default renderer, `SendBodyRender`, can be used, which writes the content of the `body` member to the output stream.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <iostream>
#include <sstream>

// Define feature-test macros required by utility.hpp
#define HAVE_LOCALTIME_R 1
#define HAVE_GMTIME_R 1

// Include YaHTTP headers in the correct order of dependency
#include "yahttp/exception.hpp"
#include "yahttp/utility.hpp"
#include "yahttp/url.hpp"
#include "yahttp/cookie.hpp"
#include "yahttp/reqresp.hpp"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);
  YaHTTP::Response resp;

  // Requirement 2: Set version to 9, 10, or 11.
  resp.version = fdp.PickValueInArray<int>({9, 10, 11});

  // Requirement 3: Set status and statusText.
  resp.status = fdp.ConsumeIntegral<int>();
  if (fdp.ConsumeBool()) {
    resp.statusText = fdp.ConsumeRandomLengthString(100);
  }

  // Requirement 4: Populate headers.
  auto num_headers = fdp.ConsumeIntegralInRange<size_t>(0, 10);
  for (size_t i = 0; i < num_headers; ++i) {
    std::string key = fdp.ConsumeRandomLengthString(50);
    std::string value = fdp.ConsumeRandomLengthString(100);
    if (!key.empty()) {
      resp.headers[key] = value;
    }
  }

  // Requirement 5: Populate CookieJar.
  auto num_cookies = fdp.ConsumeIntegralInRange<size_t>(0, 5);
  for (size_t i = 0; i < num_cookies; ++i) {
    YaHTTP::Cookie cookie;
    cookie.name = fdp.ConsumeRandomLengthString(50);
    cookie.value = fdp.ConsumeRandomLengthString(100);
    cookie.domain = fdp.ConsumeRandomLengthString(50);
    cookie.path = fdp.ConsumeRandomLengthString(50);
    
    // The 'expires' member is a DateTime object which is complex to fuzz directly.
    // We will leave it to its default initialized state.

    cookie.secure = fdp.ConsumeBool();
    cookie.httponly = fdp.ConsumeBool();

    if (!cookie.name.empty()) {
      resp.jar.cookies[cookie.name] = cookie;
    }
  }

  // Requirement 6: The default renderer is set by the constructor.
  // We just need to provide a body.
  resp.body = fdp.ConsumeRemainingBytesAsString();

  std::ostringstream oss;
  try {
    // Invoke the function under test
    oss << resp;
  } catch (const YaHTTP::ParseError &e) {
    // Catch derived class exception first
  } catch (const YaHTTP::Error &e) {
    // Catch base class exception
  }

  return 0;
}
