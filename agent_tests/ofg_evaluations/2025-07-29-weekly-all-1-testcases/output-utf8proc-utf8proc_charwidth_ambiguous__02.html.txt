
	
<description>
The function `utf8proc_charwidth_ambiguous` checks if a given Unicode character `c` has an ambiguous width. It does this by calling `utf8proc_get_property` to get the properties of the character and then returns the `ambiguous_width` member of the property struct.
</description>
<requirements>
<requirement>
The input `c` should be a valid Unicode codepoint in the range [0, 0x110000). This is because the function `utf8proc_get_property` performs a check on this range.
</requirement>
