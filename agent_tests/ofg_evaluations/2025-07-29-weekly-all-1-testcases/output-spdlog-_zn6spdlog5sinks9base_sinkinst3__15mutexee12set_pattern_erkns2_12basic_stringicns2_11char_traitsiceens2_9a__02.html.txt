The function `set_pattern_` is a protected virtual member function of the `base_sink` class. It is responsible for setting a new pattern for the log messages. This function is typically not called directly, but rather through the public `set_pattern` function which ensures thread safety by locking a mutex before calling `set_pattern_`. The `set_pattern_` function creates a new `pattern_formatter` object with the provided pattern string and sets it as the sink's formatter. A malformed pattern string can lead to a crash inside the `pattern_formatter`'s constructor during parsing.
</description>

This is because the pattern parsing logic attempts to access the character following the '%' without checking if it exists, which will result in an out-of-bounds read and a crash if '%' is the last character.
</requirement>
