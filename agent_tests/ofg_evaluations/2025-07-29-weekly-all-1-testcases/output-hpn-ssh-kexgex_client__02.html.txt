The kexgex_client function is responsible for initiating a Diffie-Hellman Group Exchange (DH-GEX) key exchange process in an SSH client. It constructs and sends a SSH2_MSG_KEX_DH_GEX_REQUEST packet to the server, specifying the client's preferred parameters for the key exchange, including the minimum, preferred, and maximum size of the Diffie-Hellman group. The function sets up a dispatch handler to process the server's SSH2_MSG_KEX_DH_GEX_GROUP response.
</description>
