
	
<description>
The `lou_getTypeformForEmphClass` function retrieves a numeric identifier for a given emphasis class name. It takes two string arguments: `tableList` and `emphClass`. `tableList` is a comma-separated list of translation table files. The function first compiles these tables into an internal representation using the `_lou_getTranslationTable` function. If the tables are compiled successfully, it iterates through the emphasis class names defined within the compiled table and compares the input `emphClass` string with each defined emphasis class name. If a match is found at index `i`, it returns a value calculated as `italic << i`. If the table cannot be loaded or if no matching emphasis class is found, the function returns 0.
</description>
<requirements>
<requirement>
The `tableList` argument must be a null-terminated string containing a comma-separated list of paths to valid liblouis translation table files. This is necessary because the function needs to compile these tables to extract the emphasis class definitions.
</requirement>
<requirement>
The `emphClass` argument must be a null-terminated string. To achieve meaningful results beyond returning 0, this string should match one of the emphasis class names defined in the provided table files via the 'emphclass' opcode.
</requirement>
<requirement>
The first three emphasis classes defined in the table files must be "italic", "underline", and "bold", in that order, for backward compatibility. This is an assertion checked during table compilation, which is called by the target function.
</requirement>
<requirement>
The number of unique emphasis classes defined across the tables in `tableList` must not exceed 10 (`MAX_EMPH_CLASSES`). Exceeding this limit during table compilation will result in an error, causing `_lou_getTranslationTable` to return NULL.
</requirement>
<requirement>
The `lou_free()` function should be called after the fuzzer is done with all calls to the target function. This is to ensure that the memory allocated for the compiled translation tables is properly deallocated, preventing memory leaks.
</requirement>
</requirements>

#include <cstdint>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider provider(data, size);
    static int counter = 0;

    // Split the input data. A portion for the table content, the rest for the emphasis class name.
    if (size == 0) {
        return 0;
    }
    size_t table_content_size = provider.ConsumeIntegralInRange<size_t>(0, size);
    std::vector<uint8_t> table_content = provider.ConsumeBytes<uint8_t>(table_content_size);
    std::string emph_class = provider.ConsumeRemainingBytesAsString();

    if (table_content.empty()) {
        return 0;
    }

    // Create a temporary file to write the table content to.
    char table_filename[256];
    sprintf(table_filename, "/tmp/fuzz-table-%d.ctb", counter++);

    FILE *fp = fopen(table_filename, "wb");
    if (!fp) {
        return 0;
    }
    fwrite(table_content.data(), 1, table_content.size(), fp);
    fclose(fp);

    // Call the function under test.
    lou_getTypeformForEmphClass(table_filename, emph_class.c_str());

    // Clean up resources.
    lou_free();
    unlink(table_filename);

    return 0;
}
