
	
<description>
The function `sraw_midpoint` returns a 'midpoint' or 'neutral' value for sRAW color data. The value returned depends on the type of sRAW file that has been loaded, which is determined by the `load_raw` function pointer member of the `LibRaw` class. It returns 8192 for Canon and Sony sRAW formats, 2048 for Nikon sRAW format, and 0 for all other cases. The `load_raw` pointer is set by the `LibRaw::open_file()` or `LibRaw::open_buffer()` methods when a raw image is opened.
</description>
<requirements>
<requirement>
A `LibRaw` object must be initialized by calling `open_file()` or `open_buffer()` with a valid raw image file before calling `sraw_midpoint()`. This is because the `sraw_midpoint()` function's return value depends on the `load_raw` member, which is initialized by `open_file()` or `open_buffer()` based on the image data.
</requirement>
<requirement>
To get a non-zero return from `sraw_midpoint`, the input data passed to `open_file()` or `open_buffer()` must be a Canon sRAW, Sony YCbCr, or Nikon sRAW file. The function only returns non-zero values (8192 or 2048) if the `load_raw` pointer is set to `&LibRaw::canon_sraw_load_raw`, `&LibRaw::sony_ycbcr_load_raw`, or `&LibRaw::nikon_load_sraw`, which corresponds to these file types; otherwise, it will return 0.
</requirement>
</requirements>
