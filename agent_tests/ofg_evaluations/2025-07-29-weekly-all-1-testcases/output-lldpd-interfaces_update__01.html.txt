
	
<description>
The `interfaces_update` function is responsible for updating the list of local network interfaces. It retrieves the current interfaces and addresses, then gathers additional information such as driver names, wireless details, and VLAN configurations. It also applies various helper functions to manage these interfaces. The function is primarily called by `lldpd_update_localports` as part of the main loop to keep the daemon's view of the network interfaces current.
</description>
<requirements>

<requirement>
The `cfg->g_sock` member must be a valid socket descriptor. This is because it is used in `ioctl` calls within functions like `iflinux_add_driver` to get interface information.
</requirement>
<requirement>
The `cfg->g_chassis` TAILQ must be initialized and contain at least one element. This is because the `LOCAL_CHASSIS` macro dereferences the first element of this queue, and a crash will occur if it's empty.
</requirement>
<requirement>
The `cfg->g_hardware` TAILQ must be initialized. The function iterates over this queue using `TAILQ_FOREACH`, which will cause a crash if it is not initialized.
</requirement>
<requirement>
The `cfg->g_netlink` member should be initialized by calling `netlink_initialize(cfg)` before the target function. `interfaces_update` relies on `cfg->g_netlink` being initialized to get interface and address information.
</requirement>
<requirement>
The `lldpd_init` function should be called before `interfaces_update`. This function is responsible for initializing the `g_chassis` and `g_hardware` tail queues and populating the `g_chassis` queue with the local chassis information.
</requirement>

</requirements>
