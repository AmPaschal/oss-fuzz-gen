
	
<description>
The `utf8proc_decompose` function decomposes a UTF-8 encoded string into a sequence of Unicode codepoints. It is a wrapper around the `utf8proc_decompose_custom` function, providing a simpler interface by omitting the custom mapping function and data. The behavior of the decomposition is controlled by a set of options passed in the `options` parameter. These options can specify, for example, whether the input string is null-terminated, and how to handle combining characters and compatibility characters.
</description>
<requirements>
<requirement>
The `str` parameter should be a valid pointer to a UTF-8 encoded string. If the `UTF8PROC_NULLTERM` option is not set, the `strlen` parameter must specify the length of the string; otherwise, the string must be null-terminated. This is to ensure that the function does not read past the end of the input string.</requirement>
<requirement>
The `buffer` parameter must be a valid pointer to a memory region that is large enough to hold the decomposed string. The `bufsize` parameter specifies the size of this buffer in 32-bit integers. A buffer size that is too small will result in an `UTF8PROC_ERROR_OVERFLOW` error.</requirement>
<requirement>
The `options` parameter must not have both the `UTF8PROC_COMPOSE` and `UTF8PROC_DECOMPOSE` flags set simultaneously. The function will return `UTF8PROC_ERROR_INVALIDOPTS` if both of these flags are set.</requirement>
<requirement>
If the `UTF8PROC_STRIPMARK` flag is set in the `options` parameter, then either the `UTF8PROC_COMPOSE` or `UTF8PROC_DECOMPOSE` flag must also be set. The function returns `UTF8PROC_ERROR_INVALIDOPTS` if this condition is not met.</requirement>
</requirements>
