
	
<description>
The function `pg_query_parse_protobuf_opts` takes a SQL query string and a set of parser options, and returns a protobuf representation of the parsed query. It is a wrapper around `pg_query_raw_parse`, which in turn calls the `raw_parser` function to perform the actual parsing. The function also handles error reporting by redirecting stderr and capturing any error messages.
</description>
