
	
<description>
The function `jv_string_implode` takes a `jv` array of numbers as input and converts it into a `jv` string. The numbers in the array are treated as Unicode codepoints. Invalid codepoints are replaced with the replacement character `U+FFFD`. The input array is consumed by the function and should not be used after the call.
</description>
<requirements>
<requirement>
The input `j` must be a `jv` object of kind `JV_KIND_ARRAY`. This is to prevent the assertion `assert(JVP_HAS_KIND(j, JV_KIND_ARRAY))` from failing.
</requirement>
<requirement>
Each element of the input array `j` must be a `jv` object of kind `JV_KIND_NUMBER`. This is because the function asserts this for each element in the array with `assert(JVP_HAS_KIND(n, JV_KIND_NUMBER))`.
</requirement>
<requirement>
The input jv array `j` should be created using the `jv_array()` function. The numbers within the array should be created using `jv_number()` to ensure they are valid jv numbers.
</requirement>
</requirements>
