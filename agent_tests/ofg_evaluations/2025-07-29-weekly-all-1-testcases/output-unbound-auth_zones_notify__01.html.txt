
	
<description>
The function `auth_zones_notify` processes a DNS NOTIFY request. It checks if the notified zone is configured for DNS updates and if the sender is allowed to send notifications. If both checks pass, it processes the notification, which may trigger a zone transfer. The function is called from `answer_notify` in `daemon/worker.c` when a NOTIFY query is received.
</description>
