
	
<description>
The `auth_zones_startprobesequence` function starts a probe sequence for a given authoritative zone. It finds the zone transfer (auth_xfer) information associated with the zone name and class. If the zone transfer information is found, it initiates the probe by calling `xfr_process_notify`. The function is called from `do_auth_zone_sonotify` in `daemon/remote.c`, which processes a "sonotify" command. The zone name and class for the probe are parsed from the command argument. The `module_env` and `auth_zones` are obtained from the worker structure.
</description>
<requirements>
<requirement>
The `az` argument, which is a pointer to a `struct auth_zones`, must be a valid and initialized structure. This can be achieved by calling `auth_zones_create`. This is a requirement because the function dereferences this pointer to access the lock and the tree of transfer information.
</requirement>
<requirement>
The `az` structure should contain the zone that is being probed. The functions `auth_zone_create` and `auth_xfer_create` can be used to create and add a zone and its transfer information to the `auth_zones` structure. This is important because `auth_xfer_find` will search for the zone in this structure, and if not found, the probe sequence will not be started.
</requirement>
<requirement>
The `env` argument, a pointer to a `struct module_env`, must be a valid and initialized structure. This is because it is passed as an argument to `xfr_process_notify` which may use it.
</requirement>
<requirement>
The `nm` argument should be a valid, wire-format domain name, and `nmlen` should be its length. The function `sldns_str2wire_dname_buf` can be used to convert a string representation of a domain name to the wire format. This is necessary because the `nm` and `nmlen` are used as a key to search for the zone in the `auth_zones` structure.
</requirement>
<requirement>
The `dclass` argument should be a valid DNS class. In the caller, `LDNS_RR_CLASS_IN` is used. Using a valid class is important for the zone lookup to succeed.
</requirement>
</requirements>

    if (!env.scratch) {

    struct auth_zones* az = auth_zones_create();
    if (!az) {
        regional_destroy(env.scratch);
        return 0;

    lock_rw_wrlock(&az->lock);
    struct auth_zone* z = auth_zone_create(az, nm_buf, nmlen, LDNS_RR_CLASS_IN);

        if (xfr) {

            auth_zones_startprobesequence(az, &env, nm_buf, nmlen, LDNS_RR_CLASS_IN);
