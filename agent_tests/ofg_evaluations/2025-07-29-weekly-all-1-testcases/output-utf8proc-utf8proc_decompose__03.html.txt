
	
<description>
The `utf8proc_decompose` function is a wrapper around the `utf8proc_decompose_custom` function, providing a simplified interface for decomposing a UTF-8 encoded string. It transforms the input string into a sequence of Unicode codepoints, with the specific transformation being controlled by the `options` parameter. This parameter allows for various operations, such as normalization and case folding. The function can be used in two ways: to determine the required buffer size for the decomposed output by passing a `NULL` buffer, or to perform the decomposition and store the result in a user-provided buffer. In the latter case, it is crucial to ensure that the buffer is large enough to prevent overflows. The function also performs error checking, returning specific error codes for invalid UTF-8 input or invalid option combinations.
</description>

<requirement>

</requirement>
<requirement>
The `options` argument must be a valid combination of flags. The function will return `UTF8PROC_ERROR_INVALIDOPTS` if mutually exclusive options, such as `UTF8PROC_COMPOSE` and `UTF8PROC_DECOMPOSE`, are used together.
</requirement>
