
	
<description>
The `pcap_findalldevs` function is used to find all available network devices. It populates a list of `pcap_if_t` structures, with the head of the list being returned in the `alldevsp` argument. The `errbuf` argument is used to store any error messages that occur during the device discovery process. The function iterates through a global array of capture source types and calls the appropriate handler for each type to get the available devices.
</description>
<requirements>
<requirement>
The `alldevsp` argument must be a pointer to a `pcap_if_t` pointer initialized to NULL. This is because the function will allocate memory for the device list and set this pointer to the head of the list.
</requirement>
<requirement>
The `errbuf` argument must be a character buffer of at least `PCAP_ERRBUF_SIZE` (256) bytes. This is to prevent buffer overflows when the function writes error messages to this buffer.
</requirement>
</requirements>
