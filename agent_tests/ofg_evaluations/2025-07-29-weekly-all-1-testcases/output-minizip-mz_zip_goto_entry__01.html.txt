
	
<description>
The function `mz_zip_goto_entry` moves the current position in the central directory of a zip archive to a specified position. It takes a handle to a zip archive and the target position as input. The handle must be a valid pointer to a `mz_zip` struct, which is initialized by opening a zip file. The function validates the handle and checks if the provided position is within the bounds of the central directory (`cd_start_pos` and `cd_start_pos + cd_size`). If the checks pass, it updates the current position in the central directory and then calls `mz_zip_goto_next_entry_int` to process the entry at the new position. This function is essential for navigating to specific entries within the zip archive.
</description>
<requirements>

<requirement>

</requirement>
<requirement>
The `handle`'s `cd_start_pos` and `cd_size` fields must be properly initialized from a valid zip archive's central directory. This is because these fields are used to validate the `cd_pos` argument, and incorrect values could lead to unexpected behavior.
</requirement>
<requirement>
The second argument, `cd_pos`, must be a valid position within the central directory of the zip archive. The function explicitly checks if `cd_pos` is within the range [`zip->cd_start_pos`, `zip->cd_start_pos + zip->cd_size`], and returns `MZ_PARAM_ERROR` if it's not.
</requirement>
