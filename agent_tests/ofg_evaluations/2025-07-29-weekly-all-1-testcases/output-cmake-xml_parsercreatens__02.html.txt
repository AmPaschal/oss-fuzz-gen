
	
<description>
The function `XML_ParserCreateNS` creates a new XML parser with namespace processing enabled. It takes an encoding name and a namespace separator character as input. It is a wrapper around `XML_ParserCreate_MM`, passing a null-terminated string for the namespace separator.
</description>
<requirements>

<requirement>
The `encodingName` argument must be a null-terminated string that represents a valid encoding. This is because the underlying function `XML_ParserCreate_MM` uses this name to look up the encoding details from an internal table of supported encodings.
</requirement>
<requirement>
The `nsSep` argument is a character that will be used as the namespace separator. The function creates a null-terminated string from this character to be passed to `XML_ParserCreate_MM`, which only considers the first character of the string.
</requirement>

</requirements>
