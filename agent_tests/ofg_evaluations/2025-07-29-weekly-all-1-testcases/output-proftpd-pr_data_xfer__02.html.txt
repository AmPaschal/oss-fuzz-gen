
	
<description>
The `pr_data_xfer` function is the core data transfer engine for ProFTPD. It handles both uploading (reading from the network into `cl_buf`) and downloading (writing from `cl_buf` to the network). The direction of the transfer is determined by the global `session.xfer.direction` variable. The function can perform ASCII translation (converting between LF and CRLF line endings) based on the `session.sf_flags` global variable. It relies heavily on a pre-initialized global `session` structure, which must contain a valid data connection (`session.d`) and transfer-specific information (`session.xfer`). Callers must set up this global state by calling `pr_data_init` and `pr_data_open` before invoking `pr_data_xfer`.
</description>
<requirements>
<requirement>
The `pr_data_init` function must be called before `pr_data_xfer`. This is because `pr_data_init` allocates and initializes the global `session.xfer` structure, which is used extensively by the target function to manage the data transfer.
</requirement>
<requirement>
The `pr_data_open` function must be called before `pr_data_xfer`. This is necessary to establish a data connection, stored in the global `session.d`, which is required for all network read/write operations in the target function.
</requirement>
<requirement>
The `session.xfer.direction` global variable must be initialized to either `PR_NETIO_IO_RD` or `PR_NETIO_IO_WR`. This variable controls the main logic of the function, determining whether it performs a read or a write operation.
</requirement>
<requirement>
The `cl_buf` argument must be a valid, non-NULL pointer to a memory buffer. A NULL buffer will cause the function to return an error, and it is dereferenced in memory operations.
</requirement>
<requirement>
The `cl_size` argument must be greater than zero. The function explicitly checks for a zero size and returns an error, as it would result in no data being transferred.
</requirement>
<requirement>
The buffer pointed to by `cl_buf` must be at least `cl_size` bytes long. This is to prevent buffer overflows, as `cl_size` is used as the size for memory and I/O operations involving `cl_buf`.
</requirement>
<requirement>
The `session.sf_flags` global variable should be fuzzed with different combinations of `SF_ASCII` and `SF_ASCII_OVERRIDE`. These flags enable the ASCII translation code path, which is more complex and a good candidate for fuzzing.
</requirement>
</requirements>

// Global session object, as used by proftpd
session_t session;
pool *g_pool = NULL;

// Forward declaration for a function that might not be in a public header
void pr_netio_init(pool *);

// One-time initialization for the fuzzer
static void fuzzer_init(void) {
    if (g_pool != NULL) {
        return;
    }

    pr_signals_init();

    g_pool = make_sub_pool(NULL);
    if (g_pool == NULL) {
        exit(1);
    }

    // Initialize logging to /dev/null to avoid polluting output
    pr_log_init(g_pool, "fuzzer");
    pr_log_set_destination(PR_LOG_DEST_FILE, "/dev/null");

    // Initialize the network I/O layer
    pr_netio_init(g_pool);

    // Initialize the session struct
    memset(&session, 0, sizeof(session));
    session.pool = make_sub_pool(g_pool);
    if (session.pool == NULL) {
        exit(1);
    }
    session.notes = pr_table_make(session.pool, 5);

    // A control connection struct is needed, even if it's empty
    session.c = pcalloc(session.pool, sizeof(struct conn_struc));
}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    fuzzer_init();

    if (size < 3) {
        return 0;
    }

    // Use the first byte to determine transfer direction
    int direction = (data[0] % 2 == 0) ? PR_NETIO_IO_RD : PR_NETIO_IO_WR;

    // Use the second byte to set session flags
    uint8_t flags = data[1];

    const uint8_t *payload = data + 2;
    size_t payload_size = size - 2;

    if (payload_size == 0) {
        return 0;
    }

    // Set up a fake data connection using a pipe. This simulates the state
    // that pr_data_open() would normally create, without real networking.
    int fds[2];
    if (pipe(fds) != 0) {
        return 0;
    }

    session.d = pcalloc(session.pool, sizeof(struct conn_struc));
    if (session.d == NULL) {
        close(fds[0]);
        close(fds[1]);
        return 0;
    }
    session.d->p = session.pool;
    session.d->instrm = pr_netio_stream_create(session.pool, fds[0]);
    session.d->outstrm = pr_netio_stream_create(session.pool, fds[1]);

    // Initialize the transfer session
    pr_data_init("fuzz_file", direction);
    
    // Set ASCII transfer flags based on fuzzer input
    session.sf_flags = 0;
    if (flags & 0x01) {
        session.sf_flags |= SF_ASCII;
    }
    if (flags & 0x02) {
        session.sf_flags |= SF_ASCII_OVERRIDE;
    }

    char *cl_buf = (char *)malloc(payload_size);
    if (cl_buf == NULL) {
        pr_data_cleanup();
        // The pipe fds are closed by pr_data_cleanup via stream_close
        return 0;
    }

    if (direction == PR_NETIO_IO_RD) {
        // We are reading from the "network" into cl_buf.
        // Write the fuzzer payload to the pipe so pr_data_xfer can read it.
        write(fds[1], payload, payload_size);
        close(fds[1]); // Close the write end so read() sees EOF

        pr_data_xfer(cl_buf, payload_size);

    } else { // PR_NETIO_IO_WR
        // We are writing from cl_buf to the "network".
        memcpy(cl_buf, payload, payload_size);
        
        pr_data_xfer(cl_buf, payload_size);
        
        // The pipe fds will be closed by pr_data_cleanup.
        // We don't need to read from the pipe, as the write is non-blocking
        // and the cleanup will handle the rest.
    }

    free(cl_buf);
    
    // Clean up the data transfer session, which closes the streams/fds.
    pr_data_cleanup();
    session.d = NULL;

    return 0;
}
