
	
<description>
The function `sf_get_chunk_iterator` is used to retrieve an iterator for chunks within a sound file. A user can either request an iterator for a specific chunk by providing its information in the `chunk_info` argument, or get an iterator for all chunks by passing `NULL` as the `chunk_info` argument. The returned iterator can be used with other functions like `sf_get_chunk_size` and `sf_get_chunk_data` to access the chunk's data. The validity of the iterator is maintained until `sf_next_chunk_iterator` is called.
</description>
<requirements>
<requirement>
The `sndfile` argument must be a valid pointer to a `SNDFILE` struct returned by `sf_open`. This is because the function dereferences this pointer, and a NULL or invalid pointer will lead to a crash.
</requirement>
<requirement>
The `chunk_info` argument can be `NULL`. If it is `NULL`, the function will return an iterator that can be used to iterate over all chunks in the file.
</requirement>
<requirement>
If the `chunk_info` argument is not `NULL`, it must point to a valid `SF_CHUNK_INFO` struct. The `id` member of this struct must be initialized with the identifier of the chunk to be retrieved, as this is used to search for the specific chunk.
</requirement>
<requirement>
To ensure there are chunks to iterate over, the file should be opened in write mode and one or more chunks should be added using `sf_set_chunk` before calling `sf_get_chunk_iterator`. This is because if no chunks are present in the file, the returned iterator will be empty.
</requirement>
</requirements>

#include <stdlib.h>

extern "C" {

extern "C" SF_CHUNK_ITERATOR * sf_get_chunk_iterator(SNDFILE *, const SF_CHUNK_INFO *);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // The chunk data needs to live until sf_close is called.
  std::vector<uint8_t> chunk_data_buffer =
      provider.ConsumeBytes<uint8_t>(provider.ConsumeIntegralInRange<size_t>(0, 512));
  std::string chunk_id_str =
      provider.ConsumeBytesAsString(provider.ConsumeIntegralInRange<size_t>(1, 63));

  SF_CHUNK_INFO chunk_info;
  memset(&chunk_info, 0, sizeof(chunk_info));
  strncpy(chunk_info.id, chunk_id_str.c_str(), sizeof(chunk_info.id) - 1);
  chunk_info.id[sizeof(chunk_info.id) - 1] = '\0';
  chunk_info.id_size = strlen(chunk_info.id);
  chunk_info.datalen = chunk_data_buffer.size();
  chunk_info.data = chunk_data_buffer.data();

  // The rest of the data is for the file content.
  std::vector<uint8_t> file_data = provider.ConsumeRemainingBytes<uint8_t>();
  if (file_data.empty()) {
    return 0;
  }

  VIO_DATA vio_data;
  SF_VIRTUAL_IO vio;
  SF_INFO sndfile_info;
  SNDFILE *sndfile = NULL;

  // Setup VIO from sndfile_fuzz_header.h
  vio.get_filelen = vfget_filelen;
  vio.seek = vfseek;
  vio.read = vfread;
  vio.write = vfwrite;
  vio.tell = vftell;

  vio_data.data = file_data.data();
  vio_data.length = file_data.size();
  vio_data.offset = 0;

  memset(&sndfile_info, 0, sizeof(SF_INFO));

  // Open in RDWR mode to allow setting chunks.
  sndfile = sf_open_virtual(&vio, SFM_RDWR, &sndfile_info, &vio_data);

  if (sndfile) {
    // Set a chunk. This may fail depending on file format and state.
    sf_set_chunk(sndfile, &chunk_info);

    // Fuzz the target function with the created chunk info.
    SF_CHUNK_ITERATOR *iterator = sf_get_chunk_iterator(sndfile, &chunk_info);
    if (iterator) {
        // To improve coverage, we can iterate through the chunks.
        sf_next_chunk_iterator(iterator);
    }

    // Fuzz the target function with NULL to get all chunks.
    SF_CHUNK_ITERATOR *all_iterator = sf_get_chunk_iterator(sndfile, NULL);
    if (all_iterator) {
        sf_next_chunk_iterator(all_iterator);
    }

    sf_close(sndfile);
  }

  return 0;
}
