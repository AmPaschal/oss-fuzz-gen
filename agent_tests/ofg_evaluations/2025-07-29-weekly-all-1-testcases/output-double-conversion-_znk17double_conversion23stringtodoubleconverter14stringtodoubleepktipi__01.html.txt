
	
<description>
The `StringToDouble` function converts a string of 16-bit unsigned characters (`uc16`) into a double-precision floating-point number. It is a member function of the `StringToDoubleConverter` class. The conversion process is highly configurable through the flags and other parameters passed to the `StringToDoubleConverter` constructor. The function can handle decimal, hexadecimal, and octal number formats, as well as special strings for infinity and NaN. It also allows for configurable handling of whitespace and case sensitivity. The core logic is implemented in the private `StringToIeee` function, which `StringToDouble` calls with `read_as_double` set to `true`.
</description>

The `infinity_symbol` and `nan_symbol` arguments to the `StringToDoubleConverter` constructor can be fuzzed with various string values. This allows testing of the parsing of special floating-point values.
