
	
<description>
The function `is_legal_2d_block_size` checks if a given 2D block size, specified by its dimensions `xdim` and `ydim`, is one of the legal block sizes supported by the ASTC texture compression format. It does this by combining the x and y dimensions into a 16-bit integer and comparing it against a list of hardcoded valid values. The function is called from within the astc-encoder library to validate block sizes before processing them.
</description>
<requirements>
<requirement>
The `xdim` and `ydim` arguments must be one of the following pairs to be considered a legal block size: (4,4), (5,4), (5,5), (6,5), (6,6), (8,5), (8,6), (8,8), (10,5), (10,6), (10,8), (10,10), (12,10), (12,12). This is necessary for the function to return true and avoid an error condition in its caller.
</requirement>
<requirement>
The input arguments `xdim` and `ydim` should be fuzzed. The caller does not constrain the values, and fuzzing will help to ensure that only the legal block sizes are accepted.
</requirement>
</requirements>
