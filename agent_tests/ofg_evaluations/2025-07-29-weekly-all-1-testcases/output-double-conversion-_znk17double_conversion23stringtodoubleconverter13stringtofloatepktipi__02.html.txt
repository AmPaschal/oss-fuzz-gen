
	
<description>
The `double_conversion::StringToDoubleConverter::StringToFloat` function is a wrapper around the `StringToIeee` function. It converts a string of `uc16` characters into a single-precision floating-point number. The function is highly configurable through flags provided during the `StringToDoubleConverter` object's construction. These flags control the handling of whitespace, special values like "Infinity" and "NaN", and different number bases like hexadecimal and octal. The function is robust to a wide range of inputs and will report the number of characters it has processed.
</description>
<requirements>
<requirement>
The `length` argument must be less than or equal to the actual size of the `buffer`. This is to prevent out-of-bounds memory access, as the function calculates the end of the buffer by adding `length` to the `buffer` pointer.
</requirement>
<requirement>
The `processed_characters_count` argument must be a valid pointer to an integer. The function writes the number of characters consumed from the buffer to this address, and a NULL pointer would cause a crash.
</requirement>
<requirement>
The `buffer` can be initialized with a wide range of string representations of numbers. To achieve high code coverage, the fuzzer should generate strings representing decimal, hexadecimal, and octal numbers, as well as special values like "Infinity" and "NaN".
</requirement>
</requirements>

#include <cstddef>
#include <cstdint>

#include "/src/double-conversion/double-conversion/string-to-double.h"

using double_conversion::StringToDoubleConverter;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  StringToDoubleConverter converter(
      StringToDoubleConverter::ALLOW_HEX |
          StringToDoubleConverter::ALLOW_OCTALS |
          StringToDoubleConverter::ALLOW_TRAILING_JUNK |
          StringToDoubleConverter::ALLOW_LEADING_SPACES |
          StringToDoubleConverter::ALLOW_TRAILING_SPACES |
          StringToDoubleConverter::ALLOW_SPACES_AFTER_SIGN |
          StringToDoubleConverter::ALLOW_CASE_INSENSIBILITY |
          StringToDoubleConverter::ALLOW_HEX_FLOATS,
      /*empty_string_value=*/0.0,
      /*junk_string_value=*/0.0, "inf", "nan");

  const uc16* buffer = reinterpret_cast<const uc16*>(data);
  int length = size / sizeof(uc16);

  int processed_characters_count;
  converter.StringToFloat(buffer, length, &processed_characters_count);

  return 0;
}
