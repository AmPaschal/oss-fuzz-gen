
	
<description>
The `opus_decode_float` function decodes an Opus packet into 16-bit signed PCM samples. It is a wrapper around the `opus_decode_native` function. The function first checks for a valid `frame_size` and then calls the native decoding function. For the non-fixed-point build, it determines the number of samples in the packet, allocates a temporary buffer, calls `opus_decode_native`, and then converts the output to float.
</description>
<requirements>

<requirement>
The `OpusDecoder` instance `st` must be created and initialized using `opus_decoder_create`. This is because `opus_decode_float` relies on the initialized state of the `OpusDecoder` structure, which is handled by `opus_decoder_create`.
</requirement>
<requirement>
The `channels` field of the `OpusDecoder` struct must be 1 or 2. This is enforced by an assertion within the function.
</requirement>
<requirement>
The `Fs` (sample rate) field of the `OpusDecoder` struct must be one of 8000, 12000, 16000, 24000, or 48000. These are the only sample rates supported by the decoder.
</requirement>
<requirement>
The `data` argument should be a fuzzed byte array, or NULL to test packet loss concealment. The function is designed to handle potentially malformed input packets.
</requirement>
<requirement>
The `pcm` buffer must be large enough to hold `frame_size * st->channels` samples. The maximum frame size is 120ms of audio, which at 48kHz corresponds to 5760 samples.
</requirement>
<requirement>
The `frame_size` argument must be a positive integer. A value less than or equal to zero will cause the function to return `OPUS_BAD_ARG`.
</requirement>
<requirement>
The `decode_fec` argument must be either 0 or 1. Any other value will result in an error.
</requirement>

</requirements>

	Fuzz target source:
#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <vector>

#include "/src/opus/include/opus.h"

// Define opus_val16 if not defined (for float builds)
#ifndef opus_val16
#define opus_val16 float
#endif

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  const opus_int32 kSampleRates[] = {8000, 12000, 16000, 24000, 48000};
  const opus_int32 Fs = provider.PickValueInArray(kSampleRates);
  const int channels = provider.ConsumeIntegralInRange<int>(1, 2);

  int err;
  OpusDecoder *decoder = opus_decoder_create(Fs, channels, &err);
  if (err != OPUS_OK || decoder == nullptr) {
    return 0;
  }

  // Max frame size is 120ms at 48kHz
  const int frame_size = provider.ConsumeIntegralInRange<int>(1, 5760);
  const int decode_fec = provider.ConsumeBool();

  std::vector<opus_val16> pcm(frame_size * channels);

  if (provider.ConsumeBool()) {
    // Test packet loss concealment
    opus_decode_float(decoder, nullptr, 0, pcm.data(), frame_size, decode_fec);
  } else {
    std::vector<uint8_t> packet = provider.ConsumeRemainingBytes<uint8_t>();
    if (!packet.empty()) {
      opus_decode_float(decoder, packet.data(),
                        static_cast<opus_int32>(packet.size()), pcm.data(),
                        frame_size, decode_fec);
    }
  }

  opus_decoder_destroy(decoder);
  return 0;
}
