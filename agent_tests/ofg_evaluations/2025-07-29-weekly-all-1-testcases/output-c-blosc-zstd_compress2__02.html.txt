
	
<description>
The ZSTD_compress2 function compresses a block of data. It takes a compression context, a destination buffer, the destination buffer's capacity, a source buffer, and the source buffer's size as input. The function returns the compressed size on success, or an error code if compression fails. The primary use case is to perform a single-shot compression of a given input buffer.
</description>
<requirements>

<requirement>
The ZSTD_CCtx object must be created by calling ZSTD_createCCtx(). This is because ZSTD_createCCtx() allocates and initializes the context needed for compression.
</requirement>
<requirement>
The dstCapacity argument must be at least ZSTD_compressBound(srcSize). This is to ensure that the destination buffer is large enough to hold the compressed data in the worst-case scenario.
</requirement>
<requirement>
The srcSize argument must be less than or equal to ZSTD_MAX_INPUT_SIZE. This is because ZSTD_compressBound() can fail if srcSize is larger than this value, leading to an error.
</requirement>
<requirement>
The src and dst pointers must not be NULL. This is to prevent null pointer dereferences within the function or its callees.
</requirement>

</requirements>

 * Mitigate compilation error: 'ZSTD_CONTENTSIZE_MAX' is not always defined
 * when building the fuzzer, likely due to a build system configuration issue.

#ifndef ZSTD_CONTENTSIZE_MAX
#define ZSTD_CONTENTSIZE_MAX (0x80000000U)
#endif

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    /* Per documentation, srcSize must be <= ZSTD_CONTENTSIZE_MAX. */
    if (size > ZSTD_CONTENTSIZE_MAX) {
        return 0;
    }

    ZSTD_CCtx* const cctx = ZSTD_createCCtx();
    if (cctx == NULL) {
        /* Cannot create context, cannot proceed. */
        return 0;
    }

    /* Ensure dst buffer is large enough */
    size_t const dstCapacity = ZSTD_compressBound(size);
    void* const dst = malloc(dstCapacity);
    if (dst == NULL) {
        /* Failed to allocate memory, free context and exit. */
        ZSTD_freeCCtx(cctx);
        return 0;
    }

    /*
     * Call the function under test.
     * The return value is the compressed size or an error code,
     * which we don't need to check for this fuzz target.
     */
    ZSTD_compress2(cctx, dst, dstCapacity, data, size);

    /* Clean up allocated resources */
    free(dst);
    ZSTD_freeCCtx(cctx);

    return 0;
}
