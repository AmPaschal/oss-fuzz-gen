
	
<description>
The `tidyParseSource` function is a core function in the Tidy HTML library responsible for parsing an input source. It takes a `TidyDoc` handle and a pointer to a `TidyInputSource` struct. The `TidyInputSource` struct contains callbacks for reading bytes from the input, allowing for flexible input sources such as files, memory buffers, or custom streams. The function reads from the input source, parses the content as HTML, and populates the `TidyDoc` with the parsed document tree. The actual parsing is delegated to the internal function `tidyDocParseSource`.
</description>
<requirements>

<requirement>
The `TidyDoc` argument must be a valid handle created by `tidyCreate()`. This is because `tidyParseSource` internally converts the `TidyDoc` to a `TidyDocImpl` and uses its internal fields, so an invalid handle will lead to a crash.
</requirement>
<requirement>
The `source` argument must be a non-NULL pointer to a `TidyInputSource` struct. The `getByte`, `ungetByte` and `eof` members of the struct must be initialized with valid function pointers, as they are dereferenced and called during parsing. This can be achieved by using functions like `initSource` or `initFileSource`.
</requirement>
<requirement>
The `sourceData` member of the `TidyInputSource` struct should be initialized to a valid source for the provided callbacks. For example, when using file-based callbacks from `initFileSource`, `sourceData` must be a valid, opened `FILE` pointer.
</requirement>
<requirement>
The `TidyInputSource` should be initialized with data that is representative of real-world HTML, including malformed and unusual constructs. This is to ensure that the fuzzer explores a wide range of parsing paths and potential vulnerabilities.
</requirement>

</requirements>

#include "/src/tidy-html5/include/tidy.h"
#include "/src/tidy-html5/include/tidybuffio.h"
#include <stdint.h>
#include <stdlib.h>

// Custom data structure to hold the fuzzer input state.
typedef struct {
  const uint8_t *data;
  size_t size;
  size_t offset;
} FuzzSource;

// Callback to get the next byte from the fuzzer input.
static int get_byte(void *sourceData) {
  FuzzSource *source = (FuzzSource *)sourceData;
  if (source->offset < source->size) {
    return source->data[source->offset++];
  }
  return -1; // EOF
}

// Callback to "unget" a byte (move the offset back).
static void unget_byte(void *sourceData, byte bt) {
  FuzzSource *source = (FuzzSource *)sourceData;
  if (source->offset > 0) {
    source->offset--;
  }
}

// Callback to check if we are at the end of the fuzzer input.
static Bool is_eof(void *sourceData) {
  FuzzSource *source = (FuzzSource *)sourceData;
  return source->offset >= source->size ? yes : no;
}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size == 0) {
    return 0;
  }

  // Initialize the Tidy document
  TidyDoc tdoc = tidyCreate();
  TidyBuffer errbuf;
  tidyBufInit(&errbuf);
  tidySetErrorBuffer(tdoc, &errbuf);

  // Set up our custom input source to read from the fuzzer's data buffer
  FuzzSource fuzz_source;
  fuzz_source.data = data;
  fuzz_source.size = size;
  fuzz_source.offset = 0;

  TidyInputSource tis;
  tis.sourceData = &fuzz_source;
  tis.getByte = get_byte;
  tis.ungetByte = unget_byte;
  tis.eof = is_eof;

  // Call the function under test
  tidyParseSource(tdoc, &tis);

  // It's good practice to also run clean/repair and save to exercise more code.
  tidyCleanAndRepair(tdoc);
  TidyBuffer output;
  tidyBufInit(&output);
  tidySaveBuffer(tdoc, &output);

  // Cleanup
  tidyBufFree(&output);
  tidyBufFree(&errbuf);
  tidyRelease(tdoc);

  return 0;
}
