
	
<description>
The function `YaHTTP::operator<<` is an overloaded operator that streams a `YaHTTP::Response` object to an `ostream`. It accomplishes this by calling the `write` method of the `Response` object. The `write` method constructs a standard HTTP response, including the status line, headers, and body, and writes it to the provided `ostream`. The HTTP version, status code, headers, and body are all taken from the `Response` object. If the HTTP version is 1.1 or greater and the `Content-Length` header is not set, the response will be sent with chunked transfer encoding.
</description>
