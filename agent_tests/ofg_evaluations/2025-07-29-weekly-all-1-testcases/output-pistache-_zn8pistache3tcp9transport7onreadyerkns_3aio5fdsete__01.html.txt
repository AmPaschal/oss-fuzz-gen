
	
<description>
The `onReady` function is the central event handler for the `Pistache::Tcp::Transport` class. It is invoked by the `Reactor` when I/O events are detected on the file descriptors managed by the transport. The function processes an `Aio::FdSet` object, which contains a collection of events, and dispatches each event to the appropriate handler based on its associated tag and flags. This includes handling events from internal queues for writes, timers, and peers, as well as notifications, incoming data from peers, timer expirations, and writable sockets.
</description>

</requirement>
<requirement>

The event flags should indicate readability to ensure the respective `handle...Queue` or `handleNotify` functions are called.
</requirement>
<requirement>
For testing peer-related logic, a `Peer` object should be added to the `Transport`'s peer list via `addPeer`. The `FdSet` must then include a `Polling::Event` with the peer's file descriptor as its tag and the readable flag set, which is necessary to trigger the `handleIncoming` function.
</requirement>
<requirement>
To validate timer handling, a timer should be armed using `armTimer`, and the `FdSet` must contain a `Polling::Event` with the timer's file descriptor as its tag and the readable flag set. This ensures that the `handleTimer` logic is executed.
</requirement>
<requirement>
To test the writable event logic, an entry must be present in the `toWrite` map of the `Transport` object. The `FdSet` should include a `Polling::Event` with the corresponding file descriptor as its tag and the writable flag set, which is required to test the `asyncWriteImpl` code path.
</requirement>
