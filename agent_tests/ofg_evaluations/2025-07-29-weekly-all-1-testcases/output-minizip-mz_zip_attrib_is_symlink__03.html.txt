
	
<description>
The function `mz_zip_attrib_is_symlink` checks if a given file attribute from a zip entry corresponds to a symbolic link. It takes two arguments: `attrib`, the 32-bit external file attributes, and `version_madeby`, an integer indicating the host system that created the zip archive. The function first determines the host system from the `version_madeby` argument. It then calls `mz_zip_attrib_convert` to convert the `attrib` from the source host system's format to the UNIX format. If the conversion is successful, it checks if the converted attribute has the `S_IFLNK` flag set, which indicates a symbolic link. It returns `MZ_OK` if it is a symbolic link and `MZ_EXIST_ERROR` otherwise. The only caller of this function is `mz_zip_entry_is_symlink`, which gets the arguments from a `mz_zip` struct after a zip entry has been scanned.
</description>
<requirements>
<requirement>
The `version_madeby` parameter must be a value such that `(version_madeby >> 8)` results in one of the following values: `MZ_HOST_SYSTEM_MSDOS` (0), `MZ_HOST_SYSTEM_UNIX` (3), `MZ_HOST_SYSTEM_WINDOWS_NTFS` (10), `MZ_HOST_SYSTEM_RISCOS` (13) or `MZ_HOST_SYSTEM_OSX_DARWIN` (19). This is to ensure that the `mz_zip_attrib_convert` function can successfully convert the attributes to the UNIX format.
</requirement>
<requirement>
The `attrib` parameter should be a valid file attribute from a supported host system, and for the function to return `MZ_OK`, it should represent a symbolic link. This is because the function's primary purpose is to identify symbolic links by converting the provided attributes to the POSIX format and checking for the `S_IFLNK` flag.
</requirement>
