
	
<description>
The function `buffer_append_base64_enc` appends a base64-encoded string to a buffer. It is a wrapper around `li_base64_enc`, which performs the actual encoding. Callers use this function through the `buffer_append_base64_encode` and `buffer_append_base64_encode_no_padding` macros, which control the padding.
</description>
<requirements>
<requirement>
The `out` buffer must be initialized. This is because the function writes the encoded string to this buffer.
</requirement>
<requirement>
The `in` argument should be a fuzzed byte stream. This is the input that is being encoded.
</requirement>
<requirement>
The `in_length` argument should be the length of the `in` buffer. This is used to control how much of the input buffer is read.
</requirement>
<requirement>
The `charset` argument should be either `BASE64_STANDARD` or `BASE64_URL`. These are the only two values used in the codebase.
</requirement>
<requirement>
The `pad` argument should be either 0 or 1. These are the only two values used by the wrapper macros.
</requirement>
</requirements>
