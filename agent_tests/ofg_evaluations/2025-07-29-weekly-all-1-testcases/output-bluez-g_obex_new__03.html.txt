
	
<description>
The `g_obex_new` function creates a new `GObex` object, which represents an OBEX session. It initializes the object with the provided I/O channel, transport type, and MTU sizes. The function allocates memory for the `GObex` structure, sets up internal read and write handlers based on the specified transport type, and establishes a watch on the `GIOChannel` to handle incoming data. On success, it returns a pointer to the newly created `GObex` object; on failure, it returns `NULL`. This function is fundamental for initiating any OBEX communication, and the returned object is used in all subsequent OBEX operations.
</description>

</requirement>

</requirement>
