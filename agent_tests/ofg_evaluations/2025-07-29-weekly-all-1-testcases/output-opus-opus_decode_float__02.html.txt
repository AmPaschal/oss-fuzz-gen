
	
<description>
The function opus_decode_float decodes an Opus packet into float samples. It is a wrapper around the opus_decode_native function. The function first performs some basic argument checks, such as ensuring that the frame_size is positive. It then calls opus_decoder_get_nb_samples to determine the number of samples in the packet, and finally calls opus_decode_native to perform the actual decoding. The decoded samples are then converted to float and stored in the pcm buffer.
</description>

</requirement>
<requirement>
The fourth argument, `pcm`, must be a pointer to a buffer large enough to hold the decoded audio samples. The required size is at least `frame_size` * channels * sizeof(opus_val16), where channels is a member of the OpusDecoder struct.
</requirement>
<requirement>
The fifth argument, `frame_size`, must be greater than zero. A non-positive value will cause the function to return an error code without attempting to decode the packet.
</requirement>
<requirement>
The sixth argument, `decode_fec`, is a flag that indicates whether to decode forward error correction data. It should be either 0 or 1. This is important for testing the FEC decoding logic.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <vector>

#include "/src/opus/include/opus.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider stream(data, size);

  const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  const opus_int32 f_s = stream.PickValueInArray(sample_rates);
  const int channels = stream.ConsumeIntegralInRange<int>(1, 2);

  int err;
  OpusDecoder *decoder = opus_decoder_create(f_s, channels, &err);
  if (err != OPUS_OK || decoder == nullptr) {
    return 0;
  }

  // A frame size of 120ms is the maximum supported.
  // 120 * 48000 / 1000 = 5760.
  const int frame_size = stream.ConsumeIntegralInRange<int>(1, 5760);
  const int decode_fec = stream.ConsumeBool();

  std::vector<uint8_t> input_packet = stream.ConsumeRemainingBytes<uint8_t>();
  const opus_int32 len = static_cast<opus_int32>(input_packet.size());

  std::vector<float> pcm(frame_size * channels);

  opus_decode_float(decoder, input_packet.data(), len, pcm.data(), frame_size,
                    decode_fec);

  opus_decoder_destroy(decoder);

  return 0;
}
