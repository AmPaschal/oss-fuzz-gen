
	
<description>
The function `StringToDouble` is a member of the `StringToDoubleConverter` class. It converts a string of 16-bit unsigned characters (`uc16`) into a double-precision floating-point number. The conversion behavior is highly customizable through the `StringToDoubleConverter`'s constructor, which accepts flags and special values to handle various input formats, such as hexadecimal or octal numbers, and to specify custom representations for infinity and NaN.
</description>

</requirement>
<requirement>
The `StringToDoubleConverter` constructor should be called with a valid `flags` argument. The flags control parsing options like allowing hex/octal numbers, leading/trailing whitespace, and case insensitivity.
</requirement>
<requirement>
The `buffer` argument, which is a pointer to a `uc16` array, must not be null. A null buffer will cause a crash when the function attempts to dereference it.
</requirement>
<requirement>
The `length` argument must be a non-negative integer representing the number of elements in the `buffer`. A negative length will lead to undefined behavior.
</requirement>
<requirement>
The `processed_characters_count` argument must be a valid pointer to an integer. The function writes the number of processed characters to this location, so a null pointer will cause a crash.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <vector>

#include "/src/double-conversion/double-conversion/string-to-double.h"

using double_conversion::StringToDoubleConverter;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  StringToDoubleConverter converter(
      StringToDoubleConverter::ALLOW_HEX |
          StringToDoubleConverter::ALLOW_OCTALS |
          StringToDoubleConverter::ALLOW_TRAILING_JUNK |
          StringToDoubleConverter::ALLOW_LEADING_SPACES |
          StringToDoubleConverter::ALLOW_TRAILING_SPACES |
          StringToDoubleConverter::ALLOW_SPACES_AFTER_SIGN |
          StringToDoubleConverter::ALLOW_CASE_INSENSIBILITY |
          StringToDoubleConverter::ALLOW_HEX_FLOATS,
      /*empty_string_value=*/0.0,
      /*junk_string_value=*/0.0, "inf", "nan");

  int processed_characters_count;
  std::vector<uint8_t> text_bytes = provider.ConsumeRemainingBytes<uint8_t>();
  
  const uc16* text_data = reinterpret_cast<const uc16*>(text_bytes.data());
  int text_length = text_bytes.size() / sizeof(uc16);

  if (text_length > 0) {
    converter.StringToDouble(text_data, text_length,
                             &processed_characters_count);
  }
  
  return 0;
}
