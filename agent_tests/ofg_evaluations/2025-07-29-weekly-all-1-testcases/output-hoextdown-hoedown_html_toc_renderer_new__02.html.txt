
	
<description>
The `hoedown_html_toc_renderer_new` function creates a new `hoedown_renderer` object specifically for rendering a table of contents (TOC) in HTML. It allocates memory for the renderer and its associated state, initializes the state with the provided `nesting_level`, and sets up a series of callback functions for rendering different elements of the markdown document. The `nesting_level` parameter determines the maximum depth of headers that will be included in the TOC. The caller is responsible for freeing the returned renderer using `hoedown_html_renderer_free`.
</description>
<requirements>
<requirement>
The `nesting_level` argument should be a non-negative integer. This is because it represents the maximum level for headers in the Table of Contents, and negative values are not meaningful in this context and may lead to unexpected behavior.
</requirement>
<requirement>
The caller must free the returned `hoedown_renderer` object by calling `hoedown_html_renderer_free`. This is to prevent memory leaks, as `hoedown_html_toc_renderer_new` allocates memory for the renderer and its state.
</requirement>
