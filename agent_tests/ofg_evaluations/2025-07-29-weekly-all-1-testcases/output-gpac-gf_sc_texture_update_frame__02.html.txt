
	
<description>
The function `gf_sc_texture_update_frame` is responsible for updating a texture from a media stream. It fetches a new frame from the stream, and if a new frame is available, it updates the texture data and marks it for refresh. The function is designed to be called repeatedly to animate textures in a scene.
</description>
<requirements>

<requirement>
The first argument, `txh`, must be a valid pointer to a `GF_TextureHandler` struct that has been initialized by `gf_sc_texture_setup`. This is because the function accesses several members of this struct, including `txh->stream` and `txh->compositor`, which are expected to be non-NULL.
</requirement>
<requirement>
The `txh->stream` member of the `GF_TextureHandler` struct must be a valid pointer to a `GF_MediaObject`. This is because the function calls `gf_mo_fetch_data` with this stream to get the texture data. This can be initialized by calling `gf_sc_texture_open` and `gf_sc_texture_play_from_to`.
</requirement>
<requirement>
The second argument, `disable_resync`, should be a boolean value (GF_TRUE or GF_FALSE). This value is passed to the `gf_mo_fetch_data` function and controls whether the stream is resynchronized.
</requirement>

</requirements>
