The `kex_gen_server` function is a server-side key exchange handler in the hpn-ssh library. It is not called directly, but rather assigned as a function pointer to a table of key exchange methods within an `ssh` struct. Its primary purpose is to register a handler for the `SSH2_MSG_KEX_ECDH_INIT` message, advancing the state of the key exchange protocol. For this function to be invoked correctly, the `ssh` struct must be properly initialized as a server, and host keys must be configured.
</description>

</requirement>

</requirement>
<requirement>
A host key must be generated and added to the `ssh` struct using `ssh_add_hostkey`. The key exchange process, of which `kex_gen_server` is a part, requires a host key to authenticate the server.
</requirement>
<requirement>
The `ssh` pointer passed to `kex_gen_server` must not be NULL. A NULL pointer would lead to a crash due to dereferencing a null pointer inside the function.
</requirement>
