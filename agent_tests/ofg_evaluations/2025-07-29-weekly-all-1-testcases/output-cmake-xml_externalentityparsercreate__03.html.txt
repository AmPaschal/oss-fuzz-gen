
	
<description>
The function `XML_ExternalEntityParserCreate` creates a new parser that is specialized for parsing external entities. This new parser inherits many of its settings from an existing parser, `oldParser`. The `context` and `encodingName` arguments are used to initialize the new parser with the correct context and character encoding for the external entity. The created parser is a child of the `oldParser`.
</description>
<requirements>
<requirement>
The `oldParser` argument must be a valid, non-NULL pointer to an `XML_Parser` struct. This is because the function directly dereferences it to access its members, and a NULL value will lead to a crash.
</requirement>
<requirement>
The `oldParser` must be initialized by `XML_ParserCreate`. This ensures the parser's internal state, particularly its memory handling functions, is set up correctly for creating the new external entity parser.
</requirement>
<requirement>
The `context` argument should be a null-terminated string. This string is used to set the parsing context, which is important for correctly handling namespaces and other XML features within the external entity.
</requirement>
<requirement>
The `encodingName` argument should be a null-terminated string specifying a valid character encoding (e.g., 'UTF-8', 'US-ASCII'). This is crucial for the new parser to correctly interpret the byte stream of the external entity.
</requirement>
<requirement>
The `encodingName` argument can be NULL. If `encodingName` is NULL, the parser will use a default encoding, so this is a valid and important test case.
</requirement>
</requirements>
