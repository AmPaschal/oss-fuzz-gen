The `clib_package_install` function is responsible for installing a clib package. It takes a `clib_package_t` object, an installation directory, and a verbosity flag as input. The function first checks if the package has already been installed. If not, it creates a directory for the package, downloads the package's source files, and then executes any installation scripts specified in the package's manifest file. The `pkg` argument should be created using the `clib_package_new_from_slug` function, which takes a slug of the form `author/repo@version` as input.
</description>

</requirement>
<requirement>

</requirement>
