
	
<description>
The function `mutt_get_postponed` retrieves a postponed email message. It takes a current mailbox `m_cur`, an email header `hdr` to be populated, a pointer `cur` to store a reference to an email, and a buffer `fcc` to store the Fcc (carbon copy) path. The function first finds the "postponed" mailbox. If this mailbox is different from `m_cur`, it opens it. It then checks if there are any messages in the postponed mailbox. If there is only one message, it selects it automatically. If there are multiple messages, it presents a dialog (`dlg_postponed`) for the user to choose one. After selecting an email, it prepares it as a template using `mutt_prepare_template`, marks the original postponed message for deletion, and then processes the headers of the retrieved email. It looks for specific "Mutt-" headers (`Mutt-References`, `Mutt-Fcc`, `Mutt-PGP`, `Mutt-SMIME`) to set up the reply context, the Fcc path, and cryptography settings in the `hdr` structure. Finally, it performs some cleanup and returns. The primary caller, `mutt_send_message`, uses this function to implement the "recall postponed message" feature. It creates a new `Email` struct and a `Buffer` and passes them to `mutt_get_postponed`. The information retrieved by `mutt_get_postponed` is then used to compose a new email based on the postponed one.
</description>

The global variable `NeoMutt->sub` must be initialized before calling this function. This is because the function uses `cs_subset_string` and `cs_subset_quad` to access configuration settings from this structure.
</requirement>
<requirement>
The configuration option "postponed" must be set to a valid mailbox path. The function uses this path to locate and open the mailbox containing postponed messages.
</requirement>
<requirement>
The `hdr` parameter must be a pointer to a valid `struct Email` object, and its `env` member must also be a valid pointer. The function accesses and modifies members of both `hdr` and `hdr->env`. The caller `mutt_send_message` initializes `hdr` using `email_new()` and `hdr->env` with `mutt_env_new()`.
</requirement>
<requirement>
The `cur` parameter must be a valid pointer to a `struct Email*`. This is because the function writes to `*cur` to return a pointer to the selected email.
</requirement>
<requirement>
The `fcc` parameter must be a pointer to a valid `struct Buffer` object. The function writes the Fcc path into this buffer using `buf_strcpy`. The caller `mutt_send_message` initializes it using `buf_pool_get()`.
</requirement>
<requirement>
The `m_cur` parameter can be NULL. The function contains a check `if (m_cur != m)` and later `if (m_cur)` which shows it can handle a NULL `m_cur`.
</requirement>
<requirement>
The postponed mailbox should contain at least one message. If the mailbox is empty, the function will display an error and return -1.
</requirement>
</requirements>
