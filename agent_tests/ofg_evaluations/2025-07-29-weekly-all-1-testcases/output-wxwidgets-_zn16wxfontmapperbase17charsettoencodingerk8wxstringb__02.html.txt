
	
<description>
The function `wxFontMapperBase::CharsetToEncoding` maps a given charset string to a `wxFontEncoding` enumeration value. It is a wrapper around `NonInteractiveCharsetToEncoding`, which performs the actual lookup. The lookup is done by consulting a configuration, which can be customized. To function correctly, the wxWidgets library must be initialized, which sets up the necessary application traits and allows for the creation of a `wxFontMapper` instance. Without proper initialization, the function will fail to obtain a font mapper instance.
</description>
<requirements>
<requirement>
An instance of the `wxInitializer` class must be created before calling the target function. This ensures that the wxWidgets library is properly initialized, which is a prerequisite for creating and using the `wxFontMapper` instance that the function relies on.
</requirement>
<requirement>
The `charset` parameter, a `wxString`, should be fuzzed with a variety of valid and invalid character set names. This is the primary input to the function, and testing with a wide range of values, including those from the `fontmaptest.cpp` test case (e.g., "us-ascii", "iso8859-1", "koi8-r", as well as empty or malformed strings), is crucial for achieving high coverage.
</requirement>
<requirement>
The `interactive` boolean parameter can be set to either `true` or `false` as it is not used by the function. The implementation forwards the call to a non-interactive version of the function, so this parameter has no effect on the execution flow.
</requirement>
</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    // wxFontMapper requires a wxApp instance to be created.
    // wxInitializer does this for us. In a --disable-gui build,
    // this creates a wxAppConsole.
    wxInitializer initializer;
    if ( !initializer.IsOk() )
    {
        return 0;
    }

    FuzzedDataProvider provider(data, size);

    const std::string charset_str = provider.ConsumeRemainingBytesAsString();
    const wxString charset(charset_str.c_str(), wxConvUTF8);
    const bool interactive = provider.ConsumeBool();

    wxFontMapperBase *mapper = wxFontMapperBase::Get();
    if (mapper)
    {
        mapper->CharsetToEncoding(charset, interactive);
    }

    return 0;
}
