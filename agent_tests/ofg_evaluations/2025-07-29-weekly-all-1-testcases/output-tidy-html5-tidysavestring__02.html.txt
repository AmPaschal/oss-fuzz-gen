
	
<description>
The tidySaveString function saves the contents of a TidyDoc document to the provided buffer. It acts as a wrapper for the tidyDocSaveString function, which performs the actual saving operation. Before calling this function, a TidyDoc object must be created and populated with HTML content. The function takes the TidyDoc, a buffer to save to, and a pointer to the length of the buffer. After the function call, the value pointed to by the length pointer is updated to the number of bytes written to the buffer.
</description>
<requirements>
<requirement>
A TidyDoc object must be created by calling `tidyCreate()` and subsequently released by calling `tidyRelease()`. This ensures proper initialization and cleanup of the document object.
</requirement>
<requirement>
The `tidyParseString()` function must be called to parse an HTML string and populate the TidyDoc object before calling `tidySaveString()`. This is because the save function needs content to write to the buffer.
</requirement>
<requirement>
The `buffer` argument must point to a valid, writable memory location. This is to avoid a crash when the function attempts to write the saved document to the buffer.
</requirement>
<requirement>
The `buflen` argument must be a valid pointer to a `uint` that holds the size of the `buffer`. The function uses this to check if the provided buffer is large enough and to report the final size of the saved string.
</requirement>
</requirements>
