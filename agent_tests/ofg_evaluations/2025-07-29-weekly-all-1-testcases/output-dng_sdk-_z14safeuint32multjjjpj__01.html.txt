
	
<description>
The function `SafeUint32Mult` multiplies three 32-bit unsigned integers (`arg1`, `arg2`, `arg3`) and stores the result in the memory location pointed to by `result`. It is designed to be safe against arithmetic overflow. The function performs the multiplication in two steps: first `arg1 * arg2`, and then the result of that is multiplied by `arg3`. If either of these multiplications would result in a value larger than can be stored in a `uint32_t`, the function catches a `dng_exception` internally and returns `false`. If the multiplication is successful, the final product is stored in `*result` and the function returns `true`. The core purpose of this function is to provide a safe way to perform multiplication without the risk of silent integer wraparound, which could lead to security vulnerabilities or program errors in downstream code.
</description>
<requirements>
<requirement>
The result parameter must be a valid pointer to a uint32_t variable. The function writes to this pointer without a null check, so a null pointer would cause a crash.
</requirement>
<requirement>
The input arguments arg1, arg2, and arg3 should be fuzzed with a wide range of values. This is to test the function's primary purpose, which is to correctly handle cases both with and without arithmetic overflow.
</requirement>
</requirements>

bool SafeUint32Mult(uint32_t, uint32_t, uint32_t, uint32_t *);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  uint32_t arg1 = provider.ConsumeIntegral<uint32_t>();
  uint32_t arg2 = provider.ConsumeIntegral<uint32_t>();
  uint32_t arg3 = provider.ConsumeIntegral<uint32_t>();

  uint32_t result;

  SafeUint32Mult(arg1, arg2, arg3, &result);

  return 0;
}
