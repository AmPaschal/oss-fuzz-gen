
	
<description>
The `kex_gen_client` function is responsible for generating the client-side key exchange pair. The function is dispatched based on the `kex_type` field of the `kex` structure. It calls the appropriate key generation function for the selected key exchange method and then sends the public key to the server using `sshpkt_start`, `sshpkt_put_stringb`, and `sshpkt_send`. The function is a critical part of the SSH key exchange process and is called after the initial connection setup and protocol negotiation.
</description>
<requirements>

<requirement>
The `ssh` structure must be initialized by calling `ssh_alloc_session_state` and `ssh_packet_set_connection`. This is necessary to set up the basic data structures and file descriptors for the SSH session.
</requirement>
<requirement>
The `kex` member of the `ssh` structure must be initialized by calling `kex_new` and then `kex_setup`. `kex_new` allocates the `kex` structure, and `kex_setup` populates it based on the client and server proposals.
</requirement>
<requirement>
The `kex->kex_type` field must be set to one of the following values: `KEX_DH_GRP1_SHA1`, `KEX_DH_GRP14_SHA1`, `KEX_DH_GRP14_SHA256`, `KEX_DH_GRP16_SHA512`, `KEX_DH_GRP18_SHA512`, `KEX_ECDH_SHA2`, `KEX_C25519_SHA256`, `KEX_KEM_SNTRUP761X25519_SHA512`, or `KEX_KEM_MLKEM768X25519_SHA256`. The function uses a switch statement on this value, and providing any other value will result in an error.
</requirement>
<requirement>
The `kex->client_pub` field must be a valid, allocated `sshbuf`. This buffer is populated by the various `kex_*_keypair` functions and then sent to the server. Failure to allocate it will lead to a crash.
</requirement>

</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  static bool initialized = false;
  if (!initialized) {
    log_init("kex_gen_client_fuzz", SYSLOG_LEVEL_QUIET, SYSLOG_FACILITY_USER, 1);
    initialized = true;
  }

  FuzzedDataProvider provider(data, size);

  struct ssh *ssh = ssh_alloc_session_state();
  if (ssh == NULL) {
    return 0;
  }
  if (ssh_packet_set_connection(ssh, -1, -1) == NULL) {
    ssh_free(ssh);
    return 0;
  }

  ssh->kex = kex_new();
  if (ssh->kex == NULL) {
    ssh_free(ssh);
    return 0;
  }

  const char *kex_algs[] = {
#ifdef WITH_OPENSSL
      "diffie-hellman-group1-sha1",
      "diffie-hellman-group14-sha1",
      "diffie-hellman-group14-sha256",
      "diffie-hellman-group16-sha512",
      "diffie-hellman-group18-sha512",
      "ecdh-sha2-nistp256",
      "ecdh-sha2-nistp384",
      "ecdh-sha2-nistp521",
#endif
      "curve25519-sha256",
      "sntrup761x25519-sha512@openssh.com",
      "mlkem768x25519-sha256",
  };
  const char *chosen_kex = provider.PickValueInArray(kex_algs);

  ssh->kex->kex_type = kex_type_from_name(chosen_kex);
  ssh->kex->hash_alg = kex_hash_from_name(chosen_kex);
  ssh->kex->ec_nid = kex_nid_from_name(chosen_kex);
  ssh->kex->client_pub = sshbuf_new();
  if (ssh->kex->client_pub == NULL) {
    ssh_free(ssh);
    return 0;
  }

  /*
   * kex_gen_client is normally called after kex_setup, which sets
   * ssh->kex->server to 0. We need to do this manually here.
   */
  ssh->kex->server = 0;

  kex_gen_client(ssh);

  ssh_free(ssh);

  return 0;
}
