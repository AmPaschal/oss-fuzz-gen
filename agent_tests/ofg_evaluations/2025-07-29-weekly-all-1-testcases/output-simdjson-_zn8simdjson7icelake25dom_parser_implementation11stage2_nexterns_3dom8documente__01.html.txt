The `simdjson::icelake::dom_parser_implementation::stage2_next` function is responsible for the second stage of JSON parsing in the simdjson library, specifically for the Icelake architecture. This stage, also known as the tape-building stage, constructs a tape-like data structure that represents the parsed JSON document. The function takes a reference to a `dom::document` object as input, which it populates with the parsed data. It's a streaming parser, meaning it can parse a JSON document incrementally from a stream of data. The function is a wrapper around `stage2::tape_builder::parse_document<true>`, which performs the actual parsing. Before calling `stage2_next`, the first stage of parsing must be completed by calling the `stage1` function. The `stage1` function performs structural indexing of the JSON input, which is a prerequisite for the tape-building process in `stage2_next`. The `dom::document` object must also be properly initialized, with its tape and string buffers allocated to sufficient capacity.

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>

// Fuzz the parser.parse_many API.
// This will internally call stage1 and then loop on stage2_next,
// which is the target function. This fuzzes the function indirectly.
// It will use the active implementation, which on a suitable machine
// will be the 'icelake' implementation. This is the most robust way
// to fuzz this internal function without fighting the build system.
extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // The batch size for parse_many can also be fuzzed.
  const size_t batch_size = provider.ConsumeIntegralInRange<size_t>(1, 4096);

  // The rest of the data is the JSON stream.
  std::string json_data = provider.ConsumeRemainingBytesAsString();
  if (json_data.empty()) {
    return 0;
  }

  simdjson::dom::parser parser;
  try {
    // parser.parse_many internally calls stage2_next repeatedly.
    for (simdjson::dom::element doc : parser.parse_many(json_data, batch_size)) {
      // We can do some trivial work on the doc to prevent it
      // from being optimized away, though the parsing itself
      // is the main work.
      simdjson_unused auto type = doc.type();
    }
  } catch (simdjson::simdjson_error &) {
    // We expect errors, just ignore them.
  }
  return 0;
}
