
	
<description>
The `symbolic_to_physical` function converts a symbolic representation of a compressed block (`symbolic_compressed_block`) into a physical hardware-ready format (`physical_compressed_block`, which is an array of 16 bytes). The function handles different types of blocks, including constant-color blocks and variable-color blocks with multiple partitions. For variable-color blocks, it encodes weights and color endpoint values into the physical block based on the block mode and partition information. The `block_size_descriptor` provides context about the block size and available encoding modes.

The function first checks if the block is a constant-color block and, if so, encodes it directly. Otherwise, it encodes the weights and color information for each partition. This involves several steps: determining the number of weights, quantizing and scrambling them, encoding them using an integer-sequence encoding (ISE) algorithm, and writing them to the physical block. It then encodes the partition information, color endpoint formats, and color endpoint values. For dual-plane blocks, it also encodes the color component of the second plane. The function relies on several helper functions like `get_block_mode`, `get_decimation_info`, `get_ise_sequence_bitcount`, `encode_ise`, and `write_bits` to perform the conversion. It also uses precomputed tables like `quant_and_xfer_tables` and `color_uquant_to_scrambled_pquant_tables`.
</description>
<requirements>

<requirement>
The `scb.block_type` must not be `SYM_BTYPE_ERROR`. This is because an assertion fails if this condition is not met.
</requirement>
<requirement>
The `scb.block_mode` must be less than `bsd.block_mode_count_all`. This is to prevent an out-of-bounds access in the `bsd.get_block_mode` function.
</requirement>
<requirement>
The `scb.partition_count` must be between 1 and 4. This is to prevent out-of-bounds access on arrays indexed by the partition count.
</requirement>
<requirement>
The `scb.quant_mode` must be between `QUANT_6` and `QUANT_12`. This is to prevent an out-of-bounds access in the `color_uquant_to_scrambled_pquant_tables` array.
</requirement>
<requirement>
The `pcb` pointer must point to a valid buffer of at least 16 bytes. This is because the function writes 16 bytes to this buffer.
</requirement>

/**
 * @brief Fuzz target for symbolic_to_physical().
 *
 * This function is the final entrypoint for compressing a symbolic block into
 * a 16 byte physical ASTC data block for storage. The symbolic block can
 * contain arbitrary valid data.
 */

#include "/src/astc-encoder/Source/astcenc_internal.h"

#include <fuzzer/FuzzedDataProvider.h>
#include <array>
#include <vector>

struct BlockSizes
{
	int x;
	int y;
	int z;
};

std::array<BlockSizes, 3> testSz {{
	{ 4,  4, 1}, // Highest bitrate
	{12, 12, 1}, // Largest 2D block
	{6,  6,  6}  // Largest 3D block
}};

std::array<block_size_descriptor, 3> testBSD;

/**
 * @brief Utility function to create all of the block size descriptors needed.
 *
 * This is triggered once via a static initializer.
 */
bool bsd_initializer()
{
	for (size_t i = 0; i < testSz.size(); i++)
	{
		init_block_size_descriptor(
		    testSz[i].x,
		    testSz[i].y,
		    testSz[i].z,
		    false,
		    4,
		    1.0f,
		    testBSD[i]);
	}

	return true;
}

void symbolic_to_physical(const struct block_size_descriptor &, const struct symbolic_compressed_block &, uint8_t *);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
	// Preinitialize the block size descriptors we need
	static bool init = bsd_initializer();

	FuzzedDataProvider stream(data, size);

	// We need enough data to populate the structures
	if (stream.remaining_bytes() < sizeof(symbolic_compressed_block))
	{
		return 0;
	}

	// Select a block size to test
	int i = stream.ConsumeIntegralInRange<int>(0, (int)testSz.size() - 1);
	const block_size_descriptor& bsd = testBSD[i];

	// Create and populate the symbolic block
	symbolic_compressed_block scb;
	stream.ConsumeData(&scb, sizeof(scb));

	// Overwrite specific fields to ensure they are valid
	scb.block_type = stream.PickValueInArray<uint8_t>({
	    SYM_BTYPE_CONST_F16,
	    SYM_BTYPE_CONST_U16,
	    SYM_BTYPE_NONCONST
	});

	if (bsd.block_mode_count_all == 0)
	{
		return 0;
	}
	scb.block_mode = stream.ConsumeIntegralInRange<uint16_t>(0, bsd.block_mode_count_all - 1);

	scb.partition_count = stream.ConsumeIntegralInRange<uint8_t>(1, BLOCK_MAX_PARTITIONS);

	scb.quant_mode = static_cast<quant_method>(stream.ConsumeIntegralInRange<uint8_t>(QUANT_6, QUANT_12));

	// Allocate the output buffer
	uint8_t pcb[16];

	// Call the function under test
	symbolic_to_physical(bsd, scb, pcb);

	return 0;
}
