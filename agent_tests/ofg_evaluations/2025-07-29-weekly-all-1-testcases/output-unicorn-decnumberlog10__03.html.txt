
	
<description>
The `decNumberLog10` function computes the base-10 logarithm of a given `decNumber`. It handles special numbers (NaNs, infinities) and validates its inputs. The core of the function uses a Taylor series expansion for the logarithm calculation, requiring a `decContext` for precision and rounding control. The result is stored in a caller-provided `decNumber` structure.
</description>
<requirements>

<requirement>
The `rhs` decNumber must not be a signaling NaN (sNaN). The function will raise an `DEC_Invalid_operation` flag and return a quiet NaN (qNaN) if it is.
</requirement>
<requirement>
The `rhs` decNumber must be non-negative. If a negative number is provided, the function will set the `DEC_Invalid_operation` flag and return a qNaN.
</requirement>
<requirement>
The `decContext` pointed to by `set` must be properly initialized. The `digits`, `emax`, and `emin` fields must be less than or equal to `DEC_MAX_MATH` (999999), and the `round` field must be a valid rounding mode.
</requirement>
<requirement>
The `res` decNumber must be allocated by the caller. The function will write the result of the logarithm calculation into this `decNumber`.
</requirement>
<requirement>
The `rhs` decNumber should have its `digits` and `exponent` fields within the range defined by `DEC_MAX_MATH`. The `decCheckMath` function will otherwise raise an `DEC_Invalid_operation` flag.
</requirement>

#define MAX_INPUT_SIZE 1024

    // way to generate a wide range of valid and invalid inputs, including
    // normal numbers, subnormals, zeros, infinities, and NaNs.
    decNumberFromString(&rhs, str, &context);

    // The result is stored in 'res', and status flags are set in 'context'.
    // The primary goal is to find inputs that cause crashes or hangs.
