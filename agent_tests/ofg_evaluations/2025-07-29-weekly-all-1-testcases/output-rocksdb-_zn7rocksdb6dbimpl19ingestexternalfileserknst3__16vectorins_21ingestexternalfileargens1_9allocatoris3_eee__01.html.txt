The `IngestExternalFiles` function is used to ingest external SST files into the database. It takes a vector of `IngestExternalFileArg` objects, each of which specifies a column family, a list of external files to ingest, and options for the ingestion. The function is atomic, meaning that all files are either ingested successfully or none are. The function performs several checks on the input arguments, including checking for null column family handles, duplicate column families, and empty external file lists. It also checks for compatibility between the ingestion options and the database options.
</description>
