
	
<description>
The `lodepng_encode_file` function encodes a raw image into a PNG file and saves it to disk. It takes the filename, a pointer to the image data, the width and height of the image, the color type, and the bit depth as input. The function first encodes the image data into a PNG format in memory by calling `lodepng_encode_memory`. If the in-memory encoding is successful, it then writes the encoded data to the file specified by the `filename` parameter using `lodepng_save_file`. Finally, it frees the memory buffer that was allocated for the in-memory encoding. The function returns an error code if any step of the process fails.
</description>
<requirements>
<requirement>
The `filename` parameter must be a valid, null-terminated string that represents a writable file path. This is because the function uses this path to save the encoded PNG data, and an invalid path will cause a file creation error.
</requirement>
<requirement>
The `image` parameter must not be a null pointer. It must point to a buffer that contains the raw image data, and the size of this buffer must be sufficient for the given width, height, color type, and bit depth to prevent memory access violations during encoding.
</requirement>
<requirement>
The `w` and `h` parameters, representing the width and height of the image, must both be greater than 0. This is to ensure that the image has a valid, non-zero area, which is necessary for the encoding process to work correctly.
</requirement>
<requirement>
The `colortype` parameter must be one of the following valid `LodePNGColorType` enum values: `LCT_GREY`, `LCT_RGB`, `LCT_PALETTE`, `LCT_GREY_ALPHA`, or `LCT_RGBA`. Using an invalid color type will result in an error since the encoder only supports these specific PNG color formats.
</requirement>
<requirement>
The `bitdepth` parameter must be a valid bit depth for the specified `colortype`. The valid combinations are: `LCT_GREY` with 1, 2, 4, 8, or 16; `LCT_RGB` with 8 or 16; `LCT_PALETTE` with 1, 2, 4, or 8; `LCT_GREY_ALPHA` with 8 or 16; and `LCT_RGBA` with 8 or 16. Providing an unsupported combination will lead to an error because the underlying `lodepng_encode` function validates these pairs.
</requirement>
</requirements>

// Amount of valid colortype/bidthdepth combinations in the PNG file format.
const size_t num_combinations = 15;

LodePNGColorType colortypes[num_combinations] = {
    LCT_GREY,       LCT_GREY,       LCT_GREY,    LCT_GREY,    LCT_GREY,
    LCT_RGB,        LCT_RGB,
    LCT_PALETTE,    LCT_PALETTE,    LCT_PALETTE, LCT_PALETTE,
    LCT_GREY_ALPHA, LCT_GREY_ALPHA,
    LCT_RGBA,       LCT_RGBA,
};

unsigned bitdepths[num_combinations] = {
    1, 2,  4, 8, 16, // gray
    8, 16,           // rgb
    1, 2,  4, 8,     // palette
    8, 16,           // gray+alpha
    8, 16,           // rgb+alpha
};

unsigned int lodepng_encode_file(const char *, const unsigned char *, unsigned int, unsigned int, LodePNGColorType, unsigned int);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Parameters for lodepng_encode_file

  unsigned h = provider.ConsumeIntegralInRange<unsigned>(1, 512);

  size_t combination_index = provider.ConsumeIntegralInRange<size_t>(0, num_combinations - 1);
  LodePNGColorType colortype = colortypes[combination_index];
  unsigned bitdepth = bitdepths[combination_index];

  LodePNGColorMode color_mode;
  lodepng_color_mode_init(&color_mode);
  color_mode.colortype = colortype;
  color_mode.bitdepth = bitdepth;
  
  // For palette, we need to provide a palette.
  if (colortype == LCT_PALETTE) {
    unsigned palette_size = 1u << bitdepth;
    for (unsigned i = 0; i < palette_size; ++i) {
        if (provider.remaining_bytes() < 4) {
            lodepng_color_mode_cleanup(&color_mode);
            return 0;
        }
        lodepng_palette_add(&color_mode, provider.ConsumeIntegral<uint8_t>(), provider.ConsumeIntegral<uint8_t>(), provider.ConsumeIntegral<uint8_t>(), provider.ConsumeIntegral<uint8_t>());
    }
  }

  // Calculate required image size
  size_t bpp = lodepng_get_bpp(&color_mode);
  size_t image_size = (w * h * bpp + 7) / 8;

  std::vector<uint8_t> image = provider.ConsumeBytes<uint8_t>(image_size);
  if (image.size() != image_size) {
    lodepng_color_mode_cleanup(&color_mode);
    return 0;
  }

  lodepng_encode_file(filename, image.data(), w, h, colortype, bitdepth);
  
  lodepng_color_mode_cleanup(&color_mode);

  return 0;
