
	
<description>
The function `LibRaw::selectCRXTrack()` is responsible for selecting the primary RAW track from a CRX (Canon RAW v3) file. It analyzes the available tracks, which can be of different types (RAW, JPEG, metadata), and selects the one with the highest resolution. It also handles frame selection within a track if multiple frames are present. The function is called from `LibRaw::identify()` after parsing the CR3 file structure with `parseCR3()`. It sets various fields in the `LibRaw` class instance based on the selected track's metadata, such as image dimensions, data offset, and the appropriate raw loader function (`crxLoadRaw`).
</description>
<requirements>

<requirement>
The `parseCR3()` function must be called before `selectCRXTrack()`. This is because `parseCR3()` populates the `crx_track_count` and `crx_header` fields in the `libraw_internal_data.unpacker_data` structure, which are essential for the logic in `selectCRXTrack()`.
</requirement>
<requirement>
The `libraw_internal_data.unpacker_data.crx_track_count` field must be an integer between 0 and 15. This field determines the number of tracks to iterate over, and the `crx_header` array has a maximum size of 16 (`LIBRAW_CRXTRACKS_MAXCOUNT`).
</requirement>
<requirement>
The `libraw_internal_data.unpacker_data.crx_header` array must be properly initialized. Each `crx_data_header_t` element in the array should have its `MediaType`, `nBits`, `f_width`, `f_height`, `sample_count`, `MediaSize`, and `MediaOffset` fields populated with valid data, as these are accessed to determine the best track.
</requirement>
<requirement>
The `shot_select` member variable should be initialized with an integer value. This variable is used to select a specific track or frame, and can be fuzzed to explore different execution paths.
</requirement>
<requirement>
The `tiff_ifd` array and `tiff_nifds` field should be initialized. The function accesses `tiff_ifd` to get flip information, so these need to be populated by a TIFF parser before calling `selectCRXTrack()`.
</requirement>

</requirements>
