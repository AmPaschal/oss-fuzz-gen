
	
<description>
The `onig_scan` function repeatedly searches for a regular expression pattern within a string, from a starting position to an end position. For each match found, it invokes a user-defined callback function, `scan_callback`. The function begins by compiling the regular expression using `onig_new` and prepares a region object with `onig_region_new`. The core of its operation is a loop that repeatedly calls `onig_search`. When `onig_search` finds a match, `onig_scan` executes the `scan_callback` function, passing it details about the match. The scan continues until no more matches can be found, the callback function returns a non-zero value, or an error occurs within `onig_search`. The function returns the total number of matches found or an error code if the scan fails.
</description>
<requirements>

<requirement>
The `onig_initialize` function must be called before any other Oniguruma function. This sets up the necessary environment and internal structures for the library to operate correctly.
</requirement>
<requirement>
The first argument, `reg`, must be a compiled regular expression of type `regex_t*`, initialized by `onig_new`. `onig_scan` uses this compiled pattern to perform the search, and a valid object is essential to prevent null pointer dereferences or crashes.
</requirement>
<requirement>
The fourth argument, `region`, must be a valid `OnigRegion*` object created by `onig_region_new`. This structure is used internally to store information about the matched substrings, and it must be properly allocated to avoid memory corruption.
</requirement>
<requirement>
The `str` and `end` pointers, the second and third arguments, must define a valid and accessible memory range. The `end` address must be greater than or equal to `str` to prevent buffer overflows or segmentation faults during scanning.
</requirement>
<requirement>
The sixth argument, `scan_callback`, must be a non-null function pointer. This callback is dereferenced and executed for every match found, so a null pointer would lead to a crash.
</requirement>
<requirement>
The `scan_callback` function should return 0 to ensure the scan continues through all possible matches. A non-zero return value will cause `onig_scan` to terminate its operation prematurely.
</requirement>
<requirement>
To prevent resource leaks, `onig_free` must be called on the `regex_t` object and `onig_region_free` on the `OnigRegion` object after `onig_scan` has completed. Futhermore, `onig_end` should be called for a final cleanup of all resources used by the Oniguruma library.
</requirement>

</requirements>

  // Initialize Oniguruma library.
  OnigEncoding encodings[] = {ONIG_ENCODING_UTF8};
  onig_initialize(encodings, sizeof(encodings) / sizeof(encodings[0]));

  // Manually split the input data in a C-compatible way.
  // First, consume the options.
  OnigOptionType options;
  memcpy(&options, data, sizeof(OnigOptionType));
  
  const uint8_t *remaining_data = data + sizeof(OnigOptionType);
  size_t remaining_size = size - sizeof(OnigOptionType);

  // Split the rest of the data in half for the pattern and the search string.
  size_t pattern_size = remaining_size / 2;
  size_t search_size = remaining_size - pattern_size;

  const OnigUChar *pattern = (const OnigUChar *)remaining_data;
  const OnigUChar *pattern_end = pattern + pattern_size;
  const OnigUChar *str = (const OnigUChar *)(remaining_data + pattern_size);
  const OnigUChar *end = str + search_size;

  regex_t *reg = NULL;
  OnigErrorInfo einfo;
  int r = onig_new(&reg, pattern, pattern_end, options, ONIG_ENCODING_UTF8, ONIG_SYNTAX_DEFAULT, &einfo);

  if (r == ONIG_NORMAL) {
    OnigRegion *region = onig_region_new();
    if (region) {
      // Call the function under test.
      // The `scan_callback` is a simple function that returns 0 to continue scanning.
      // The `callback_arg` (last parameter) is NULL as we don't use it.
      onig_scan(reg, str, end, region, options, scan_callback, NULL);
      onig_region_free(region, 1 /* free self */);
    }
    onig_free(reg);
  }

  // Clean up Oniguruma library resources.
  onig_end();

  return 0;
