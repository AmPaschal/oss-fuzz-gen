
	
<description>
The `XML_ExternalEntityParserCreate` function creates a new parser for handling external entities. It takes an existing parser (`oldParser`) and uses its settings to create a new parser. This new parser is then used to parse the external entity specified by the `context` and `encodingName` arguments. The newly created parser is linked to the original parser, making it a child parser. This hierarchical structure is essential for managing parsing state and context, especially when dealing with complex XML documents that include external entities.
</description>

The `oldParser` argument must be a valid, non-NULL pointer to an `XML_Parser` object. This is because the function dereferences this pointer to access and copy properties to the new parser, and a NULL pointer would lead to a crash.
</requirement>
<requirement>
The `oldParser` object should be initialized by calling `XML_ParserCreate` before being passed to the function. This ensures that the parser's internal state, including memory handlers and DTD information, is properly set up, which is crucial for the new parser's creation and operation.
</requirement>
<requirement>
The `context` argument can be a fuzzed string, including NULL. When non-NULL, it is treated as XML content to be parsed, so fuzzing helps uncover vulnerabilities in the XML parsing logic.
</requirement>
<requirement>
The `encodingName` argument can be a fuzzed string, including NULL. The function is designed to handle various encoding names and will return NULL if an unsupported or invalid encoding is provided, so fuzzing can test the robustness of the encoding handling mechanism.
</requirement>
</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  XML_Parser oldParser = XML_ParserCreate(nullptr);
  if (!oldParser) {
    return 0;
  }

  const std::string encoding = provider.ConsumeBytesAsString(32);
  const std::string context = provider.ConsumeRemainingBytesAsString();

  XML_Parser newParser = XML_ExternalEntityParserCreate(
      oldParser, reinterpret_cast<const XML_Char *>(context.c_str()),
      reinterpret_cast<const XML_Char *>(encoding.c_str()));

  if (newParser) {
    XML_ParserFree(newParser);
  }

  XML_ParserFree(oldParser);

  return 0;
}
