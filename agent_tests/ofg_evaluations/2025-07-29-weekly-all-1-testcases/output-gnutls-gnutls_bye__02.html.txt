
	
<description>
The `gnutls_bye()` function is used to close a TLS session. It sends a 'close notify' alert to the peer to inform it that the connection is being closed. The function takes two arguments: a `gnutls_session_t` object representing the session and a `gnutls_close_request_t` enum value that specifies how to close the connection. `GNUTLS_SHUT_RDWR` closes both read and write directions, while `GNUTLS_SHUT_WR` only closes the write direction. Before calling `gnutls_bye()`, the session must be properly initialized and a handshake must have been completed. This involves creating a `gnutls_session_t` object using `gnutls_init()`, setting up credentials, setting transport information, and completing the TLS handshake using `gnutls_handshake()`.
</description>
<requirements>

<requirement>
The `gnutls_global_init()` function must be called before any other GnuTLS function. This is because it initializes the GnuTLS library, and other functions will fail if the library is not initialized.
</requirement>
<requirement>
A `gnutls_session_t` object must be initialized by calling `gnutls_init`. The session object contains all the state information for a TLS session, which is necessary for `gnutls_bye` to function correctly.
</requirement>
<requirement>
The transport medium must be set for the session using `gnutls_transport_set_int` or `gnutls_transport_set_ptr`. This is because `gnutls_bye` needs to send a close notify alert over the transport layer.
</requirement>
<requirement>
A TLS handshake must be successfully completed using `gnutls_handshake` before calling `gnutls_bye`. The `gnutls_bye` function sends a close notify alert, which can only be done after a secure channel has been established.
</requirement>
<requirement>
The `how` parameter should be one of `GNUTLS_SHUT_RDWR` or `GNUTLS_SHUT_WR`. The function's behavior is determined by this parameter, and other values will lead to unexpected results.
</requirement>

</requirements>

int __attribute__((visibility("protected")))
gnutls_rnd(gnutls_rnd_level_t level, void *data, size_t len)
{
	memset(data, 0xff, len);

	/* Flip the first byte to avoid infinite loop in the RSA
	 * blinding code of Nettle */
	if (len > 0)
		memset(data, 0x0, 1);
	return 0;
}

/* This function simulates a successful write operation.
 * It is needed for gnutls_bye to send the close notify alert.
 */
static ssize_t success_push(gnutls_transport_ptr_t tr, const void *data,
			  size_t len)
{
	return len;
}

/* This function simulates a read operation that finds no data.
 * It sets errno to EAGAIN to signal a non-blocking operation.
 */
static ssize_t nodata_pull(gnutls_transport_ptr_t tr, void *data, size_t len)
{
	errno = EAGAIN;
	return -1;
}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
	int res;
	gnutls_session_t session;
	gnutls_certificate_credentials_t xcred;
	struct mem_st memdata;
	unsigned int retry;

	res = gnutls_init(&session, GNUTLS_CLIENT);
	assert(res >= 0);

	res = gnutls_certificate_allocate_credentials(&xcred);
	assert(res >= 0);
	res = gnutls_credentials_set(session, GNUTLS_CRD_CERTIFICATE, xcred);
	assert(res >= 0);

	/*res = gnutls_set_default_priority(session); */
	res = gnutls_priority_set_direct(
		session, "NORMAL:-VERS-TLS-ALL:+VERS-TLS1.3", NULL);
	assert(res >= 0);

	memdata.data = data;
	memdata.size = size;

	gnutls_transport_set_push_function(session, success_push);
	gnutls_transport_set_pull_function(session, nodata_pull);
	gnutls_handshake_set_read_function(session, handshake_discard);

	retry = 0;
	do {
		res = gnutls_handshake(session);
		if (res == GNUTLS_E_AGAIN) {
			if (handshake_pull(session, &memdata) < 0) {
				res = GNUTLS_E_INTERNAL_ERROR;
				break;
			}
			if (retry > HANDSHAKE_MAX_RETRY_COUNT) {
				break;
			}
			retry++;
		} else {
			retry = 0;
		}
	} while (res < 0 && gnutls_error_is_fatal(res) == 0);

	/* After the handshake, call the function under test. */
	gnutls_bye(session, GNUTLS_SHUT_RDWR);
	gnutls_bye(session, GNUTLS_SHUT_WR);

	gnutls_deinit(session);
	gnutls_certificate_free_credentials(xcred);
	return 0;
}
