
	
<description>
The function `lou_getEmphClasses` retrieves the list of emphasis class names from a compiled translation table. It takes a string `tableList` which acts as an identifier for the table. The function looks up the pre-compiled table using `_lou_getTranslationTable`. If found, it iterates through the `emphClassNames` array within the table's header, copies the non-null names into a newly allocated array, and returns this new array. The returned array is null-terminated and the caller is responsible for freeing its memory.
</description>
<requirements>
<requirement>
The `tableList` argument should be a null-terminated string that corresponds to a table previously compiled and loaded into memory. This is because the function uses `_lou_getTranslationTable` to look up the table, and a mismatch or invalid name will cause the lookup to fail, preventing the function's primary logic from being executed.
</requirement>
<requirement>
A table compilation function such as `lou_compileString()` or `lou_getTable()` must be called before calling `lou_getEmphClasses`. This is necessary to parse a table definition and populate the internal state that the target function queries.
</requirement>
<requirement>
The `tableList` input can be fuzzed with arbitrary strings. Although a valid table is needed for the function to be fully tested, fuzzing the `tableList` can help uncover vulnerabilities in the table lookup mechanism itself.
</requirement>
<requirement>
The `lou_free()` function should be called after all operations involving the library are completed. This is to ensure that all global resources and memory allocated by the library during table compilation and other operations are properly released, preventing memory leaks.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>

extern "C" const char ** lou_getEmphClasses(const char *);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Consume a string for the table name.
  std::string tableName = provider.ConsumeRandomLengthString(50);
  if (tableName.empty()) {
    return 0;
  }

  // Consume the rest of the data as the table definition.
  std::string tableDefinition = provider.ConsumeRemainingBytesAsString();

  // Compile the table from the fuzzed definition.
  // This is a prerequisite for lou_getEmphClasses.
  if (lou_compileString(tableName.c_str(), tableDefinition.c_str()) == 1) {
    // If compilation was successful, call the target function.
    const char **emphClasses = lou_getEmphClasses(tableName.c_str());

    // The documentation states to free the returned array itself,
    // but not the strings within it.
    if (emphClasses) {
      free(emphClasses);
    }
  }

  // Clean up all liblouis resources to prevent memory leaks across runs.
  lou_free();

  return 0;
}
