
	
<description>
The function `hoedown_html_toc_renderer_new` allocates and initializes a new `hoedown_renderer` struct, which is used for generating an HTML Table of Contents (TOC). It takes an integer `nesting_level` as input, which specifies the maximum header level to be included in the TOC. The function allocates memory for its internal state (`hoedown_html_renderer_state`) and for the renderer itself, setting up a series of default callback functions for TOC generation. The `nesting_level` is stored in the state and used by the `toc_header` callback function to filter headers based on their level. The caller is responsible for freeing the allocated renderer with `hoedown_html_renderer_free`.
</description>
<requirements>
<requirement>
The `nesting_level` argument can be any integer value. This is because the only caller of this function obtains this value from a command-line argument without performing any validation, so any integer is a valid input.
</requirement>
<requirement>
The returned `hoedown_renderer` pointer must be freed by calling `hoedown_html_renderer_free`. This is to prevent memory leaks as the target function allocates memory for the renderer and its associated state.
</requirement>
</requirements>
