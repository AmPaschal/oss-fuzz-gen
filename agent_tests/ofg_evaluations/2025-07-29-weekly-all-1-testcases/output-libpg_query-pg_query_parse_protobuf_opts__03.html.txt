
	
<description>
The function `pg_query_parse_protobuf_opts` takes a SQL query string and a set of parser options as input, and returns a protobuf representation of the parsed query. It internally calls `pg_query_raw_parse` to perform the parsing and then converts the resulting parse tree to a protobuf format. The caller is responsible for freeing the memory allocated for the `stderr_buffer`, `error`, and `parse_tree` fields of the returned `PgQueryProtobufParseResult` struct.
</description>
<requirements>
<requirement>
The `input` argument must be a null-terminated string. This is because it is passed to `pg_query_raw_parse` which expects a null-terminated string.
</requirement>
<requirement>
The `parser_options` argument should be one of the following values: PG_QUERY_PARSE_DEFAULT (0), PG_QUERY_PARSE_TYPE_NAME (1), PG_QUERY_PARSE_PLPGSQL_EXPR (2), PG_QUERY_PARSE_PLPGSQL_ASSIGN1 (3), PG_QUERY_PARSE_PLPGSQL_ASSIGN2 (4), or PG_QUERY_PARSE_PLPGSQL_ASSIGN3 (5). These are the only supported parser modes.
</requirement>
</requirements>
