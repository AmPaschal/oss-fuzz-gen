
	
<description>
The function opus_projection_encode_float is an entry point for encoding a float array of PCM data into the opus format. It is a wrapper around the internal function opus_multistream_encode_native, and it uses a pre-defined callback function opus_projection_copy_channel_in_float to copy input channels. The OpusProjectionEncoder struct that is passed as an argument is not a simple struct, but a larger allocated block of memory that contains other structs and data after the main struct. This memory block must be initialized by calling opus_projection_ambisonics_encoder_create.
</description>
<requirements>
<requirement>
The `st` argument, a pointer to an `OpusProjectionEncoder` struct, must be initialized by calling `opus_projection_ambisonics_encoder_create`. This is because the `st` pointer is used to derive pointers to other data structures, and `opus_projection_ambisonics_encoder_create` allocates the required memory and initializes it.
</requirement>
<requirement>
The `pcm` array must have a size that is at least `frame_size` * `channels` * `sizeof(float)`. The `channels` argument is provided to the `opus_projection_ambisonics_encoder_create` function during the initialization of the `st` struct. This is to prevent out-of-bounds reads when the function processes the input audio data.
</requirement>
<requirement>
The `frame_size` argument must be a valid Opus frame size. This is because the underlying `opus_multistream_encode_native` function expects a valid frame size to function correctly. Common valid frame sizes are 120, 240, 480, 960, 1920, and 3840 for a 48000Hz sample rate.
</requirement>
<requirement>
The `max_data_bytes` argument must be large enough to hold the encoded data. A value of 4000 is recommended, as this is a safe upper bound for the size of an Opus packet.
</requirement>
</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Parameters for opus_projection_ambisonics_encoder_create
  constexpr opus_int32 Fs = 48000;
  const int channels = provider.ConsumeIntegralInRange<int>(1, 8);
  const int mapping_family = provider.ConsumeIntegralInRange<int>(0, 255);
  const int application = provider.PickValueInArray({OPUS_APPLICATION_VOIP, OPUS_APPLICATION_AUDIO, OPUS_APPLICATION_RESTRICTED_LOWDELAY});

  int streams;
  int coupled_streams;
  int error;

  OpusProjectionEncoder *st = opus_projection_ambisonics_encoder_create(
      Fs, channels, mapping_family, &streams, &coupled_streams, application, &error);

  if (error != OPUS_OK || st == nullptr) {
    return 0;
  }

  // Parameters for opus_projection_encode_float
  const int frame_sizes[] = {120, 240, 480, 960, 1920, 2880, 3840};
  const int frame_size = provider.PickValueInArray(frame_sizes);
  const opus_int32 max_data_bytes = 4000;

  const size_t pcm_elements = frame_size * channels;
  std::vector<float> pcm(pcm_elements);
  const size_t pcm_bytes_to_consume = pcm_elements * sizeof(float);
  
  size_t consumed_bytes = provider.ConsumeData(pcm.data(), pcm_bytes_to_consume);

  if (consumed_bytes != pcm_bytes_to_consume) {
      opus_projection_encoder_destroy(st);
      return 0;
  }

  std::vector<unsigned char> out_data(max_data_bytes);

  opus_projection_encode_float(st, pcm.data(), frame_size, out_data.data(), max_data_bytes);

  opus_projection_encoder_destroy(st);

  return 0;
}
