
	
<description>
The opus_decode_float function decodes an Opus packet into float samples. It is a wrapper around the opus_decode_native function. The function first performs some basic validation on the frame_size argument. It then determines the number of samples in the packet and allocates a buffer to store the decoded samples. The function then calls opus_decode_native to perform the actual decoding. Finally, it converts the decoded samples from opus_res to float and copies them to the output buffer.
</description>
<requirements>
<requirement>
The OpusDecoder state `st` must be initialized by calling `opus_decoder_create`. This is because the decoder contains the state necessary for decoding, including sample rate and number of channels.
</requirement>
<requirement>
The `data` and `len` parameters should be the fuzzed input. This allows the fuzzer to explore different encoded packet configurations.
</requirement>
<requirement>
The `pcm` buffer must be allocated to a size of at least `frame_size * st->channels * sizeof(float)`. This is to prevent a buffer overflow when the function writes the decoded audio samples.
</requirement>
<requirement>
The `frame_size` argument must be greater than 0. The function will return `OPUS_BAD_ARG` if the frame_size is not positive.
</requirement>
<requirement>
If `decode_fec` is set to 1, or if `data` is NULL, `frame_size` must be a multiple of `st->Fs / 400`. This is an internal requirement of the decoder for handling Forward Error Correction and packet loss.
</requirement>
<requirement>
The `decode_fec` argument must be either 0 or 1. The underlying `opus_decode_native` function will return `OPUS_BAD_ARG` for other values.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <vector>
#include <cstdint>
#include "/src/opus/include/opus.h"

// Fuzzer for opus_decode_float.
extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  const opus_int32 Fs = provider.PickValueInArray(sample_rates);

  const int channels = provider.ConsumeIntegralInRange<int>(1, 2);

  int err;
  OpusDecoder *dec = opus_decoder_create(Fs, channels, &err);
  if (err != OPUS_OK) {
    return 0;
  }

  // From the Opus documentation, valid frame durations are 2.5, 5, 10, 20, 40, 60ms.
  // frame_size is the number of samples per channel.
  // At Fs Hz, 2.5ms corresponds to Fs * 0.0025 = Fs / 400 samples.
  const int multipliers[] = {1, 2, 4, 8, 16, 24}; // Corresponds to 2.5, 5, 10, 20, 40, 60 ms
  const int frame_size = (Fs / 400) * provider.PickValueInArray(multipliers);

  const int decode_fec = provider.ConsumeBool();

  std::vector<float> pcm(frame_size * channels);
  auto opus_data = provider.ConsumeRemainingBytes<unsigned char>();

  opus_decode_float(dec, opus_data.data(), opus_data.size(), pcm.data(), frame_size, decode_fec);

  opus_decoder_destroy(dec);
  return 0;
}
