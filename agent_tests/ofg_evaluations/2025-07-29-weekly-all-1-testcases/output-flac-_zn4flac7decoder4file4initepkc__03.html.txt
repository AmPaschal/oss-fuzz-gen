
	
<description>
The function `FLAC::Decoder::File::init` initializes a FLAC stream decoder for reading from a file. It is a wrapper around the C API function `FLAC__stream_decoder_init_file`, and it passes member callbacks (`write_callback_`, `metadata_callback_`, `error_callback_`) to the underlying function. The `decoder_` member must be a valid pointer to a `FLAC__StreamDecoder` instance. The state of this decoder instance is crucial for the function to succeed. Specifically, it must be in the `FLAC__STREAM_DECODER_UNINITIALIZED` state.
</description>
<requirements>
<requirement>
The `decoder_` member of the `FLAC::Decoder::File` object must not be NULL. This is because it is dereferenced in the function and a `NULL` value will cause a crash.
</requirement>
<requirement>
The `decoder_` member must be in the `FLAC__STREAM_DECODER_UNINITIALIZED` state before calling `init`. This is because `init_file_internal_` checks the state and returns `FLAC__STREAM_DECODER_INIT_STATUS_ALREADY_INITIALIZED` if the state is not `FLAC__STREAM_DECODER_UNINITIALIZED`.
</requirement>
<requirement>
The `filename` argument must be a valid path to a readable file. This is because the underlying `init_file_internal_` function will attempt to open and read from this file.
</requirement>
<requirement>
The `write_callback_` and `error_callback_` members of the `FLAC::Decoder::File` class must be non-NULL. This is because `init_file_internal_` checks for `NULL` and returns `FLAC__STREAM_DECODER_INIT_STATUS_INVALID_CALLBACKS` if they are `NULL`.
</requirement>
</requirements>

class FuzzDecoder : public FLAC::Decoder::File {
public:
	FuzzDecoder() : FLAC::Decoder::File() {}
	~FuzzDecoder() {}

protected:
	virtual ::FLAC__StreamDecoderWriteStatus write_callback(const ::FLAC__Frame *frame, const FLAC__int32 * const buffer[]) override {
		(void)frame;
		(void)buffer;
		return FLAC__STREAM_DECODER_WRITE_STATUS_CONTINUE;
	}

	virtual void error_callback(::FLAC__StreamDecoderErrorStatus status) override {
		(void)status;
	}
};

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
	if (size == 0)
		return 0;

	const char *tmp_filename = "/tmp/fuzz.flac";
	FILE *f = fopen(tmp_filename, "wb");
	if (!f)
		return 0;
	fwrite(data, 1, size, f);
	fclose(f);

	FuzzDecoder decoder;

	/* The following line calls the function under test */
	decoder.init(tmp_filename);

	decoder.finish();

	return 0;
}
