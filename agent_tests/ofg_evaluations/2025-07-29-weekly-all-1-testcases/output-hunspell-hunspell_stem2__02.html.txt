
	
<description>
The Hunspell_stem2 function is a C wrapper for the C++ `HunspellImpl::stem` method. This function takes a list of words (`desc`) and returns a list of their stems (`slst`). The `pHunspell` handle must be created by calling `Hunspell_create`, and the caller is responsible for freeing the memory allocated for `slst` by calling `Hunspell_free_list`.
</description>
<requirements>
<requirement>
The first argument `pHunspell` must be a valid `Hunhandle*` returned by `Hunspell_create`. This is because the function casts this handle to a `HunspellImpl*` and calls a method on it.
</requirement>
<requirement>
The second argument `slst` must be a valid pointer to a `char**`. This is because the function will allocate memory for the stems and store the result in `*slst`.
</requirement>
<requirement>
The third argument `desc` must be a valid array of `n` null-terminated strings. This is because the function iterates through this array to process each string.
</requirement>
<requirement>
The fourth argument `n` must be the number of strings in `desc`. This is to prevent out-of-bounds access on `desc`.
</requirement>
<requirement>
The caller must free the memory allocated for `*slst` by calling `Hunspell_free_list`. This is to prevent memory leaks as the function allocates memory for the stems.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <fstream>
#include <string>
#include <vector>

#include "/src/hunspell/src/hunspell/hunspell.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Create aff and dic files from fuzzer data
  size_t aff_size = provider.ConsumeIntegralInRange<size_t>(0, 2048);
  std::string aff_data = provider.ConsumeBytesAsString(aff_size);
  std::ofstream aff_file("/tmp/fuzz.aff");
  aff_file.write(aff_data.c_str(), aff_data.size());
  aff_file.close();

  size_t dic_size = provider.ConsumeIntegralInRange<size_t>(0, 4096);
  std::string dic_data = provider.ConsumeBytesAsString(dic_size);
  std::ofstream dic_file("/tmp/fuzz.dic");
  dic_file.write(dic_data.c_str(), dic_data.size());
  dic_file.close();

  Hunhandle* handle = Hunspell_create("/tmp/fuzz.aff", "/tmp/fuzz.dic");
  if (!handle) {
    return 0;
  }

  // Prepare the list of words for Hunspell_stem2
  std::vector<std::string> words;
  std::vector<char*> words_c_str;
  while (provider.remaining_bytes() > 0) {
    words.push_back(provider.ConsumeRandomLengthString(128));
  }

  // Hunspell C API expects char**, so we need to convert from std::string
  for (auto& word : words) {
    words_c_str.push_back(&word[0]);
  }

  if (!words_c_str.empty()) {
    char** slst = nullptr;
    int num_stems = Hunspell_stem2(handle, &slst, words_c_str.data(), words_c_str.size());
    if (num_stems > 0 && slst) {
      Hunspell_free_list(handle, &slst, num_stems);
    }
  }

  Hunspell_destroy(handle);

  return 0;
}
