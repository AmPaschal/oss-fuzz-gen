
	
<description>
The `tidySaveString` function saves a Tidy document to a string buffer. It takes a `TidyDoc` handle, a character buffer, and a pointer to the buffer's length as input. It is a wrapper around the internal `tidyDocSaveString` function, which performs the actual saving operation. The internal function first initializes an output buffer (`outbuf`), then saves the document's content into this buffer as a stream. Finally, it copies the content of the output buffer to the user-provided buffer if it's large enough. If the provided buffer is too small, it returns an error and sets `*buflen` to the required size.
</description>
<requirements>

<requirement>
The `tdoc` argument must be a valid `TidyDoc` object. This can be created by calling `tidyCreate()` and parsing a document with a function like `tidyParseString()`.
</requirement>
<requirement>
The `buffer` argument must be a valid, writable buffer. The saved document content will be written to this buffer.
</requirement>
<requirement>
The `buflen` argument must be a valid pointer to a `uint` and cannot be NULL. The function uses this to read the initial buffer size and write the final output size.
</requirement>
<requirement>
The value pointed to by `buflen` should be initialized to the size of the allocated `buffer`. If this size is insufficient, the function will return an error and update the value to the required size.
</requirement>
<requirement>
After using `tidySaveString`, the `TidyDoc` object should be released by calling `tidyRelease()`. This is to prevent memory leaks.
</requirement>
