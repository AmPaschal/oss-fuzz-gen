The `ole2_open_file` function is responsible for opening and parsing an OLE2 compound file. It takes a single argument, the path to the file, opens it, and then proceeds to read the header and body of the file to populate an `OLE2` structure. This function is the initial entry point for handling OLE2 files in the libxls library, and it is called by `xls_open_file` which passes the filename directly, meaning the input is user-controlled.
</description>
<requirements>
<requirement>
The input file path must point to a valid and readable file. The function uses `fopen` to open the file in binary read mode (`"rb"`), and if this operation fails, the function returns `NULL`.
</requirement>
<requirement>
The file must be a valid OLE2 compound file, starting with the magic bytes `D0 CF 11 E0 A1 B1 1A E1`. The function `ole2_read_header` verifies these bytes to ensure it is processing a correct file type.
</requirement>
<requirement>
The OLE2 file must have a little-endian byte order (0xFFFE). This is a strict requirement checked within `ole2_read_header` to ensure correct parsing of the file structure.
</requirement>
<requirement>
The major and minor sector sizes of the OLE2 file must be 512 and 64 bytes respectively. The header parsing code asserts that `lsectorB` is 9 and `lssectorB` is 6.
</requirement>
</requirements>
