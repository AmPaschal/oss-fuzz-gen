
	
<description>
The function `SafeUint32Mult` safely multiplies four 32-bit unsigned integers and stores the result in a 32-bit unsigned integer pointer. It returns true if the multiplication is successful and false if an overflow occurs. The underlying implementation recursively calls a safe multiplication function for two numbers, which throws a `dng_exception` on overflow. The target function catches this exception and returns false.
</description>
<requirements>

<requirement>
The `result` pointer, the fifth argument, must not be a null pointer. The function attempts to dereference this pointer to store the result of the multiplication, and a null pointer would cause a crash.
</requirement>
<requirement>
The product of the first four arguments (`arg1`, `arg2`, `arg3`, `arg4`) must not exceed the maximum value of a 32-bit unsigned integer (UINT32_MAX). An overflow will cause the underlying multiplication function to throw an exception, leading to the function returning false and not producing a valid result.
</requirement>
