
	
<description>
The function `sepol_policydb_to_image` converts a policy database (`sepol_policydb_t`) into a binary image in memory. It is a wrapper around the `policydb_to_image` function. The caller provides a policy database, and the function allocates a buffer for the image and returns a pointer to it (`newdata`) and its size (`newlen`). Callers are responsible for freeing the allocated buffer. A typical usage pattern involves creating a `sepol_handle_t`, then creating and populating a `sepol_policydb_t` from a policy file using `sepol_policydb_from_file`, and then calling `sepol_policydb_to_image` to get the binary image.
</description>

</requirement>
<requirement>
The third and fourth arguments, `void **newdata` and `size_t *newlen`, must be valid pointers to a `void *` and `size_t` respectively. These are used as output parameters to return the location and size of the generated policy image, and must be valid to avoid memory corruption.
</requirement>
