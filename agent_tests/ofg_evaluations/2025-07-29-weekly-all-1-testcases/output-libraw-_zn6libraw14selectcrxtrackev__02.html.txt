
	
<description>
The function `selectCRXTrack` is responsible for selecting the correct track from a CRX file. The CRX file format can contain multiple tracks, and this function analyzes the available tracks to find the RAW image data. It inspects the `crx_header` data, which is populated by `parseCR3`, to calculate bit counts and frame counts for each track. Based on this information and the value of `shot_select`, it selects a track and a frame, and then sets various global variables like `data_offset`, `data_size`, `raw_width`, `raw_height`, etc., based on the selected track's properties. The caller function `identify` first parses the CR3 file using `parseCR3` and then calls `selectCRXTrack` to process the parsed information.
</description>
<requirements>
<requirement>
The global variable `libraw_internal_data.unpacker_data.crx_track_count` must be initialized to a value between 0 and 15. This is because the function uses this variable to iterate over the `crx_header` array, and a value outside this range would lead to an out-of-bounds access.
</requirement>
<requirement>
The global array `libraw_internal_data.unpacker_data.crx_header` must be initialized. The function accesses members of this array up to the index specified by `crx_track_count`, so these elements must contain valid data.
</requirement>
<requirement>
The function `parseCR3` must be called before `selectCRXTrack`. `parseCR3` is responsible for populating the `crx_track_count` and `crx_header` data structures that are essential for the correct execution of `selectCRXTrack`.
</requirement>
<requirement>
The global variable `shot_select` should be fuzzed. This variable is used to select a specific track or frame, and different values will exercise different paths within the function.
</requirement>
<requirement>
The global variable `tiff_nifds` must be initialized to a value less than `LIBRAW_IFD_MAXCOUNT`, and the `tiff_ifd` array must be populated. The function reads from the `tiff_ifd` array, so it must be valid to prevent crashes.
</requirement>
<requirement>
The global array `imgdata.makernotes.canon.multishot` must be initialized. The function accesses elements of this array, so it must contain valid data to avoid out-of-bounds reads.
</requirement>
</requirements>
