
	
<description>
The function `SafeUint32Mult` safely multiplies three 32-bit unsigned integers (`arg1`, `arg2`, `arg3`). It checks for arithmetic overflow before performing the multiplication. If the multiplication would result in an overflow, the function returns `false`. Otherwise, it stores the result in the memory location pointed to by the `result` parameter and returns `true`. This function is a wrapper around another `SafeUint32Mult` function that throws a `dng_exception` on overflow, which is then caught by the target function. The core logic relies on checking if `arg2 <= max_uint32 / arg1` to prevent overflow. This function is widely used throughout the codebase for calculating buffer sizes and image dimensions, where the inputs are derived from the DNG file being processed.
</description>
