
	
<description>
The `evhttp_start` function initializes a new HTTP server instance. It first creates a new `evhttp` object by calling `evhttp_new_object`. After that, it binds the server to a specific address and port by calling `evhttp_bind_socket`. If either of these steps fails, the function cleans up any allocated resources and returns NULL. Otherwise, it returns a pointer to the newly created `evhttp` structure.
</description>
<requirements>
<requirement>
The `address` parameter should be a valid IP address, such as "127.0.0.1", "::1" or "0.0.0.0". This is because the address is passed to the `bind_socket` function, which expects a valid IP address to bind the socket to.
</requirement>
<requirement>
The `port` parameter should be a valid port number. The callers of this function use a variety of ports, including 0 to indicate that any available port can be used.
</requirement>
</requirements>
