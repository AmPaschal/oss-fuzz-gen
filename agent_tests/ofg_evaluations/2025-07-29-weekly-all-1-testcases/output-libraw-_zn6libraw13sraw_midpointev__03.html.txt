The returned value is determined by the `load_raw` function pointer, which is a member of the `LibRaw` class. The function returns 8192 for Canon sRAW and Sony YCbCr files, 2048 for Nikon sRAW files, and 0 for all other file types. The `load_raw` member is initialized by the `open_file()` method, which determines the file type and assigns the appropriate raw loading function.
</description>
