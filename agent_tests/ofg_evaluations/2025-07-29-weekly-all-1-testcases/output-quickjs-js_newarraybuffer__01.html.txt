
	
<description>
The JS_NewArrayBuffer function is used to create a new JavaScript ArrayBuffer. It is a wrapper around the js_array_buffer_constructor3 function, which does the actual work of creating the ArrayBuffer object and allocating the underlying buffer. The caller can provide a pre-allocated buffer or have the function allocate a new one. The caller can also provide a custom free function to release the buffer when the ArrayBuffer is garbage collected.
</description>
<requirements>
<requirement>
The `len` argument must be less than or equal to INT32_MAX. This is because the underlying function `js_array_buffer_constructor3` has a check that throws a RangeError if the length is greater than INT32_MAX.
</requirement>
<requirement>
The `buf` argument can be a pointer to a pre-allocated buffer. If `buf` is not NULL, the `free_func` argument should be a pointer to a function that can free the buffer.
</requirement>
<requirement>
The `is_shared` argument should be either TRUE or FALSE. This argument determines whether a normal or shared ArrayBuffer is created.
</requirement>
<requirement>
The `ctx` argument must be a valid pointer to a JSContext struct. This is because the function dereferences this pointer to access the JSRuntime.
</requirement>
</requirements>
