The function `xls_open_file` opens and parses an XLS file. It takes a file path, a character set, and an optional error pointer. It first opens the file as an OLE2 container using `ole2_open_file`. If successful, it then proceeds to parse the workbook data from the OLE container using `xls_open_ole`, which reads various streams like "Workbook" or "Book", "SummaryInformation", and "DocumentSummaryInformation". The function returns a pointer to an `xlsWorkBook` structure on success, or `NULL` on failure.
</description>

<requirement>

</requirement>
<requirement>
The second argument `charset` can be a NULL pointer, in which case "UTF-8" is used as the default character set. If it is not NULL, it should be a null-terminated string representing a valid character encoding.
</requirement>
<requirement>
The third argument `outError` is an optional output parameter and can be a NULL pointer. If it is not NULL, it will be used to store the error code in case of failure.
</requirement>
