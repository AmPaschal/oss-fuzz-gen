
	
<description>
The function `cmsCreateProofingTransform` creates a proofing transform. This transform maps colors from an input profile to an output profile, simulating the output on a proofing device. It is a wrapper around `cmsCreateProofingTransformTHR` which, in turn, calls `cmsCreateExtendedTransform` to create a complex transform involving multiple profiles and intents. The function takes as input three profiles (input, output, and proofing), their corresponding color formats, two rendering intents (one for the main transform and one for the proofing), and a set of flags to control the transform.
</description>
<requirements>
<requirement>
The `InputProfile`, `OutputProfile`, and `ProofingProfile` arguments must be valid `cmsHPROFILE` handles. These can be created using functions like `cmsOpenProfileFromFile`, `cmsCreate_sRGBProfile`, or `cmsCreateLab4Profile`, and must be closed with `cmsCloseProfile` after use to avoid memory leaks.
</requirement>
<requirement>
The `InputFormat` and `OutputFormat` arguments must be valid format specifiers. These are bitmasks composed of color space and data type flags (e.g., `PT_RGB` and `PT_U8`, `TYPE_BGRA_8`).
</requirement>
<requirement>
The `nIntent` and `ProofingIntent` arguments must be a value between 0 and 3. These correspond to the predefined rendering intents `INTENT_PERCEPTUAL`, `INTENT_RELATIVE_COLORIMETRIC`, `INTENT_SATURATION`, and `INTENT_ABSOLUTE_COLORIMETRIC`.
</requirement>
<requirement>
The `dwFlags` argument must contain either `cmsFLAGS_SOFTPROOFING` or `cmsFLAGS_GAMUTCHECK`. This is because the function will otherwise call `cmsCreateTransformTHR` instead of creating a proofing transform.
</requirement>
<requirement>
The transform created by this function should be deleted with `cmsDeleteTransform`. This is to free the resources allocated for the transform.
</requirement>
</requirements>

#include <stdint.h>

// Forward declaration of the function under test.
cmsHTRANSFORM cmsCreateProofingTransform(cmsHPROFILE, cmsUInt32Number, cmsHPROFILE, cmsUInt32Number, cmsHPROFILE, cmsUInt32Number, cmsUInt32Number, cmsUInt32Number);

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    // We need 16 bytes for parameters and at least 1 byte for the profile data.
    if (size < 17) {
        return 0;
    }

    // --- Parameter Extraction ---
    // Use the first 16 bytes of the input data to derive integer parameters.
    const uint32_t nIntent = ((const uint32_t *)data)[0] % 4;
    const uint32_t proofingIntent = ((const uint32_t *)data)[1] % 4;
    uint32_t dwFlags = ((const uint32_t *)data)[2];

    // As per requirements, the flags must contain either SOFTPROOFING or GAMUTCHECK.
    // We'll alternate between them based on a fuzzing byte to cover both paths.
    if (((const uint32_t *)data)[3] % 2) {
        dwFlags |= cmsFLAGS_SOFTPROOFING;
    } else {
        dwFlags |= cmsFLAGS_GAMUTCHECK;
    }

    // The rest of the data will be used to create the input profile.
    const uint8_t *profileData = data + 16;
    size_t profileSize = size - 16;

    // --- Profile Creation ---
    cmsHPROFILE hInputProfile = cmsOpenProfileFromMem(profileData, profileSize);
    if (hInputProfile == NULL) {
        return 0;
    }

    // Create standard, valid profiles for the other arguments.
    cmsHPROFILE hOutputProfile = cmsCreate_sRGBProfile();
    if (hOutputProfile == NULL) {
        cmsCloseProfile(hInputProfile);
        return 0;
    }

    cmsHPROFILE hProofingProfile = cmsCreateLab4Profile(NULL);
    if (hProofingProfile == NULL) {
        cmsCloseProfile(hInputProfile);
        cmsCloseProfile(hOutputProfile);
        return 0;
    }

    // Use fixed, common formats for simplicity and stability.
    cmsUInt32Number InputFormat = TYPE_RGB_8;
    cmsUInt32Number OutputFormat = TYPE_CMYK_8;

    // --- Function Invocation ---
    cmsHTRANSFORM hTransform = cmsCreateProofingTransform(hInputProfile,
                                                          InputFormat,
                                                          hOutputProfile,
                                                          OutputFormat,
                                                          hProofingProfile,
                                                          nIntent,
                                                          proofingIntent,
                                                          dwFlags);

    // --- Cleanup ---
    if (hTransform != NULL) {
        cmsDeleteTransform(hTransform);
    }

    cmsCloseProfile(hInputProfile);
    cmsCloseProfile(hOutputProfile);
    cmsCloseProfile(hProofingProfile);

    return 0;
}
