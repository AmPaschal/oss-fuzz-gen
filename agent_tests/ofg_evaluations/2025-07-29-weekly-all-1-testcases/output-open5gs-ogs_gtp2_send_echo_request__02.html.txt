
	
<description>
The function `ogs_gtp2_send_echo_request` sends a GTPv2 Echo Request message to a peer GTP node. It constructs the echo request message using `ogs_gtp2_build_echo_request`, creates a local transaction using `ogs_gtp_xact_local_create`, and commits the transaction with `ogs_gtp_xact_commit`. The function expects a valid `ogs_gtp_node_t` object representing the peer, and `recovery` and `features` values to be included in the echo request.
</description>
<requirements>
<requirement>
The `gnode` parameter must be a non-NULL pointer to a valid `ogs_gtp_node_t` structure. The function asserts this condition, and the `gnode`'s `addr` and `local_list` members are accessed in the called function `ogs_gtp_xact_local_create`.
</requirement>
<requirement>
The global application and local configuration state must be initialized before calling this function. The called function `ogs_gtp_xact_local_create` depends on global state accessed via `ogs_app()` and `ogs_local_conf()`.
</requirement>
<requirement>
The `recovery` and `features` parameters are `uint8_t` values passed to `ogs_gtp2_build_echo_request`. Their specific constraints are not apparent from the target function's implementation and should be fuzzed.
</requirement>
</requirements>

#include <stdio.h>
#include <stdint.h>

#include "fuzzing.h"
#include "ogs-gtp.h"

void ogs_gtp2_send_echo_request(ogs_gtp_node_t *, uint8_t, uint8_t);

extern int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size)
{
    if (Size < 2) {
        return 0;
    }

    if (!initialized) {
        initialize();
        ogs_log_install_domain(&__ogs_gtp_domain, "gtp", OGS_LOG_NONE);
        ogs_log_install_domain(&__ogs_tlv_domain, "tlv", OGS_LOG_NONE);
    }

    uint8_t recovery = Data[0];
    uint8_t features = Data[1];

    ogs_sockaddr_t *sa = NULL;
    if (ogs_sockaddr_from_ip_or_fqdn(&sa, AF_INET, "127.0.0.1", 2123) != OGS_OK) {
        return 0;
    }
    if (!sa) {
        return 0;
    }

    ogs_gtp_node_t *gnode = ogs_gtp_node_new(sa);
    if (!gnode) {
        ogs_freeaddrinfo(sa);
        return 0;
    }

    ogs_gtp2_send_echo_request(gnode, recovery, features);

    ogs_gtp_node_free(gnode);

    return 0;
}
