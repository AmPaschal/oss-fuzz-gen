The function is designed for a single-shot compression operation and is not intended for streaming compression. It is a simplified version of the more general ZSTD_compressStream2 function, and it handles the setup and finalization of the compression stream internally. The caller is responsible for allocating the necessary memory for the input and output buffers and for the compression context.
