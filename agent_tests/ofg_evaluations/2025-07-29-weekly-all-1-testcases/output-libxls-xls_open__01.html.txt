
	
<description>
The `xls_open` function opens an Excel file and prepares it for reading. It is a wrapper around `xls_open_file`, which in turn calls `ole2_open_file` to open the provided file as an OLE2 compound file. After successfully opening the OLE file, it proceeds to call `xls_open_ole` to parse the workbook data. The function expects a valid file path to an XLS file and an optional character set for string encoding.
</description>
<requirements>
<requirement>
The first argument, `file`, must be a path to a readable OLE2 file. This is necessary because the underlying `ole2_open_file` function uses `fopen` to open the file in binary read mode.
</requirement>
<requirement>
The OLE2 file must contain a stream named "Workbook" or "Book". The function `xls_open_ole` requires one of these streams to be present to parse the spreadsheet data.
</requirement>
<requirement>
The `charset` argument can be a null-terminated string that specifies the character encoding, or it can be `NULL`. If it is `NULL`, the function will default to using "UTF-8" for the character set.
</requirement>
</requirements>
