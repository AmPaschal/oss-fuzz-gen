
	
<description>
The `cil_write_build_ast` function builds an Abstract Syntax Tree (AST) from a parse tree within a CIL database and then writes the built AST to a file. It first validates the database pointer, then builds the AST using `cil_build_ast`, destroys the parse tree, and finally writes the AST to the provided file pointer. The caller is responsible for all initial setup of the database and for managing the output file stream.
</description>
<requirements>

<requirement>
The `out` argument must be a valid file pointer opened for writing. This is because the function writes the AST to this file stream.
</requirement>
<requirement>
The `db` argument must be a valid pointer to a `cil_db_t` structure and must not be NULL. The function performs a NULL check on this pointer and will fail if it is NULL.
</requirement>
<requirement>
The `cil_db_init` function must be called to initialize the `cil_db_t` struct before it is passed to `cil_write_build_ast`. This ensures that the internal structures, including the parse and AST trees, are properly set up.
</requirement>
<requirement>
The `db->parse` tree must be populated by calling `cil_add_file` with CIL source data before calling `cil_write_build_ast`. This is a critical step because the primary purpose of this function is to build the AST from this parse tree.
</requirement>

</requirements>

#include <stdio.h>
#include <stdlib.h>

#include <sepol/cil/cil.h>

// Define the missing symbol to satisfy the linker. This variable is required
// by the checkpolicy object files that are incorrectly linked by the build script.
jmp_buf fuzzing_pre_parse_stack_state;

// Log handler to suppress output during fuzzing.
static void log_handler(__attribute__((unused)) int lvl, __attribute__((unused)) const char *msg) {
    /* be quiet */
}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    cil_db_t *db = NULL;
    FILE *out = NULL;

    // Use /dev/null for output to avoid disk I/O.
    out = fopen("/dev/null", "w");
    if (out == NULL) {
        return 0;
    }

    // Set a quiet log handler to prevent spamming fuzzer logs.
    cil_set_log_handler(log_handler);

    // Initialize the CIL database.
    cil_db_init(&db);
    if (db == NULL) {
        fclose(out);
        return 0;
    }

    // Load the fuzzer-provided data as a CIL file to populate the parse tree.
    // This is a prerequisite for cil_write_build_ast.
    if (cil_add_file(db, "fuzz_input", (const char *)data, size) != SEPOL_OK) {
        cil_db_destroy(&db);
        fclose(out);
        return 0;
    }

    // Call the function under test.
    cil_write_build_ast(out, db);

    // Clean up allocated resources.
    cil_db_destroy(&db);
    fclose(out);

    return 0;
}
