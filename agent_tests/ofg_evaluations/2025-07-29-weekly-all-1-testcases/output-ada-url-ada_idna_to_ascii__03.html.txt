
	
<description>
The `ada_idna_to_ascii` function converts a UTF-8 string to an ASCII string using the IDNA (Internationalizing Domain Names in Applications) standard. It takes a character pointer and its length as input, and returns an `ada_owned_string` struct containing the ASCII representation of the input string. The caller is responsible for freeing the memory allocated for the returned string by calling `ada_free_owned_string`.
</description>
<requirements>
<requirement>
The `input` argument should be a valid pointer to a character array. This is to prevent null pointer dereferences inside the function.</requirement>
<requirement>
The `length` argument should be the correct length of the `input` character array. This is to prevent out-of-bounds memory access when creating the `std::string_view`.</requirement>
<requirement>
The returned `ada_owned_string` must be freed by calling `ada_free_owned_string`. This is because the function allocates memory for the `data` member of the struct, which must be deallocated to prevent memory leaks.</requirement>
</requirements>
