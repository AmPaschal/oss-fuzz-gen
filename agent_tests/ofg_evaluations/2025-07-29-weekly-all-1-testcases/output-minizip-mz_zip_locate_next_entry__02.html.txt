
	
<description>
The function `mz_zip_locate_next_entry` iterates through the entries of a zip archive and calls a user-provided callback function for each entry. The iteration starts from the current entry and continues until the end of the archive or until the callback function returns 0. The primary purpose of this function is to allow searching for specific entries within the zip file based on criteria defined in the callback function.
</description>
<requirements>

<requirement>
The `handle` argument must be a valid pointer to a `mz_zip` structure that has been successfully opened using `mz_zip_open`. This is because the function internally casts the handle to a `mz_zip*` and accesses its members, so an invalid handle will lead to a crash.
</requirement>
<requirement>
The `cb` argument must be a valid function pointer to a callback function with the signature `int32_t (*mz_zip_locate_entry_cb)(void *handle, void *userdata, mz_zip_file *file_info)`. The callback function should be designed to return 0 when the desired entry is found, which will stop the iteration, and a non-zero value to continue to the next entry.
</requirement>
<requirement>
The function `mz_zip_goto_first_entry` must be called before calling `mz_zip_locate_next_entry`. This is necessary to position the internal entry cursor at the beginning of the central directory, allowing the iteration to start from the first entry.
</requirement>
<requirement>
The `userdata` argument can be a pointer to any custom data that needs to be accessed within the callback function. The user is responsible for managing the memory for this data, ensuring it is valid for the duration of the `mz_zip_locate_next_entry` call.
</requirement>

</requirements>
