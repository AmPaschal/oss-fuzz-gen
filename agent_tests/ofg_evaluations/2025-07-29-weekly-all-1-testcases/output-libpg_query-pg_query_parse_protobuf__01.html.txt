
	
<description>
The `pg_query_parse_protobuf` function parses a SQL query string and returns the parse tree in a protocol buffer format. It is a wrapper around `pg_query_parse_protobuf_opts` which takes an additional `parser_options` argument. This argument is a bitmask that controls the parsing behavior. The lower 4 bits specify the parse mode, and the other bits control various parsing options. The function returns a `PgQueryProtobufParseResult` struct which contains the parse tree, a stderr buffer, and an error object.
</description>
