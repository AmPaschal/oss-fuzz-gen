
	
<description>
The function `StringToDouble` converts a string representation of a number to a double-precision floating-point value. It is a member of the `StringToDoubleConverter` class and its behavior is heavily influenced by the flags and values set during the instantiation of the converter object. The function itself is a wrapper around the `StringToIeee` function, which performs the actual conversion. The `StringToIeee` function parses the input string, handling optional signs, special values like 'infinity' and 'NaN', and different number bases (decimal, hexadecimal, or octal) as specified by the converter's flags.
</description>
<requirements>
<requirement>
The `StringToDoubleConverter` object must be initialized before calling the target function. This is because the function's behavior depends on the flags and symbols set in the converter object during its construction.
</requirement>
<requirement>
The `buffer` argument should be a valid pointer to an array of `uc16` characters, and the `length` argument should be the number of elements in that array. A null pointer for `buffer` with a non-zero `length` will lead to a crash.
</requirement>
<requirement>
The `processed_characters_count` argument must be a valid pointer to an integer. The function writes the number of processed characters to this location, so a null or invalid pointer will cause a crash.
</requirement>
<requirement>
The `length` argument should be a non-negative integer. A negative value will cause `end` to be less than `current`, leading to incorrect behavior and potential crashes.
</requirement>
</requirements>

#include <cstddef>
#include <cstdint>
#include <cstdlib>

#include "double-conversion.h"

using double_conversion::StringToDoubleConverter;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  StringToDoubleConverter converter(
      StringToDoubleConverter::ALLOW_HEX |
          StringToDoubleConverter::ALLOW_OCTALS |
          StringToDoubleConverter::ALLOW_TRAILING_JUNK |
          StringToDoubleConverter::ALLOW_LEADING_SPACES |
          StringToDoubleConverter::ALLOW_TRAILING_SPACES |
          StringToDoubleConverter::ALLOW_SPACES_AFTER_SIGN |
          StringToDoubleConverter::ALLOW_CASE_INSENSIBILITY |
          StringToDoubleConverter::ALLOW_HEX_FLOATS,
      /*empty_string_value=*/0.0,
      /*junk_string_value=*/0.0, "inf", "nan");

  const uc16 *buffer = reinterpret_cast<const uc16 *>(data);
  int length = size / sizeof(uc16);
  int processed_characters_count;

  converter.StringToDouble(buffer, length, &processed_characters_count);
  return 0;
}
