
	
<description>
The function `MmsValue_createArray` creates a new `MmsValue` object of type `MMS_ARRAY`. It allocates memory for the array and initializes each element to a default value based on the provided `elementType`. The caller `MmsValue_newDefaultValue` shows that this function can be called recursively to create multi-dimensional arrays.
</description>
<requirements>
<requirement>
The `elementType` argument must be a valid pointer to a `MmsVariableSpecification` struct. This is because it is dereferenced to determine the type of the array elements.
</requirement>
<requirement>
The `size` argument should be a non-negative integer. This is because it is used as a loop counter and for memory allocation, so a negative value would lead to undefined behavior.
</requirement>
<requirement>
If the `elementType->type` is `MMS_ARRAY`, the `elementType->typeSpec.array.elementTypeSpec` must be a valid pointer and `elementType->typeSpec.array.elementCount` must be a valid size. This is to prevent crashes or infinite recursion when creating nested arrays.
</requirement>
</requirements>
