
	
<description>
The function `lou_getEmphClasses` retrieves the emphasis class names from a compiled translation table. The `tableList` parameter is a string containing a comma-separated list of table files. The function first calls `_lou_getTranslationTable` to get the table header for the given `tableList`. If the table is found, it iterates through the `emphClassNames` array in the table header, copying the names into a newly allocated array. The returned array is NULL-terminated and the caller is responsible for freeing it.
</description>
<requirements>
<requirement>
The `tableList` argument must be a null-terminated string that represents a valid, compiled translation table or a list of tables. This is because the function internally calls `_lou_getTranslationTable` to resolve this string to a table structure.
</requirement>
<requirement>
The `lou_getTable()` function should be called before `lou_getEmphClasses()`. This is to ensure that the table passed as `tableList` has been compiled and is available in memory for `_lou_getTranslationTable` to find.
</requirement>
<requirement>
The number of emphasis classes defined in the table should be less than or equal to `MAX_EMPH_CLASSES`, which is 10. The function will only read up to `MAX_EMPH_CLASSES` names.
</requirement>
<requirement>
The caller must free the memory allocated for the returned array of strings. The function uses `malloc` to allocate memory for the result, and this memory must be freed to prevent leaks.
</requirement>
</requirements>
