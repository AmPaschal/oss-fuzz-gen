
	
<description>
The function `opus_encode_float` encodes a frame of floating-point audio data. It requires a properly initialized `OpusEncoder` state, and the `analysis_frame_size` argument is constrained by the sample rate configured in the encoder state. The `pcm` buffer must be large enough to hold the audio data for the given frame size and number of channels.
</description>
<requirements>
<requirement>
The `OpusEncoder *st` argument must be initialized by calling `opus_encoder_create`. This is because `opus_encoder_create` allocates and initializes the encoder state required by `opus_encode_float`.
</requirement>
<requirement>
The `analysis_frame_size` argument must be greater than or equal to `st->Fs / 400`. This is a requirement from the internal `frame_size_select` function, which will return an error otherwise.
</requirement>
<requirement>
The `pcm` buffer must have a size of at least `analysis_frame_size * st->channels`. This is to prevent out-of-bounds memory access when the function reads from this buffer.
</requirement>
<requirement>
The `max_data_bytes` argument should be a reasonable value to prevent buffer overflows, with 1276 being a safe value used in the project's own test suites. This is to ensure the output buffer `data` is large enough to hold the encoded packet.
</requirement>
<requirement>
The `st->variable_duration` field, configurable via `opus_encoder_ctl` with `OPUS_SET_EXPERT_FRAME_DURATION_REQUEST`, must be a valid `OPUS_FRAMESIZE` constant. This is necessary for the `frame_size_select` function to correctly calculate the frame size.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <vector>

#include "/src/opus/include/opus.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Setup encoder
  const opus_int32 kSampleRates[] = {8000, 12000, 16000, 24000, 48000};
  const int kChannels[] = {1, 2};
  const int kApplications[] = {OPUS_APPLICATION_VOIP, OPUS_APPLICATION_AUDIO,
                               OPUS_APPLICATION_RESTRICTED_LOWDELAY};

  const opus_int32 fs = provider.PickValueInArray(kSampleRates);
  const int channels = provider.PickValueInArray(kChannels);
  const int application = provider.PickValueInArray(kApplications);

  int err;
  OpusEncoder *encoder = opus_encoder_create(fs, channels, application, &err);
  if (encoder == nullptr) {
    return 0;
  }

  // Setup PCM data and frame size.
  // Valid frame durations are 2.5, 5, 10, 20, 40, 60 ms.
  const float kFrameDurationsMs[] = {2.5f, 5.0f, 10.0f, 20.0f, 40.0f, 60.0f};
  const float frame_duration_ms = provider.PickValueInArray(kFrameDurationsMs);
  const int frame_size = static_cast<int>(frame_duration_ms * fs / 1000.0f);

  const size_t pcm_size = frame_size * channels;
  if (pcm_size == 0) {
    opus_encoder_destroy(encoder);
    return 0;
  }

  // Create the float vector for PCM input and fill it with fuzzer data.
  std::vector<float> pcm(pcm_size);
  const size_t bytes_to_consume = pcm_size * sizeof(float);
  const size_t consumed_bytes = provider.ConsumeData(pcm.data(), bytes_to_consume);

  if (consumed_bytes != bytes_to_consume) {
    opus_encoder_destroy(encoder);
    return 0;
  }

  // Setup output buffer. 4000 is a recommended size.
  const opus_int32 kMaxDataBytes = 4000;
  unsigned char output_data[kMaxDataBytes];

  // Call the function under test.
  (void)opus_encode_float(encoder, pcm.data(), frame_size, output_data,
                          kMaxDataBytes);

  // Cleanup.
  opus_encoder_destroy(encoder);

  return 0;
}
