
	
<description>
The `sf_get_chunk_iterator` function retrieves an iterator for accessing RIFF chunks within a sound file. It takes a `SNDFILE` pointer, `sndfile`, and an optional `SF_CHUNK_INFO` pointer, `chunk_info`, as input. If `chunk_info` is provided, the iterator will point to the chunk whose ID matches the `id` field of the `chunk_info` struct. If `chunk_info` is `NULL`, the iterator will point to the first chunk in the file. The returned `SF_CHUNK_ITERATOR` can be used with other chunk-related functions to retrieve chunk data and navigate through the file's chunks.
</description>
<requirements>

<requirement>
The `sndfile` argument must be a valid pointer to a `SNDFILE` struct returned by `sf_open`. This is because the `VALIDATE_SNDFILE_AND_ASSIGN_PSF` macro will cause a crash if `sndfile` is `NULL`.
</requirement>
<requirement>
The `SNDFILE` handle must be opened in read mode (`SFM_READ`). This is to ensure that the file is in a readable state for chunk iteration.
</requirement>
<requirement>
The file associated with the `sndfile` pointer should be a valid sound file containing chunks. The test code calls `sf_set_chunk` to add chunks to the file before calling `sf_get_chunk_iterator`.
</requirement>
<requirement>
The `chunk_info` argument can be `NULL`. The target function has a `NULL` check for this argument.
</requirement>
<requirement>
If the `chunk_info` argument is not `NULL`, the `id` field of the `SF_CHUNK_INFO` struct must be a null-terminated string. The `chunk_test.c` example uses `snprintf` to initialize this field, which is subsequently used to search for a specific chunk.
</requirement>

</requirements>

#include <inttypes.h>

extern "C" SF_CHUNK_ITERATOR * sf_get_chunk_iterator(SNDFILE *, const SF_CHUNK_INFO *);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Use a portion of the data for the virtual file content.
  size_t file_size = provider.ConsumeIntegralInRange<size_t>(0, provider.remaining_bytes());
  std::vector<uint8_t> file_data = provider.ConsumeBytes<uint8_t>(file_size);

  SF_INFO sndfile_info;
  VIO_DATA vio_data;
  SF_VIRTUAL_IO vio;
  SNDFILE *sndfile = NULL;

  // Initialize the virtual file using the helper function.
  int err = sf_init_file(file_data.data(), file_data.size(), &sndfile,
                         &vio_data, &vio, &sndfile_info);
  if (err || !sndfile) {
    return 0;
  }

  SF_CHUNK_ITERATOR *iterator = NULL;
  
  // Decide whether to pass a NULL or a valid chunk_info pointer.
  if (provider.ConsumeBool()) {
    SF_CHUNK_INFO chunk_info;
    memset(&chunk_info, 0, sizeof(chunk_info));

    // Populate the id field of the chunk_info struct with fuzzed data.
    std::string id = provider.ConsumeRandomLengthString(sizeof(chunk_info.id) - 1);
    strncpy(chunk_info.id, id.c_str(), sizeof(chunk_info.id) - 1);
    chunk_info.id[sizeof(chunk_info.id) - 1] = '\0'; // Ensure null termination.
    chunk_info.id_size = strlen(chunk_info.id);

    iterator = sf_get_chunk_iterator(sndfile, &chunk_info);
  } else {
    iterator = sf_get_chunk_iterator(sndfile, NULL);
  }

  // The iterator's memory is managed by the SNDFILE handle.
  // Closing the SNDFILE handle is sufficient for cleanup.
  sf_close(sndfile);

  return 0;
}
