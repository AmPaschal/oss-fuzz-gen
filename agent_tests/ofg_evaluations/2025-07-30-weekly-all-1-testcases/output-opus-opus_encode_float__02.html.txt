
	
<description>
The function opus_encode_float encodes a frame of floating-point audio data into the Opus format. It first determines the appropriate frame size, converts the input PCM data to an internal fixed-point representation, and then calls the opus_encode_native function to perform the encoding. The behavior of the encoding process is controlled by parameters set in the OpusEncoder state, which can be modified using the opus_encoder_ctl function. The function returns the number of bytes written to the output buffer on success, or an error code on failure.
</description>
<requirements>

<requirement>
The OpusEncoder `st` must be initialized by `opus_encoder_create()`. This is because `opus_encoder_create` allocates and initializes the encoder state, including essential parameters like the sample rate (Fs) and number of channels, which are necessary for `opus_encode_float` to function correctly.
</requirement>
<requirement>
The `pcm` buffer must point to a valid float array with a size of at least `analysis_frame_size * st->channels`. The function accesses this buffer up to `frame_size * st->channels` times, where `frame_size` is derived from `analysis_frame_size`, so an insufficiently sized buffer will lead to out-of-bounds reads and potential crashes.
</requirement>
<requirement>
The `analysis_frame_size` parameter should correspond to a supported frame duration (e.g., 2.5, 5, 10, 20, 40, 60 ms). An invalid `analysis_frame_size` will cause `frame_size_select` to return a non-positive value, resulting in `opus_encode_float` returning `OPUS_BAD_ARG`.
</requirement>
<requirement>
The `data` parameter must be a valid pointer to a buffer of size `max_data_bytes`. The encoded output is written to this buffer within the `opus_encode_native` function, and an invalid pointer would lead to a crash.
</requirement>
<requirement>
The `max_data_bytes` parameter must be large enough to accommodate the maximum possible encoded packet size. Based on the test cases, a value of 1276 is a safe choice to prevent buffer overflows when `opus_encode_native` writes the encoded data.
</requirement>
<requirement>
The `OpusEncoder` can be configured using `opus_encoder_ctl` before calling `opus_encode_float`. Various encoding parameters, such as bitrate, bandwidth, and complexity, can be set via `opus_encoder_ctl`, influencing the behavior and output of the encoding process.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <cstdlib>
#include <vector>

#include "opus.h"
#include "opus_types.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  const opus_int32 Fs_options[] = {8000, 12000, 16000, 24000, 48000};
  const opus_int32 Fs = provider.PickValueInArray(Fs_options);

  const int channels_options[] = {1, 2};
  const int channels = provider.PickValueInArray(channels_options);

  const int application_options[] = {OPUS_APPLICATION_VOIP,
                                     OPUS_APPLICATION_AUDIO,
                                     OPUS_APPLICATION_RESTRICTED_LOWDELAY};
  const int application = provider.PickValueInArray(application_options);

  int error;
  OpusEncoder *encoder = opus_encoder_create(Fs, channels, application, &error);
  if (error != OPUS_OK) {
    if (encoder) {
      opus_encoder_destroy(encoder);
    }
    return 0;
  }

  const int frame_duration_ms_options[] = {10, 20, 40, 60};
  const int frame_duration_ms =
      provider.PickValueInArray(frame_duration_ms_options);
  const int frame_size = (Fs / 1000) * frame_duration_ms;

  const size_t pcm_size_in_floats = frame_size * channels;
  const size_t pcm_size_in_bytes = pcm_size_in_floats * sizeof(float);

  std::vector<uint8_t> pcm_bytes =
      provider.ConsumeBytes<uint8_t>(pcm_size_in_bytes);
  if (pcm_bytes.size() < pcm_size_in_bytes) {
    opus_encoder_destroy(encoder);
    return 0;
  }
  const float *pcm_data = reinterpret_cast<const float *>(pcm_bytes.data());

  const opus_int32 max_data_bytes = 4000;
  std::vector<unsigned char> encoded_data(max_data_bytes);

  opus_int32 ret = opus_encode_float(encoder, pcm_data, frame_size,
                                     encoded_data.data(), max_data_bytes);
  (void)ret;

  opus_encoder_destroy(encoder);
  return 0;
}
