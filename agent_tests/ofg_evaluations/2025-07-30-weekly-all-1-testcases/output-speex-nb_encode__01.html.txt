
	
<description>
The `nb_encode` function is the core narrowband encoding function in the Speex audio codec. It takes the encoder state, a frame of audio data, and a bitstream structure as input, and writes the encoded audio data to the bitstream. The encoder state must be initialized by `speex_encoder_init`, and various encoding parameters can be configured using `speex_encoder_ctl`. The input audio data is a frame of 16-bit samples. The `SpeexBits` structure must be initialized using `speex_bits_init` before calling this function. The function returns 1 on success and 0 on failure.
</description>
<requirements>
<requirement>
The first argument, a void pointer to the encoder state, must be initialized by calling `speex_encoder_init`. This is because the function expects a fully initialized `EncState` structure to access various encoding parameters and memory buffers.
</requirement>
<requirement>
The third argument, a pointer to a `SpeexBits` struct, must be initialized by calling `speex_bits_init`. This is to ensure that the bit-packing operations within the function have a valid buffer to write to.
</requirement>
<requirement>
The `submodeID` field of the `EncState` struct, which is set using `speex_encoder_ctl` with the `SPEEX_SET_MODE` request, must be a valid sub-mode ID. This is to prevent out-of-bounds access to the `submodes` array and to avoid null pointer dereferences when calling sub-mode specific functions.
</requirement>
<requirement>
The second argument, `vin`, must point to a buffer of `spx_int16_t` of at least `NB_FRAME_SIZE` (160) samples. This is because the function reads this many samples from the buffer to perform encoding.
</requirement>
</requirements>

#define FIXED_POINT 1

#include <fuzzer/FuzzedDataProvider.h>
#include <stdint.h>
#include <vector>

#include "speex/speex.h"
#include "speex/speex_bits.h"

extern "C" {
#include "/src/speex/libspeex/nb_celp.h"
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider fdp(data, size);

    // Initialize Speex encoder for narrowband mode.
    void *st = speex_encoder_init(&speex_nb_mode);
    if (!st) {
        return 0;
    }

    // Initialize SpeexBits struct to hold the encoded data.
    SpeexBits bits;
    speex_bits_init(&bits);

    // Get the required frame size for the narrowband encoder.
    spx_int32_t frame_size;
    speex_encoder_ctl(st, SPEEX_GET_FRAME_SIZE, &frame_size);
    if (frame_size <= 0) {
        speex_encoder_destroy(st);
        speex_bits_destroy(&bits);
        return 0;
    }

    // Prepare the input audio frame.
    const size_t input_buffer_size = frame_size * sizeof(spx_int16_t);
    if (fdp.remaining_bytes() < input_buffer_size) {
        speex_encoder_destroy(st);
        speex_bits_destroy(&bits);
        return 0;
    }
    std::vector<spx_int16_t> input_buffer(frame_size);
    fdp.ConsumeData(input_buffer.data(), input_buffer_size);

    // Call the function under test.
    nb_encode(st, input_buffer.data(), &bits);

    // Clean up resources.
    speex_encoder_destroy(st);
    speex_bits_destroy(&bits);

    return 0;
}
