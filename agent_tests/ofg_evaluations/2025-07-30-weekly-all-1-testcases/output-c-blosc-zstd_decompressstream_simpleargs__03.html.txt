
	
<description>
The function ZSTD_decompressStream_simpleArgs is a wrapper around ZSTD_decompressStream. It takes a pre-allocated destination buffer and a source buffer with compressed data and decompresses the data from the source buffer into the destination buffer. The function updates the positions in the source and destination buffers. It returns 0 on success, or an error code if something goes wrong.
</description>
