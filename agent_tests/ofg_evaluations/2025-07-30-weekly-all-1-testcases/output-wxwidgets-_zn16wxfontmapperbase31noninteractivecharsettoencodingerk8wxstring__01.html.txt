
	
<description>
The function `wxFontMapperBase::NonInteractiveCharsetToEncoding` converts a charset string, provided as a `wxString`, to its corresponding `wxFontEncoding` enum value. The function is designed to handle various formats of charset strings. It first attempts to resolve the charset by looking up a user-defined mapping in the application's configuration. If no mapping is found in the configuration, the function proceeds to perform a series of checks to identify the encoding. It compares the input string against a predefined list of known encoding names (case-insensitively). If a match is found, the corresponding enum value is returned. If there is still no match, the function attempts to parse the string as an ISO-8859-X or a Windows CPXXXX encoding. If all these attempts fail, it returns a default system encoding.
</description>
