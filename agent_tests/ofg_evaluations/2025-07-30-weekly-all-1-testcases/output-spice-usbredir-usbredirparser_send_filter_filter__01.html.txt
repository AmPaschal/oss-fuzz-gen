
	
<description>
The function `usbredirparser_send_filter_filter` sends a filter to the peer. It first checks if the peer has the `usb_redir_cap_filter` capability. If it does, it converts the given filter rules to a string and queues it to be sent to the peer. The function is part of a library and does not have any callers within the project.
</description>
<requirements>
<requirement>
The first argument, `parser_pub`, must be a valid pointer to a `usbredirparser` struct. This is because it is dereferenced in the function `usbredirparser_peer_has_cap`.
</requirement>
<requirement>
The `parser_pub` argument must be initialized to have the `usb_redir_cap_filter` capability. This is because the function will return early if the capability is not present.
</requirement>
<requirement>
If the `rules_count` argument is greater than 0, the `rules` argument must be a valid pointer to an array of `usbredirfilter_rule` structs of size `rules_count`. This is to prevent a crash when the `rules` array is accessed in `usbredirfilter_rules_to_string`.
</requirement>
<requirement>
If the `rules_count` argument is 0, the `rules` argument can be NULL. This is because `usbredirfilter_rules_to_string` handles this case gracefully.
</requirement>
</requirements>

namespace {
struct ParserDeleter {
    void operator()(struct usbredirparser *p) {
        if (p) {
            usbredirparser_destroy(p);
        }
    }
};

// A dummy write callback that simply consumes all data to prevent blocking.
int parser_write_cb(void *priv, uint8_t *data, int count) {
    return count;
}
} // namespace

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider fdp(data, size);

    std::unique_ptr<usbredirparser, ParserDeleter> parser(usbredirparser_create());
    if (!parser) {
        return 0;
    }

    parser->write_func = parser_write_cb;

    std::array<uint32_t, USB_REDIR_CAPS_SIZE> caps = {0};
    usbredirparser_caps_set_cap(caps.data(), usb_redir_cap_filter);
    usbredirparser_init(parser.get(), "fuzzer", caps.data(), caps.size(), 0);

    const int rules_count = fdp.ConsumeIntegralInRange<int>(0, 50);
    std::vector<usbredirfilter_rule> rules;
    if (rules_count > 0) {
        rules.reserve(rules_count);
        for (int i = 0; i < rules_count; ++i) {
            usbredirfilter_rule rule;
            rule.device_class = fdp.PickValueInArray<int>({-1, fdp.ConsumeIntegralInRange<int>(0, 255)});
            rule.vendor_id = fdp.PickValueInArray<int>({-1, fdp.ConsumeIntegralInRange<int>(0, 65535)});
            rule.product_id = fdp.PickValueInArray<int>({-1, fdp.ConsumeIntegralInRange<int>(0, 65535)});
            rule.device_version_bcd = fdp.PickValueInArray<int>({-1, fdp.ConsumeIntegralInRange<int>(0, 65535)});
            rule.allow = fdp.ConsumeBool();
            rules.push_back(rule);
        }
    }

    usbredirparser_send_filter_filter(parser.get(), rules.empty() ? nullptr : rules.data(), rules.size());

    while (usbredirparser_has_data_to_write(parser.get())) {
        if (usbredirparser_do_write(parser.get()) < 0) {
            break;
        }
    }

    return 0;
}
