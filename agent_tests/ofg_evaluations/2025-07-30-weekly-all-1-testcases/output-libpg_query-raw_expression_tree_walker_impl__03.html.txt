
	
<description>
The function `raw_expression_tree_walker_impl` recursively traverses a tree of `Node` structures. It takes a starting node, a callback function, and a context as input. For each node in the tree, it calls the callback function with the current node and the context. The traversal can be stopped if the callback function returns `true`. The function is primarily used to extract information from the abstract syntax tree (AST) of a SQL query.
</description>
<requirements>

</requirement>

<requirement>
The `walker` argument must be a valid function pointer to a function that matches the `tree_walker_callback` typedef, which is `bool (*)(Node *, void *)`. This is because the function is called for each node in the tree, and a NULL pointer would lead to a crash.
</requirement>
<requirement>
The `context` argument can be a NULL pointer or a pointer to a data structure that the `walker` function uses. This is because the context is passed directly to the walker function, so its validity depends on the walker's implementation.
</requirement>
<requirement>
A custom `walker` function can be provided. This function should handle a NULL `Node *` argument gracefully. The walker function can recursively call `raw_expression_tree_walker` to continue the traversal of the AST. The walker should return `true` to stop the traversal or `false` to continue.
</requirement>
