
	
<description>
The function `ada_parse_with_base` parses a URL string relative to a base URL. It takes two string views, one for the URL to be parsed and one for the base URL. The function first parses the base URL. If the base URL is invalid, the function returns a result indicating failure. Otherwise, it parses the input URL against the parsed base URL and returns the result.
</description>
<requirements>

<requirement>
The `base` and `input` pointers must not be NULL. This is to prevent a crash when constructing `std::string_view`.
</requirement>
<requirement>
The `base_length` and `input_length` arguments must be the correct lengths for the `base` and `input` buffers, respectively. This is to prevent out-of-bounds memory access.
</requirement>
<requirement>
The `base` buffer must contain a valid, absolute URL. The internal parsing of the base URL must succeed for the main parsing to be attempted.
</requirement>
<requirement>
The `input` buffer should be fuzzed. This is the main input to be tested by the fuzzer.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <string>
#include <vector>

// The build script uses -I build/singleheader, so we can include the amalgamated
// source and headers directly.
#include "ada.h"
#include "ada.cpp"

// By including ada.cpp, we get the full implementation of the C API,
// so we do not need to include ada_c.h or provide forward declarations.

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Split the input data into two strings: one for the input URL, and the
  // other for the base URL.
  size_t input_length = provider.ConsumeIntegralInRange<size_t>(0, provider.remaining_bytes());
  std::string input_str = provider.ConsumeBytesAsString(input_length);
  std::string base_str = provider.ConsumeRemainingBytesAsString();

  ada_url url = ada_parse_with_base(input_str.c_str(), input_str.length(),
                                    base_str.c_str(), base_str.length());

  // The returned ada_url is heap-allocated and must be freed.
  // The ada_free function is also defined within ada.cpp.
  if (url != nullptr) {
    ada_free(url);
  }

  return 0;
}
