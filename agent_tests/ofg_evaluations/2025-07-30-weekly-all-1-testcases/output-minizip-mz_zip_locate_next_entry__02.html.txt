
	
<description>
The `mz_zip_locate_next_entry` function iterates through the entries of a zip archive, starting from the current entry, and calls a callback function for each entry. The iteration stops when the callback function returns 0 or when all entries have been processed. The `handle` argument is a pointer to a `mz_zip` struct, which represents the zip archive. The `userdata` argument is a pointer to user-defined data that is passed to the callback function. The `cb` argument is a function pointer to the callback function.
</description>
<requirements>

<requirement>
The `handle` argument must be a valid pointer to a `mz_zip` struct that has been initialized by `mz_zip_open`. This is because the function operates on the internal state of the `mz_zip` struct to locate entries.
</requirement>
<requirement>
The `mz_zip_goto_first_entry` function must be called before calling `mz_zip_locate_next_entry`. This is to ensure that the internal state of the `mz_zip` struct is positioned at the beginning of the zip archive, allowing the function to iterate through all entries.
</requirement>
<requirement>
The `cb` argument must be a valid function pointer to a callback function with the signature `int32_t (*)(void *, void *, mz_zip_file *)`. This callback function is essential for processing each zip entry found by `mz_zip_locate_next_entry`.
</requirement>
<requirement>
The `userdata` argument can be a pointer to any data that the callback function needs. The caller is responsible for ensuring that the `userdata` is valid and that the callback function correctly interprets it.
</requirement>

</requirements>
