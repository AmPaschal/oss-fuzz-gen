
	
<description>
The function `cil_write_resolve_ast` takes a CIL (Common Intermediate Language) database and a file pointer as input. It builds an Abstract Syntax Tree (AST) from the parse tree within the database, resolves the AST, qualifies names, and finally writes the resolved AST to the provided file pointer. The caller, `secil2tree.c`, initializes a `cil_db_t` structure using `cil_db_init`, populates it by reading CIL files from disk and calling `cil_add_file`, and then passes the database and an output file pointer to the target function.
</description>

</requirement>

</requirement>
<requirement>
The `db->parse` member of the `db` struct must be populated by calling `cil_add_file` with CIL policy data before calling the target function. This is because the first step in the target function is to build an AST from `db->parse->root`.
</requirement>
<requirement>
The function `cil_db_destroy` should be called on the `db` object after `cil_write_resolve_ast` has returned. This is to ensure that all memory allocated for the CIL database is properly deallocated.
</requirement>

#include <stdlib.h>
#include <stdio.h>
#include <stdint.h>

#include "/src/selinux/libsepol/cil/include/cil/cil.h"
#include <sepol/policydb.h>

static void log_handler(__attribute__((unused)) int lvl, __attribute__((unused)) const char *msg) {
	/* be quiet */
}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
	struct cil_db *db = NULL;
	FILE *dev_null = NULL;

	cil_set_log_handler(log_handler);

	cil_db_init(&db);
	if (db == NULL) {
		return 0;
	}

	cil_set_disable_dontaudit(db, 0);
	cil_set_multiple_decls(db, 0);
	cil_set_disable_neverallow(db, 0);
	cil_set_preserve_tunables(db, 0);
	cil_set_mls(db, -1);
	cil_set_target_platform(db, SEPOL_TARGET_SELINUX);
	cil_set_policy_version(db, POLICYDB_VERSION_MAX);

	if (cil_add_file(db, "fuzz", (const char *)data, size) != SEPOL_OK) {
		goto exit;
	}

	dev_null = fopen("/dev/null", "w");
	if (dev_null == NULL) {
		goto exit;
	}

	cil_write_resolve_ast(dev_null, db);

exit:
	if (dev_null != NULL) {
		fclose(dev_null);
	}

	if (db != NULL) {
		cil_db_destroy(&db);
	}

	return 0;
}
