The ZSTD_decompressStream_simpleArgs function is a simplified wrapper around the ZSTD_decompressStream function. It takes a pre-allocated ZSTD_DCtx context, input and output buffer parameters, and decompresses a stream of data. The function updates the input and output positions, and returns a hint for the next input size.
</description>
