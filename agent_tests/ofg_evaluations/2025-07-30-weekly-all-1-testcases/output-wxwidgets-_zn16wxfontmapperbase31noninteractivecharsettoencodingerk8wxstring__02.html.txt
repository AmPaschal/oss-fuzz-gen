
	
<description>
The function `wxFontMapperBase::NonInteractiveCharsetToEncoding` takes a charset string as input and returns the corresponding `wxFontEncoding`. It is a non-interactive function that looks up the encoding from a configuration file. The function is called by `wxFontMapper::CharsetToEncoding` and `wxFontMapperBase::CharsetToEncoding`, which are higher-level functions for mapping charsets to encodings. These callers handle cases where the encoding is not found, and may interact with the user to determine the correct encoding.
</description>
<requirements>

<requirement>
The `charset` argument can be any valid `wxString`. The function is designed to handle unknown charsets, so fuzzing this input is desireable.</requirement>
<requirement>
A configuration file should be set up before calling this function. This can be done by calling `wxFontMapper::Get()->SetConfig()` with a valid `wxConfig` object. This is because the function reads from a config file to map charsets to encodings.</requirement>
<requirement>
The input `charset` can be a key in the config file. The value associated with this key should be a long integer representing a `wxFontEncoding`. If the value is -1, it means the charset is unknown. If the value is between 0 and `wxFONTENCODING_MAX`, it represents a valid encoding. Any other value is considered invalid.</requirement>
