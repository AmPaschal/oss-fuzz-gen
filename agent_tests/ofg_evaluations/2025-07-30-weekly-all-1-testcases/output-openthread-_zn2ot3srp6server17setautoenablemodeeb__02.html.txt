
	
<description>
The `SetAutoEnableMode` function sets the auto-enable mode for the SRP server. When this mode is enabled, the SRP server will be automatically enabled when the device becomes a Border Router leader. The function takes a boolean argument to enable or disable this mode. The function only proceeds if the new mode is different from the current mode. It then updates the internal state and notifies the `RoutingManager` of the change. The function relies on a properly initialized `otInstance` to get the `Srp::Server` and `RoutingManager` objects.
</description>
<requirements>

<requirement>
The `otInstance` must be initialized before calling this function. This is because the `Srp::Server` object is retrieved from the `otInstance`, and an uninitialized instance will lead to a crash.
</requirement>
<requirement>
The boolean argument `aEnabled` can be fuzzed with either true or false values. The function handles both cases, and the callers in the existing code use both values.
</requirement>
