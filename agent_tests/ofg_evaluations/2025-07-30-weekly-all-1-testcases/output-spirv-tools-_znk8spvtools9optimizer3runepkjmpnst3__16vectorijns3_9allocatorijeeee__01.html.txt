
	
<description>
The `spvtools::Optimizer::Run` function is the main entry point for the SPIR-V optimizer. It takes a raw SPIR-V binary as a `const uint32_t*` and its size, and an output vector `std::vector<uint32_t>*` to store the optimized binary. The function first validates the input binary (if not skipped), then builds an internal representation (IR) of the module. After that, it applies a series of registered optimization passes to the IR. Finally, it converts the modified IR back to binary form and writes it to the output vector. The return value indicates whether the optimization was successful.
</description>
<requirements>

<requirement>
The `original_binary` pointer must not be null. This is because it is dereferenced in the `BuildModule` function, and a null pointer would lead to a crash.
</requirement>
<requirement>
The `original_binary_size` must be greater than 0. A size of 0 will cause a crash when the `BuildModule` function tries to access the binary data.
</requirement>
<requirement>
The `original_binary` should represent a valid SPIR-V module. The function has an optional validation step, but even if it's skipped, the `BuildModule` function expects a well-formed binary to construct its internal representation, and invalid binaries can cause crashes.
</requirement>
<requirement>
The `optimized_binary` pointer must not be null. The function clears and writes to this vector, so a null pointer will cause a crash.
</requirement>

</requirements>

#include <cstdint>
#include <vector>

#include "spirv-tools/libspirv.hpp"
#include "spirv-tools/optimizer.hpp"
#include "test/fuzzers/random_generator.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
  if (size < 4) {
    return 0;
  }

  spvtools::fuzzers::RandomGenerator random_gen(data, size);
  spvtools::Optimizer opt(random_gen.GetTargetEnv());

  // Set a message consumer to ignore optimizer messages, which would otherwise
  // go to standard output.
  opt.SetMessageConsumer(
      [](spv_message_level_t, const char*, const spv_position_t&,
         const char*) {});

  // Use the project's RandomGenerator to make a choice about which passes to
  // register. GetUInt32(min, max) returns a value in [min, max].
  switch (random_gen.GetUInt32(0, 3)) {
    case 0:
      opt.RegisterPerformancePasses();
      break;
    case 1:
      opt.RegisterSizePasses();
      break;
    case 2:
      opt.RegisterLegalizationPasses();
      break;
    case 3:
      // Run with no passes registered. The optimizer will still validate.
      break;
  }

  // Convert the raw bytes to a vector of uint32_t words.
  std::vector<uint32_t> input_words;
  input_words.resize(size / 4);
  size_t count = 0;
  for (size_t i = 0; (i + 3) < size; i += 4) {
    input_words[count++] = data[i] | (data[i + 1] << 8) |
                           (data[i + 2] << 16) | (data[i + 3] << 24);
  }

  std::vector<uint32_t> optimized_binary;

  // Execute the optimizer.
  opt.Run(input_words.data(), input_words.size(), &optimized_binary);

  return 0;
}
