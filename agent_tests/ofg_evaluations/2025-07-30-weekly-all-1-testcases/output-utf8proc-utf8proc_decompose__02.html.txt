
	
<description>
The `utf8proc_decompose` function decomposes a UTF-8 string. It is a wrapper around `utf8proc_decompose_custom`, which iterates through the input string, decomposes each character, and then reorders the decomposed characters based on their combining class. The behavior of the function is controlled by the `options` parameter.
</description>
<requirements>
<requirement>
The `str` argument must be a valid UTF-8 string. This is because the function uses `utf8proc_iterate` to iterate through the string, which will return an error if it encounters invalid UTF-8 sequences.</requirement>
<requirement>
If the `options` field does not have the `UTF8PROC_NULLTERM` flag set, the `strlen` argument must be the correct length of the `str` buffer. This is to prevent out-of-bounds reads when iterating through the string.</requirement>
<requirement>
If the `options` field has the `UTF8PROC_NULLTERM` flag set, the `str` argument must be null-terminated. This is because the function will iterate through the string until it encounters a null terminator.</requirement>
<requirement>
The `buffer` argument must be a valid pointer to a writable memory region with a size of at least `bufsize` bytes. This is to prevent buffer overflows when the decomposed characters are written to the buffer.</requirement>
<requirement>
The `bufsize` argument should be large enough to store the decomposed string. If `bufsize` is too small, the decomposed string will be truncated and the reordering of combining characters will not be performed.</requirement>
<requirement>
The `options` argument must not contain both `UTF8PROC_COMPOSE` and `UTF8PROC_DECOMPOSE` flags. The function returns an error if both flags are set.</requirement>
<requirement>
If the `options` argument contains the `UTF8PROC_STRIPMARK` flag, it must also contain either the `UTF8PROC_COMPOSE` or `UTF8PROC_DECOMPOSE` flag. The function returns an error if this condition is not met.</requirement>
</requirements>
