
	
<description>
The function `firebase::firestore::core::OrderBy::Compare` compares two `Document` objects based on the field and direction specified in the `OrderBy` object. If the `OrderBy` object is configured to sort by the document key, the function compares the keys of the two documents. Otherwise, it extracts the value of the specified field from each document and compares them. The function will abort if the specified field does not exist in both documents.
</description>
<requirements>
<requirement>
The `OrderBy` object must be initialized with a valid `model::FieldPath` and `Direction`. This is because the function uses these members to determine which fields to compare and in what order.
</requirement>
<requirement>
If the `OrderBy` object is not configured to sort by document key, the two `Document` arguments, `d1` and `d2`, must both contain the field specified by the `OrderBy` object's `field_` member. This is to prevent a `HARD_FAIL` assertion failure in `AssertBothOptionalsHaveValues`.
</requirement>
<requirement>
The `Document` objects should be created from `MutableDocument` objects, which can be constructed with a key, a version, and field-value data. This ensures that the `Document` objects are in a valid state for comparison.
</requirement>
</requirements>

// Helper function to create a Document from fuzzed data.
Document CreateDocument(FuzzedDataProvider& provider) {
  // Create DocumentKey
  auto path_str = provider.ConsumeRandomLengthString(100);
  auto key = DocumentKey::FromPathString(path_str);

  // Create SnapshotVersion
  auto seconds = provider.ConsumeIntegral<int64_t>();
  auto nanos = provider.ConsumeIntegralInRange<int32_t>(0, 999999999);
  auto timestamp = Timestamp(seconds, nanos);
  auto version = SnapshotVersion(timestamp);

  // Create ObjectValue from a fuzzed protobuf
  auto proto_bytes = provider.ConsumeRandomLengthString(1024);
  StringReader reader(
      reinterpret_cast<const uint8_t*>(proto_bytes.data()), proto_bytes.size());
  auto value_proto =
      Message<firebase::firestore::google_firestore_v1_Value>::TryParse(&reader);

  if (!reader.ok()) {
    return Document(MutableDocument::InvalidDocument(std::move(key)));
  }

  auto object_value = ObjectValue(std::move(value_proto));

  // Create MutableDocument and then Document
  auto mutable_doc = MutableDocument::FoundDocument(
      std::move(key), version, std::move(object_value));
  return Document(std::move(mutable_doc));
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
  FuzzedDataProvider provider(data, size);
