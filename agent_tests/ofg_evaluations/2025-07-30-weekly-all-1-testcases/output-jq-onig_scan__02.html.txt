
	
<description>
The `onig_scan` function scans a string for all matches of a compiled regular expression. For each match found, it calls a user-provided callback function with the match details. The function begins by checking the validity of the input string if the corresponding option is set. It then enters a loop, repeatedly calling `onig_search` to find subsequent matches. After each successful match, the `scan_callback` is invoked. The return value of the callback can terminate the scan prematurely if it is non-zero. The scan progresses through the string, either by the length of the match or by a single character in the case of a zero-length match, until the entire string is processed or an error occurs. The function returns the total number of matches found.
</description>
