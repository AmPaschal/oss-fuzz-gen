The `mutt_resend_message` function is responsible for taking an existing email, `e_cur`, and preparing it to be resent. It creates a new email, `e_new`, and uses `mutt_prepare_template` to populate it with the content of `e_cur` written to the file pointer `fp`. It then handles cryptographic settings based on the `WithCrypto` global variable and configuration options from the `sub` parameter. Finally, it calls `mutt_send_message` to send the newly created email. The function's primary role is to orchestrate the process of resending a message, including template preparation, crypto configuration, and the final sending action.
</description>

<requirement>

</requirement>
<requirement>
The `sub` argument, a `ConfigSubset`, must not be NULL. The function uses this argument to query configuration settings without a prior null check, so a NULL value would lead to a crash.
</requirement>
<requirement>
The global variable `WithCrypto` should be initialized to a valid value. This is because its value determines the cryptographic operations applied to the resent message.
</requirement>
