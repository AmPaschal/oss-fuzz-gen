The `InitWeaveStack` function initializes the Weave stack. It takes two boolean arguments, `listen` and `initExchangeMgr`, which control whether the Weave message layer listens for incoming connections and whether the Weave exchange manager is initialized, respectively. The function initializes several global objects, including `FabricState`, `MessageLayer`, and optionally `ExchangeMgr` and `SecurityMgr`. The initialization of these objects depends on several global option variables, such as `gWeaveNodeOptions`, `gNetworkOptions`, and various security-related option variables.
</description>
