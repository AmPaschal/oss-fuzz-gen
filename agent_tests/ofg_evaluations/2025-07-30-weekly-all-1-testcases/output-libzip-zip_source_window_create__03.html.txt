
	
<description>
The function `zip_source_window_create` creates a new zip source from a window of another zip source. It is a wrapper around the internal function `_zip_source_window_new`, passing `NULL` for many of the extended parameters. The new source reads data from the original source `src` starting at `start` and reading `len` bytes. If `len` is -1, it reads until the end of the source. The function is used to create a view into a part of an existing zip source, for example to read a compressed file from within a zip archive.
</description>
<requirements>
<requirement> The `src` argument must be a valid `zip_source_t` pointer, created by functions such as `zip_source_buffer_create`. This is because the function reads from this source, and a valid source is needed to avoid crashes. </requirement> <requirement> The `start` and `len` arguments must specify a valid window within the provided `src`. This means `start` and `start + len` should be within the bounds of the source data to prevent out-of-bounds reads. </requirement> <requirement> The `len` argument can be -1. This is a special value indicating that the window should extend to the end of the source `src`. </requirement> <requirement> The `error` argument can be a pointer to a `zip_error_t` structure or `NULL`. If it's not `NULL`, it will be used to store error information. </requirement> <requirement> The returned `zip_source_t` object should be freed using `zip_source_free`. This is to prevent memory leaks, as is standard practice for `zip_source_t` objects. </requirement>
</requirements>

#include <stdint.h>
#include <stdlib.h>
#include <string.h>

#include "/src/libzip/lib/zip.h"

/**
This fuzzing target takes input data, uses some of it for parameters
(start, len) and the rest to create a zip_source. It then calls
zip_source_window_create to create a new source from a window
into the original source.

The purpose of this fuzzer is to test the window creation logic
in libzip by subjecting it to a wide range of start offsets and
lengths, including potentially invalid or edge-case values.
**/

#ifdef __cplusplus
extern "C"
#endif
int
LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    if (size < sizeof(zip_uint64_t) + sizeof(zip_int64_t)) {
        return 0;
    }

    zip_uint64_t start;
    memcpy(&start, data, sizeof(start));
    zip_int64_t len;
    memcpy(&len, data + sizeof(start), sizeof(len));

    const uint8_t *buffer_data = data + sizeof(start) + sizeof(len);
    size_t buffer_size = size - (sizeof(start) + sizeof(len));

    const char *path = "fuzz_window.zip";
    int errorp = 0;
    zip_t *archive;

    (void)remove(path);
    if ((archive = zip_open(path, ZIP_CREATE, &errorp)) == NULL) {
        return 0;
    }

    zip_source_t *source = zip_source_buffer(archive, buffer_data, buffer_size, 0);
    if (source == NULL) {
        zip_discard(archive);
        (void)remove(path);
        return 0;
    }

    zip_source_t *window_source = zip_source_window_create(source, start, len, NULL);

    if (window_source != NULL) {
        zip_source_free(window_source);
    }

    zip_discard(archive);
    (void)remove(path);

    return 0;
}
