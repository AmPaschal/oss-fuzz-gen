
	
<description>
The `ada_idna_to_ascii` function converts a UTF-8 string to an ASCII string using the IDNA standard. It takes a character pointer and its length as input. The function allocates memory for the output string, which must be freed by the caller using `ada_free_owned_string`.
</description>
<requirements>
<requirement>
The `input` pointer should not be null if `length` is not 0. A null pointer with a non-zero length will cause a crash.
</requirement>
<requirement>
The `length` parameter must be the correct size of the `input` buffer. This is to ensure that the function does not read out of bounds.
</requirement>
<requirement>
The `input` data can be fuzzed. The function is expected to handle any arbitrary byte sequences.
</requirement>
<requirement>
The caller must call `ada_free_owned_string` on the returned `ada_owned_string` object. This is to prevent memory leaks as the returned object contains dynamically allocated memory.
</requirement>
</requirements>
