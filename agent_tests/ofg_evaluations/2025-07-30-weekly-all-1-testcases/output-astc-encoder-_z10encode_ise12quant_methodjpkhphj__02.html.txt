
	
<description>
The function `encode_ise` encodes a sequence of integers using either a simple bit packing, or a joint bit packing and pre-calculated integer sequence encoding (ISE). The specific encoding used is determined by the `quant_level` parameter, which selects an entry from the `btq_counts` table. This table defines the number of bits, trits, or quints to use for the encoding.
</description>
<requirements>
<requirement>
The `quant_level` must be a value between 0 and 20, inclusive. This is because `quant_level` is used to index into the global `btq_counts` array which has a size of 21.
</requirement>
<requirement>
The `character_count` must be greater than 0. The function has a `promise(character_count > 0)` which will cause a crash if this condition is not met.
</requirement>
<requirement>
The `input_data` buffer must be at least `character_count` bytes long. The function reads up to `character_count` bytes from this buffer, and reading beyond its bounds will cause a crash.
</requirement>
<requirement>
The `output_data` buffer must be large enough to hold the encoded data. The maximum number of bits written per character is 11, so a safe buffer size would be `(character_count * 11 + bit_offset + 7) / 8` bytes.
</requirement>
</requirements>
