
	
<description>
The function `JS_NewArrayBuffer` creates a new JavaScript `ArrayBuffer` or `SharedArrayBuffer` object. It wraps an existing C buffer (`buf`) of a given length (`len`). The `is_shared` flag determines whether a standard `ArrayBuffer` or a `SharedArrayBuffer` is created. A custom deallocation function (`free_func`) can be provided to free the buffer when it's no longer needed by the JavaScript engine. The `opaque` pointer is passed to this deallocation function. The core logic is implemented in `js_array_buffer_constructor3`, which handles the object creation and memory management. The caller in `run-test262.c` uses this function to create a `SharedArrayBuffer` for inter-thread communication.
</description>
<requirements>
<requirement>
The `ctx` argument must be a valid pointer to a `JSContext`. This is because the function internally dereferences this pointer to access the runtime state.
</requirement>
<requirement>
The `len` argument must be less than or equal to `INT32_MAX` (2147483647). This is because the underlying function `js_array_buffer_constructor3` will otherwise throw a `RangeError`.
</requirement>
<requirement>
If the `buf` argument is not `NULL`, it must point to a valid memory buffer of at least `len` bytes. This is to prevent out-of-bounds memory accesses when the buffer is used by the JavaScript engine.
</requirement>
<requirement>
The `free_func` argument should be a function pointer to a function that can deallocate the `buf` pointer. This is crucial for preventing memory leaks when the ArrayBuffer is garbage collected.
</requirement>
<requirement>
The `is_shared` argument can be either TRUE or FALSE. This will determine whether a regular or shared array buffer is created, and both paths should be tested.
</requirement>
</requirements>

#include "/src/quickjs/quickjs.h"
#include "quickjs-libc.h"
#include "cutils.h"
#include <stdint.h>
#include <stdlib.h>
#include <string.h>

// This function will be called by QuickJS to free the buffer
// when the ArrayBuffer is garbage collected.
static void free_buffer_func(JSRuntime *rt, void *opaque, void *ptr) {
    free(ptr);
}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    // We need at least 1 byte to determine the 'is_shared' flag.
    if (size < 1) {
        return 0;
    }

    JSRuntime *rt = JS_NewRuntime();
    if (!rt) {
        return 0;
    }
    JSContext *ctx = JS_NewContext(rt);
    if (!ctx) {
        JS_FreeRuntime(rt);
        return 0;
    }

    // The first byte of the fuzzer input determines the 'is_shared' flag.
    BOOL is_shared = data[0] % 2;
    const uint8_t *buffer_data = data + 1;
    size_t buffer_size = size - 1;

    // JS_NewArrayBuffer requires a mutable buffer and takes ownership,
    // so we must copy the fuzzer data.
    uint8_t *buffer = malloc(buffer_size);
    if (!buffer) {
        JS_FreeContext(ctx);
        JS_FreeRuntime(rt);
        return 0;
    }
    memcpy(buffer, buffer_data, buffer_size);

    // Create the ArrayBuffer. QuickJS will own the buffer now.
    JSValue val = JS_NewArrayBuffer(ctx, buffer, buffer_size, free_buffer_func, NULL, is_shared);

    if (JS_IsException(val)) {
        // If creation failed, QuickJS did not take ownership of the buffer.
        // We must free it ourselves.
        free(buffer);
    } else {
        // If creation succeeded, the JSValue now owns the buffer.
        // Freeing the JSValue will cause QuickJS to call our free_buffer_func.
        JS_FreeValue(ctx, val);
    }

    JS_FreeContext(ctx);
    JS_FreeRuntime(rt);

    return 0;
}
