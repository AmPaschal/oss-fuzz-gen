
	
<description>
The function `m3_GetMemorySize` retrieves the size of the allocated memory of a wasm3 runtime. It takes a pointer to a `M3Runtime` struct as input and returns the value of the `length` field within the nested `mallocated` structure. For the function to execute correctly, the `i_runtime` pointer and its nested pointers `i_runtime->memory.mallocated` must be valid. This requires proper initialization of the runtime object, which can be achieved by calling `m3_NewRuntime`, `m3_ParseModule` and `m3_LoadModule` in sequence.
</description>
<requirements>
<requirement>
The `i_runtime` argument must be a valid pointer to a `M3Runtime` struct. This is because the function dereferences this pointer to access its members.
</requirement>
<requirement>
The `i_runtime->memory.mallocated` pointer must be non-NULL. This is because the function dereferences this pointer to access the `length` field.
</requirement>
<requirement>
The `i_runtime` object should be initialized by calling `m3_NewRuntime`. This function allocates and correctly initializes the runtime, including its memory structures.
</requirement>
<requirement>
A module should be loaded into the runtime using `m3_ParseModule` and `m3_LoadModule` before calling `m3_GetMemorySize`. This ensures that the runtime's memory is properly set up and allocated.
</requirement>
</requirements>
