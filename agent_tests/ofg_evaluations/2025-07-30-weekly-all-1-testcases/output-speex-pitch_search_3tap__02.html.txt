
	
<description>
This function performs a 3-tap pitch search for the Speex codec. It finds the optimal pitch and gain for long-term prediction (LTP) by minimizing the error between the synthesized and target signals. The function is called on a subframe basis from the main narrowband encoding function, and it packs the resulting pitch and gain information into a bitstream for transmission. It also updates the excitation and target buffers based on the prediction.
</description>
<requirements>

<requirement>
The `par` argument must be a valid pointer to an `ltp_params` struct. This struct provides essential parameters for the pitch search, including the gain codebook and the number of bits for pitch and gain, and can be initialized with `nb_ltp_params`, `wb_ltp_params` or `uwb_ltp_params`.</requirement>
<requirement>
The `start` and `end` arguments define the range of the pitch search, and `end` must be greater than or equal to `start`. The function will return early if this condition is not met.</requirement>
<requirement>
The `exc2` buffer must be allocated with sufficient space before the pointer. The function accesses `exc2` with negative indices up to `end`, so `exc2` must point to a location at least `end` samples into an allocated buffer.</requirement>
<requirement>
The `bits` argument must be a valid pointer to a `SpeexBits` struct, which must be initialized before calling this function. This is because the function writes the encoded pitch and gain to this bitstream.</requirement>
<requirement>
The `nsf` argument, representing the number of samples in a subframe, should correspond to the size of the `target` and `exc` arrays. This is to prevent buffer overflows when accessing these arrays.</requirement>
<requirement>
The `p` argument, representing the number of LPC coefficients, must match the size of the `ak`, `awk1`, and `awk2` arrays. This is to avoid out-of-bounds access when reading the LPC coefficients.</requirement>
<requirement>
The `stack` parameter must point to a memory region of sufficient size. This is because the function uses this memory for dynamic allocations via the `ALLOC` macro.</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>

#ifdef HAVE_CONFIG_H

#include "speex/speex.h"

extern "C" {

#include "libspeex/ltp.h"

// Define a reasonable maximum size for frame and LPC order to avoid OOM.
constexpr int kMaxNsf = 160; // NB_FRAME_SIZE
constexpr int kMaxP = 10;    // NB_ORDER
constexpr int kMaxPitch = 144; // NB_PITCH_END
constexpr int kMinPitch = 17;  // NB_PITCH_START

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Consume parameters for the function call.
  const int p = provider.ConsumeIntegralInRange<int>(1, kMaxP);
  const int nsf = provider.ConsumeIntegralInRange<int>(1, kMaxNsf);
  const int start = provider.ConsumeIntegralInRange<int>(kMinPitch, kMaxPitch - 1);
  const int end = provider.ConsumeIntegralInRange<int>(start, kMaxPitch);
  const int complexity = provider.ConsumeIntegralInRange<int>(0, 10);
  const int cdbk_offset = provider.ConsumeIntegral<int>();
  const int plc_tuning = provider.ConsumeIntegral<int>();
  const spx_word16_t pitch_coef = provider.ConsumeIntegral<spx_word16_t>();
  spx_word32_t cumul_gain = provider.ConsumeIntegral<spx_word32_t>();

  // Get a valid ltp_params pointer from the available Speex modes.
  std::vector<const void *> valid_ltp_params;
  const SpeexMode *mode = speex_lib_get_mode(SPEEX_MODEID_NB);
  if (!mode) {
    return 0;
  }
  const SpeexNBMode *nb_mode = (const SpeexNBMode *)mode->mode;
  for (int i = 0; i < 16; ++i) {
    if (nb_mode->submodes[i] && nb_mode->submodes[i]->ltp_params) {
      valid_ltp_params.push_back(nb_mode->submodes[i]->ltp_params);
    }
  }
  if (valid_ltp_params.empty()) {
    return 0;
  }
  size_t par_index = provider.ConsumeIntegralInRange<size_t>(0, valid_ltp_params.size() - 1);
  const void *par = valid_ltp_params[par_index];

  // Allocate and fill buffers.
  std::vector<spx_word16_t> target(nsf);
  provider.ConsumeData(target.data(), target.size() * sizeof(spx_word16_t));

  std::vector<spx_coef_t> ak(p + 1);
  provider.ConsumeData(ak.data(), ak.size() * sizeof(spx_coef_t));

  std::vector<spx_coef_t> awk1(p + 1);
  provider.ConsumeData(awk1.data(), awk1.size() * sizeof(spx_coef_t));

  std::vector<spx_coef_t> awk2(p + 1);
  provider.ConsumeData(awk2.data(), awk2.size() * sizeof(spx_coef_t));

  std::vector<spx_sig_t> exc(nsf);
  provider.ConsumeData(exc.data(), exc.size() * sizeof(spx_sig_t));

  std::vector<spx_word16_t> r(nsf);
  provider.ConsumeData(r.data(), r.size() * sizeof(spx_word16_t));

  // Buffers `sw` and `exc2` are accessed with negative indices up to `end`.
  // Allocate larger buffers and offset the pointers to provide a valid range.
  std::vector<spx_word16_t> sw_buf(nsf + end);
  provider.ConsumeData(sw_buf.data(), sw_buf.size() * sizeof(spx_word16_t));
  spx_word16_t *sw = sw_buf.data() + end;

  std::vector<spx_word16_t> exc2_buf(nsf + end);
  provider.ConsumeData(exc2_buf.data(), exc2_buf.size() * sizeof(spx_word16_t));
  spx_word16_t *exc2 = exc2_buf.data() + end;

  // Provide a stack for the ALLOC macro used inside the function.
  std::vector<char> stack(1024 * 32);

  // Initialize SpeexBits.
  SpeexBits bits;
  speex_bits_init(&bits);

  // Call the function under test.
  pitch_search_3tap(target.data(), sw, ak.data(), awk1.data(), awk2.data(),
                    exc.data(), par, start, end, pitch_coef, p, nsf, &bits,
                    stack.data(), exc2, r.data(), complexity, cdbk_offset,
                    plc_tuning, &cumul_gain);

  // Cleanup.
  speex_bits_destroy(&bits);

  return 0;
}
