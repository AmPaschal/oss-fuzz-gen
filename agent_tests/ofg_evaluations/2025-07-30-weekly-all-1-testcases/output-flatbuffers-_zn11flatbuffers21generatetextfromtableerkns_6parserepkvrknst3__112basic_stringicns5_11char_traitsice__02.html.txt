
	
<description>
The `GenerateTextFromTable` function generates a JSON-like text representation of a FlatBuffers table. It takes a parser, a pointer to the table, the table's name, and a pointer to a string to store the output. The function relies on an internal `GenTextFromTable` function, which looks up the table's structure definition in the parser, and then generates the text. The callers of this function first parse a schema, then create a flatbuffer object, and finally call this function to serialize parts of the flatbuffer to text.
</description>
<requirements>

<requirement>
The `parser` object must be initialized with a schema that defines the struct specified by `table_name`. This is because the function calls `parser.LookupStruct(table_name)` which will fail if the struct is not defined.
</requirement>
<requirement>
The `table` argument must be a valid pointer to a FlatBuffers table of the type specified by `table_name`. The function casts the `table` pointer to a `Table*` and will crash if it is not a valid table.
</requirement>
<requirement>
The `table_name` argument must be a null-terminated string representing a struct defined in the parser's schema. This is necessary for `parser.LookupStruct` to find the corresponding struct definition.
</requirement>
<requirement>
The `_text` argument must be a valid pointer to a `std::string` object. This is to avoid a crash when the function attempts to write the generated text into the string.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include "/src/flatbuffers/include/flatbuffers/idl.h"
#include <string>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size < 3) {
    return 0;
  }

  FuzzedDataProvider provider(data, size);

  flatbuffers::IDLOptions opts;
  opts.strict_json = provider.ConsumeBool();
  opts.allow_non_utf8 = provider.ConsumeBool();
  opts.output_default_scalars_in_json = provider.ConsumeBool();
  
  flatbuffers::Parser parser(opts);

  // The fuzzer input is split into a schema and a JSON string.
  std::string schema_data = provider.ConsumeRandomLengthString(provider.remaining_bytes() / 2);
  std::string json_data = provider.ConsumeRemainingBytesAsString();

  if (schema_data.empty() || json_data.empty()) {
    return 0;
  }

  // First, parse the schema.
  if (!parser.Parse(schema_data.c_str())) {
    return 0;
  }

  // A valid schema must have a root type.
  if (!parser.root_struct_def_) {
    return 0;
  }

  // Now, parse the JSON data against the schema.
  if (!parser.ParseJson(json_data.c_str())) {
    return 0;
  }

  // If both parsing steps were successful, we can generate text.
  const void *table = parser.builder_.GetBufferPointer();
  const std::string &table_name = parser.root_struct_def_->name;
  std::string generated_text;

  // Call the function under test.
  flatbuffers::GenerateTextFromTable(parser, table, table_name, &generated_text);

  return 0;
}
