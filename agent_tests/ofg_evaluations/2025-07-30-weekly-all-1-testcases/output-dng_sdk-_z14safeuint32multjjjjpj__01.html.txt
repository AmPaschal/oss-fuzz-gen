
	
<description>
The `SafeUint32Mult` function safely multiplies up to four `uint32_t` values, checking for overflow at each step. The target function, which accepts four integer arguments and a pointer to a `uint32_t` for the result, is one of several overloaded versions. The core logic resides in the `SafeUnsignedMult` template function, which is called by the non-template `SafeUint32Mult` functions. `SafeUnsignedMult` checks for overflow before performing the multiplication. If an overflow would occur, a `dng_exception` is thrown. The target function catches this exception and returns `false`, indicating failure. If the multiplication is successful, the result is stored in the output parameter, and `true` is returned. The primary requirement for this function to succeed is that the product of the input integers does not exceed the maximum value of a `uint32_t`. Additionally, the output pointer must be valid to prevent a crash.
</description>
<requirements>
<requirement>
The final argument, `result`, must be a valid pointer to a uint32_t. This is because the function will dereference this pointer to store the result of the multiplication, and a NULL pointer will cause a crash.
</requirement>
<requirement>
The product of the four integer arguments must not exceed 0xFFFFFFFF. An intermediate or final product that exceeds this value will trigger an overflow exception, causing the function to return false.
</requirement>
</requirements>
