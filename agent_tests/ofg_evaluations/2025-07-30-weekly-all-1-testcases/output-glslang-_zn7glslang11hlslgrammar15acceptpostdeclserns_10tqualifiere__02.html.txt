
	
<description>
The `acceptPostDecls` function is a part of the HLSL parser in glslang. It is responsible for parsing post-declaration specifiers, which can include semantics, register assignments, pack-offsets, and layout qualifiers. The function is called after a type or variable has been declared to parse any of these optional specifiers that follow the declaration. It consumes tokens from the input stream and populates the provided `TQualifier` object with the parsed information. The function returns true if any post-declarations were found and parsed, and false otherwise.
</description>
<requirements>

<requirement>
The `HlslGrammar` object must be properly initialized with a token stream. This is because the function operates on the token stream to parse the post-declarations.
</requirement>
<requirement>
The `qualifier` argument must be a valid, writable `TQualifier` object. This is because the function uses this argument as an out-parameter to store the parsed qualifier information.
</requirement>
<requirement>
When parsing a `register` directive, if the `registerDesc.string` has a size of 1, it will cause an out-of-bounds read in the condition `!isdigit((*registerDesc.string)[1])`. The fuzzer should ensure that if the size is 1, the second part of the condition is not evaluated.
</requirement>
<requirement>
When parsing the subcomponent of a `register` directive (within `[]`), the token must be an integer constant. This is because the code directly accesses `token.i` to get the subcomponent value, and a wrong token type could lead to a crash.
</requirement>
<requirement>
The input to the parser should be fuzzed to cover different code paths. This includes providing valid and invalid sequences for `layout`, `packoffset`, `register`, and semantic declarations.
</requirement>

</requirements>

// A derived class to expose the protected glslang::HlslGrammar::acceptPostDecls method.
class FuzzHlslGrammar : public glslang::HlslGrammar {
public:
    FuzzHlslGrammar(glslang::HlslScanContext& scanner, glslang::HlslParseContext& pc)
        : glslang::HlslGrammar(scanner, pc) {}

    // Public wrapper for the protected method under test.
    bool public_acceptPostDecls(glslang::TQualifier& q) {
        return acceptPostDecls(q);
    }
};

// Dummy includer for the preprocessor.
class FuzzerIncluder : public glslang::TShader::Includer {
public:
    IncludeResult* includeSystem(const char*, const char*, size_t) override {
        return nullptr;
    }
    IncludeResult* includeLocal(const char*, const char*, size_t) override {
        return nullptr;
    }
    void releaseInclude(IncludeResult* result) override {
        // Do nothing, as we never allocate anything.
    }
};

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider provider(data, size);

    glslang::InitializeProcess();

    // Set up the complex hierarchy of objects needed to instantiate HlslGrammar.
    TInfoSink infoSink;
    EShLanguage language = EShLangVertex;
    glslang::TIntermediate intermediate(language);
    glslang::TSymbolTable symbolTable;
    glslang::SpvVersion spvVersion;
    spvVersion.vulkan = 100;
    spvVersion.spv = 0x10000;

    glslang::HlslParseContext parseContext(symbolTable, intermediate, false, 100, ENoProfile,
                                           spvVersion, language, infoSink, "main");

    // Use the fuzzer input as the source string for the scanner.
    std::string fuzzed_string = provider.ConsumeRemainingBytesAsString();
    const char* fuzzed_char_ptr = fuzzed_string.c_str();
    size_t fuzzed_len_arr[] = { fuzzed_string.length() };
    glslang::TInputScanner inputScanner(1, &fuzzed_char_ptr, fuzzed_len_arr);
    
    FuzzerIncluder includer;
    glslang::TPpContext ppContext(parseContext, "", includer);
    ppContext.setInput(inputScanner, false);
    
    glslang::HlslScanContext scanContext(parseContext, ppContext);

    // Instantiate the derived grammar class.
    FuzzHlslGrammar grammar(scanContext, parseContext);

    // Create the TQualifier parameter for the function under test.
    glslang::TQualifier qualifier;
    qualifier.clear();

    // Call the target function.
    grammar.public_acceptPostDecls(qualifier);

    glslang::FinalizeProcess();
    return 0;
}
