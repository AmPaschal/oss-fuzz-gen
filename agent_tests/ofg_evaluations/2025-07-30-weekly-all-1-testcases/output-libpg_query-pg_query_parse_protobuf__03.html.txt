
	
<description>
The `pg_query_parse_protobuf` function takes a SQL query string as input and returns a `PgQueryProtobufParseResult` structure. This structure contains the parsed protobuf representation of the query, as well as any errors that occurred during parsing. The function is a wrapper around `pg_query_parse_protobuf_opts`, which it calls with the default parser options (`PG_QUERY_PARSE_DEFAULT`). The core parsing logic is handled by the `pg_query_raw_parse` function, which is called by `pg_query_parse_protobuf_opts`. `pg_query_raw_parse` sets up error handling and then calls the `raw_parser` function to perform the actual parsing of the input string.
</description>
<requirements>
<requirement>
The input argument should be a null-terminated string representing a valid SQL query. This is because the function is designed to parse SQL queries, and a null-terminator is expected by the underlying parsing functions to prevent buffer overflows.
</requirement>
<requirement>
The `pg_query_free_protobuf_parse_result` function should be called on the returned `PgQueryProtobufParseResult` object. This is necessary to free the memory allocated for the `parse_tree`, `stderr_buffer` and `error` fields, preventing memory leaks.
</requirement>
