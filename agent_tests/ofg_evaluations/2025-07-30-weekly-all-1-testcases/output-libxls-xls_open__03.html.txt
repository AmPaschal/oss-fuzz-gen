
	
<description>
The function `xls_open` opens an Excel file and returns a `xlsWorkBook` structure. It is a wrapper for `xls_open_file`, which in turn opens an OLE2 file and prepares it for parsing. The main work is done in `xls_open_ole`, which is called by `xls_open_file`.
</description>
<requirements>
<requirement>
The first argument, `file`, must be a path to a readable file. This is because the function attempts to open the file and will fail if the file does not exist or is not accessible.
</requirement>
<requirement>
The second argument, `charset`, should be a valid, null-terminated string representing the character encoding. The value "UTF-8" is a safe default, as seen in the test cases, but other valid encodings are also acceptable.
</requirement>
</requirements>
