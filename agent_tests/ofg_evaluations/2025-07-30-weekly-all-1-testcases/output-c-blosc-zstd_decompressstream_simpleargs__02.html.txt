The ZSTD_decompressStream_simpleArgs function is a wrapper around the ZSTD_decompressStream function. It takes a ZSTD decompression context, input and output buffers, and pointers to the current positions in the buffers. It sets up the ZSTD_inBuffer and ZSTD_outBuffer structures and then calls ZSTD_decompressStream to perform the decompression. The function returns 0 on successful frame decompression, a positive value to indicate more input is required, or an error code.
</description>
