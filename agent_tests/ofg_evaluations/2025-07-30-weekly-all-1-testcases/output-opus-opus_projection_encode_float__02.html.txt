
	
<description>
The function opus_projection_encode_float is used to encode a projection of an audio signal. It takes an OpusProjectionEncoder, a float array of audio data, the frame size, an output buffer and the maximum size of the output buffer. It uses the opus_multistream_encode_native function to perform the encoding. The OpusProjectionEncoder must be created using opus_projection_ambisonics_encoder_create and initialized with valid parameters.
</description>
<requirements>

<requirement>
The `OpusProjectionEncoder` struct pointed to by `st` must be created by calling `opus_projection_ambisonics_encoder_create`. This is because the function `get_multistream_encoder` expects a specific memory layout for the `OpusProjectionEncoder` struct which is only guaranteed when created by the allocation function.
</requirement>
<requirement>
The `frame_size` argument must be a valid frame size. A valid frame size must be greater than or equal to `Fs/400`, where `Fs` is the sample rate, and also satisfy the condition that `400*frame_size`, `200*frame_size`, `100*frame_size`, `50*frame_size`, `25*frame_size` is a multiple of `Fs`, `3*Fs`, `4*Fs`, `5*Fs` or `6*Fs`.
</requirement>
<requirement>
The `max_data_bytes` argument must be large enough to hold the encoded data. It should be at least `st->layout.nb_streams * 3 - 1` to avoid a buffer too small error.
</requirement>
<requirement>
The `pcm` argument must be a valid pointer to a float array of size `frame_size` * `channels`. The `channels` is a parameter to `opus_projection_ambisonics_encoder_create`, which is used to initialize the `OpusProjectionEncoder`.
</requirement>

</requirements>

#include <cstddef>
#include <cstdint>
#include <vector>

#include "opus.h"
#include "/src/opus/include/opus_projection.h"
#include <fuzzer/FuzzedDataProvider.h>

// Pre-defined valid frame sizes for a 48kHz sample rate.
const int valid_frame_sizes[] = {120, 240, 480, 960, 1920, 3840};
// Pre-defined valid channel counts for ambisonics mapping family 3.
const int valid_channel_counts[] = {4, 9, 16, 25};

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);

  const opus_int32 Fs = 48000;
  const int channels = fdp.PickValueInArray(valid_channel_counts);
  const int mapping_family = 3; // Ambisonics projection
  const int application = OPUS_APPLICATION_AUDIO;

  int streams;
  int coupled_streams;
  int error;

  OpusProjectionEncoder *st = opus_projection_ambisonics_encoder_create(
      Fs, channels, mapping_family, &streams, &coupled_streams, application,
      &error);

  if (error != OPUS_OK || st == nullptr) {
    return 0;
  }

  const int frame_size = fdp.PickValueInArray(valid_frame_sizes);
  const size_t pcm_size = static_cast<size_t>(frame_size) * channels;

  std::vector<float> pcm_data(pcm_size);
  const size_t bytes_to_consume = pcm_size * sizeof(float);
  if (fdp.remaining_bytes() < bytes_to_consume) {
    opus_projection_encoder_destroy(st);
    return 0;
  }
  fdp.ConsumeData(pcm_data.data(), bytes_to_consume);
  
  // Allocate a buffer for the encoded data. 4000 bytes is a common max packet size.
  const opus_int32 max_data_bytes = 4000;
  std::vector<unsigned char> encoded_data(max_data_bytes);

  opus_projection_encode_float(st, pcm_data.data(), frame_size,
                               encoded_data.data(), max_data_bytes);

  opus_projection_encoder_destroy(st);
  return 0;
}
