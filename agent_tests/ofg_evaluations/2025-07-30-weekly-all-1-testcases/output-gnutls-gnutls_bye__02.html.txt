
	
<description>
The `gnutls_bye()` function is used to terminate a TLS/DTLS session. It sends a 'close notify' alert to the peer to inform it that the connection is being closed. The function takes a `gnutls_session_t` object representing the session and a `gnutls_close_request_t` flag as input. The flag indicates how the session should be closed. `GNUTLS_SHUT_WR` sends the alert and waits for the peer's corresponding alert, while `GNUTLS_SHUT_RDWR` sends the alert and immediately terminates the session locally. This function should be called after a successful handshake and when the application is done with the TLS session.
</description>
<requirements>
<requirement>
The `session` argument must be initialized by calling `gnutls_init` before calling `gnutls_bye`. This is because `gnutls_init` allocates and initializes the necessary resources for the session object.
</requirement>
<requirement>
A successful handshake must be performed using `gnutls_handshake` before calling `gnutls_bye`. The `gnutls_bye` function sends a close notify alert, which is a part of the TLS/DTLS protocol that assumes a session has been established.
</requirement>
<requirement>
The `how` argument must be either `GNUTLS_SHUT_WR` or `GNUTLS_SHUT_RDWR`. The function implementation explicitly checks for these values, and any other value will cause the function to return an error.
</requirement>
</requirements>

/* This is for deterministic fuzzing */
int __attribute__((visibility("protected")))
gnutls_rnd(gnutls_rnd_level_t level, void *data, size_t len)
{
	memset(data, 0xff, len);

	/* Flip the first byte to avoid infinite loop in the RSA
	 * blinding code of Nettle */
	if (len > 0)
		memset(data, 0x0, 1);
	return 0;
}

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
	gnutls_session_t session;
	gnutls_close_request_t how;
	int ret;

	if (size < 1) {
		return 0;
	}

	ret = gnutls_init(&session, GNUTLS_CLIENT);
	assert(ret >= 0);

	/* Use the first byte of the input to select the 'how' parameter. */
	if (data[0] % 2 == 0) {
		how = GNUTLS_SHUT_RDWR;
	} else {
		how = GNUTLS_SHUT_WR;
	}

	gnutls_bye(session, how);

	gnutls_deinit(session);
	return 0;
}
