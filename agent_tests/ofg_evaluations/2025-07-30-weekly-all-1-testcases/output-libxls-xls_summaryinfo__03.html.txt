
	
<description>
The `xls_summaryInfo` function extracts summary information from an Excel file. It takes a pointer to an `xlsWorkBook` structure, which represents an opened Excel file. The function allocates a new `xlsSummaryInfo` structure, and then populates it by calling `xls_dumpSummary` on the `summary` and `docSummary` members of the `xlsWorkBook` structure. Finally, it returns the populated `xlsSummaryInfo` structure.
</description>
<requirements>

<requirement>
The input argument `pWB` should be a valid pointer to an `xlsWorkBook` structure. A NULL pointer will cause a crash when the function attempts to dereference it to access the `summary` and `docSummary` members.
</requirement>
<requirement>
The `pWB` structure should be initialized by calling `xls_open_file` and `xls_parseWorkBook`. The `xls_open_file` function reads the file and allocates the `xlsWorkBook` structure, and `xls_parseWorkBook` parses the workbook stream to populate the structure, including the `summary` and `docSummary` members that `xls_summaryInfo` depends on.
</requirement>
<requirement>
The `pWB->summary` and `pWB->docSummary` fields must be valid pointers to `OLE2Stream` structures, or NULL. If they are not NULL, they will be dereferenced by the `xls_dumpSummary` function.
</requirement>

</requirements>
