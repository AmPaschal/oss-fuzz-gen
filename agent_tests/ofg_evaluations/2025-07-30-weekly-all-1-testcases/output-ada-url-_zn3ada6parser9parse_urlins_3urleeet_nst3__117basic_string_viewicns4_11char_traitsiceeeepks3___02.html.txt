
	
<description>
The function `ada::parser::parse_url` is a template function that parses a given string input into a URL object, which can be either an `ada::url` or an `ada::url_aggregator`. The target signature specifies `ada::url` as the return type. The function can handle both absolute URLs and relative URLs. When parsing a relative URL, it uses the provided `base_url` to resolve the components. The core implementation is a state machine that iterates through the input string, and it is designed to be robust against malformed inputs, including invalid UTF-8 sequences. The callers, especially in the fuzzing harnesses, provide fuzzed, arbitrary strings as input. The `base_url` can be `nullptr` if no base is needed.
</description>
