
	
<description>
The function `wxFontMapperBase::CharsetToEncoding` maps a charset string to a `wxFontEncoding` enumeration value. It first attempts to find a user-defined mapping in the application's configuration. If no user-defined mapping is found, it proceeds to check against a built-in list of known charset names and their aliases. The function is designed to be robust against unknown or malformed charset strings, in which case it returns a default system encoding.
</description>
