
	
<description>
The function `nxt_runtime_create` initializes the Unit runtime. It takes a pointer to a `nxt_task_t` structure as input and sets up the necessary components for the runtime environment, including memory pools, services, languages, listen sockets, and thread pools. The function is called once during the master process's initialization. The `task` argument is a pointer to the global `nxt_main_task` variable, which is initialized by the `nxt_lib_init` function. `nxt_runtime_create` orchestrates the initialization of various modules and registers a start function to be executed by the event engine. If any of the initialization steps fail, the function cleans up allocated resources and returns an error.
</description>
<requirements>

<requirement>
The `task` argument must be a valid pointer to a `nxt_task_t` structure. This is because the function accesses fields of this structure, such as `task->thread`.
</requirement>
<requirement>
The `task->thread` field must be a valid pointer to a `nxt_thread_t` structure. This is because the function accesses `task->thread->runtime` and `task->thread->engine`.
</requirement>
<requirement>
The `task->thread->engine` field must be a valid pointer to a `nxt_event_engine_t` structure. This is because the function accesses `task->thread->engine->fast_work_queue` to add a work item.
</requirement>
<requirement>
The `nxt_lib_init` function must be called before `nxt_runtime_create`. This is because `nxt_lib_init` initializes the global `nxt_main_task`, which is the argument to `nxt_runtime_create`.
</requirement>

</requirements>

#include <nxt_main.h>
#include "/src/unit/src/nxt_runtime.h"

/* Add prototypes to fix -Wmissing-prototypes errors. */
extern int LLVMFuzzerInitialize(int *argc, char ***argv);
extern int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size);

extern char  **environ;

/*
 * Define the nxt_main_thread variable directly in the fuzzer.
 * Including "nxt_main.c" has proven problematic due to build system
 * complexities and preprocessor guards. Since nxt_lib_start() is
 * responsible for initializing this global variable, defining it here
 * makes it available to both the library and the fuzzer code, resolving
 * the "undeclared identifier" error.
 */
nxt_thread_t  nxt_main_thread;


int
LLVMFuzzerInitialize(int *argc, char ***argv)
{
    /* nxt_lib_start initializes the global nxt_main_thread variable. */
    if (nxt_lib_start("fuzzing", NULL, &environ) != NXT_OK) {
        return -1;
    }

    return 0;
}


int
LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    static nxt_bool_t  called = 0;

    if (called) {
        /*
         * nxt_runtime_create() is a one-shot initialization function.
         * Calling it multiple times in the same process without a full
         * teardown (which is complex) leads to resource leaks and
         * undefined behavior. This harness ensures it is called once
         * per fuzzer process execution.
         */
        return 0;
    }

    called = 1;

    /*
     * nxt_lib_start() in LLVMFuzzerInitialize sets up the main thread
     * and its task, which we can pass to the function.
     */
    nxt_runtime_create(nxt_main_thread.task);

    /*
     * No cleanup is performed as the function is called only once and
     * the fuzzer will restart the process for new test cases.
     * The created runtime will live for the remainder of the process
     * lifetime.
     */

    return 0;
}
