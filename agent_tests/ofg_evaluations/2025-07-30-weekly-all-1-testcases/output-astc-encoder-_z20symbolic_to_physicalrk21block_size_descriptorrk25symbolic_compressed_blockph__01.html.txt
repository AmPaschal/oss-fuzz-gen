
	
<description>
This function, `symbolic_to_physical`, is responsible for converting a symbolic representation of a compressed block (`symbolic_compressed_block`) into a physical, 16-byte hardware-encodable block (`pcb`). The conversion process is guided by the block's size and mode, which are provided by the `block_size_descriptor`.

The function handles three main cases for the conversion:
1.  **Constant Color Blocks (UNORM16):** If the symbolic block's type is `SYM_BTYPE_CONST_U16`, the function populates the physical block with a predefined header and the 16-bit unsigned integer color values from the symbolic block.
2.  **Constant Color Blocks (FP16):** If the symbolic block's type is `SYM_BTYPE_CONST_F16`, the function populates the physical block with a different predefined header and the 16-bit floating-point color values from the symbolic block.
3.  **Non-Constant Color Blocks:** For other block types, the function performs a more complex encoding. It first encodes the weights associated with the block, using information about the block's mode, decimation, and quantization. It then encodes the block's mode and partition information. For blocks with multiple partitions, it encodes the partition index and color endpoint types. If the block uses dual planes, the color component for the second plane is also encoded. Finally, the color endpoint values are encoded.

The callers of this function, primarily `compress_block`, are responsible for creating a valid `symbolic_compressed_block`. This is achieved through a complex compression process that tries various encoding schemes and populates the `symbolic_compressed_block` with the one that yields the lowest error. The `block_size_descriptor` is initialized from the compression context and provides the necessary parameters for the encoding process. The `pcb` is an output buffer that the function fills with the resulting physical block data.
</description>
<requirements>
<requirement>
The `scb.block_type` must not be `SYM_BTYPE_ERROR`. The function has an assertion to prevent this, and the callers ensure that a valid block type is always set before calling the function.
</requirement>
<requirement>
The `scb.block_mode` field must be a valid index for the block modes in the `bsd` (block_size_descriptor). This is crucial because it's used to retrieve the block mode information, including decimation and quantization settings, which are essential for the encoding process.
</requirement>
<requirement>
The `scb.quant_mode` must be a value such that `scb.quant_mode - QUANT_6` is a valid index for the `color_uquant_to_scrambled_pquant_tables` array. This is necessary to correctly pack the color endpoint values.
</requirement>
<requirement>
The `scb.partition_count` field should be between 1 and 4. This value determines the control flow for encoding partition-related data, and out-of-range values could lead to incorrect behavior.
</requirement>
<requirement>
If the block mode is dual-plane (`is_dual_plane` is true), the `scb.plane2_component` field must be a valid component index (0-3). This is because it is used to encode the color component for the second plane of weights.
</requirement>
<requirement>
The `scb.weights` array should be initialized with valid, quantized weight values. These weights are read and processed to generate the physical block's weight data.
</requirement>
</requirements>

/**
 * @brief Fuzz target for symbolic_to_physical().
 *
 * This function is the final entrypoint for compressing a symbolic block into
 * a 16 byte physical block for storage on disk.
 */

#include "/src/astc-encoder/Source/astcenc_internal.h"

#include <fuzzer/FuzzedDataProvider.h>
#include <array>
#include <vector>

struct BlockSizes
{
	int x;
	int y;
	int z;
};

std::array<BlockSizes, 3> testSz {{
	{ 4,  4, 1}, // Highest bitrate
	{12, 12, 1}, // Largest 2D block
	{6,  6,  6}  // Largest 3D block
}};

std::array<block_size_descriptor, 3> testBSD;

/**
 * @brief Utility function to create all of the block size descriptors needed.
 *
 * This is triggered once via a static initializer.
 *
 * Triggering once is important so that we only create a single BSD per block
 * size we need, rather than one per fuzzer iteration (it's expensive). This
 * improves fuzzer throughput by ~ 1000x!
 *
 * Triggering via a static initializer, rather than a lazy init in the fuzzer
 * function, is important because is means that the BSD is allocated before
 * fuzzing starts. This means that leaksanitizer will ignore the fact that we
 * "leak" the dynamic allocations inside the BSD (we never call term()).
 */
bool bsd_initializer()
{
	for (size_t i = 0; i < testSz.size(); i++)
	{
		init_block_size_descriptor(
		    testSz[i].x,
		    testSz[i].y,
		    testSz[i].z,
		    false,
		    4,
		    1.0f,
		    testBSD[i]);
	}

	return true;
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
	// Preinitialize the block size descriptors we need
	static bool init = bsd_initializer();

	if (size < 256)
	{
		return 0;
	}

	FuzzedDataProvider stream(data, size);

	// Select a block size to test
	int i = stream.ConsumeIntegralInRange<int>(0, testSz.size() - 1);

	// Populate the symbolic block
	symbolic_compressed_block scb;
	std::memset(&scb, 0, sizeof(scb));

	// Set a non-error block type to avoid asserts
	scb.block_type = stream.PickValueInArray<uint8_t>({SYM_BTYPE_NONCONST, SYM_BTYPE_CONST_U16, SYM_BTYPE_CONST_F16});

	if (scb.block_type == SYM_BTYPE_NONCONST)
	{
		scb.partition_count = stream.ConsumeIntegralInRange<uint8_t>(1, BLOCK_MAX_PARTITIONS);
		scb.block_mode = stream.ConsumeIntegralInRange<uint16_t>(0, 2047);
		scb.quant_mode = (quant_method)stream.ConsumeIntegralInRange<int>(QUANT_2, QUANT_32);
		scb.color_formats_matched = stream.ConsumeBool();
		scb.plane2_component = stream.ConsumeIntegralInRange<int8_t>(-1, 3);
		scb.partition_index = stream.ConsumeIntegral<uint16_t>();

		size_t consumed = stream.ConsumeData(scb.color_formats, sizeof(scb.color_formats));
		if (consumed != sizeof(scb.color_formats)) return 0;

		consumed = stream.ConsumeData(scb.color_values, sizeof(scb.color_values));
		if (consumed != sizeof(scb.color_values)) return 0;
	}
	else
	{
		size_t consumed = stream.ConsumeData(scb.constant_color, sizeof(scb.constant_color));
		if (consumed != sizeof(scb.constant_color)) return 0;
	}

	size_t consumed = stream.ConsumeData(scb.weights, sizeof(scb.weights));
	if (consumed != sizeof(scb.weights)) return 0;

	// Call the function under test
	uint8_t pcb[16];
	symbolic_to_physical(testBSD[i], scb, pcb);

	return 0;
}
