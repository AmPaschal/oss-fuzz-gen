
	
<description>
The `XML_ParserReset` function re-initializes an `XML_Parser` object, allowing it to be reused for parsing a new XML document without the overhead of creating a new parser. It clears internal data structures like the tag stack, open entities, and temporary memory pools, and then re-initializes the parser's state, optionally with a new character encoding.
</description>
<requirements>
<requirement>
The `parser` argument must be a valid pointer to an `XML_Parser` object previously created by `XML_ParserCreate`, `XML_ParserCreateNS`, or `XML_ParserCreate_MM`. This is because the function expects the parser to be in a valid, initialized state to safely access its members for cleanup and re-initialization.
</requirement>
<requirement>
The `parser` argument must not be NULL. The function contains a NULL check, but a valid object is necessary for the function to perform its intended operations.
</requirement>
<requirement>
The `parser->m_parentParser` field of the `XML_Parser` object must be NULL. The function will not reset a parser that is a child of another parser.
</requirement>
<requirement>
The `encodingName` argument should be a null-terminated string representing a character encoding, or it can be NULL. If it's not NULL, it will be used to set the new encoding for the parser.
</requirement>
<requirement>
After all parsing operations with a given parser are finished, `XML_ParserFree` should be called on the `XML_Parser` object. While `XML_ParserReset` reclaims some memory, it does not free the parser object itself, and failing to call `XML_ParserFree` will result in a memory leak.
</requirement>
</requirements>

#include <cstddef>

// A no-op handler to be used with the parser.
static void NoOpHandler(void* userData, const XML_Char* s, int len)
{
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size)
{
  FuzzedDataProvider provider(data, size);

  // The encoding can be NULL.
  XML_Parser parser = XML_ParserCreate(NULL);
  if (!parser) {
    return 0;
  }

  // Set some handlers to make parsing do something.
  XML_SetDefaultHandler(parser, NoOpHandler);

  // Consume a portion of the input for the encoding name.
  const std::string encoding = provider.ConsumeBytesAsString(
    provider.ConsumeIntegralInRange<size_t>(0, 128));

  // Call the function under test.
  XML_ParserReset(parser, encoding.c_str());

  // Use the remaining data to test the parser after reset.
  const std::vector<char> buffer = provider.ConsumeRemainingBytes<char>();
  XML_Parse(parser, buffer.data(), buffer.size(), 1);

  XML_ParserFree(parser);
  return 0;
}
