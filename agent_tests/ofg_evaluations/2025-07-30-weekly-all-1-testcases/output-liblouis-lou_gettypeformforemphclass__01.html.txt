
	
<description>
The function `lou_getTypeformForEmphClass` retrieves a `formtype` value associated with a given emphasis class name from a specified translation table. It first loads the translation table using the `tableList` path. If the table is loaded successfully, it iterates through the list of emphasis class names defined in the table's header. It compares the input `emphClass` string with each defined class name. If a match is found, it returns a bit-shifted `formtype` value corresponding to that class. If the table cannot be loaded, or if the `emphClass` is not found in the table, the function returns 0.
</description>
<requirements>
<requirement>
The `tableList` argument must be a null-terminated string that represents a path to a valid translation table file. The file must exist and be readable by the program, and it should contain the necessary `emphclass` definitions.
</requirement>
<requirement>
The `emphClass` argument must be a non-NULL, null-terminated C-string. If it is NULL, `strcmp` will dereference a null pointer, leading to a crash.
</requirement>
<requirement>
The value of the `emphClass` string should correspond to one of the emphasis classes defined in the table file provided by `tableList`. Common examples include "italic", "underline", and "bold", though custom classes are also possible.
</requirement>
<requirement>
It is good practice to call `lou_free()` after finishing all operations with `liblouis`. This function cleans up resources, including the cached translation tables loaded by functions like `_lou_getTranslationTable`, preventing memory leaks.
</requirement>

// Helper to write data to a file.
static bool write_data_to_file(const char* path, const std::vector<uint8_t>& data) {
    FILE* fp = fopen(path, "wb");
    if (!fp) {
        return false;
    }
    if (fwrite(data.data(), 1, data.size(), fp) != data.size()) {
        fclose(fp);
        return false;
    }
    fclose(fp);
    return true;
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
    FuzzedDataProvider provider(data, size);

    // We need some data for the table and some for the emphasis class string.
    if (provider.remaining_bytes() < 2) {
        return 0;
    }

    // Split the input data. Part for the table definition, part for the emphClass.
    size_t table_data_size = provider.ConsumeIntegralInRange<size_t>(1, provider.remaining_bytes());
    std::vector<uint8_t> table_data = provider.ConsumeBytes<uint8_t>(table_data_size);
    std::string emph_class_str = provider.ConsumeRemainingBytesAsString();

    const char* tmp_table_def_path = "/tmp/fuzz_table.uti";
    const char* compiled_table_path = "/tmp/fuzz_table.ctb";

    // Write table definition data to a temporary file.
    if (!write_data_to_file(tmp_table_def_path, table_data)) {
        return 0;
    }

    // Compile the table definition. `lou_compileString` can create a compiled
    // table from a definition string, which can include other files.
    std::string compile_string = "include ";
    compile_string += tmp_table_def_path;
    if (lou_compileString(compiled_table_path, compile_string.c_str()) == 0) {
        // Compilation failed. Clean up and exit.
        remove(tmp_table_def_path);
        lou_free();
        return 0;
    }

    // Call the function under test with the compiled table and fuzzed class name.
    lou_getTypeformForEmphClass(compiled_table_path, emph_class_str.c_str());

    // Clean up liblouis state and temporary files for the next run.
    lou_free();
    remove(tmp_table_def_path);
    remove(compiled_table_path);

    return 0;
}
