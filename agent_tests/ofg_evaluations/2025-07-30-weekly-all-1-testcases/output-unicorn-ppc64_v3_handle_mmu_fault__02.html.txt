
	
<description>
The function `ppc64_v3_handle_mmu_fault` is a dispatcher function that handles MMU faults for PowerPC 64-bit CPUs. It determines whether the guest is using radix or hash-based address translation by calling `ppc64_v3_radix()`. Based on the result, it calls either `ppc_radix64_handle_mmu_fault()` or `ppc_hash64_handle_mmu_fault()` to handle the fault. The function is called from `ppc_cpu_do_interrupts`, `ppc_cpu_tlb_fill` and `helper_store_access` when a memory access causes a fault. The `rwx` parameter indicates the type of access that caused the fault (read, write, or execute).
</description>
<requirements>

<requirement>
The first argument, `PowerPCCPU *cpu`, must be a valid pointer to a `PowerPCCPU` struct. This is because it is dereferenced in the `ppc64_v3_radix` function to determine the address translation mode.
</requirement>
<requirement>
The `rwx` argument should be a valid combination of `MMU_INST_FETCH`, `MMU_DATA_LOAD`, and `MMU_DATA_STORE`. The callers of `ppc64_v3_handle_mmu_fault` use these values to indicate the type of memory access that caused the fault, and the function passes this value to `ppc_radix64_handle_mmu_fault` or `ppc_hash64_handle_mmu_fault`, so valid values are required to ensure correct fault handling.
</requirement>

</requirements>
