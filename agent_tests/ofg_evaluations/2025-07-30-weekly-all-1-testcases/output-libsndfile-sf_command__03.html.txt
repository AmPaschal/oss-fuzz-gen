
	
<description>
The sf_command function is a versatile command dispatcher for the libsndfile library. It takes a command ID and a data pointer with its size to perform a wide range of operations on a sound file handle (SNDFILE*). The function's behavior is determined by the 'command' parameter, which is an integer corresponding to a specific operation. These operations include retrieving library version information, getting and setting sound file properties (like normalization, scaling, and dithering), performing calculations (like signal maximum), and managing file metadata (like PEAK chunks, broadcast info, and cues).

The function uses a large switch statement to delegate tasks based on the command. Some commands do not require a valid SNDFILE handle and can be called with sndfile set to NULL. However, most commands require a valid handle to an open sound file. The 'data' and 'datasize' parameters are used to pass data to and from the function, and their required types and sizes are command-specific. Many commands have strict requirements on the size of the 'data' buffer to prevent buffer overflows. Additionally, some commands impose state-based restrictions, such as requiring the file to be opened in a specific mode (e.g., write-only) or that no data has been written to the file yet.
</description>
<requirements>

<requirement>
The `sndfile` argument should be a valid pointer to a `SNDFILE` struct, returned by a successful call to `sf_open`. This ensures the function operates on a valid and initialized sound file handle.
</requirement>
<requirement>
The `command` argument should be one of the values from the `SFC_` enum defined in `sndfile.h`. Using an invalid command will result in an error.
</requirement>
<requirement>
For the `SFC_GET_LIB_VERSION` command, the `data` pointer must not be NULL, and the `datasize` must be large enough to hold the version string. A buffer size of 256 bytes is recommended to be safe.
</requirement>
<requirement>
For commands that retrieve information into a struct (e.g., `SFC_GET_SIMPLE_FORMAT`, `SFC_GET_FORMAT_INFO`, `SFC_GET_CURRENT_SF_INFO`, `SFC_GET_EMBED_FILE_INFO`, `SFC_GET_LOOP_INFO`, `SFC_GET_INSTRUMENT`), the `datasize` must exactly match the size of the corresponding struct. This prevents writing data out of bounds.
</requirement>
<requirement>
For the `SFC_CALC_MAX_ALL_CHANNELS` and `SFC_GET_MAX_ALL_CHANNELS` commands, the `datasize` must be equal to `sizeof(double) * psf->sf.channels`. This ensures the provided buffer is large enough to hold the peak information for all channels.
</requirement>
<requirement>
For the `SFC_FILE_TRUNCATE` command, the file must be opened in `SFM_WRITE` or `SFM_RDWR` mode, and the `datasize` must be equal to `sizeof(sf_count_t)`. The `data` pointer should point to a valid `sf_count_t` value representing the desired truncation position.
</requirement>
<requirement>
For the `SFC_SET_CHANNEL_MAP_INFO` command, the file must not have had any data written to it yet (`psf->have_written` must be false), and the `datasize` must be equal to `sizeof(int) * psf->sf.channels`. The integer values in the `data` array must be within the valid range defined by `SF_CHANNEL_MAP_INVALID` and `SF_CHANNEL_MAP_MAX`.
</requirement>
<requirement>
For the `SFC_SET_ADD_PEAK_CHUNK` command, the file must be opened in `SFM_WRITE` or `SFM_RDWR` mode, and no data should have been written to it. This command is only supported for specific file formats (WAV, AIFF, CAF, WAVEX, RF64) and data formats (float or double).
</requirement>
<requirement>
For commands that set boolean-like properties (e.g., `SFC_SET_NORM_FLOAT`, `SFC_SET_NORM_DOUBLE`), the `datasize` parameter is used as a boolean flag, where 0 represents false and any non-zero value represents true. The `data` parameter is ignored in these cases.
</requirement>

</requirements>

#include <cstdint>

extern "C" {
#include <stdio.h>

#include "/src/libsndfile/include/sndfile.h"
#include "sndfile_fuzz_header.h"

extern "C" int sf_command(SNDFILE *, int, void *, int);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider provider(data, size);

    // Initialize a virtual file from part of the input data.
    size_t file_data_size = provider.ConsumeIntegralInRange<size_t>(0, provider.remaining_bytes() / 2);
    std::vector<uint8_t> file_data = provider.ConsumeBytes<uint8_t>(file_data_size);

    SF_INFO sndfile_info;
    VIO_DATA vio_data;
    SF_VIRTUAL_IO vio;
    SNDFILE *sndfile = NULL;

    // It's valid to call sf_command with a NULL SNDFILE handle for some commands.
    // We'll decide whether to initialize a file or not based on the fuzzer input.
    if (provider.ConsumeBool()) {
        sf_init_file(file_data.data(), file_data.size(), &sndfile, &vio_data, &vio, &sndfile_info);
    }

    // A list of commands to test.
    // Taken from sndfile.h
    const int commands[] = {
        SFC_GET_LIB_VERSION, SFC_GET_LOG_INFO, SFC_GET_CURRENT_SF_INFO,
        SFC_GET_NORM_DOUBLE, SFC_GET_NORM_FLOAT, SFC_SET_NORM_DOUBLE,
        SFC_SET_NORM_FLOAT, SFC_SET_SCALE_FLOAT_INT_READ,
        SFC_SET_SCALE_INT_FLOAT_WRITE, SFC_GET_SIMPLE_FORMAT_COUNT,
        SFC_GET_SIMPLE_FORMAT, SFC_GET_FORMAT_INFO, SFC_GET_FORMAT_MAJOR_COUNT,
        SFC_GET_FORMAT_MAJOR, SFC_GET_FORMAT_SUBTYPE_COUNT,
        SFC_GET_FORMAT_SUBTYPE, SFC_CALC_SIGNAL_MAX, SFC_CALC_NORM_SIGNAL_MAX,
        SFC_CALC_MAX_ALL_CHANNELS, SFC_CALC_NORM_MAX_ALL_CHANNELS,
        SFC_GET_SIGNAL_MAX, SFC_GET_MAX_ALL_CHANNELS, SFC_UPDATE_HEADER_NOW,
        SFC_SET_UPDATE_HEADER_AUTO, SFC_FILE_TRUNCATE, SFC_SET_RAW_START_OFFSET,
        SFC_SET_DITHER_ON_WRITE, SFC_SET_DITHER_ON_READ,
        SFC_GET_DITHER_INFO_COUNT, SFC_GET_DITHER_INFO, SFC_GET_EMBED_FILE_INFO,
        SFC_SET_CLIPPING, SFC_GET_CLIPPING, SFC_GET_CUE_COUNT, SFC_GET_CUE,
        SFC_SET_CUE, SFC_GET_INSTRUMENT, SFC_SET_INSTRUMENT, SFC_GET_LOOP_INFO,
        SFC_SET_BROADCAST_INFO, SFC_GET_BROADCAST_INFO,
        SFC_RAW_DATA_NEEDS_ENDSWAP, SFC_GET_CHANNEL_MAP_INFO,
        SFC_SET_CHANNEL_MAP_INFO, SFC_SET_VBR_ENCODING_QUALITY,
        SFC_SET_OGG_PAGE_LATENCY_MS
    };

    int command = provider.PickValueInArray(commands);

    // Provide a buffer for the command's data parameter.
    // The sf_command function has internal checks for the size and content
    // of this buffer depending on the command. We'll let the fuzzer explore these.
    std::vector<uint8_t> cmd_data_vec = provider.ConsumeRemainingBytes<uint8_t>();

    sf_command(sndfile, command, cmd_data_vec.data(), cmd_data_vec.size());

    if (sndfile) {
        sf_close(sndfile);
    }

    return 0;
}
