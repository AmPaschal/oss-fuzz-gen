
	
<description>
The encode_ise function encodes a sequence of integers using the Bounded Integer Sequence Encoding (ISE) method. The quantization level determines the number of bits, trits, or quints used to represent each integer in the sequence. The function reads from the input_data buffer, encodes the data, and writes the encoded bitstream to the output_data buffer.
</description>
<requirements>
<requirement>
The `quant_level` parameter must be a value between 0 and 12, inclusive. This is because `quant_level` is used as an index into the `btq_counts` array, and values outside this range will result in an out-of-bounds memory access.</requirement>
<requirement>
The `character_count` parameter must be greater than 0. This is because the function has a `promise(character_count > 0)` which will cause a crash if not met.</requirement>
<requirement>
The `input_data` buffer must be allocated with a size of at least `character_count`. This is to prevent a buffer over-read when the function accesses `input_data[i]`, where `i` can go up to `character_count`.</requirement>
<requirement>
The `output_data` buffer must be allocated with a size large enough to hold the encoded data. A safe size would be `character_count * 4` bytes, as the number of bits per character is at most 32. A smaller buffer could result in a buffer overflow when `write_bits` is called.</requirement>
<requirement>
The `bit_offset` parameter should be initialized to 0. This ensures that the encoded data is written to the beginning of the `output_data` buffer.</requirement>
</requirements>

#include "/src/astc-encoder/Source/astcenc_internal.h"

#include <fuzzer/FuzzedDataProvider.h>
#include <vector>

// Forward declaration for the function under test.
// It is defined in astcenc_integer_sequence.cpp and declared in astcenc_internal.h
void encode_ise(quant_method, unsigned int, const uint8_t *, uint8_t *, unsigned int);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider stream(data, size);

  // Consume parameters for encode_ise
  // The quant_method enum values range from 0 (QUANT_2) to 20 (QUANT_256).
  // ConsumeEnum cannot be used as the enum does not have a kMaxValue member.
  quant_method quant = static_cast<quant_method>(
      stream.ConsumeIntegralInRange<int>(QUANT_2, QUANT_256));
  unsigned int bit_offset = stream.ConsumeIntegralInRange<unsigned int>(0, 127);

  // Character count must be > 0 as per source code promise.
  // Capping at 64 as a reasonable maximum for weights in a block.
  unsigned int character_count = stream.ConsumeIntegralInRange<unsigned int>(1, 64);

  // Consume the input data buffer
  std::vector<uint8_t> input_data = stream.ConsumeBytes<uint8_t>(character_count);
  if (input_data.size() != character_count) {
    // Not enough data in the input stream to fill the buffer.
    return 0;
  }

  // Determine the required size for the output buffer.
  // The max bits added per character is 4 (e.g., QUANT_12 is 2 value bits + 2 trit bits).
  // The write_bits function can write up to 8 bytes at a time via memcpy.
  size_t output_size = (bit_offset + character_count * 4) / 8 + 8;
  std::vector<uint8_t> output_data(output_size, 0);

  // Call the function under test
  encode_ise(quant, character_count, input_data.data(), output_data.data(), bit_offset);

  return 0;
}
