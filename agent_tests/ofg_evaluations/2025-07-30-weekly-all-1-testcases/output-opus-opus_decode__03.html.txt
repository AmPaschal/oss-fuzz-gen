
	
<description>
The `opus_decode` function decodes an Opus packet. It takes an OpusDecoder state, the encoded packet, its length, an output buffer for the decoded PCM data, the frame size, and a flag to indicate whether to decode FEC data. The decoder state must be initialized by `opus_decoder_create`. The encoded packet and its length can be obtained from `opus_encode` or from a fuzzer. The output buffer must be large enough to hold the decoded audio. The frame size must be positive, and the `decode_fec` flag is a boolean.
</description>
<requirements>
<requirement>
The `st` argument, a pointer to an `OpusDecoder` struct, must be initialized by `opus_decoder_create`. This is because `opus_decode` relies on the initialized state of the `OpusDecoder` to perform decoding.
</requirement>
<requirement>
The `frame_size` argument must be a positive integer. A non-positive `frame_size` will cause the function to return `OPUS_BAD_ARG` without attempting to decode.
</requirement>
<requirement>
The `pcm` buffer should be large enough to hold `frame_size * st->channels` samples of type `opus_int16`. This is to prevent a buffer overflow when the decoded samples are written to `pcm`.
</requirement>
<requirement>
If `decode_fec` is 0, the `data` pointer should not be `NULL` and `len` should be positive. This is because these values are used to determine the number of samples to decode, and invalid values can lead to a crash or `OPUS_INVALID_PACKET` error.
</requirement>
<requirement>
The `st->channels` field of the `OpusDecoder` struct must be 1 or 2. This is enforced by an assertion within `opus_decode`, and violating it will crash the program.
</requirement>
<requirement>
The `data` and `len` arguments should be fuzzed. These represent the compressed audio packet and can be malformed, leading to potential vulnerabilities.
</requirement>
<requirement>
The `frame_size` argument should be fuzzed, with values ranging from 1 up to `MAX_FRAME_SAMP` (5760). This is to test the handling of different frame sizes and prevent potential buffer overflows or other memory errors.
</requirement>
<requirement>
The `decode_fec` argument should be fuzzed with values 0 or 1. This is to test both the normal and FEC decoding paths.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <vector>
#include <cstdint>
#include <cstdlib>

#include "/src/opus/include/opus.h"
#include "opus_types.h"

#define MAX_FRAME_SAMP 5760

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider fdp(data, size);

    const int sample_rates[] = {8000, 12000, 16000, 24000, 48000};
    int fs = fdp.PickValueInArray(sample_rates);
    int channels = fdp.ConsumeIntegralInRange<int>(1, 2);

    int err;
    OpusDecoder *dec = opus_decoder_create(fs, channels, &err);
    if (err != OPUS_OK || dec == nullptr) {
        return 0;
    }

    int decode_fec = fdp.ConsumeBool();
    
    std::vector<opus_int16> pcm(MAX_FRAME_SAMP * channels);

    std::vector<uint8_t> opus_data = fdp.ConsumeRemainingBytes<uint8_t>();
    
    if (opus_data.empty()) {
        // Test Packet Loss Concealment
        opus_decode(dec, nullptr, 0, pcm.data(), MAX_FRAME_SAMP, decode_fec);
    } else {
        opus_decode(dec, opus_data.data(), static_cast<opus_int32>(opus_data.size()), pcm.data(), MAX_FRAME_SAMP, decode_fec);
    }

    opus_decoder_destroy(dec);

    return 0;
}
