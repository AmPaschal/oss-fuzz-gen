The function `xls_open` opens an XLS file and prepares it for reading. It is a wrapper around `xls_open_file`. The `file` argument is a path to the XLS file, and the `charset` argument specifies the character encoding to be used. The function first opens the file as an OLE2 container using `ole2_open_file`. It then attempts to open and read several streams from the OLE2 file, including "Workbook" or "Book", "\005SummaryInformation", and "\005DocumentSummaryInformation". If these streams are not found or cannot be read, the function will fail. If the `charset` is not provided, it defaults to "UTF-8".
