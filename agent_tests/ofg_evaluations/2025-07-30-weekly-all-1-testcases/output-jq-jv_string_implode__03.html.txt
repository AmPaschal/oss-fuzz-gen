
	
<description>
The function `jv_string_implode` takes a `jv` array of `jv` numbers and implodes them into a `jv` string. The numbers are treated as Unicode codepoints. If a number is not a valid codepoint, it is replaced by the replacement character U+FFFD.
</description>

</requirement>
