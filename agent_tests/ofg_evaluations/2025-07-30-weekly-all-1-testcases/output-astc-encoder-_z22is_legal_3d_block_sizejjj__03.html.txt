
	
<description>
The function `is_legal_3d_block_size` checks if a given 3D block size, defined by the dimensions `xdim`, `ydim`, and `zdim`, is valid. It works by combining the three unsigned integer inputs into a single integer value and then checking this value against a hardcoded list of 10 valid sizes using a switch statement. If the combined value matches any of the cases, the function returns true, indicating a legal block size; otherwise, it returns false. The primary caller of this function only invokes it when the z-dimension (`zdim`) is 2 or greater.
</description>
