
	
<description>
The `SetAutoEnableMode` function is used to configure the auto-enable mode of the SRP server. It takes a single boolean argument, `aEnabled`, to either enable or disable this mode. The function will only proceed to change the state if the provided `aEnabled` value is different from the current `mAutoEnable` state. If the state is changed, it then calls `HandleSrpServerAutoEnableMode` on the `RoutingManager` to notify it of the change. Callers of this function, primarily through the C wrapper `otSrpServerSetAutoEnableMode`, exist in unit tests, fuzz targets, and command-line interface (CLI) handlers, indicating that the `aEnabled` parameter can be user-controlled. For the function to execute correctly, an initialized `otInstance` with an enabled `BorderRouter::RoutingManager` is necessary.
</description>
<requirements>
<requirement>
An `otInstance` must be created and initialized before calling this function. This is necessary because the function operates on an `Srp::Server` object obtained from the `otInstance`.
</requirement>
<requirement>
The `aEnabled` parameter should be fuzzed with both `true` and `false`. Callers of the function use both values, and toggling this value is required to bypass the `VerifyOrExit` check in the function.
</requirement>
<requirement>
The `BorderRouter::RoutingManager` must be enabled and initialized. The function depends on the `RoutingManager` to handle the state change, and will fail if it is not available.
</requirement>
<requirement>
The `OPENTHREAD_CONFIG_SRP_SERVER_ENABLE` configuration option must be enabled during compilation. The target function and its callers are conditionally compiled under this flag.
</requirement>
</requirements>

// Custom FuzzDataProvider from the project's other fuzzers, as the standard
// one is not available in this build environment.
class FuzzDataProvider
{
public:
    FuzzDataProvider(const uint8_t *aData, size_t aSize)
        : mData(aData)
        , mSize(aSize)
    {
    }

    void ConsumeData(void *aBuf, size_t aLength)
    {
        if (aLength > mSize)
        {
            aLength = mSize;
        }
        memcpy(aBuf, mData, aLength);
        mData += aLength;
        mSize -= aLength;
    }

    bool ConsumeBool()
    {
        uint8_t val = 0;
        ConsumeData(&val, sizeof(val));
        return (val % 2) != 0;
    }

private:
    const uint8_t *mData;
    size_t         mSize;
};

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    FuzzDataProvider fdp(data, size);

    // Minimal setup from radio-one-node.cpp to get a valid Srp::Server instance
    Core nexus;
    Node &node = nexus.CreateNode();

    // Initialize RoutingManager as it is used by SetAutoEnableMode
    node.GetInstance().Get<BorderRouter::RoutingManager>().Init(/* aInfraIfIndex */ 1, /* aInfraIfIsRunning */ true);
    node.GetInstance().Get<BorderRouter::RoutingManager>().SetEnabled(true);

    // The function to be fuzzed
    bool enable = fdp.ConsumeBool();
    node.GetInstance().Get<Srp::Server>().SetAutoEnableMode(enable);

    // Advance time to allow any state changes to propagate
    nexus.AdvanceTime(10 * 1000);

    return 0;
}
