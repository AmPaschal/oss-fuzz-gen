
	
<description>
The function `nts_make_cookie` generates a cookie for NTS. It uses HMAC-SHA256 with the provided keys `c2s` and `s2c` to generate a cookie of length `cookielen` and writes it to the `storage` buffer. It is used by both the NTS client and server. The server uses it to generate cookies to send to the client, and the client uses it to verify received cookies.
</description>
<requirements>
<requirement>
The `storage` argument must be a valid pointer to a buffer of at least `cookielen` bytes. This is to prevent a buffer overflow when the generated cookie is written to this buffer.
</requirement>
<requirement>
The `cookielen` argument must be at least 32. This is because the function checks for a minimum cookie length of 32.
</requirement>
<requirement>
The `c2s` argument must be a valid pointer to a buffer of at least `keylen` bytes. This is to ensure that the HMAC function has a valid key.
</requirement>
<requirement>
The `s2c` argument must be a valid pointer to a buffer of at least `keylen` bytes. This is to ensure that the HMAC function has a valid key.
</requirement>
<requirement>
The `keylen` argument can be any value up to 256. This is the maximum key length supported by the `nts_key` struct.
</requirement>
<requirement>
The `nts_server_key_fetch` function should be called before `nts_make_cookie` to populate the key structure. This is because the server uses this function to generate the keys used to create the cookie.
</requirement>
</requirements>

extern int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size) {
    // We need at least 3 bytes: 2 for aead, 1 for keylen.
    if (Size < 3) {
        return 0;
    }

    // This generates the keys used internally by nts_make_cookie.
    nts_make_cookie_key();

    // Consume the fuzzer input.
    uint16_t aead;
    memcpy(&aead, Data, sizeof(aead));

    // Use one byte from input to determine keylen to keep it small and positive.
    int keylen = Data[2] % (NTS_MAX_KEYLEN + 1);

    const size_t offset = 3;
    if (Size < offset + (size_t)(2 * keylen)) {
        return 0;
    }

    const uint8_t *key_data_start = Data + offset;
    uint8_t *c2s = (uint8_t *)key_data_start;
    uint8_t *s2c = (uint8_t *)key_data_start + keylen;

    uint8_t cookie[NTS_MAX_COOKIELEN];

    // Call the function under test.
    nts_make_cookie(cookie, aead, c2s, s2c, keylen);

    return 0;
}
