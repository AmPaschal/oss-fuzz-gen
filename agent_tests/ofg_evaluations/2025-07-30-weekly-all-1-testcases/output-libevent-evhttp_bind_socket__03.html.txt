
	
<description>
The `evhttp_bind_socket` function binds an `evhttp` object to a specific address and port. It acts as a wrapper for `evhttp_bind_socket_with_handle`, which handles the socket creation, binding, and listening. The primary caller of this function is `evhttp_start`, which initializes an `evhttp` object before binding it.
</description>
<requirements>

<requirement>
The first argument, `http`, must be a valid pointer to a `struct evhttp` initialized by `evhttp_new_object()`. This is because the function and its callees dereference this pointer, and it must be in a valid state to avoid crashes.
</requirement>
<requirement>
The second argument, `address`, should be a valid, null-terminated string representing an IP address, or NULL. This is passed to the underlying `bind_socket` function, which expects a valid network address to work correctly.
</requirement>
<requirement>
The third argument, `port`, must be a valid port number. An invalid port number will cause the underlying `bind` system call to fail.
</requirement>

</requirements>
