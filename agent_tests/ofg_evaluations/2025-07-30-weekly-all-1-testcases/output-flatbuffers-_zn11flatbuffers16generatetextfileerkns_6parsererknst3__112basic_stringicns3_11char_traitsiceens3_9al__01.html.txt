
	
<description>
The function `GenerateTextFile` is a wrapper around `GenTextFile`. It generates a text file from a given FlatBuffer parser. The function has two main execution paths depending on the `use_flexbuffers` option in the parser. If `use_flexbuffers` is true, it converts the flexbuffer root to a JSON string and saves it to a file. Otherwise, it generates a JSON representation from the parser's builder and saves it. The function's behavior is heavily dependent on the state of the `Parser` object, which must be properly initialized before calling this function.
</description>
<requirements>

<requirement>
The `parser` object passed to the function must be fully initialized. This is because the function accesses member fields of the parser object, and an uninitialized parser will lead to crashes.
</requirement>
<requirement>
If `parser.opts.use_flexbuffers` is set to false, `parser.builder_.GetSize()` must be greater than zero. Otherwise the function will return early without generating a file.
</requirement>
<requirement>
If `parser.opts.use_flexbuffers` is set to false, `parser.root_struct_def_` must not be a nullptr. An uninitialized `root_struct_def_` will cause the function to return early.
</requirement>
<requirement>
The `path` and `file_name` arguments should be valid path components. These are used to construct the output filename, and invalid paths could lead to file creation errors.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <string>
#include <vector>

#include "/src/flatbuffers/include/flatbuffers/idl.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size == 0) {
    return 0;
  }

  FuzzedDataProvider provider(data, size);

  // Define options for the parser, and fuzz them.
  flatbuffers::IDLOptions opts;
  opts.strict_json = provider.ConsumeBool();
  opts.allow_non_utf8 = provider.ConsumeBool();
  opts.output_default_scalars_in_json = provider.ConsumeBool();
  opts.use_flexbuffers = provider.ConsumeBool();
  opts.indent_step = provider.ConsumeIntegralInRange<int>(-1, 8);

  flatbuffers::Parser parser(opts);

  // The rest of the data is used for the schema and filename.
  std::string file_name = provider.ConsumeRandomLengthString(128);
  std::string schema_data = provider.ConsumeRemainingBytesAsString();

  if (schema_data.empty()) {
    return 0;
  }

  // Parse the schema. GenerateTextFile is still called even if parsing fails
  // to test its behavior with an uninitialized/error-state parser.
  parser.Parse(schema_data.c_str());

  // Call the function under test.
  // Use a safe, writable path like "/tmp/" to handle file I/O.
  flatbuffers::GenerateTextFile(parser, "/tmp/", file_name);

  return 0;
}
