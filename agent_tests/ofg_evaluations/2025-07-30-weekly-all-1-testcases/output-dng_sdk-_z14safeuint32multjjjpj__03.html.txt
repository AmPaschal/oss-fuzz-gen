
	
<description>
The function `SafeUint32Mult` safely multiplies three 32-bit unsigned integers (`arg1`, `arg2`, `arg3`). It checks for arithmetic overflow. If the multiplication results in an overflow, the function returns `false`. Otherwise, it stores the result in the memory location pointed to by the `result` parameter and returns `true`. The core logic is implemented in a series of overloaded functions, which ultimately rely on a template function `SafeUnsignedMult` to perform the overflow check. The check for overflow is `arg1 == 0 || arg2 <= std::numeric_limits<T>::max() / arg1`.
</description>
<requirements>
<requirement>
The `result` parameter must be a valid, non-null pointer to a uint32_t. The function writes the result of the multiplication to this pointer, so a NULL pointer would lead to a crash.
</requirement>
<requirement>
The input integer arguments `arg1`, `arg2`, and `arg3` should be fuzzed with a wide range of values. This is to test the overflow detection logic within the function.
</requirement>
</requirements>
