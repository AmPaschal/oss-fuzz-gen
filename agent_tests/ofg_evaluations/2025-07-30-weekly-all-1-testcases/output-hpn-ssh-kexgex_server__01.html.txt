
	
<description>
The `kexgex_server` function is responsible for setting up the server-side key exchange process for the Diffie-Hellman Group Exchange protocol. It accomplishes this by registering a handler, `input_kex_dh_gex_request`, for the `SSH2_MSG_KEX_DH_GEX_REQUEST` message type. This registration is done via the `ssh_dispatch_set` function, which modifies the `ssh` object's dispatch table. Consequently, when a client initiates a key exchange with this method, the server is prepared to receive and process the request.
</description>
