The `fuse_opt_add_opt` function appends a new option to a comma-separated list of options. It is a wrapper around the `add_opt_common` function with the `esc` parameter set to 0, which means that no characters are escaped in the option string.

The function takes two arguments. The first argument, `opts`, is a pointer to a string that holds the options. This string is reallocated to accommodate the new option, so it must be a pointer to a buffer that was allocated using `malloc`, or a pointer to a `NULL` pointer. The second argument, `opt`, is the option to be added. It must be a null-terminated string. The function returns 0 on success and -1 on failure.

Callers of this function, such as `fuse_parse_cmdline` and `fuse_mount_super`, pass the address of a character pointer as the first argument, and a string literal or a variable as the second argument.
</description>
