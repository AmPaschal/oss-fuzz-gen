It serializes a `Cookie` object into a standard C++ output stream (`std::ostream`). The function's implementation is a simple wrapper that calls the private `Cookie::write` method. The `Cookie::write` method is responsible for formatting the cookie's attributes—such as name, value, path, domain, and max-age—into a string that conforms to the HTTP cookie specification (RFC 6265) and writing this string to the provided output stream. The function safely handles the optional attributes of the `Cookie` struct by checking for their existence using `std::optional::has_value()` before attempting to access and write them to the stream, thus preventing crashes from dereferencing empty optional values.
