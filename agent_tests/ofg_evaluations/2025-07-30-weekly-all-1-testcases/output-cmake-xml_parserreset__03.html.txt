
	
<description>
The `XML_ParserReset` function re-initializes an XML parser object, allowing it to be reused to parse a new document. It works by clearing internal data structures like the tag stack and open entities, and then sets up the parser for a new session, optionally with a new character encoding. This is more efficient than destroying an old parser and creating a new one when parsing multiple XML files in succession. The function is designed to work on a root parser and will fail if given a parser created for an external entity.
</description>
<requirements>
<requirement>
The `parser` argument must be a valid pointer to an `XML_Parser` structure. This is because the function dereferences this pointer to access and modify the parser's internal state.
</requirement>
<requirement>
The `XML_ParserCreate` function should be called to create the `XML_Parser` object before calling `XML_ParserReset`. `XML_ParserReset` does not allocate a new parser; it re-initializes an existing one.
</requirement>
<requirement>
The `parser` object should not be a child parser, meaning its `m_parentParser` member must be NULL. The function contains a check for this and will return `XML_FALSE` if it is a child parser.
</requirement>
<requirement>
The `encodingName` argument should be a null-terminated string or NULL. This string specifies the character encoding for the next parsing operation, and the function handles NULL by using a default encoding.
</requirement>
</requirements>
