The function `Pistache::Http::Header::LastModified::write` is responsible for writing a formatted `Last-Modified` HTTP header to a given output stream. It retrieves the date and time information from an internal `FullDate` object and formats it according to the RFC 1123 standard. The `LastModified` object can be constructed with a specific `FullDate` object, or if default-constructed, it will represent the Unix epoch.
</description>

</requirement>
<requirement>
The `LastModified` object should be initialized with a valid `FullDate` object. This can be done using the `LastModified(const FullDate&)` constructor, or by default-constructing the `LastModified` object, which will in turn default-construct the `fullDate_` member to the epoch.
</requirement>
