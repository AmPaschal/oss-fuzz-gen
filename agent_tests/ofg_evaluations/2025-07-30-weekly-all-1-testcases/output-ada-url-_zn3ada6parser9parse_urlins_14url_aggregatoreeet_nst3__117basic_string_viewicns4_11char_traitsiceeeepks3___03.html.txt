
	
<description>
The function `ada::parser::parse_url` parses a URL from a given string input (`user_input`). It can optionally take a base URL (`base_url`) to resolve relative URLs. The function is a template that can produce either an `ada::url` or an `ada::url_aggregator` object. The core parsing logic is implemented in `parse_url_impl`, which is a state machine that handles various parts of a URL. The function is designed to be robust against invalid inputs, returning a result object with a flag `is_valid` set to false in case of a parsing failure.
</description>
<requirements>

<requirement>
The `user_input` argument is a string view representing the URL to parse and should be fuzzed. This is because it is the primary input to the function and can expose parsing vulnerabilities.
</requirement>
<requirement>
The `base_url` argument is a pointer to a `result_type` object, which can be `ada::url` or `ada::url_aggregator`, and can be `nullptr`. If not `nullptr`, it should be initialized by a prior call to `ada::parser::parse_url` with a valid URL string, as the function uses it to resolve relative URLs and expects a valid, parsed URL object.
</requirement>

</requirements>
