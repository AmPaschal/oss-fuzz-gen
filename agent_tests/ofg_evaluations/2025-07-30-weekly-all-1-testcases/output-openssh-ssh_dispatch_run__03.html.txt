
	
<description>
The `ssh_dispatch_run` function is the main dispatch loop for the SSH protocol. It reads incoming packets, determines the packet type, and calls the appropriate handler function from a dispatch table. The function's behavior is controlled by the `mode` argument, which can be either blocking (`DISPATCH_BLOCK`) or non-blocking (`DISPATCH_NONBLOCK`). The `done` argument provides a mechanism for gracefully terminating the dispatch loop.
</description>
<requirements>

<requirement>
The `ssh` argument must be a valid pointer to a `struct ssh` initialized by `ssh_alloc_session_state`. This is because the function accesses several members of this struct, including the dispatch table and connection state.
</requirement>
<requirement>
The `ssh->dispatch` array must be populated with valid function pointers for the expected packet types. The function will crash if it attempts to call a `NULL` function pointer.
</requirement>
<requirement>
The `mode` argument must be either `DISPATCH_BLOCK` or `DISPATCH_NONBLOCK`. These are the only values used by the callers of this function.
</requirement>
<requirement>
If the `done` argument is not `NULL`, it must point to a valid `volatile sig_atomic_t` variable. This variable is used to signal the dispatch loop to terminate.
</requirement>
<requirement>
The `type` variable, read from the packet, must be less than `DISPATCH_MAX` (255). This is to prevent an out-of-bounds access on the `ssh->dispatch` array.
</requirement>

</requirements>

// The prompt requires this non-standard type. We typedef it to the
// correct underlying type from signal.h to make the code compilable.
typedef volatile sig_atomic_t DW_TAG_volatile_typesig_atomic_t;

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    // Suppress logging to avoid spamming the fuzzer output
    log_init("fuzz", SYSLOG_LEVEL_QUIET, SYSLOG_FACILITY_USER, 1);

    FuzzedDataProvider provider(data, size);

    struct ssh *ssh = NULL;
    struct kex_params kex_params;
    char *myproposal[PROPOSAL_MAX];
    const char *proposal[PROPOSAL_MAX] = { KEX_CLIENT };
    int r;
    DW_TAG_volatile_typesig_atomic_t done = 0;

    for (int i = 0; i < PROPOSAL_MAX; i++) {
        myproposal[i] = strdup(proposal[i]);
        if (myproposal[i] == NULL) {
            for (int j = 0; j < i; j++) {
                free(myproposal[j]);
            }
            return 0;
        }
    }
    memcpy(kex_params.proposal, myproposal, sizeof(myproposal));

    bool is_server = provider.ConsumeBool();
    if ((r = ssh_init(&ssh, is_server, &kex_params)) != 0) {
        for (int i = 0; i < PROPOSAL_MAX; i++) {
            free(myproposal[i]);
        }
        return 0;
    }

    std::vector<uint8_t> ssh_input = provider.ConsumeRemainingBytes<uint8_t>();
    if (ssh_input_append(ssh, ssh_input.data(), ssh_input.size()) != 0) {
        ssh_free(ssh);
        for (int i = 0; i < PROPOSAL_MAX; i++) {
            free(myproposal[i]);
        }
        return 0;
    }

    int mode = provider.ConsumeBool() ? DISPATCH_BLOCK : DISPATCH_NONBLOCK;

    ssh_dispatch_run(ssh, mode, &done);

    ssh_free(ssh);
    for (int i = 0; i < PROPOSAL_MAX; i++) {
        free(myproposal[i]);
    }

    return 0;
}
