
	
<description>
The `xls_summaryInfo` function extracts summary information from a given `xlsWorkBook` structure. It allocates and populates an `xlsSummaryInfo` structure by calling `xls_dumpSummary` on the `summary` and `docSummary` members of the input `xlsWorkBook`. The caller is responsible for freeing the returned `xlsSummaryInfo` structure using `xls_close_summaryInfo`.
</description>
<requirements>

<requirement>
The `pWB` argument, a pointer to an `xlsWorkBook` struct, must be initialized by calling `xls_open_file` or `xls_open_buffer`. This ensures that the `xlsWorkBook` struct is properly populated with data from a valid XLS file.
</requirement>
<requirement>
The `summary` and `docSummary` members of the `xlsWorkBook` struct can be NULL. The `xls_summaryInfo` function handles this case by passing these pointers to `xls_dumpSummary`, which checks for NULL before dereferencing.
</requirement>

</requirements>
