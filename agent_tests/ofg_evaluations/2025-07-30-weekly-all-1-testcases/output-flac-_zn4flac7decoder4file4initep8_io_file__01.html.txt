The function takes a FILE pointer as input, and uses member variables of the class as callbacks for the underlying C implementation. These callbacks are set up during the construction of the FLAC::Decoder::File object.
</description>

</requirement>
<requirement>
The FILE pointer argument must not be NULL. This is a requirement of the underlying C function FLAC__stream_decoder_init_FILE, which will return an error if the file pointer is NULL.
</requirement>
<requirement>
The write_callback_ and error_callback_ member variables of the FLAC::Decoder::File object must not be NULL. These callbacks are passed to the underlying C function which checks for their validity. The default callbacks are set in the constructor of the FLAC::Decoder::File class, so this requirement is met by creating an object of this class.
</requirement>
<requirement>
The state of the decoder_ member variable must be FLAC__STREAM_DECODER_UNINITIALIZED. This is required by the underlying C function. The decoder is created and initialized to this state in the constructor of the FLAC::Decoder::File class, and is set to another state after a successful call to init(). Calling init() twice on the same object without an intervening finish() call will result in an error.
</requirement>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    FuzzedDataProvider stream(data, size);
    std::string file_contents = stream.ConsumeRemainingBytesAsString();

    FILE *tmp = tmpfile();
    if (!tmp) {
        return 0;
    }
    fwrite(file_contents.data(), 1, file_contents.size(), tmp);
    rewind(tmp);

    FuzzDecoder decoder;
    decoder.init(tmp);

    fclose(tmp);

    return 0;
}
