
	
<description>
The function JS_NewArrayBuffer is used to create a new JavaScript ArrayBuffer object. It is a wrapper around the internal function js_array_buffer_constructor3, which handles the actual creation and initialization of the ArrayBuffer. The function takes a context, an optional buffer with its length, a custom free function, an opaque pointer for the free function, and a boolean to indicate if the buffer is shared.
</description>
<requirements>

<requirement>
The `ctx` argument must be a valid pointer to a `JSContext` object. This can be obtained by first calling `JS_NewRuntime()` and then `JS_NewContext(rt)`.
</requirement>
<requirement>
The `len` argument must be less than or equal to `INT32_MAX`. The wrapped function `js_array_buffer_constructor3` will throw a `RangeError` for larger values.
</requirement>
<requirement>
If `len` is not 0, the `buf` argument must point to a valid memory region of at least `len` bytes. This is because `JS_NewArrayBuffer` calls `js_array_buffer_constructor3` with `alloc_flag` set to `FALSE`, which directly assigns `buf` to the internal data pointer of the ArrayBuffer.
</requirement>
<requirement>
The `free_func` argument can be `NULL`. If it is not `NULL`, it should be a function of type `JSFreeArrayBufferDataFunc` that can handle the deallocation of the provided `buf`.
</requirement>
<requirement>
The `is_shared` argument should be a boolean value (`TRUE` or `FALSE`). This determines whether a regular or shared ArrayBuffer is created.
</requirement>

</requirements>

#include "/src/quickjs/quickjs.h"
#include "quickjs-libc.h"
#include "cutils.h"
#include <stdint.h>
#include <stddef.h>

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    // We need at least one byte for the 'is_shared' flag.
    if (size < 1) {
        return 0;
    }

    JSRuntime *rt = JS_NewRuntime();
    if (!rt) {
        return 0;
    }
    JSContext *ctx = JS_NewContext(rt);
    if (!ctx) {
        JS_FreeRuntime(rt);
        return 0;
    }

    // Use the first byte of the input to determine the 'is_shared' flag.
    BOOL is_shared = data[0] & 1;
    // The rest of the data is the buffer content.
    uint8_t *buf = (uint8_t *)data + 1;
    size_t len = size - 1;

    // Call the target function.
    // The fuzzer-provided buffer is not copied. QuickJS will not free it
    // because we pass NULL as the free function.
    JSValue val = JS_NewArrayBuffer(ctx, buf, len, NULL, NULL, is_shared);

    // Free the created JSValue. This does not free 'buf'.
    if (!JS_IsException(val)) {
        JS_FreeValue(ctx, val);
    }

    // Clean up the QuickJS environment.
    JS_FreeContext(ctx);
    JS_FreeRuntime(rt);

    return 0;
}
