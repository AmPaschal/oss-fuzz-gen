
	
<description>
The function opus_decode_float decodes an Opus packet into float samples. It is a wrapper for opus_decode_native, which performs the actual decoding. The function takes an initialized OpusDecoder state, the encoded data, its length, a buffer for the decoded PCM samples, the frame size, and a flag to indicate whether to decode FEC data. The decoder state must be created by opus_decoder_create and initialized by opus_decoder_init.
</description>
<requirements>
<requirement>
The first argument, a pointer to an OpusDecoder struct, should be initialized by calling opus_decoder_create. This is because the decoder contains state information that is necessary for the decoding process.
</requirement>
<requirement>
The first argument, a pointer to an OpusDecoder struct, should also be initialized by calling opus_decoder_init. This is because opus_decoder_init sets up the decoder with the correct sample rate and number of channels.
</requirement>
<requirement>
The third argument, len, which represents the length of the input data, should be a non-negative value. A negative value for len will cause the function to return OPUS_BAD_ARG.
</requirement>
<requirement>
The fourth argument, pcm, should be a buffer large enough to hold the decoded audio. The required size is determined by the frame_size and the number of channels, which is set during the decoder initialization.
</requirement>
<requirement>
The fifth argument, frame_size, must be a positive integer. A non-positive value will result in the function returning OPUS_BAD_ARG.
</requirement>
<requirement>
If the sixth argument, decode_fec, is set to 1, or if the input data is NULL or its length is 0, frame_size must be a multiple of the sample rate divided by 400. This is an internal requirement of the Opus codec for handling packet loss concealment.
</requirement>
<requirement>
The sixth argument, decode_fec, must be either 0 or 1. Other values will cause the function to return OPUS_BAD_ARG.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>
#include <vector>

#include "/src/opus/include/opus.h"
#include "/src/opus/include/opus_types.h"

// For opus_decode_float, opus_val16 is a float. This is defined in
// celt/arch.h, but the header is not in the default include path.
typedef float opus_val16;


extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);

  const int sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  opus_int32 Fs = fdp.PickValueInArray(sample_rates);
  int channels = fdp.ConsumeIntegralInRange(1, 2);

  int err;
  OpusDecoder *dec = opus_decoder_create(Fs, channels, &err);
  if (err != OPUS_OK || !dec) {
    return 0;
  }

  // The maximum frame size is 5760 samples per channel.
  const int max_frame_size = 5760;
  int frame_size = fdp.ConsumeIntegralInRange(1, max_frame_size);
  std::vector<opus_val16> pcm(frame_size * channels);

  int decode_fec = fdp.ConsumeBool();

  std::vector<uint8_t> opus_data = fdp.ConsumeRemainingBytes<uint8_t>();

  // A valid opus packet can't be empty.
  if (opus_data.empty()) {
    opus_decoder_destroy(dec);
    return 0;
  }

  opus_decode_float(dec, opus_data.data(),
                    static_cast<opus_int32>(opus_data.size()), pcm.data(),
                    frame_size, decode_fec);

  opus_decoder_destroy(dec);

  return 0;
}
