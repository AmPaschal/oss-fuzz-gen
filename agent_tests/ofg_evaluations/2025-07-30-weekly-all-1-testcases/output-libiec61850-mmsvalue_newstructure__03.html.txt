
	
<description>
The function `MmsValue_newStructure` allocates and initializes a new `MmsValue` object with the type `MMS_STRUCTURE`. It uses the provided `MmsVariableSpecification` to determine the number and types of the structure's components. For each component, it recursively calls `MmsValue_newDefaultValue` to create a default value. The function is typically called by `MmsValue_newDefaultValue` itself when it encounters an `MMS_STRUCTURE` type.
</description>

The `typeSpec->typeSpec.structure.elements` field must not be NULL. It must point to an array of `MmsVariableSpecification` pointers with a size equal to `elementCount`. A NULL value will lead to a null pointer dereference inside the component initialization loop.
</requirement>
<requirement>

These are passed to `MmsValue_newDefaultValue`, and if any are invalid and cause `MmsValue_newDefaultValue` to return NULL, the entire structure creation will be aborted, and the function will return NULL.
</requirement>
