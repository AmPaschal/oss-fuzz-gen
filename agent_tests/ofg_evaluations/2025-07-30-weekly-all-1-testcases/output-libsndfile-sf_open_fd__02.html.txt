
	
<description>
The sf_open_fd function is a versatile file opening function within the libsndfile library, designed to handle audio files from file descriptors. It supports various modes such as read, write, and read-write, and can work with different audio file formats. The function's behavior is primarily controlled by the 'mode' and 'sfinfo' parameters. The 'mode' parameter dictates the access type (read, write, or both), while the 'sfinfo' struct specifies the audio file's characteristics, such as sample rate, number of channels, and format. Additionally, the 'close_desc' parameter allows the caller to decide whether the file descriptor should be closed when the file is eventually closed. A notable limitation of this function is its inability to handle SD2 (Sound Designer II) files, a check for which is explicitly implemented at the beginning of the function.
</description>
<requirements>
<requirement>
The 'fd' parameter must be a valid file descriptor. This is crucial as an invalid file descriptor will cause the function to fail and return an error.
</requirement>
<requirement>
The 'mode' parameter should be one of the following values: SFM_READ (0x10), SFM_WRITE (0x20), or SFM_RDWR (0x30). Using any other value for 'mode' will lead to undefined behavior and potential errors.
</requirement>
<requirement>
The 'sfinfo' parameter must be a pointer to a valid SF_INFO struct. The 'format' field within this struct should not be set to SF_FORMAT_SD2 (0x00100000), as the function explicitly disallows this format and will return NULL.
</requirement>
<requirement>
The 'close_desc' parameter must be a boolean value (0 or 1). This parameter determines whether the file descriptor 'fd' will be closed when the SNDFILE handle is closed.
</requirement>
</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider provider(data, size);

    // Ensure there's enough data to work with.
    if (provider.remaining_bytes() < 1) {
        return 0;
    }

    // 1. Create and populate SF_INFO
    SF_INFO sfinfo;
    memset(&sfinfo, 0, sizeof(sfinfo));
    provider.ConsumeData(&sfinfo, provider.ConsumeIntegralInRange<size_t>(0, sizeof(sfinfo)));

    // 2. Consume other parameters
    const int mode = provider.ConsumeIntegral<int>();
    const int close_desc = provider.ConsumeBool();

    // 3. Create a temporary file and write remaining data to it
    const char* tmp_filename = "/tmp/sf_fuzz_file.bin";
    std::vector<uint8_t> file_contents = provider.ConsumeRemainingBytes<uint8_t>();

    int fd = open(tmp_filename, O_RDWR | O_CREAT | O_TRUNC, 0644);
    if (fd < 0) {
        return 0;
    }

    if (write(fd, file_contents.data(), file_contents.size()) != (ssize_t)file_contents.size()) {
        close(fd);
        unlink(tmp_filename);
        return 0;
    }
    
    // Reset the file offset to the beginning for reading
    lseek(fd, 0, SEEK_SET);

    // 4. Call the function under test
    SNDFILE *sndfile = sf_open_fd(fd, mode, &sfinfo, close_desc);

    // 5. Cleanup
    if (sndfile) {
        sf_close(sndfile);
    } else {
        // If sf_open_fd fails, it is responsible for closing the fd if close_desc is true.
        // If close_desc is false, we are responsible.
        if (!close_desc) {
            close(fd);
        }
    }

    unlink(tmp_filename);

    return 0;
}
