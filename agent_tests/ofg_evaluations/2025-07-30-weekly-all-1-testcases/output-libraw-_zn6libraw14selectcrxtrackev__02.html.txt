
	
<description>
The function `selectCRXTrack` is responsible for selecting the primary RAW track from a CRX (Canon Raw v3) file. It iterates through the available tracks, identifies the RAW track with the highest resolution, and then proceeds to extract metadata and thumbnail information from other related tracks (like JPEG and CTMD metadata). This function is called from `LibRaw::identify` after a CR3 file has been parsed by `parseCR3`.
</description>
<requirements>
<requirement>
The `parseCR3` function must be called before `selectCRXTrack`. This is because `parseCR3` populates the `crx_track_count` and `crx_header` fields in the `libraw_internal_data.unpacker_data` struct, which are essential for the logic in `selectCRXTrack`.
</requirement>
<requirement>
The `libraw_internal_data.unpacker_data.crx_track_count` field should be initialized to a value between 0 and `LIBRAW_CRXTRACKS_MAXCOUNT - 1`. This field determines the number of tracks to iterate over, and an uninitialized or negative value will cause the function to return prematurely.
</requirement>
<requirement>
The `libraw_internal_data.unpacker_data.crx_header` array must be populated with valid data. `selectCRXTrack` directly accesses elements of this array, and invalid data can lead to crashes or incorrect behavior.
</requirement>
<requirement>
At least one of the `crx_data_header_t` entries in the `crx_header` array should have its `MediaType` member set to 1 (RAW). This is necessary for the function to find a RAW track to process.
</requirement>
<requirement>
For the RAW track, the `nBits`, `f_width`, and `f_height` members of its `crx_data_header_t` struct should be initialized to values that result in a `maxbitcount` of at least 8. Otherwise, the function will return early, assuming no valid RAW track was found.
</requirement>
<requirement>
The `shot_select` member of the `LibRaw` class should be fuzzed. This member is used to select a specific track or frame, and providing a range of values can help explore different code paths.
</requirement>

</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {

  // To trigger the call to selectCRXTrack(), the input buffer needs to be
  // identified as a CRX file. The identify() function checks for
  // "ftypcrx " at offset 4.
  const std::string crx_header = "....ftypcrx ";
  
  std::vector<uint8_t> buffer;
  buffer.reserve(crx_header.size() + size);
  buffer.insert(buffer.end(), crx_header.begin(), crx_header.end());
  buffer.insert(buffer.end(), data, data + size);

  LibRaw lib_raw;

  // open_buffer will call identify(), which should call selectCRXTrack()
  // if the header is recognized and parsing is successful enough.
  int result = lib_raw.open_buffer(buffer.data(), buffer.size());

  // Optionally continue processing to exercise more code,
  // similar to the reference fuzzer.
  if (result == LIBRAW_SUCCESS) {
    lib_raw.unpack();
    lib_raw.unpack_thumb();
  }

  return 0;
}
