
	
<description>
The `janet_loop_fiber` function is the main entry point for executing a Janet fiber. It takes a fiber as input and runs it to completion or until an event occurs. In the `shell.c` caller, this function is used to execute the main script of the program. The fiber is initialized with the `cli-main` function, which is resolved from the core environment. The environment is set up with `janet_init` and `janet_core_env`. The fiber is created using `janet_fiber` and then passed to `janet_loop_fiber`. Finally, the VM is deinitialized with `janet_deinit`.
</description>
<requirements>
<requirement>
The `janet_init()` function must be called before any other janet functions. This is because it initializes the Janet VM and all necessary data structures.
</requirement>
<requirement>
A `JanetFiber` must be created and initialized using `janet_fiber`. This is to ensure the fiber has a valid function and stack to execute.
</requirement>
<requirement>
The `fiber->env` field of the `JanetFiber` struct must be initialized with a valid `JanetTable`, which can be created using `janet_core_env(NULL)`. This is because the fiber will use this environment for symbol resolution and global state.
</requirement>
<requirement>
The `JanetFiber` must be registered as a GC root using `janet_gcroot(janet_wrap_fiber(fiber))`. This is to prevent the garbage collector from freeing the fiber while it is still in use.
</requirement>
</requirements>

    JanetCompileResult compile_result = janet_compile(source_janet, env, NULL);

        JanetFunction *func = janet_thunk(compile_result.funcdef);

                janet_loop_fiber(fiber);

        }
    }

    /* Deinitialize Janet */
    janet_deinit();
