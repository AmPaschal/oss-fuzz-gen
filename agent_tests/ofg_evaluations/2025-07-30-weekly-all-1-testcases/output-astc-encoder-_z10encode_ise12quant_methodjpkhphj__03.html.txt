
	
<description>
The `encode_ise` function performs Bounded Integer Sequence Encoding (BISE), a variable-bit-length encoding scheme. It can encode sequences of integers, trits (3-level values), or quints (5-level values), with the encoding method determined by the `quant_level` parameter. The function processes an input character array and writes the resulting bitstream to an output buffer, starting at a specified `bit_offset` to allow for the concatenation of encoded sequences.

The function operates in one of three modes depending on the `quant_level`:
1.  **Trits and Bits:** When the `quant_level` indicates trits, the input is processed in blocks of five characters. Each character is divided into a value and a trit, which are then packed into the output buffer.
2.  **Quints and Bits:** If the `quant_level` specifies quints, the input is handled in blocks of three characters. Each character is split into a value and a quint before being packed into the output buffer.
3.  **Bits only:** In cases where the `quant_level` specifies only bits, each input character is written directly to the output buffer using the defined number of bits.

The function is designed to handle partial blocks at the end of the input sequence, ensuring all characters are correctly encoded. Its core logic relies on pre-calculated tables such as `btq_counts`, `integer_of_trits`, and `integer_of_quints` for efficient encoding. These tables must be properly initialized before the function is called. A `promise` at the start of the function indicates an assumption that the character count will always be greater than zero, which callers must respect. The `output_data` buffer needs to be large enough to hold the encoded data, with its required size determined by the `get_ise_sequence_bitcount` function. The `input_data` buffer should contain at least `character_count` elements, with values that are within a valid range to be used as indices for lookup tables.
</description>
<requirements>
<requirement>
The `quant_level` parameter must be a valid index for the `btq_counts` array. This is to prevent out-of-bounds access on `btq_counts`.</requirement>
<requirement>
The `character_count` parameter must be greater than zero. This is to prevent assertion failures and undefined behavior due to the function's internal promise.</requirement>
<requirement>
The `input_data` buffer must be allocated with a size of at least `character_count` bytes. This is to prevent out-of-bounds reads when accessing `input_data`.</requirement>
<requirement>
The values in the `input_data` buffer must be within a valid range for the `integer_of_trits` and `integer_of_quints` lookup tables. This is to prevent out-of-bounds access on these tables.</requirement>
<requirement>
The `output_data` buffer must be large enough to hold the encoded data. The required size can be determined by calling `get_ise_sequence_bitcount` with the `character_count` and `quant_level` parameters, and adding the `bit_offset`.</requirement>
</requirements>

#include "/src/astc-encoder/Source/astcenc_internal.h"

#include <fuzzer/FuzzedDataProvider.h>
#include <vector>

// Forward declaration to match the function signature
void encode_ise(quant_method, unsigned int, const uint8_t *, uint8_t *, unsigned int);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider stream(data, size);

  // The function has a promise(character_count > 0)
  const unsigned int character_count = stream.ConsumeIntegralInRange<unsigned int>(1, 216);

  // A physical block is 128 bits, so bit offset can't be larger
  const unsigned int bit_offset = stream.ConsumeIntegralInRange<unsigned int>(0, 127);

  // Check if there is enough data to proceed
  if (stream.remaining_bytes() < character_count) {
    return 0;
  }

  // quant_method is a plain enum with 21 values (0-20). ConsumeEnum doesn't
  // work, so we consume an integer in the valid range and cast it.
  const quant_method quant_level =
      static_cast<quant_method>(stream.ConsumeIntegralInRange<int>(0, 20));
  std::vector<uint8_t> input_data = stream.ConsumeBytes<uint8_t>(character_count);

  // The function uses |= to write bits, so the buffer must be zeroed.
  // Max bits written = bit_offset + character_count * (max_bits_per_char)
  // Max bits written = 127 + 216 * 11 = 2503 bits = 313 bytes.
  // We allocate 512 to be safe.
  std::vector<uint8_t> output_data(512, 0);

  encode_ise(quant_level, character_count, input_data.data(), output_data.data(), bit_offset);

  return 0;
}
