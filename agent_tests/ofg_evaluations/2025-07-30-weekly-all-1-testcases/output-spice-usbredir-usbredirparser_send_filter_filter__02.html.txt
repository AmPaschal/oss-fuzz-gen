
	
<description>
The function `usbredirparser_send_filter_filter` sends a USB filter to a peer. It first checks if the peer has the `usb_redir_cap_filter` capability. If it does, it converts the provided filter rules into a string representation and queues the filter to be sent to the peer. The function handles the allocation and freeing of the string representation of the filter rules.
</description>
<requirements>
<requirement>
The `parser_pub` argument must be a valid, initialized `usbredirparser` struct. This is because the function casts it to a private type and accesses its members.
</requirement>
<requirement>
The `usbredirparser`'s peer must have the `usb_redir_cap_filter` capability. This is enforced by a check at the beginning of the function, and if the capability is missing the filter is not sent.
</requirement>
<requirement>
The `rules` argument must be a valid pointer to an array of `usbredirfilter_rule` structs. This is passed to `usbredirfilter_rules_to_string` to generate the filter string.
</requirement>
<requirement>
The `rules_count` argument must accurately represent the number of elements in the `rules` array. This is also passed to `usbredirfilter_rules_to_string`.
</requirement>
</requirements>

void usbredirparser_send_filter_filter(struct usbredirparser *, const struct usbredirfilter_rule *, int);

namespace {
// Dummy write callback that pretends to write all data successfully.
// This is needed for usbredirparser_do_write to function.
int parser_write_dummy(void *priv, uint8_t *data, int count) {
    // We don't need to do anything with the data, just say we wrote it.
    return count;
}

// Deleter for the usbredirparser to be used with unique_ptr
struct ParserDeleter {
  void operator()(struct usbredirparser *p) {
    if (p) {
        usbredirparser_destroy(p);
    }
  }
};
} // namespace

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider fdp(data, size);

    std::unique_ptr<struct usbredirparser, ParserDeleter> parser(usbredirparser_create());
    if (!parser) {
        return 0;
    }

    // A write callback is necessary for usbredirparser_do_write to work.
    parser->write_func = parser_write_dummy;

    // Initialize the parser with default values.
    usbredirparser_init(parser.get(), "fuzzer", nullptr, 0, 0);

    // Create filter rules from fuzzer data.
    const int rules_count = fdp.ConsumeIntegralInRange<int>(0, 32);
    std::vector<usbredirfilter_rule> rules;
    rules.reserve(rules_count);
    for (int i = 0; i < rules_count; i++) {
        if (fdp.remaining_bytes() < sizeof(usbredirfilter_rule)) {
            break;
        }
        usbredirfilter_rule rule;
        rule.device_class = fdp.ConsumeIntegral<int>();
        rule.vendor_id = fdp.ConsumeIntegral<int>();
        rule.product_id = fdp.ConsumeIntegral<int>();
        rule.device_version_bcd = fdp.ConsumeIntegral<int>();
        rule.allow = fdp.ConsumeBool();
        rules.push_back(rule);
    }

    // Call the function under test.
    usbredirparser_send_filter_filter(parser.get(), rules.data(), rules.size());

    // The target function queues a packet. Calling usbredirparser_do_write()
    // will attempt to serialize and "send" this packet, exercising more code.
    while (usbredirparser_has_data_to_write(parser.get())) {
        if (usbredirparser_do_write(parser.get()) < 0) {
            break;
        }
    }

    return 0;
}
