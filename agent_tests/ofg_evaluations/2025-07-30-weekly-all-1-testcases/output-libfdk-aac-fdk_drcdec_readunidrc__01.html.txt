
	
<description>
The FDK_drcDec_ReadUniDrc function reads and decodes UniDrc data from a bitstream. The function first checks if the DRC decoder handle `hDrcDec` is valid and ready. If so, it calls `drcDec_readUniDrc` to read the UniDrc data, which includes the configuration, loudness information, and gain. After reading the data, it calls `startSelectionProcess` to initialize the selection process based on the new data. Finally, it updates the status of the decoder based on whether new gain payload was found.
The function is part of a larger DRC decoding module. Before calling this function, the caller must first create and initialize a DRC decoder instance by calling FDK_drcDec_Open and FDK_drcDec_Init. The caller must also provide a valid bitstream handle `hBitstream` from which the UniDrc data will be read. This function is one of several functions that can be used to read different parts of the DRC data from the bitstream. For example, `FDK_drcDec_ReadUniDrcConfig` and `FDK_drcDec_ReadUniDrcGain` can be used to read the configuration and gain data separately. `FDK_drcDec_ReadUniDrc` is a convenience function that reads all parts of the UniDrc data in one call.
</description>

</requirement>
<requirement>
The `hBitstream` handle must be a valid handle to a bitstream. The function reads data from the bitstream, and will fail if the handle is invalid.
</requirement>
<requirement>

</requirement>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <vector>

#include "/src/aac/libDRCdec/include/FDK_drcDecLib.h"
#include "/src/aac/libFDK/include/FDK_bitstream.h"
#include "aacdecoder_lib.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Consume parameters for decoder initialization.
  const int frameSize = provider.ConsumeIntegralInRange<int>(256, 4096);
  const int sampleRate = provider.ConsumeIntegralInRange<int>(8000, 96000);
  const int baseChannelCount = provider.ConsumeIntegralInRange<int>(1, 8);

  if (provider.remaining_bytes() == 0) {
    return 0;
  }

  HANDLE_DRC_DECODER hDrcDec = NULL;
  DRC_DEC_ERROR drc_err;

  drc_err = FDK_drcDec_Open(&hDrcDec, DRC_DEC_ALL);
  if (drc_err != DRC_DEC_OK) {
    return 0;
  }

  drc_err = FDK_drcDec_Init(hDrcDec, frameSize, sampleRate, baseChannelCount);
  if (drc_err != DRC_DEC_OK) {
    FDK_drcDec_Close(&hDrcDec);
    return 0;
  }

  std::vector<uint8_t> bitstream_data = provider.ConsumeRemainingBytes<uint8_t>();
  HANDLE_FDK_BITSTREAM hBitstream = FDKcreateBitStream(
      const_cast<uint8_t *>(bitstream_data.data()), bitstream_data.size());

  if (hBitstream == NULL) {
    FDK_drcDec_Close(&hDrcDec);
    return 0;
  }

  FDK_drcDec_ReadUniDrc(hDrcDec, hBitstream);

  FDK_drcDec_Close(&hDrcDec);
  // FDKcreateBitStream allocates a handle which is not freed here,
  // as no public deallocation function was found. This is acceptable for fuzzing.

  return 0;
}
