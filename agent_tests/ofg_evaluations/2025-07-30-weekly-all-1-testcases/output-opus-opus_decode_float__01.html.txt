
	
<description>
The `opus_decode_float` function is a wrapper around the `opus_decode_native` function. The primary purpose of this function is to decode an Opus packet into floating-point PCM audio samples. The function can also be used to perform packet loss concealment (PLC) by passing `NULL` for the `data` parameter. The function's behavior is heavily dependent on the state of the `OpusDecoder` struct, which is initialized by `opus_decoder_create`. The `frame_size` parameter is critical and must be chosen carefully, as it depends on the sample rate and whether forward error correction (FEC) is being decoded. Invalid `frame_size` values are a common source of errors. The `decode_fec` parameter controls whether the function will attempt to decode FEC data from the provided packet. The `data` and `len` parameters represent the encoded Opus packet and its length, which are the primary inputs to be fuzzed. The `pcm` buffer must be large enough to hold the decoded audio. The `opus_decode_native` function, which does the actual work, contains complex logic for parsing the Opus packet, handling different modes and bandwidths, and performing the decoding and PLC operations. It also has checks for invalid arguments and buffer sizes. Therefore, to fuzz `opus_decode_float` effectively, it is essential to create a valid `OpusDecoder` instance, provide valid `frame_size` and `decode_fec` parameters, and supply fuzzer-generated data for the `data` and `len` parameters.
</description>
<requirements>
<requirement>
The first argument, `st`, must be a valid pointer to an `OpusDecoder` struct initialized by `opus_decoder_create`. This is because the function dereferences this pointer to access decoder state information.
</requirement>
<requirement>
The third argument, `len`, must be non-negative. A negative value for `len` will cause the function to return `OPUS_BAD_ARG` without performing any decoding.
</requirement>
<requirement>
The fourth argument, `pcm`, must be a buffer large enough to hold the decoded audio. The required size is `frame_size * channels * sizeof(opus_val16)`, where `channels` is the channel count used to create the `OpusDecoder`.
</requirement>
<requirement>
The fifth argument, `frame_size`, must be a positive integer. If `frame_size` is not positive, the function will return `OPUS_BAD_ARG`.
</requirement>
<requirement>
If the sixth argument, `decode_fec`, is true (1), or if packet loss concealment is being performed (`data` is `NULL` or `len` is 0), then `frame_size` must be a multiple of `st->Fs / 400`. This is a requirement of the underlying `opus_decode_native` function to ensure proper frame alignment.
</requirement>
<requirement>
The sixth argument, `decode_fec`, must be either 0 or 1. Any other value will result in an `OPUS_BAD_ARG` error.
</requirement>
<requirement>
The `data` and `len` arguments should be fuzzed. These arguments represent the compressed audio data and can be the source of vulnerabilities.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <vector>
#include <cstdint>

#include "/src/opus/include/opus.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);

  const opus_int32 kSampleRates[] = {8000, 12000, 16000, 24000, 48000};
  opus_int32 sample_rate = fdp.PickValueInArray(kSampleRates);
  int channels = fdp.ConsumeIntegralInRange<int>(1, 2);

  int err;
  OpusDecoder *decoder = opus_decoder_create(sample_rate, channels, &err);
  if (err != OPUS_OK || !decoder) {
    return 0;
  }

  // From the documentation, frame_size must be a multiple of 2.5 ms.
  // The maximum packet duration is 120ms.
  // 120ms / 2.5ms = 48 blocks.
  const int samples_per_2_5_ms = sample_rate / 400;
  int num_blocks = fdp.ConsumeIntegralInRange<int>(1, 48);
  int frame_size = num_blocks * samples_per_2_5_ms;

  std::vector<float> pcm(frame_size * channels);
  int decode_fec = fdp.ConsumeBool();

  std::vector<uint8_t> packet = fdp.ConsumeRemainingBytes<uint8_t>();
  
  // The function might not handle a null data pointer with a non-zero size,
  // so we ensure the packet is not empty.
  if (!packet.empty()) {
    opus_decode_float(decoder, packet.data(), packet.size(), pcm.data(), frame_size, decode_fec);
  }

  opus_decoder_destroy(decoder);

  return 0;
}
