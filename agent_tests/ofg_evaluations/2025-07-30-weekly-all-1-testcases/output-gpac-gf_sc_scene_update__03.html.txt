
	
<description>
The function `gf_sc_scene_update` updates the scene in the compositor. The first argument is a pointer to the compositor, the second argument is the type of the update, and the third argument is the update command. The function first checks if the compositor and the command are valid. Then, it checks the type of the update. If the type is `application/ecmascript` or `js`, it executes the command as a script. Otherwise, it parses the command as a scene update. The command can be a simple command like `gpac add`, `gpac splice`, or `gpac select`, or it can be a scene description in BT, XMT, SVG, or X3D format.
</description>
