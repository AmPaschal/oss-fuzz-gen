
	
<description>
The `symbolic_to_physical` function converts a symbolic representation of a compressed block (`symbolic_compressed_block`) into a physical hardware-ready block format (`pcb`). The block size descriptor (`block_size_descriptor`) provides the context for the conversion, including block dimensions and encoding modes. The function handles both constant-color blocks and more complex data blocks with multiple partitions and encoding schemes. It first checks for constant color blocks and directly writes the physical representation. For other blocks, it encodes weights, partition information, color endpoint formats, and color endpoint values into the physical block according to the ASTC specification.
</description>
<requirements>

<requirement>
The `scb.block_type` field must not be `SYM_BTYPE_ERROR`. The function asserts this condition, and a failure indicates that no valid encoding was found for the block before calling this function.
</requirement>
<requirement>
If `scb.block_type` is `SYM_BTYPE_CONST_U16` or `SYM_BTYPE_CONST_F16`, the `scb.constant_color` array must be initialized. This array provides the color data for constant-color blocks.
</requirement>
<requirement>
The `bsd` (block_size_descriptor) argument must be properly initialized. The `init_block_size_descriptor` function should be called to populate the `bsd` structure with valid data for the target block size.
</requirement>
<requirement>
For non-constant blocks, `scb.partition_count` must be between 1 and 4, inclusive. This value determines the number of partitions to encode and affects how other data is processed.
</requirement>
<requriement>
For non-constant blocks, the `scb.block_mode` must be a valid index into the `bsd.block_modes` array. An invalid mode will lead to out-of-bounds access when fetching block mode and decimation info.
</requirement>
<requirement>
The output array `pcb` must point to a buffer of at least 16 bytes. The function writes 16 bytes of data for the physical block representation, and a smaller buffer will result in a buffer overflow.
</requirement>
<requirement>
For non-constant blocks, the weight values in `scb.weights` should be in the range [0, 64]. These values are scaled and quantized based on this assumed range.
</requirement>

</requirements>

/**
 * @brief Fuzz target for symbolic_to_physical().
 *
 * This function is the final entrypoint for compressing a symbolic block into
 * a 16 byte physical ASTC data block for storing on disk.
 */

#include "/src/astc-encoder/Source/astcenc_internal.h"

#include <fuzzer/FuzzedDataProvider.h>
#include <array>
#include <vector>

struct BlockSizes {
  int x;
  int y;
  int z;
};

// A representative set of block sizes to test
std::array<BlockSizes, 3> testSz{{
    {4, 4, 1},   // Highest bitrate
    {12, 12, 1}, // Largest 2D block
    {6, 6, 6}    // Largest 3D block
}};

std::array<block_size_descriptor, 3> testBSD;

/**
 * @brief Utility function to create all of the block size descriptors needed.
 *
 * This is triggered once via a static initializer.
 *
 * Triggering once is important so that we only create a single BSD per block
 * size we need, rather than one per fuzzer iteration (it's expensive). This
 * improves fuzzer throughput by ~ 1000x!
 *
 * Triggering via a static initializer, rather than a lazy init in the fuzzer
 * function, is important because is means that the BSD is allocated before
 * fuzzing starts. This means that leaksanitizer will ignore the fact that we
 * "leak" the dynamic allocations inside the BSD (we never call term()).
 */
bool bsd_initializer() {
  for (size_t i = 0; i < testSz.size(); i++) {
    // The partition count limit doesn't matter for decompression so set to max
    init_block_size_descriptor(testSz[i].x, testSz[i].y, testSz[i].z, false, 4, 1.0f, testBSD[i]);
  }
  return true;
}

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  // Preinitialize the block size descriptors we need
  static bool init = bsd_initializer();

  FuzzedDataProvider stream(data, size);

  // Select a block size to test
  int i = stream.ConsumeIntegralInRange<int>(0, testSz.size() - 1);
  const block_size_descriptor& bsd = testBSD[i];

  // Create and populate the symbolic block
  symbolic_compressed_block scb;

  // The function asserts that the block type is not an error
  scb.block_type = stream.PickValueInArray<uint8_t>({
      SYM_BTYPE_CONST_F16,
      SYM_BTYPE_CONST_U16,
      SYM_BTYPE_NONCONST
  });

  if (scb.block_type != SYM_BTYPE_NONCONST) {
    if (stream.remaining_bytes() < sizeof(scb.constant_color)) {
      return 0;
    }
    stream.ConsumeData(scb.constant_color, sizeof(scb.constant_color));
  } else {
    scb.partition_count = stream.ConsumeIntegralInRange<uint8_t>(1, 4);

    if (bsd.block_mode_count_all == 0) {
        return 0;
    }
    scb.block_mode = stream.ConsumeIntegralInRange<uint16_t>(0, bsd.block_mode_count_all - 1);

    const auto& bm = bsd.get_block_mode(scb.block_mode);
    if (bm.is_dual_plane) {
      scb.plane2_component = stream.ConsumeIntegralInRange<int8_t>(0, 3);
    } else {
      scb.plane2_component = -1;
    }

    if (scb.partition_count > 1) {
        if (bsd.partitioning_count_selected[scb.partition_count - 1] == 0) {
            return 0;
        }
        scb.partition_index = stream.ConsumeIntegralInRange<uint16_t>(
            0, bsd.partitioning_count_selected[scb.partition_count - 1] - 1);
    } else {
        scb.partition_index = 0;
    }

    scb.color_formats_matched = stream.ConsumeBool();
    scb.quant_mode = static_cast<quant_method>(stream.ConsumeIntegralInRange<int>(QUANT_2, QUANT_256));

    if (stream.remaining_bytes() < sizeof(scb.color_formats) + sizeof(scb.color_values)) {
      return 0;
    }
    stream.ConsumeData(scb.color_formats, sizeof(scb.color_formats));
    stream.ConsumeData(scb.color_values, sizeof(scb.color_values));
  }

  if (stream.remaining_bytes() < sizeof(scb.weights)) {
    return 0;
  }
  stream.ConsumeData(scb.weights, sizeof(scb.weights));

  // The error value is not used by symbolic_to_physical
  scb.errorval = 0.0f;

  // Create the output buffer
  uint8_t pcb[16];

  // Call the function under test
  symbolic_to_physical(bsd, scb, pcb);

  return 0;
}
