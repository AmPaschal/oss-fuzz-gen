The `mbedtls_ssl_close_notify` function is used to notify the peer that the TLS connection is being closed. It sends a TLS alert message with the value `close_notify`. The function checks if the provided SSL context and its configuration are valid. Its main action, sending the alert, is only performed if the SSL/TLS handshake has been completed successfully (i.e., `mbedtls_ssl_is_handshake_over()` returns true). To achieve this state, the caller must first initialize the SSL context (`mbedtls_ssl_init`), set up the configuration (`mbedtls_ssl_config_defaults`, `mbedtls_ssl_conf_*`), associate the configuration with the context (`mbedtls_ssl_setup`), set the I/O callbacks (`mbedtls_ssl_set_bio`), and then perform the handshake (`mbedtls_ssl_handshake`). Calling this function before the handshake is complete will result in no action and a success return code.
</description>

int fuzz_recv(void *ctx, unsigned char *buf, size_t len)
{
    fuzzBufferOffset_t *biomemfuzz = (fuzzBufferOffset_t *) ctx;
    if (biomemfuzz->Offset == biomemfuzz->Size) {
        return 0;
    }
    if (len > INT_MAX) {
        return -1;
    }
    if (len + biomemfuzz->Offset > biomemfuzz->Size) {
        len = biomemfuzz->Size - biomemfuzz->Offset;
    }
    memcpy(buf, biomemfuzz->Data + biomemfuzz->Offset, len);
    biomemfuzz->Offset += len;
    return (int) len;
}
