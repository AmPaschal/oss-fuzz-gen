
	
<description>
The `crxDecodePlane` function decodes a single plane of a CRX image. It takes a pointer to a `CrxImage` struct and a plane number as input. The `CrxImage` struct contains all the necessary information for decoding, such as image dimensions, tile information, and subband data. The function iterates through the tiles of the image, and for each tile, it sets up the subband data, performs inverse wavelet transformation, and converts the decoded data to the final output format. The `crxDecodePlane` function is called by `crxLoadDecodeLoop`, which in turn is called by `crxLoadRaw`, the main function for loading CRX images.
</description>
<requirements>

<requirement>
The first argument, a void pointer, must be a valid pointer to a `CrxImage` struct. This struct must be properly initialized by calling `crxSetupImageData` before calling `crxDecodePlane`, as it contains all the necessary data for decoding.
</requirement>
<requirement>
The `planeNumber` argument must be less than the `nPlanes` field of the `CrxImage` struct. This is to prevent out-of-bounds access to the `tile->comps` array.
</requirement>
<requirement>
The `CrxImage` struct should have its `tileRows` and `tileCols` fields initialized to values greater than 0. These fields determine the number of tiles to be processed, and incorrect values can lead to memory access errors.
</requirement>
<requirement>
The `CrxImage` struct should have its `tiles` field pointing to a valid, allocated memory region. The `crxSetupImageData` function is responsible for this allocation.
</requirement>

</requirements>
