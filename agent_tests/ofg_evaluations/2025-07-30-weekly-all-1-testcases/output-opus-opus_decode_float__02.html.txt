
	
<description>
The `opus_decode_float` function decodes an Opus packet into floating-point PCM samples. It is a wrapper around the `opus_decode_native` function. The function takes an initialized `OpusDecoder` state, a buffer containing the compressed Opus data, the length of this buffer, an output buffer for the PCM data, the desired frame size, and a flag to indicate whether to decode FEC data. Callers must first create a decoder instance using `opus_decoder_create()`. The output buffer `pcm` must be large enough to hold the decoded audio, which is dependent on the `frame_size` and the number of channels configured in the decoder state. The function returns the number of decoded samples per channel on success, or an error code on failure.
</description>
<requirements>
<requirement>
The `st` parameter must be a valid `OpusDecoder` pointer initialized by `opus_decoder_create()`. This is because the function relies on the decoder's initialized state for decoding.
</requirement>
<requirement>
The `frame_size` parameter must be a positive integer. The function returns an error for non-positive values, and a positive value is needed to allocate a correctly-sized output buffer.
</requirement>
<requirement>
The `decode_fec` parameter must be either 0 or 1. Any other value will cause the function to return `OPUS_BAD_ARG`.
</requirement>
<requirement>
If `decode_fec` is 1 or `data` is NULL, `frame_size` must be a multiple of `st->Fs / 400`. This is required by `opus_decode_native` to handle Forward Error Correction and Packet Loss Concealment.
</requirement>
<requirement>
The `pcm` buffer must be allocated with a size of at least `frame_size * st->channels * sizeof(opus_val16)`. A smaller buffer can lead to a buffer overflow or an `OPUS_BUFFER_TOO_SMALL` error.
</requirement>
<requirement>
The `len` parameter, representing the size of the data buffer, must be non-negative. A negative length is invalid and will cause an error.
</requirement>
<requirement>
The `data` and `len` parameters should be fuzzed. As these represent the compressed audio input, they are the primary targets for fuzzing to discover vulnerabilities in the parsing and decoding logic.
</requirement>
</requirements>

#include <cstdint>
#include <vector>

// Header for the function-under-test
#include "opus.h"
// opus.h includes opus_types.h, so a separate include is not needed.

// The function is declared in opus.h, no need to redeclare.

#define MAX_FRAME_SAMP 5760
#define MAX_CHANNELS 2

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);

  // Parameters for decoder creation
  const int channels = fdp.PickValueInArray<int>({1, 2});
  const opus_int32 Fs = fdp.PickValueInArray<opus_int32>({8000, 12000, 16000, 24000, 48000});

  // Create the decoder
  int err;
  OpusDecoder *dec = opus_decoder_create(Fs, channels, &err);
  if (err != OPUS_OK || dec == NULL) {
    return 0;
  }

  // Parameters for opus_decode_float
  const int decode_fec = fdp.ConsumeBool();
  // As per documentation, frame_size must be large enough for the maximum packet duration (120ms).
  // 5760 samples at 48kHz is 120ms.
  const int frame_size = MAX_FRAME_SAMP;

  // Allocate buffer for decoded PCM data. The function expects float.
  float pcm[MAX_FRAME_SAMP * MAX_CHANNELS];

  // Consume the rest of the data as the Opus packet
  std::vector<uint8_t> opus_packet = fdp.ConsumeRemainingBytes<uint8_t>();
  const unsigned char *packet_data = opus_packet.data();
  opus_int32 packet_len = static_cast<opus_int32>(opus_packet.size());

  // Call the function under test
  opus_decode_float(dec, packet_data, packet_len, pcm, frame_size, decode_fec);

  // Clean up
  opus_decoder_destroy(dec);

  return 0;
}
