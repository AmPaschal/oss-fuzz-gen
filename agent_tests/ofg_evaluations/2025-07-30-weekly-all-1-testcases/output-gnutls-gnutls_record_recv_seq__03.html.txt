
	
<description>
The gnutls_record_recv_seq function is used to receive data from a TLS/DTLS session and retrieve the corresponding sequence number. It is a variant of gnutls_record_recv that provides the sequence number of the received record, which is particularly useful in DTLS to handle out-of-order packets. The function is typically called after a TLS/DTLS handshake has been completed or has failed. It takes a gnutls_session_t object, a buffer to store the received data, the size of the buffer, and a buffer to store the 8-byte sequence number as input.
</description>
<requirements>

<requirement>
The first argument, gnutls_session_t, must be an initialized session handle. This is because the function relies on the internal state of the session to receive and process records.
</requirement>
<requirement>
A TLS/DTLS handshake must be performed on the session before calling this function. This is because the function is intended to be used for receiving data after a session has been established.
</requirement>
<requirement>
The second argument, a `void` pointer to a data buffer, must be a valid and allocated buffer. This is to prevent a segmentation fault when the function attempts to write the received data to this buffer.
</requirement>
<requirement>
The third argument, `size_t data_size`, should be the size of the buffer pointed to by the second argument. This is to avoid buffer overflows.
</requirement>
<requirement>
The fourth argument, an `unsigned char` pointer for the sequence number, must be a valid and allocated buffer of at least 8 bytes. This is to prevent a segmentation fault when the function writes the 8-byte sequence number.
</requirement>

#include <assert.h>
#include <fcntl.h>
#include <stdint.h>
#include <sys/types.h>
#include <unistd.h>
#include <string.h>
#include <stdlib.h>
#include <stdbool.h>

#include <gnutls/gnutls.h>
#include "mem.h"
#include "fuzzer.h"

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
	int res;
	gnutls_session_t session;
	gnutls_certificate_credentials_t xcred;
	struct mem_st memdata;

	res = gnutls_init(&session, GNUTLS_CLIENT);
	assert(res >= 0);

	res = gnutls_certificate_allocate_credentials(&xcred);
	assert(res >= 0);
	res = gnutls_credentials_set(session, GNUTLS_CRD_CERTIFICATE, xcred);
	assert(res >= 0);

	/* Use a simple priority string to avoid dependency on VERS_STR */
	res = gnutls_priority_set_direct(session, "NORMAL", NULL);
	assert(res >= 0);

	memdata.data = data;
	memdata.size = size;

	gnutls_transport_set_push_function(session, mem_push);
	gnutls_transport_set_pull_function(session, mem_pull);
	gnutls_transport_set_pull_timeout_function(session, mem_pull_timeout);
	gnutls_transport_set_ptr(session, &memdata);

	do {
		res = gnutls_handshake(session);
	} while (res < 0 && gnutls_error_is_fatal(res) == 0);

	if (res >= 0) {
		/* After a successful handshake, try to receive data. */
		while (true) {
			char buf[16384];
			unsigned char seq[8];
			res = gnutls_record_recv_seq(session, buf, sizeof(buf), seq);
			if (res <= 0) {
				break;
			}
		}
	}

	gnutls_deinit(session);
	gnutls_certificate_free_credentials(xcred);
	return 0;
}
