
	
<description>
The function `is_legal_2d_block_size` checks if a given 2D block size, defined by `xdim` and `ydim`, is one of the legal block sizes supported by the ASTC encoder. It does this by combining `xdim` and `ydim` into a single unsigned integer and using a switch statement to check against a hardcoded list of valid combined values. The function is called from `astcenc_validate_block_size` in `astcenc_entry.cpp` as part of the block size validation process. `astcenc_validate_block_size` is in turn called from `astcenc_config_init`, which suggests that the block size is part of the initial configuration of the encoder.
</description>

This is to satisfy the switch statement in the function and return `true`, which is the condition for the block size to be considered legal in the calling code. Any other combination will result in a `false` return value and will likely cause the calling function to return an error.
