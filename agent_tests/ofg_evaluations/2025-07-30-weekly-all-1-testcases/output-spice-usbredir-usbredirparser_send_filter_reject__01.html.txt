
	
<description>
The function `usbredirparser_send_filter_reject` sends a filter reject message. It checks if the peer has the `usb_redir_cap_filter` capability, and if so, queues a `usb_redir_filter_reject` message to be sent. This is part of the USB redirection protocol to inform the peer that a device has been rejected by the filter.
</description>
<requirements>

<requirement>
The `parser` argument must be a valid pointer to a `usbredirparser` struct initialized by `usbredirparser_create` and `usbredirparser_init`. This is because the function dereferences this pointer, and it must point to a valid and initialized structure to avoid crashes and undefined behavior.
</requirement>
<requirement>
The `parser` must have its `peer_caps` member initialized, which is done by processing a `usb_redir_hello` message from the peer. This is a precondition for the `usbredirparser_peer_has_cap` check to work correctly.
</requirement>
<requirement>
The `peer_caps` bitmask must have the `usb_redir_cap_filter` bit set. This is because the function will only proceed to send a message if this capability is present in the peer's capabilities, otherwise it will return silently.
</requirement>

</requirements>
