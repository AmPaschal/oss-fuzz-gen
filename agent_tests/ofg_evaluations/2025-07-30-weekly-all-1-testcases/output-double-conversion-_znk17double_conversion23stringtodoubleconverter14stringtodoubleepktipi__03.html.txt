
	
<description>
The function `StringToDouble` converts a string to a double-precision floating-point number. It is a wrapper around the `StringToIeee` function, which performs the actual conversion. The behavior of the conversion is controlled by the flags passed to the `StringToDoubleConverter` constructor. These flags control aspects of the conversion like allowing hexadecimal or octal numbers, allowing leading or trailing spaces, and the strings used to represent infinity and NaN.
</description>
<requirements>

<requirement>
The `StringToDoubleConverter` object should be initialized with a fuzzed `flags` argument. This is because the `flags` argument controls the parsing logic of the function, and fuzzing it will allow for testing of different parsing paths.
</requirement>
<requirement>
The `buffer` argument should be a valid pointer to a buffer of at least `length` bytes. This is to prevent a crash due to an out-of-bounds read in the `StringToIeee` function.
</requirement>
<requirement>
The `length` argument should be the length of the `buffer` argument. This is to ensure that the function does not read past the end of the buffer.
</requirement>
<requirement>
The `processed_characters_count` argument should be a valid pointer to an integer. This is because the function writes the number of processed characters to this address, and a null or invalid pointer would cause a crash.
</requirement>

</requirements>

#include <cstddef>
#include <cstdint>
#include <cstdlib>

#include "double-conversion.h"
#include "/src/double-conversion/double-conversion/string-to-double.h"

using double_conversion::StringToDoubleConverter;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  StringToDoubleConverter converter(
      StringToDoubleConverter::ALLOW_HEX |
          StringToDoubleConverter::ALLOW_OCTALS |
          StringToDoubleConverter::ALLOW_TRAILING_JUNK |
          StringToDoubleConverter::ALLOW_LEADING_SPACES |
          StringToDoubleConverter::ALLOW_TRAILING_SPACES |
          StringToDoubleConverter::ALLOW_SPACES_AFTER_SIGN |
          StringToDoubleConverter::ALLOW_CASE_INSENSIBILITY |
          StringToDoubleConverter::ALLOW_HEX_FLOATS,
      /*empty_string_value=*/0.0,
      /*junk_string_value=*/0.0, "inf", "nan");
  
  if (size < sizeof(uc16)) {
    return 0;
  }

  const uc16* buffer = reinterpret_cast<const uc16*>(data);
  int length = size / sizeof(uc16);
  int processed_characters_count;

  converter.StringToDouble(buffer, length, &processed_characters_count);
  
  return 0;
}
