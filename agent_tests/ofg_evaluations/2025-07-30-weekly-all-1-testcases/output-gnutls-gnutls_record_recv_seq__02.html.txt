
	
<description>
The `gnutls_record_recv_seq` function is used to receive application data from a TLS/DTLS session. It is a wrapper around the internal function `_gnutls_recv_int`. This function is typically called after a successful handshake to receive data from the peer. It can also be called after a failed handshake to receive and process any pending alert messages sent by the peer. The function takes a session object, a buffer to store the received data (`data`), the size of that buffer (`data_size`), and a buffer to store the received packet's sequence number (`seq`). The `session` parameter must be a valid `gnutls_session_t` that has been initialized and has undergone the handshake process. The `data` buffer must be a valid, non-NULL pointer with its size specified in `data_size`, which must be greater than zero. The `seq` buffer is used to store the 64-bit sequence number of the received record and thus must be at least 8 bytes long. The callers in the test suite demonstrate that before calling this function, the gnutls library must be initialized with `gnutls_global_init`, a session created with `gnutls_init`, and configured with priorities, credentials, and transport functions before performing the handshake with `gnutls_handshake`.
</description>
<requirements>
<requirement>
The `gnutls_session_t` object must be initialized by calling `gnutls_init()` and a TLS/DTLS handshake must be performed using `gnutls_handshake()` before calling this function. This is because the function expects a session that is either fully established or has failed in a way that allows for receiving alerts.
</requirement>
<requirement>
The `void *data` buffer must not be NULL. The internal logic asserts that for receiving application data, the buffer must be valid.
</requirement>
<requirement>
The `size_t data_size` must be greater than zero. The internal logic asserts this condition to prevent reading into an empty buffer.
</requirement>
<requirement>
The `unsigned char *seq` buffer must be allocated with a size of at least 8 bytes. Callers of this function, such as in `mini-dtls-record.c`, read a 32-bit sequence number from the latter half of this buffer (`seq[4]` to `seq[7]`), implying an expected size of 8 bytes for a 64-bit sequence number.
</requirement>
<requirement>
Call `gnutls_global_init()` once before any other gnutls function. Also, `gnutls_priority_set_direct`, `gnutls_credentials_set`, and transport functions like `gnutls_transport_set_int` must be called to properly configure the session object before the handshake. This ensures the session is in a valid state for communication.
</requirement>
</requirements>

#include <assert.h>
#include <fcntl.h>
#include <stdint.h>
#include <sys/types.h>
#include <unistd.h>
#include <string.h>
#include <stdlib.h>
#include <stdbool.h>

#include <gnutls/gnutls.h>
#include "mem.h"
#include "fuzzer.h"

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
	int res;
	gnutls_session_t session;
	gnutls_certificate_credentials_t xcred;
	struct mem_st memdata;

	res = gnutls_init(&session, GNUTLS_CLIENT);
	assert(res >= 0);

	res = gnutls_certificate_allocate_credentials(&xcred);
	assert(res >= 0);
	res = gnutls_credentials_set(session, GNUTLS_CRD_CERTIFICATE, xcred);
	assert(res >= 0);

	res = gnutls_priority_set_direct(session, "NORMAL", NULL);
	assert(res >= 0);

	memdata.data = data;
	memdata.size = size;

	gnutls_transport_set_push_function(session, mem_push);
	gnutls_transport_set_pull_function(session, mem_pull);
	gnutls_transport_set_pull_timeout_function(session, mem_pull_timeout);
	gnutls_transport_set_ptr(session, &memdata);

	do {
		res = gnutls_handshake(session);
	} while (res < 0 && gnutls_error_is_fatal(res) == 0);

	if (res >= 0) {
		for (;;) {
			char buf[16384];
			unsigned char seq[8];
			res = gnutls_record_recv_seq(session, buf, sizeof(buf), seq);
			if (res <= 0) {
				break;
			}
		}
	}

	gnutls_deinit(session);
	gnutls_certificate_free_credentials(xcred);
	return 0;
}
