
	
<description>
The JS_ParseJSON function parses a JSON string and returns a Javascript value. It is a wrapper around JS_ParseJSON2, which performs the actual parsing. The function takes a JSContext, a C string buffer, the buffer's length, and a filename for error reporting.
</description>
<requirements>

<requirement>
The JS_NewRuntime function must be called to create a JSRuntime. This is because it initializes the Javascript engine and is a prerequisite for creating a JSContext.
</requirement>
<requirement>
The JS_NewContext function must be called to create a JSContext. This is because it provides the execution environment for all Javascript operations, including JSON parsing.
</requirement>
<requirement>
The second argument, 'buf', should be a fuzzed byte array. This is the main input to the function and is expected to contain the JSON data to be parsed.
</requirement>
<requirement>
The third argument, 'buf_len', must be the length of the 'buf' argument. This is to prevent buffer over-reads and other memory-related errors during parsing.
</requirement>
<requirement>
The fourth argument, 'filename', can be a constant, null-terminated string. This is because it is primarily used for error reporting and does not affect the parsing logic itself.
</requirement>
<requirement>
After calling JS_ParseJSON, JS_FreeContext and JS_FreeRuntime must be called. This is to release the resources allocated for the context and runtime, preventing memory leaks.
</requirement>

#include "/src/quickjs/quickjs.h"
#include "quickjs-libc.h"
#include "fuzz/fuzz_common.h"

#include <stdint.h>
#include <string.h>

// Forward declaration of the function under test.
JSValue JS_ParseJSON(JSContext *, const char *, size_t, const char *);

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    if (size == 0 || size > 1024 * 1024) {
        // Ignore empty or very large inputs
        return 0;
    }

    JSRuntime *rt = JS_NewRuntime();
    if (!rt) {
        return 0;
    }
    JSContext *ctx = JS_NewContext(rt);
    if (!ctx) {
        JS_FreeRuntime(rt);
        return 0;
    }

    // Use the common initialization function from fuzz_common.c
    test_one_input_init(rt, ctx);

    // JS_ParseJSON takes a buffer and length, no null termination needed.
    JSValue val = JS_ParseJSON(ctx, (const char *)data, size, "<fuzz>");

    if (!JS_IsException(val)) {
        JS_FreeValue(ctx, val);
    }

    // Cleanup
    js_std_free_handlers(rt);
    JS_FreeContext(ctx);
    JS_FreeRuntime(rt);

    return 0;
}
