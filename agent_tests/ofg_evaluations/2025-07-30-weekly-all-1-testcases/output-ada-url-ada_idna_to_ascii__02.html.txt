
	
<description>
The function `ada_idna_to_ascii` converts a UTF-8 domain name to its ASCII representation using the IDNA standard. It takes a string input and its length, performs the conversion, and returns an `ada_owned_string` containing the ASCII version of the domain name. The returned string must be freed by the caller using `ada_free_owned_string`.
</description>
<requirements>

<requirement>
The `input` argument should be a pointer to a character array, and the `length` argument should be its size. The `input` does not need to be null-terminated, and can be any arbitrary string, as seen from the fuzzing harness `fuzz/idna.cc` which uses a random string from the fuzzer.
</requirement>
<requirement>
The `length` argument must accurately represent the number of bytes in `input`. An incorrect length could lead to out-of-bounds reads.
</requirement>
<requirement>
The caller is responsible for freeing the returned `ada_owned_string` by calling `ada_free_owned_string`. Failure to do so will result in a memory leak, as shown in the test `tests/ada_c.cpp`.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <string>

// The C++ implementation of the library. Including the .cpp file directly is a common
// pattern in this project to simplify the build process. It contains the definitions
// for both the C++ and C APIs.
#include "ada.cpp"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);
  std::string input_str = fdp.ConsumeRemainingBytesAsString();

  // ada_idna_to_ascii is part of the C API, but its implementation is included
  // via ada.cpp.
  ada_owned_string result =
      ada_idna_to_ascii(input_str.c_str(), input_str.length());

  // The returned ada_owned_string contains data that was allocated on the heap
  // and must be freed to avoid memory leaks.
  ada_free_owned_string(result);

  return 0;
}
