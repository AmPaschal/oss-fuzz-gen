
	
<description>
The opus_decode function decodes an Opus packet. It takes an OpusDecoder state, a packet of compressed audio data, and a buffer for the decoded audio. It returns the number of decoded samples per channel on success, or an error code on failure. The function can also perform forward error correction (FEC) if requested.
</description>
<requirements>

<requirement>
The first argument, a pointer to an OpusDecoder struct, must be initialized by calling opus_decoder_create(). This is because opus_decode() relies on the internal state of the OpusDecoder, which is set up by opus_decoder_create().
</requirement>
<requirement>
The third argument, len, should be non-negative. A negative value for len will cause the function to return OPUS_BAD_ARG, as seen in the function's implementation and tests.
</requirement>
<requirement>
The fourth argument, pcm, must be a buffer large enough to hold the decoded audio. The required size is at least frame_size * st->channels * sizeof(opus_int16). The value 5760, defined as MAX_FRAME_SAMP in the test files, is a safe upper bound for frame_size.
</requirement>
<requirement>
The fifth argument, frame_size, must be a positive integer. The function returns OPUS_BAD_ARG if frame_size is less than or equal to zero.
</requirement>
<requirement>
The sixth argument, decode_fec, should be either 0 or 1. This argument controls whether the decoder should perform forward error correction, and is used as a boolean in the implementation.
</requirement>
<requirement>
The second argument, data, which represents the compressed audio packet, can be fuzzed. This is because the function is designed to handle potentially malformed or invalid packets from external sources.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <vector>
#include "/src/opus/include/opus.h"

// MAX_FRAME_SAMP is the maximum frame size used in the opus library tests.
#define MAX_FRAME_SAMP 5760

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  const int sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  const int sample_rate = provider.PickValueInArray(sample_rates);
  const int channels = provider.ConsumeIntegralInRange<int>(1, 2);

  int err;
  OpusDecoder *decoder = opus_decoder_create(sample_rate, channels, &err);
  if (err != OPUS_OK || decoder == nullptr) {
    return 0;
  }

  const int decode_fec = provider.ConsumeBool();

  std::vector<uint8_t> packet_data = provider.ConsumeRemainingBytes<uint8_t>();
  opus_int32 packet_len = static_cast<opus_int32>(packet_data.size());

  std::vector<opus_int16> pcm_out(MAX_FRAME_SAMP * channels);

  opus_decode(decoder, packet_data.data(), packet_len, pcm_out.data(), MAX_FRAME_SAMP, decode_fec);

  opus_decoder_destroy(decoder);

  return 0;
}
