
	
<description>
The `cJSON_Compare` function compares two `cJSON` objects for equality. It handles different types of `cJSON` objects, including numbers, strings, booleans, arrays, and objects. The comparison can be case-sensitive or case-insensitive for strings, as controlled by the `case_sensitive` parameter. The function recursively compares nested objects and arrays. The callers of this function, primarily in the test suite, create `cJSON` objects by parsing JSON strings using `cJSON_Parse`.
</description>
