
	
<description>
The function `hsql::operator<<` is an overloaded operator that writes a textual representation of a `ColumnType` struct to a `std::ostream`. It switches on the `data_type` member of the `ColumnType` struct and prints the corresponding data type name. For `CHAR` and `VARCHAR` data types, it also prints the `length` member.
</description>
<requirements>
<requirement>
The `data_type` member of the `ColumnType` struct should be initialized with one of the values from the `hsql::DataType` enum. This is because the function uses a switch statement on this member, and an invalid value could lead to undefined behavior.
</requirement>
<requirement>
The `length` member of the `ColumnType` struct should be fuzzed. The `length` member is used when `data_type` is `DataType::CHAR` or `DataType::VARCHAR`, and it is directly printed to the output stream, so it is a good candidate for fuzzing.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <sstream>
#include "sql/ColumnType.h"

using namespace hsql;

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // Create a ColumnType object with fuzzed data.
  // ConsumeEnum cannot be used as DataType does not have kMaxValue.
  // Instead, generate an integer in the valid range and cast it.
  DataType type = static_cast<DataType>(provider.ConsumeIntegralInRange(
      0, static_cast<int>(DataType::BOOLEAN)));

  int64_t length = provider.ConsumeIntegral<int64_t>();
  int64_t precision = provider.ConsumeIntegral<int64_t>();
  int64_t scale = provider.ConsumeIntegral<int64_t>();
  ColumnType col_type(type, length, precision, scale);

  // Create a string stream to avoid writing to stdout.
  std::ostringstream stream;

  // Call the function under test.
  stream << col_type;

  return 0;
}
