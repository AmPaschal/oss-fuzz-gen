
	
<description>
The function `cmsCreateProofingTransformTHR` creates a proofing transform. It can create a simple transform using `cmsCreateTransformTHR` or a more complex one using `cmsCreateExtendedTransform` depending on the `dwFlags` argument. The transform is created based on the input, output, and proofing profiles, as well as the specified intents and formats. The function is a thread-safe version of `cmsCreateProofingTransform`.
</description>
<requirements>
<requirement>
The `ContextID` argument should be a valid `cmsContext` created by `cmsCreateContext(NULL, NULL)`. This is because the function uses the context to manage memory and error logging.
</requirement>
<requirement>
The `InputProfile`, `OutputProfile`, and `ProofingProfile` arguments must be valid `cmsHPROFILE` handles. These can be created using functions like `cmsCreate_sRGBProfile()`, `cmsCreateGrayProfile()`, or `cmsCreateLab4Profile(NULL)`.
</requirement>
<requirement>
The `InputFormat` and `OutputFormat` arguments should be valid pixel type formatters. For example, `PT_RGB_8`, `PT_CMYK_8`, etc. from `lcms2.h`. Providing valid formats is crucial for the transform creation to succeed.
</requirement>
<requirement>
The `nIntent` and `ProofingIntent` arguments should be integers between 0 and 3. These correspond to the defined rendering intents like `INTENT_PERCEPTUAL` or `INTENT_RELATIVE_COLORIMETRIC`.
</requirement>
<requirement>
The `dwFlags` argument is a bitmask that controls the transform creation. It should be fuzzed with combinations of `cmsFLAGS_SOFTPROOFING` and `cmsFLAGS_GAMUTCHECK` to test both main branches of the function, and with `cmsFLAGS_BLACKPOINTCOMPENSATION` as it affects the BPC array.
</requirement>
</requirements>

  // We need at least 12 bytes for the integer parameters and some data for
  // two profiles.
  if (size < 32) {
    return 0;
  }

  // Consume integer parameters from the start of the data.
  const uint32_t nIntent = ((const uint32_t *)data)[0] % 16;
  const uint32_t ProofingIntent = ((const uint32_t *)data)[1] % 16;
  const uint32_t dwFlags = ((const uint32_t *)data)[2];
  data += 12;
  size -= 12;

  // Split the remaining data into two parts for the input and proofing
  // profiles.
  const size_t size1 = size / 2;
  const uint8_t *data1 = data;
  const size_t size2 = size - size1;
  const uint8_t *data2 = data + size1;

  cmsHPROFILE hInputProfile = cmsOpenProfileFromMem(data1, size1);
  if (hInputProfile == NULL) {
    return 0;
  }

  cmsHPROFILE hProofingProfile = cmsOpenProfileFromMem(data2, size2);
  if (hProofingProfile == NULL) {
    cmsCloseProfile(hInputProfile);
    return 0;
  }

  cmsHPROFILE hOutputProfile = cmsCreate_sRGBProfile();
  if (hOutputProfile == NULL) {
    cmsCloseProfile(hInputProfile);
    cmsCloseProfile(hProofingProfile);
    return 0;
  }

  // Determine the input format based on the created profile.
  cmsColorSpaceSignature srcCS = cmsGetColorSpace(hInputProfile);
  cmsUInt32Number nSrcComponents = cmsChannelsOf(srcCS);
  cmsUInt32Number InputFormat;
  if (srcCS == cmsSigLabData) {
    InputFormat =
        COLORSPACE_SH(PT_Lab) | CHANNELS_SH(nSrcComponents) | BYTES_SH(0);
  } else {
    InputFormat =
        COLORSPACE_SH(PT_ANY) | CHANNELS_SH(nSrcComponents) | BYTES_SH(1);
  }
  const cmsUInt32Number OutputFormat = TYPE_BGR_8;

  cmsContext ContextID = cmsGetProfileContextID(hInputProfile);

  // Call the function under test.
  cmsHTRANSFORM hTransform = cmsCreateProofingTransformTHR(
      ContextID, hInputProfile, InputFormat, hOutputProfile, OutputFormat,
      hProofingProfile, nIntent, ProofingIntent, dwFlags);

  if (hTransform != NULL) {
    cmsDeleteTransform(hTransform);
  }

  cmsCloseProfile(hInputProfile);
  cmsCloseProfile(hOutputProfile);
  cmsCloseProfile(hProofingProfile);

  return 0;
}
