
	
<description>
The function `Pistache::Http::operator<<` is an overloaded operator that writes a `Cookie` object to an output stream. It does this by calling the `write()` method of the `Cookie` object. The `write()` method serializes the cookie's attributes (name, value, path, domain, expiration, etc.) into the format specified by HTTP cookie standards.
</description>
<requirements>

<requirement>
The `cookie` object should be initialized. The `Cookie` constructor `Cookie(name, value)` can be used for basic initialization with fuzzer-generated strings for name and value.
</requirement>
<requirement>
To achieve high code coverage, all members of the `Cookie` struct should be initialized with fuzzed data. The optional members `path`, `domain`, `maxAge` and `expires` should be initialized, and the `ext` map should be populated.
</requirement>
<requirement>
The `expires` member is of type `std::optional<FullDate>`. The `FullDate` object can be constructed with fuzzer-generated integers for day, year, hour, minute, second, and a month value between 1 and 12, as the `Month` enum is 1-indexed.
</requirement>
