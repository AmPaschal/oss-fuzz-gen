
	
<description>
The `auth_zones_notify` function processes a DNS NOTIFY request. It first finds the corresponding authoritative zone based on the domain name and class in the request. If a matching zone is found, it then checks if the source address of the NOTIFY is in the zone's configured list of allowed notification providers. If the source is allowed, the function proceeds to process the notification, which may involve updating the zone's serial number and initiating a zone transfer. The function returns 1 if the notification is processed and 0 otherwise, and it uses the `refused` parameter to indicate whether the notification was denied due to the source address not being on the allow list.
</description>
