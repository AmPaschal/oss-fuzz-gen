
	
<description>
The nxt_main_process_start function initializes the main process in the NGINX Unit application. It sets the process type, creates a port for the main process, sets the process title, and then starts the discovery process. This function is called by nxt_runtime_initial_start after some initial runtime setup has been performed.
</description>
<requirements>
<requirement>
The 'rt' argument, a pointer to a nxt_runtime_t struct, must be properly initialized. This is because the function accesses and modifies members of this structure, such as setting the 'type' field and passing it to other functions.
</requirement>
<requirement>
The 'task' argument, a pointer to a nxt_task_t struct, must be a valid and initialized. This is because it is used by the helper functions nxt_main_process_port_create, nxt_main_process_title, and nxt_process_init_start.
</requirement>
<requirement>
The 'thr' argument, a pointer to a nxt_thread_t struct, must be valid. This is because the caller, nxt_runtime_initial_start, derives it from the task, and it is passed to nxt_main_process_start, although not directly used in the immediate function body.
</requirement>
<requirement>
The nxt_runtime_pid_file_create function should be called before nxt_main_process_start. This is because nxt_main_process_start relies on the process ID file being created, which is handled by this function.
</requirement>
</requirements>

extern int LLVMFuzzerInitialize(int *argc, char ***argv);

extern char  **environ;


int
LLVMFuzzerInitialize(int *argc, char ***argv)
{
    /*
     * Initialize the Unit library. This sets up the necessary
     * global state, including the main task, thread, and runtime.
     */
    if (nxt_lib_start("fuzzing", NULL, &environ) != NXT_OK) {
        return -1;
    }

    return 0;
}


int
LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    nxt_thread_t   *thr;
    nxt_task_t     *task;
    nxt_runtime_t  *rt;

    /*
     * This fuzzer does not use the input 'data' and 'size' because the
     * target function relies on a pre-initialized global state, not on
     * external input. The primary purpose is to detect crashes during
     * the initialization sequence when run with sanitizers.
     */

    thr = nxt_thread();
    if (thr == NULL) {
        return 0;
    }

    task = thr->task;
    rt = thr->runtime;

    if (task == NULL || rt == NULL) {
        return 0;
    }

    /*
     * Call the target function. This function is part of the process
     * startup and is not designed to be called repeatedly in a loop.
     * The fuzzer environment handles process isolation, so we call it
     * once per run.
     */
    nxt_main_process_start(thr, task, rt);

    return 0;
}
