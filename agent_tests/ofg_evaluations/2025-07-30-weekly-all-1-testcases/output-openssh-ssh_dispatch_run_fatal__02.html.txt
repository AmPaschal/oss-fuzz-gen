
	
<description>
The function `ssh_dispatch_run_fatal` is a wrapper around `ssh_dispatch_run`. It runs a dispatch loop that processes incoming SSH packets. The `mode` parameter determines whether the loop is blocking (`DISPATCH_BLOCK`) or non-blocking (`DISPATCH_NONBLOCK`). The `done` parameter is a pointer to a flag that can be used to terminate the loop externally. If `ssh_dispatch_run` returns an error, this function calls `sshpkt_fatal` to terminate the connection.
</description>
<requirements>
<requirement>
The `ssh` parameter must be a valid pointer to a `struct ssh` initialized by `ssh_init`. A valid `ssh` structure is necessary for the function to access connection-specific data.
</requirement>
<requirement>
The `mode` parameter must be either `DISPATCH_BLOCK` (0) or `DISPATCH_NONBLOCK` (1). This parameter controls the blocking behavior of the packet reading loop within `ssh_dispatch_run`.
</requirement>
<requirement>
The `done` parameter can be `NULL`. If it is not `NULL`, it must point to a valid `sig_atomic_t` variable that is used to signal termination of the dispatch loop.
</requirement>
<requirement>
Before calling this function, `ssh_dispatch_init` must be called to initialize the dispatch table. Failure to initialize the dispatch table will lead to a `NULL` pointer dereference.
</requirement>
</requirements>

#include <signal.h>
#include <stddef.h>

extern "C" {
#include "includes.h"
#include "ssh_api.h"
#include "ssherr.h"
#include "dispatch.h"
#include "packet.h"

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider provider(data, size);

    struct ssh *ssh = NULL;
    int r;

    // Forcing client mode because server headers/objects are not available
    // in this fuzzer's build context.
    int is_server = 0;

    // Initialize ssh structure. Passing NULL for kex_params uses defaults.
    r = ssh_init(&ssh, is_server, NULL);
    if (r != 0) {
        if (ssh != NULL)
            ssh_free(ssh);
        return 0;
    }

    // Initialize dispatch table with no specific handlers.
    // The second argument is a fallback handler for unassigned messages.
    // This will cause the dispatch loop to fatal on any received packet.
    ssh_dispatch_init(ssh, NULL);

    // The dispatch loop needs data to process.
    if (ssh_input_append(ssh, data, size) != 0) {
        ssh_free(ssh);
        return 0;
    }

    // Prepare parameters for the function under test
    int mode = provider.ConsumeIntegralInRange(0, 1); // Mode can be LOOP or NONBLOCK
    volatile sig_atomic_t done = 0;

    // The function under test is fatal and may not return.
    // The fuzzer infrastructure will catch any crash or exit.
    ssh_dispatch_run_fatal(ssh, mode, &done);

    // This part will likely not be reached if the function aborts,
    // but it's good practice for cleanup in case of non-fatal paths.
    ssh_free(ssh);

    return 0;
}

} // extern "C"
