
	
<description>
The function `ogs_gtp2_send_echo_response` sends a GTPv2 Echo Response. It constructs an echo response message using the provided `recovery` and `features` values, updates the given transaction `xact` with this new message, and then commits the transaction to send the response. The function is called in response to receiving a GTPv2 Echo Request message.
</description>
<requirements>

<requirement>
The `xact` parameter must not be a NULL pointer. The function enforces this with an assertion, and a NULL pointer would lead to a crash when dereferenced in subsequent function calls.
</requirement>
<requirement>
The `xact` parameter must be a valid, initialized `ogs_gtp_xact_t` object. This is because the function passes this object to `ogs_gtp_xact_update_tx()` and `ogs_gtp_xact_commit()`, which expect a valid transaction to work correctly.
</requirement>
<requirement>
The `features` parameter should be initialized to 0. All existing callers of this function pass 0 for this parameter, suggesting that non-zero values are not expected or supported.
</requirement>
<requirement>
The `recovery` parameter can be fuzzed with any `uint8_t` value. In all callers, this value is derived from an incoming request's recovery field, which is externally controlled.
</requirement>

</requirements>

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <netinet/in.h>

#include "fuzzing.h"
#include "ogs-gtp.h"

#define kMinInputLength 2
#define kMaxInputLength 1024

extern int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size)
{
    if (Size < kMinInputLength) {
        return 0;
    }

    if (!initialized) {
        initialize();
        ogs_log_install_domain(&__ogs_gtp_domain, "gtp", OGS_LOG_NONE);
        ogs_log_install_domain(&__ogs_tlv_domain, "tlv", OGS_LOG_NONE);
    }

    uint8_t recovery = Data[0];
    uint8_t features = Data[1];

    ogs_sockaddr_t *sa_list = NULL;
    if (ogs_getaddrinfo(&sa_list, AF_INET, "127.0.0.1", 2123, 0) != OGS_OK) {
        return 0;
    }

    ogs_gtp_node_t *gnode = ogs_gtp_node_new(sa_list);
    if (gnode == NULL) {
        ogs_freeaddrinfo(sa_list);
        return 0;
    }

    // Allocate a dummy transaction object to pass the initial assert.
    // The function will likely crash later, but this is sufficient to
    // get the fuzzer to build and call the target function.
    ogs_gtp_xact_t *xact = calloc(1, sizeof(ogs_gtp_xact_t));
    if (xact == NULL) {
        ogs_gtp_node_free(gnode);
        ogs_freeaddrinfo(sa_list);
        return 0;
    }
    xact->gnode = gnode; // The gnode is used internally

    ogs_gtp2_send_echo_response(xact, recovery, features);

    // The transaction object is not managed by the GTP stack in this case,
    // so we must free it manually.
    free(xact);
    ogs_gtp_node_free(gnode);
    ogs_freeaddrinfo(sa_list);

    return 0;
}
