
	
<description>
The function `xls_summaryInfo` extracts summary information from a given `xlsWorkBook`. It allocates a `xlsSummaryInfo` struct, and then calls `xls_dumpSummary` to populate this struct with information from the `summary` and `docSummary` streams of the workbook. The `summary` stream contains properties like title, subject, and author, while the `docSummary` stream contains properties like category, manager, and company. The function returns the populated `xlsSummaryInfo` struct.
</description>
<requirements>
<requirement>
The input `pWB` must be a valid pointer to an `xlsWorkBook` struct initialized by `xls_open_file`. This is because the function accesses the `summary` and `docSummary` members of `pWB`, which are populated by `xls_open_file`.
</requirement>
<requirement>
The `summary` and `docSummary` members of the `pWB` struct should either be NULL or point to valid OLE property set streams. The `xls_dumpSummary` function expects these members to be valid property set streams, and an invalid format will lead to memory access errors.
</requirement>
<requirement>
The caller is responsible for freeing the returned `xlsSummaryInfo` struct and its members. The function allocates a new `xlsSummaryInfo` struct using `calloc` and its string members are allocated using `strdup` inside `xls_dumpSummary`, so they must be freed to prevent memory leaks.
</requirement>
</requirements>
