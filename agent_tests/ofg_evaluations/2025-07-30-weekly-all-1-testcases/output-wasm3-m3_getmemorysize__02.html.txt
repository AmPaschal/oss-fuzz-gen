
	
<description>
The `m3_GetMemorySize` function returns the size of the memory allocated for a given wasm3 runtime. It takes a pointer to an `M3Runtime` struct as input, and returns the `length` field from the `mallocated` member of the `memory` structure. This function is used by the `m3ApiCheckMem` macro to perform bounds checking on memory accesses.
</description>
<requirements>

<requirement>
The i_runtime parameter must be a valid pointer to an M3Runtime struct. This is because the function dereferences this pointer to access its members, and a NULL or invalid pointer will cause a crash.
</requirement>
<requirement>
The i_runtime struct should be initialized by calling `m3_NewRuntime`. This is because `m3_NewRuntime` allocates and initializes the M3Runtime struct and its components, which `m3_GetMemorySize` depends on.
</requirement>
<requirement>
A wasm module must be loaded into the runtime before calling `m3_GetMemorySize`. Loading a module with `m3_LoadModule` will allocate the memory that `m3_GetMemorySize` inspects. Without a loaded module, `i_runtime->memory.mallocated` will be NULL, causing a crash.
</requirement>
<requirement>
The `i_runtime->memory.mallocated` pointer must not be NULL. The function directly dereferences this pointer to get the memory size, so a NULL pointer will lead to a crash. This pointer is initialized when a module is loaded and memory is allocated for it.
</requirement>

</requirements>
