
	
<description>
The `ogs_nas_esm_decode` function parses a raw NAS (Non-Access Stratum) ESM (EPS Session Management) message from a packet buffer (`ogs_pkbuf_t`). It first decodes the ESM header to identify the message type, then calls a message-specific decoder function to parse the rest of the packet. The results of the decoding are stored in the `ogs_nas_eps_message_t` struct provided by the caller. The primary caller in `mme-sm.c` uses this function to decode incoming ESM messages from network events.
</description>
<requirements>

<requirement>
The `pkbuf` argument must not be a NULL pointer, and its `data` member must also not be NULL. The function asserts these conditions at the beginning to prevent null pointer dereferences.
</requirement>
<requirement>
The `pkbuf->len` must be greater than or equal to the size of `ogs_nas_esm_header_t`. This is necessary for the initial header decoding to succeed without causing an error.
</requirement>
<requirement>
The `pkbuf->data` buffer should be populated with fuzzed data. This data represents a raw network packet and is the main source of input for the function to test various decoding scenarios.
</requirement>
<requirement>
The `message_type` field in the header portion of the `pkbuf->data` should be fuzzed with a range of values. This is crucial for exercising the different parsing paths within the `switch` statement in the function.
</requirement>
<requirement>
The `message` parameter must be a valid pointer to a `ogs_nas_eps_message_t` structure. The function uses this as an output parameter to write the decoded message into.
</requirement>

</requirements>

#include <stdio.h>
#include <stdint.h>

#include "fuzzing.h"
#include "ogs-nas-eps.h"

#define kMinInputLength 5
#define kMaxInputLength 1024

extern int LLVMFuzzerTestOneInput(const uint8_t *Data, size_t Size)
{
    if (Size < kMinInputLength || Size > kMaxInputLength) {
        return 1;
    }

    if (!initialized) {
        initialize();
        ogs_log_install_domain(&__ogs_nas_domain, "nas", OGS_LOG_NONE);
    }

    ogs_pkbuf_t *pkbuf;
    pkbuf = ogs_pkbuf_alloc(NULL, OGS_MAX_SDU_LEN);

    if (pkbuf == NULL) {
        return 1;
    }
    ogs_pkbuf_put_data(pkbuf, Data, Size);

    ogs_nas_eps_message_t message;
    ogs_nas_esm_decode(&message, pkbuf);

    ogs_pkbuf_free(pkbuf);

    return 0;
}
