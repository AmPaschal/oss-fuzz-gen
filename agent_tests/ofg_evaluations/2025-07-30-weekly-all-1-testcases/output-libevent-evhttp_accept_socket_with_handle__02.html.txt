
	
<description>
The function `evhttp_accept_socket_with_handle` is an internal helper function that is used to create a new `evconnlistener` for a given socket and associate it with an `evhttp` object. The function is called by `evhttp_bind_socket_with_handle` and `evhttp_accept_socket`. The first argument, `http`, is a pointer to an `evhttp` structure, which is created by `evhttp_new`. The second argument, `fd`, is a socket file descriptor that has already been bound to a port and is in a listening state. The function returns a pointer to a `evhttp_bound_socket` structure on success, or `NULL` on failure.
</description>
<requirements>

<requirement>
The first argument, `http`, must be a valid pointer to a `struct evhttp` that has been initialized by `evhttp_new()`. This is because the function accesses the `base` member of the `http` structure, which is initialized in `evhttp_new()`.
</requirement>
<requirement>
The second argument, `fd`, must be a valid, non-blocking, and listening socket file descriptor. This is because `evconnlistener_new()`, which is called by the target function, expects a listening socket, and the caller `evhttp_bind_socket_with_handle()` calls `listen()` on the socket before calling the target function.
</requirement>
<requirement>
The `bind_socket()` function can be used to create and bind the socket before calling the target function. This is how the file descriptor is created in the caller `evhttp_bind_socket_with_handle()`.
</requirement>
<requirement>
The `listen()` function must be called on the socket before calling the target function. The caller `evhttp_bind_socket_with_handle()` calls `listen()` with a backlog of 128.
</requirement>

</requirements>

#include <stddef.h>
#include <stdint.h>

#include <fuzzer/FuzzedDataProvider.h>

#include "libevent/include/event2/event.h"
#include "/src/libevent/include/event2/http.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider data_provider(data, size);

  struct event_base *base = event_base_new();
  if (!base) {
    return 0;
  }

  struct evhttp *http = evhttp_new(base);
  if (!http) {
    event_base_free(base);
    return 0;
  }

  int fd = data_provider.ConsumeIntegral<int>();

  struct evhttp_bound_socket *bound_socket =
      evhttp_accept_socket_with_handle(http, fd);

  if (bound_socket) {
    evhttp_del_accept_socket(http, bound_socket);
  }

  evhttp_free(http);
  event_base_free(base);

  return 0;
}
