
	
<description>
The `hoedown_html_toc_renderer_new` function creates a renderer specifically for generating a Table of Contents (TOC). It allocates and initializes a `hoedown_renderer` structure and its associated state (`hoedown_html_renderer_state`). The renderer is configured with a set of predefined callback functions (e.g., `toc_header`, `toc_link`) that handle the logic for building the TOC from parsed headers. The single integer argument, `nesting_level`, determines the maximum depth of headers to include in the TOC. This value is stored in the renderer's state and is later used by the `toc_header` callback to decide whether a given header should be part of the TOC. Analysis of the main caller shows that a `nesting_level` of 0 is treated as a special case to disable TOC generation, so for the TOC to be generated, this value should be greater than 0.
</description>
<requirements>
<requirement>
The `nesting_level` argument should be a non-negative integer. This is because this value is used to control the depth of the Table of Contents, and a negative value would have unintended consequences in the `toc_header` callback logic.
</requirement>
<requirement>
For the function to have a meaningful effect and generate a Table of Contents, the `nesting_level` argument should be greater than 0. The primary caller only proceeds with full TOC state initialization if the level is positive, and the documentation indicates a value of zero disables the TOC.
</requirement>
