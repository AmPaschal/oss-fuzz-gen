
	
<description>
The function `LLVMFuzzerInitialize` is a weak symbol that is called by the fuzzer runtime before fuzzing starts. The project provides two implementations of this function, one for each fuzz target.
The implementation in `fuzz_command_parser.c` is simple and only calls `RTPPInitialize()`.
The implementation in `fuzz_rtp_session.c` is more complex. It initializes a global parameter `RTPPInitializeParams.ttl`, calls `RTPPInitialize()`, initializes a semaphore, executes a setup script and registers a cleanup function with `atexit`.
The arguments `_argc` and `_argv` are not used in either implementation.

The main purpose of `LLVMFuzzerInitialize` is to initialize the rtpproxy library for fuzzing by calling `RTPPInitialize()`. Depending on the fuzzing target, additional setup might be needed.
</description>
<requirements>
<requirement>
The `_argc` and `_argv` arguments can be NULL. This is because they are not used in any of the provided implementations of `LLVMFuzzerInitialize`.
</requirement>
<requirement>
The `RTPPInitialize()` function must be called within `LLVMFuzzerInitialize`. This function initializes the rtpproxy library, which is essential for the fuzzer to work correctly.
</requirement>
<requirement>
The `RTPPInitializeParams.ttl` global variable can be set before calling `RTPPInitialize()`. In `fuzz_rtp_session.c`, it is set to "60" to configure the TTL value used by the library.
</requirement>
<requirement>
For fuzzing `rtp_session`, a semaphore must be initialized using `sem_init()`. The `fuzz_rtp_session` target uses a semaphore to synchronize between the main thread and worker threads.
</requirement>
<requirement>
For fuzzing `rtp_session`, a setup script is executed via `ExecuteScript()`. This script, defined in `fuzz_rtp_session.setup`, sets up the initial state for the fuzzing session.
</requirement>
</requirements>

int
LLVMFuzzerInitialize(int *argc, char ***argv)
{
    (void)argc;
    (void)argv;
    log = rtpp_log_ctor("rtpproxy", NULL, LF_REOPEN);
    assert(log != NULL);
    rap = rtpp_analyzer_ctor(log);
    assert(rap != NULL);
    return (0);
}

int
LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    struct rtp_packet *pktp;

    if (size > MAX_RPKT_LEN)
        return (0);

    pktp = rtp_packet_alloc();
    assert(pktp != NULL);
    pktp->size = size;
    memcpy(pktp->data.buf, data, size);

    CALL_SMETHOD(rap, update, pktp);
    RTPP_OBJ_DECREF(pktp);
    return (0);
}
