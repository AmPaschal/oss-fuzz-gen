
	
<description>
The function `sraw_midpoint` returns a midpoint value that is specific to the type of RAW file loaded. The return value is determined by checking the `load_raw` function pointer, which is a member of the `LibRaw` class. This function pointer is set during the raw file opening process, typically by the `open_file` method, which identifies the file type and assigns the corresponding raw loading function to `load_raw`. The `sraw_midpoint` function returns 8192 for Canon and Sony sRAW files, 2048 for Nikon sRAW files, and 0 for all other file types.
</description>
<requirements>

<requirement>
The `LibRaw::open_file()` method must be called before calling `sraw_midpoint`. This is because `open_file()` is responsible for identifying the raw file type and setting the `load_raw` function pointer, which `sraw_midpoint` uses to determine the correct midpoint value.
</requirement>
<requirement>
The `load_raw` member of the `LibRaw` class must be initialized to one of the following values: `&LibRaw::canon_sraw_load_raw`, `&LibRaw::sony_ycbcr_load_raw`, or `&LibRaw::nikon_load_sraw`. The `sraw_midpoint` function will return 0 if `load_raw` is not one of these values, which may not be the desired behavior.
</requirement>

</requirements>
