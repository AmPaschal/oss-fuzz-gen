
	
<description>
The `SafeUint32Mult` function safely multiplies up to four `uint32_t` integers. It checks for potential arithmetic overflow before performing the multiplication. If the multiplication would result in an overflow, the function returns `false`. Otherwise, it performs the multiplication, stores the result in the memory location pointed to by the `result` parameter, and returns `true`. The function is implemented by chaining calls to overloaded versions of `SafeUint32Mult`, with the core overflow check happening in the `SafeUnsignedMult` template function. A `dng_exception` is thrown on overflow, which is caught by the target function, leading to a `false` return value.
</description>
<requirements>
<requirement>
The `result` pointer must not be null. The function dereferences this pointer to store the result, and a null pointer would cause a crash.
</requirement>

The input integer arguments `arg1`, `arg2`, `arg3`, and `arg4` should be fuzzed. These inputs are used in a multiplication operation and their values determine whether an overflow will occur, so fuzzing is essential for testing the overflow detection logic.
</requirement>
