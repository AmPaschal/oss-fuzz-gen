
	
<description>
The `buffer_append_strftime` function formats a timestamp according to a given format string and appends the result to a buffer. The format string can be either a fixed string literal or a user-configurable string, for instance in `mod_ssi` and `mod_accesslog`. The `tm` struct is always initialized using `localtime64_r` or `gmtime64_r`, ensuring it is valid before being passed to `strftime`. The function handles `NULL` `tm` structs by returning early. The function makes an initial attempt to append the formatted time with a 64-byte buffer, and if that fails, it retries with a larger 4096-byte buffer.
</description>
