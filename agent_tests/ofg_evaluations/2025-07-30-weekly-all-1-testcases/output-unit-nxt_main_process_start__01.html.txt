
	
<description>
The `nxt_main_process_start` function initializes the main process of the Unit application. It sets the process type, creates a communication port for the main process, sets the process title, and starts the discovery process. It is called by `nxt_runtime_initial_start` during the application startup sequence.
</description>
<requirements>
<requirement>
The `task` argument must be a valid pointer to a fully initialized `nxt_task_t` structure. This is because it is passed to multiple sub-functions that rely on its fields to be correctly set up.
</requirement>
<requirement>
The `task->thread` field must point to a valid and initialized `nxt_thread_t` structure. This is because the `thread` is used to access the `runtime` environment of the application.
</requirement>
<requirement>
The `thr->runtime` field must point to a valid and initialized `nxt_runtime_t` structure. This is because the runtime object is modified and used to create the main process port.
</requirement>
<requirement>
The `rt->processes` list in the runtime structure must contain a process corresponding to the current process ID (`nxt_pid`). This is because the `nxt_main_process_port_create` function attempts to retrieve and use this process.
</requirement>
<requirement>
The global variable `nxt_process_argv` must be a `NULL`-terminated array of strings, typically representing the command-line arguments of the program. This is because `nxt_main_process_title` iterates through this array to construct the process title.
</requirement>
</requirements>

#include <nxt_main.h>
#include <nxt_runtime.h>
#include "/src/unit/src/nxt_main_process.h"

extern int LLVMFuzzerInitialize(int *argc, char ***argv);
extern int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size);

extern char       **environ;
extern nxt_task_t    nxt_main_task;


int
LLVMFuzzerInitialize(int *argc, char ***argv)
{
    if (nxt_lib_start("fuzzing", NULL, &environ) != NXT_OK) {
        return -1;
    }

    return 0;
}


int
LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    nxt_thread_t   *thr;
    nxt_runtime_t  *rt;

    /*
     * The fuzzer input is not used to drive the logic. Instead, this fuzzer
     * repeatedly executes the complex initialization sequence to find bugs.
     */

    if (nxt_runtime_create(&nxt_main_task) != NXT_OK) {
        /* nxt_runtime_create cleans up after itself on failure. */
        return 0;
    }

    thr = nxt_main_task.thread;
    rt = thr->runtime;

    if (rt == NULL) {
        /* This should not be reached if nxt_runtime_create() succeeded. */
        return 0;
    }

    /* Call the function under test. */
    nxt_main_process_start(thr, &nxt_main_task, rt);

    /*
     * The function being tested may not return (e.g., if it calls exit()).
     * If it does, we must clean up the resources allocated by
     * nxt_runtime_create() to avoid leaks in subsequent fuzzing iterations.
     * The runtime object holds the memory pool for all its allocations.
     */
    if (thr->runtime != NULL) {
        rt = thr->runtime;
        nxt_mp_destroy(rt->mem_pool);
        /* Avoid use-after-free in the next iteration. */
        thr->runtime = NULL;
    }

    return 0;
}
