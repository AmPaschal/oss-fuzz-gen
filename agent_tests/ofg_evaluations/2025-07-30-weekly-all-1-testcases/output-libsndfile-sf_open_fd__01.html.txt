
	
<description>
The sf_open_fd function opens a sound file using a file descriptor instead of a path. It takes an integer file descriptor `fd`, a mode (`SFM_READ`, `SFM_WRITE`, or `SFM_RDWR`), a pointer to an `SF_INFO` struct which contains information about the file to be opened, and a boolean `close_desc` which if true will cause the file descriptor to be closed when the sound file is closed. It returns a pointer to a `SNDFILE` struct on success and NULL on failure.
</description>
<requirements>

<requirement>
The `fd` argument must be a valid file descriptor. This is because the function may pass this file descriptor to `close()` which will cause a crash if it is invalid.
</requirement>
<requirement>
The `mode` argument must be one of `SFM_READ`, `SFM_WRITE`, or `SFM_RDWR`. This is because the function uses this argument to determine how to open the file, and other values are not supported.
</requirement>
<requirement>
The `sfinfo` argument must be a valid pointer to an `SF_INFO` struct. This is because the function dereferences this pointer to access its members, and a NULL pointer will cause a crash.
</requirement>
<requirement>
The `format` member of the `SF_INFO` struct must not be `SF_FORMAT_SD2`. This is because the function has a specific check to disallow this format.
</requirement>
<requirement>
The `samplerate` and `channels` members of the `SF_INFO` struct must be greater than zero. This is to avoid errors in the callee function `psf_open_file`.
</requirement>
<requirement>
The `close_desc` argument should be either `SF_TRUE` or `SF_FALSE`. This argument is a boolean that determines if `close(fd)` is called when the `SNDFILE` handle is closed or an error occurs.
</requirement>

</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // We need some data for parameters and some for file content.
  if (provider.remaining_bytes() < 32) {
    return 0;
  }

  SF_INFO sfinfo;
  memset(&sfinfo, 0, sizeof(sfinfo));

  // Fill SF_INFO with fuzzed data.
  sfinfo.samplerate = provider.ConsumeIntegral<int>();
  sfinfo.channels = provider.ConsumeIntegralInRange<int>(1, 4);
  sfinfo.format = provider.ConsumeIntegral<int>();

  // Fuzz the mode and close_desc parameters.
  const int mode = provider.PickValueInArray({SFM_READ, SFM_WRITE, SFM_RDWR});
  const int close_desc = provider.ConsumeBool();

  // Create an in-memory file descriptor.
  const int fd = memfd_create("fuzz_file", 0);
  if (fd == -1) {
    return 0;
  }

  // Write the remaining fuzzed data to the in-memory file.
  std::vector<uint8_t> file_content =
      provider.ConsumeRemainingBytes<uint8_t>();
  if (!file_content.empty()) {
    write(fd, file_content.data(), file_content.size());
    lseek(fd, 0, SEEK_SET);
  }

  // Call the target function.
  SNDFILE *sndfile = sf_open_fd(fd, mode, &sfinfo, close_desc);

  if (sndfile) {
    sf_close(sndfile);
  }

  // If close_desc is false, we are responsible for closing the fd.
  // If close_desc is true, sf_open_fd (on failure) or sf_close (on success)
  // is responsible for closing the fd.
  if (!close_desc) {
    close(fd);
  }

  return 0;
}
