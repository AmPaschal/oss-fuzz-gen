
	
<description>
The `tidySaveString` function saves the contents of a `TidyDoc` document to a specified buffer. It acts as a wrapper around the `tidyDocSaveString` function, which performs the actual saving operation. The `tidyDocToImpl` macro is used to convert the `TidyDoc` handle to its underlying implementation structure, `TidyDocImpl`. The function allocates a temporary buffer, saves the document into it, and then copies the content to the user-provided buffer if it's large enough.
</description>
<requirements>

<requirement>
The `tdoc` argument must be a valid `TidyDoc` object. This can be created by calling the `tidyCreate()` function, which initializes the necessary internal structures and memory allocators.
</requirement>
<requirement>
The `buffer` argument must be a non-null pointer to a writable memory region. This is because the function will write the saved document content into this buffer using `memcpy`.
</requirement>
<requirement>
The `buflen` argument must be a non-null pointer to a `uint` variable. The function reads the initial size of the buffer from this variable and writes the final size of the saved string back to it.
</requirement>
<requirement>
The value pointed to by `buflen` should be large enough to accommodate the saved document. If the buffer is too small, the function will return an error and not copy the data, so a sufficiently large buffer is needed to test the success path.
</requirement>
