
	
<description>
The function `SafeUint32Mult` safely multiplies three 32-bit unsigned integers (`arg1`, `arg2`, `arg3`) and stores the result in the location pointed to by `result`. It is designed to prevent integer overflows. The function achieves this by calling a series of internal helper functions that perform overflow checks before executing the multiplication. If the product of the three arguments would exceed the maximum value of a `uint32_t`, an internal `dng_exception` is thrown, which is caught by the target function. In this overflow case, the function returns `false`. If the multiplication is successful without any overflow, the calculated value is placed into `*result`, and the function returns `true`.
</description>
<requirements>
<requirement>
The `result` parameter must be a valid, non-null pointer to a `uint32_t` variable. The function dereferences this pointer to store the outcome of the multiplication, and providing a null pointer will lead to a crash.
</requirement>
<requirement>
The input arguments `arg1`, `arg2`, and `arg3` can be fuzzed with arbitrary `uint32_t` values. This is because the function is specifically designed to handle potential overflow conditions, and fuzzing with a wide range of inputs will effectively test both its success and failure paths.
</requirement>
