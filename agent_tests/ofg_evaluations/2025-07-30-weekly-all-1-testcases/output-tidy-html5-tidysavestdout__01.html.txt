
	
<description>
The `tidySaveStdout` function saves the parsed and cleaned-up HTML document to the standard output. It acts as a wrapper for the internal `tidyDocSaveStdout` function, which handles the actual serialization of the document. The function requires a valid `TidyDoc` object that has been previously created and has been used to parse a document.
</description>
<requirements>
<requirement>
The `TidyDoc` argument `tdoc` must be created by calling `tidyCreate()`. This is to ensure that the internal document structure is correctly initialized.
</requirement>
<requirement>
A document must be parsed into the `TidyDoc` object before calling `tidySaveStdout`. This can be achieved by using functions like `tidyParseString`, `tidyParseFile`, or `tidyParseBuffer`, as the function needs a document to save.
</requirement>
<requirement>
Configuration options on the `TidyDoc` should be set before saving. The `tidyDocSaveStdout` function uses configuration values such as `TidyOutCharEncoding` and `TidyNewline` from the `TidyDoc` object.
</requirement>
<requirement>
The `TidyDoc` object must be released after use by calling `tidyRelease(tdoc)`. This is crucial to prevent memory leaks as `tidySaveStdout` does not free the `TidyDoc` object itself.
</requirement>
</requirements>
