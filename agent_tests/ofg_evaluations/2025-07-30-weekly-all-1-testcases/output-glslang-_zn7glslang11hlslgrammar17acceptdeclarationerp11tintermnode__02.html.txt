
	
<description>
The function `acceptDeclaration` is a core component of the HLSL parser in `glslang`. It is responsible for parsing a single declaration from a stream of HLSL tokens and translating it into an Abstract Syntax Tree (AST) node. The function handles a wide variety of HLSL declarations, such as namespaces, variables (including complex types, arrays, and initializers), functions (both prototypes and full definitions), constant buffers (`cbuffer`), and typedefs. It relies heavily on the state maintained within the `HlslGrammar` and its associated `HlslParseContext` object, which includes the token stream, symbol table, and the intermediate AST representation. The parsed AST nodes are returned through the `nodeList` output parameter. The function's return value indicates whether a declaration was successfully parsed.
</description>

The `HlslParseContext` member of the `HlslGrammar` object must be properly initialized. This context contains the symbol table and the intermediate representation builder, which are essential for tracking declared symbols and constructing the AST.

The token stream within the `HlslGrammar` object must be initialized with a valid HLSL source string. The function's primary role is to consume tokens from this stream to parse declarations.
</requirement>

</requirement>
<requirement>
The `nodeList` parameter can be `nullptr` upon calling the function. The function is designed to either create a new AST node if `nodeList` is null or append to the existing node if it's not.
</requirement>
<requirement>
The `annotationNestingLevel` in the `HlslParseContext` should be 0 when parsing typical declarations. The function has a specific check to avoid declaring variables or types when inside an annotation block.
</requirement>

// 1. Include headers that provide full definitions for core types first.
#include "glslang/Include/InfoSink.h"
#include "glslang/Include/intermediate.h"
#include "glslang/MachineIndependent/SymbolTable.h"

// 2. Include other necessary headers.
#include "glslang/Public/ShaderLang.h"
#include "glslang/Public/ResourceLimits.h"
#include "glslang/HLSL/hlslGrammar.h"
#include "glslang/HLSL/hlslParseHelper.h"
#include "glslang/HLSL/hlslScanContext.h"
#include "glslang/MachineIndependent/preprocessor/PpContext.h"
#include "glslang/MachineIndependent/Scan.h"
#include "glslang/MachineIndependent/ParseHelper.h"


extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    glslang::InitializeProcess();

    // Basic setup required for parsing
    EShLanguage language = EShLangVertex;
    int version = 450;
    EProfile profile = ECoreProfile;
    EShMessages messages = EShMsgDefault;

    // TInfoSink is in the global namespace
    TInfoSink infoSink;
    glslang::TIntermediate intermediate(language, version, profile);
    glslang::TSymbolTable symbolTable;
    glslang::SpvVersion spvVersion;

    // The HLSL parser requires a specific set of contexts.
    glslang::HlslParseContext parseContext(symbolTable, intermediate, false, version, profile,
                                           spvVersion, language, infoSink, "main", false, messages);

    glslang::TShader::ForbidIncluder includer;
    glslang::TPpContext ppContext(parseContext, "", includer);
    glslang::HlslScanContext scanContext(parseContext, ppContext);
    parseContext.setPpContext(&ppContext);

    // Feed the fuzzer input to the scanner.
    const char* shaderStrings[] = {reinterpret_cast<const char*>(data)};
    size_t shaderLengths[] = {size};
    glslang::TInputScanner inputScanner(1, shaderStrings, shaderLengths);
    ppContext.setInput(inputScanner, false);

    // Create the grammar object.
    glslang::HlslGrammar grammar(scanContext, parseContext);

    // Call the public parse() method, which will in turn call the
    // protected acceptDeclaration function.
    grammar.parse();

    glslang::FinalizeProcess();
    return 0;
}
