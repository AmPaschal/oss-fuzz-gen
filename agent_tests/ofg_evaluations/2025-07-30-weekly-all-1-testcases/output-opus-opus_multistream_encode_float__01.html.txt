
	
<description>
The function `opus_multistream_encode_float` encodes a multistream Opus frame from floating-point input. It is a wrapper around the `opus_multistream_encode_native` function. It takes an initialized OpusMSEncoder state, a buffer of PCM audio data, the frame size, an output buffer for the encoded data, and the maximum size of the output buffer. The encoder must be created using `opus_multistream_encoder_create` or `opus_multistream_surround_encoder_create` and configured using `opus_multistream_encoder_ctl`. The function returns the number of bytes written to the output buffer, or a negative error code on failure.
</description>
<requirements>
<requirement>The `st` argument, a pointer to an `OpusMSEncoder` struct, must be initialized by `opus_multistream_encoder_create` or `opus_multistream_surround_encoder_create`. A value of at least `st->layout.nb_streams*2-1` is required to avoid a `OPUS_BUFFER_TOO_SMALL` error.</requirement><requirement>The `pcm` argument must be a valid pointer to a float array of size `frame_size * st->layout.nb_channels`. This is because the function reads this amount of data from the `pcm` buffer.</requirement>
</requirements>

  int err = OPUS_OK;
  OpusMSEncoder *enc = opus_multistream_encoder_create(frequency, nb_channels, streams, coupled_streams, mapping.data(), application, &err);

    return 0;

  unsigned char out_buffer[MAX_PACKET_BYTES];

  return 0;
