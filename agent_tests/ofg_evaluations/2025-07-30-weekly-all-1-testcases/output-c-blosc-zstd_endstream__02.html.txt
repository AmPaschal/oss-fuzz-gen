
	
<description>
The ZSTD_endStream function is the final step in a Zstandard streaming compression operation. It is responsible for flushing any remaining data from the internal buffers, writing the end-of-frame marker, and finalizing the compressed stream. It takes a ZSTD_CStream object, which holds the context and state of the compression, and a ZSTD_outBuffer object, which specifies the destination for the last piece of compressed data. The function is called after the stream has been created with `ZSTD_createCStream`, initialized with `ZSTD_initCStream` (or a similar function), and used for compression with `ZSTD_compressStream2`.
</description>

</requirement>
<requirement>
The `output` argument must be a valid pointer to a `ZSTD_outBuffer` struct, with its `dst` member pointing to a valid, writable memory buffer. This is necessary because the function will write the final compressed data to this location.
</requirement>
<requirement>
The `pos` member of the `ZSTD_outBuffer` struct pointed to by `output` should be initialized to 0, and the `size` member must reflect the actual allocated size of the `dst` buffer. This ensures that the function has a correct understanding of the available space in the output buffer, preventing buffer overflows.
</requirement>
<requirement>
Prior to calling `ZSTD_endStream`, the `zcs` stream should have been used in at least one call to `ZSTD_compressStream2` with the `ZSTD_e_continue` or `ZSTD_e_flush` operation. This ensures the stream is in a valid state for being ended.
</requirement>
