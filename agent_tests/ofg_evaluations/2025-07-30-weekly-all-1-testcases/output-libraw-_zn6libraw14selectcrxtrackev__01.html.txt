
	
<description>
The function `LibRaw::selectCRXTrack()` is a private member function of the `LibRaw` class. It is called by `LibRaw::identify()` after parsing a CR3 file with `parseCR3()`. Its purpose is to select the primary RAW track from a CR3 file that may contain multiple tracks of different types (RAW, JPEG, metadata). It analyzes the tracks found by `parseCR3()`, determines the best quality RAW track, and can select a specific frame or track based on the `shot_select` member variable. It then sets various members of the `LibRaw` object, such as `data_offset`, `data_size`, `raw_width`, `raw_height`, `load_raw`, `tiff_bps`, and `filters`, to reflect the properties of the selected RAW track. It also processes other tracks like JPEG for thumbnail extraction and CTMD for metadata.
</description>
<requirements>

<requirement>
The LibRaw::identify() function must be called before LibRaw::selectCRXTrack(). This is because identify() is responsible for calling the parseCR3() function which populates the crx_track_count and crx_header fields that are used in selectCRXTrack().
</requirement>
<requirement>
The libraw_internal_data.unpacker_data.crx_track_count must be an integer between 0 and 15. This is to avoid out-of-bounds access on the crx_header array which has a size of 16 (defined by LIBRAW_CRXTRACKS_MAXCOUNT).
</requirement>
<requirement>
The libraw_internal_data.unpacker_data.crx_header array must contain valid data for each track. For RAW tracks (MediaType == 1), the nBits, f_width, and f_height members must be set to values such that their product is at least 8, otherwise the function will return before any processing.
</requirement>
<requirement>
The shot_select member should be fuzzed. This integer controls which track or frame is selected when multiple options are available, allowing for testing of different code paths.
</requirement>

</requirements>
