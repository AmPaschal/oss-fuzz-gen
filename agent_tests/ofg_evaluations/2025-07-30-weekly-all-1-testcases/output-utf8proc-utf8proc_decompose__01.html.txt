
	
<description>
The `utf8proc_decompose` function decomposes a UTF-8 encoded string into a sequence of Unicode code points. The function takes a UTF-8 string, its length, a buffer to store the decomposed code points, the buffer's size, and a set of options to control the decomposition process. The options can specify normalization forms, casefolding, and other transformations. The function returns the number of code points written to the buffer, or a negative error code if an error occurs.
</description>
<requirements>

<requirement>
The `str` argument must be a valid UTF-8 encoded string. The function iterates through the string and performs UTF-8 validation, and will return an error if the string is not valid UTF-8.</requirement>
<requirement>
If the `UTF8PROC_NULLTERM` option is not set, the `strlen` argument must be the correct length of the `str` argument. The function uses `strlen` to determine the end of the input string, and an incorrect length can lead to buffer overflows.</requirement>
<requirement>
The `bufsize` argument must be large enough to hold the decomposed string. If the buffer is too small, the function will not be able to store the entire decomposed string, and will return an error.</requirement>
<requirement>
The `options` argument must not have both `UTF8PROC_COMPOSE` and `UTF8PROC_DECOMPOSE` flags set. These flags are mutually exclusive, and setting both will result in an error.</requirement>
<requirement>
The `options` argument must have either `UTF8PROC_COMPOSE` or `UTF8PROC_DECOMPOSE` set if `UTF8PROC_STRIPMARK` is set. The `UTF8PROC_STRIPMARK` option only works in conjunction with one of the decomposition or composition options.</requirement>

</requirements>
