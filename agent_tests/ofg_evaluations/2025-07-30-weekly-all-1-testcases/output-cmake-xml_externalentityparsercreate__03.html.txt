
	
<description>
The function `XML_ExternalEntityParserCreate` creates a new XML_Parser object for parsing an external general entity. It inherits handlers and other properties from an existing parser (`oldParser`). The `context` string provides information about the parsing context, such as open entities and namespace declarations. The `encodingName` specifies the encoding of the external entity. This function is typically called from within an `XML_ExternalEntityRefHandler` callback to handle external entity references found during parsing.
</description>
<requirements>
<requirement>
The `oldParser` argument must be a valid, initialized `XML_Parser` object. This is because the function copies various attributes from `oldParser` to the newly created parser. A `NULL` or uninitialized parser will lead to a crash.
</requirement>
<requirement>
The `context` argument should be a null-terminated string, where tokens are separated by formfeed characters (\f). This argument can be fuzzed to test the handling of different parsing contexts. It can also be NULL, which is a valid value.
</requirement>
<requirement>
The `encodingName` argument should be a null-terminated string representing a valid encoding, or it can be NULL. Fuzzing this input with both valid and invalid encoding names is recommended to test the parser's error handling.
</requirement>
<requirement>
Before calling `XML_ExternalEntityParserCreate`, an initial parser should be created using `XML_ParserCreate` or `XML_ParserCreateNS`. This is necessary to have a valid `oldParser` to pass to the function.
</requirement>
<requirement>
An `XML_ExternalEntityRefHandler` should be set on the `oldParser` using `XML_SetExternalEntityRefHandler`. `XML_ExternalEntityParserCreate` is designed to be called from within this handler.
</requirement>
</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size)
{
  FuzzedDataProvider provider(data, size);

  XML_Parser parser = XML_ParserCreate(NULL);
  if (!parser) {
    return 0;
  }

  const std::string context = provider.ConsumeRandomLengthString();
  const std::string encoding = provider.ConsumeRemainingBytesAsString();

  XML_Parser ext_parser =
    XML_ExternalEntityParserCreate(parser, context.c_str(), encoding.c_str());

  if (ext_parser) {
    XML_ParserFree(ext_parser);
  }
  XML_ParserFree(parser);

  return 0;
}
