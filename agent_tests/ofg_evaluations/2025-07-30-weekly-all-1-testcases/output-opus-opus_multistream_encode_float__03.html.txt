
	
<description>
The `opus_multistream_encode_float` function encodes a multistream Opus frame from floating-point input. It is a wrapper for `opus_multistream_encode_native`.
</description>
<requirements>
<requirement>
The first argument `st` must be a valid pointer to an `OpusMSEncoder` struct initialized by `opus_multistream_encoder_create`. This is because the function accesses members of this struct to perform the encoding.
</requirement>
<requirement>
The `frame_size` argument must be a value that corresponds to a valid frame duration (2.5, 5, 10, 20, 40, 60, 80, 100, or 120 ms). This is to prevent the function from returning `OPUS_BAD_ARG`.
</requirement>
<requirement>
The `max_data_bytes` argument must be greater than or equal to `st->layout.nb_streams * 2 - 1`. If the frame size is 100ms, it must be greater than or equal to `st->layout.nb_streams * 3 - 1`. This is to prevent the function from returning `OPUS_BUFFER_TOO_SMALL`.
</requirement>
<requirement>
The `pcm` argument must be a valid pointer to a float array of size `frame_size` multiplied by the number of channels. The number of channels is specified when creating the `OpusMSEncoder` with `opus_multistream_encoder_create`. This is to avoid memory access violations.
</requirement>
<requirement>
The `data` argument must be a valid pointer to a buffer of size `max_data_bytes`. This is to avoid buffer overflows when the encoded data is written to it.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <vector>
#include <cstdint>
#include <cstdlib>

#include "opus.h"
#include "opus_multistream.h"
#include "opus_types.h"

#define MAX_PACKET_SIZE 4000
#define MAX_CHANNELS 8

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    FuzzedDataProvider fdp(data, size);

    const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
    opus_int32 Fs = fdp.PickValueInArray(sample_rates);

    int channels = fdp.ConsumeIntegralInRange<int>(1, MAX_CHANNELS);
    int streams = fdp.ConsumeIntegralInRange<int>(1, channels);
    int coupled_streams = fdp.ConsumeIntegralInRange<int>(0, streams);

    if (streams + coupled_streams > channels) {
        return 0;
    }

    unsigned char mapping[MAX_CHANNELS] = {0};
    for (int i = 0; i < channels; ++i) {
        mapping[i] = fdp.ConsumeIntegralInRange<unsigned char>(0, 255);
    }

    const int applications[] = {OPUS_APPLICATION_VOIP, OPUS_APPLICATION_AUDIO, OPUS_APPLICATION_RESTRICTED_LOWDELAY};
    int application = fdp.PickValueInArray(applications);

    int error;
    OpusMSEncoder *encoder = opus_multistream_encoder_create(Fs, channels, streams, coupled_streams, mapping, application, &error);
    if (error != OPUS_OK || encoder == nullptr) {
        return 0;
    }

    const int frame_sizes[] = {120, 240, 480, 960, 1920, 2880, 5760};
    int frame_size = fdp.PickValueInArray(frame_sizes);

    const size_t pcm_size = frame_size * channels;
    if (fdp.remaining_bytes() < pcm_size * sizeof(float)) {
        opus_multistream_encoder_destroy(encoder);
        return 0;
    }
    
    std::vector<float> pcm(pcm_size);
    fdp.ConsumeData(pcm.data(), pcm.size() * sizeof(float));

    unsigned char output_data[MAX_PACKET_SIZE];

    (void)opus_multistream_encode_float(encoder, pcm.data(), frame_size, output_data, MAX_PACKET_SIZE);

    opus_multistream_encoder_destroy(encoder);

    return 0;
}
