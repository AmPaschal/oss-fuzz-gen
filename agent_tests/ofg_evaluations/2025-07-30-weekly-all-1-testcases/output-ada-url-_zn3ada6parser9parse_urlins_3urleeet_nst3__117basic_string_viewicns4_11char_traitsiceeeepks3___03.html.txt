
	
<description>
The function `ada::parser::parse_url` is a template function responsible for parsing a URL string (`user_input`). It can handle both absolute URLs and relative URLs. When parsing a relative URL, it uses an optional `base_url` to resolve the components of the new URL. The core parsing logic is implemented in the `parse_url_impl` function, which is a state machine that processes the input string character by character according to the WHATWG URL Standard. The function handles various URL components like scheme, username, password, host, port, path, query, and fragment. It also performs sanitization on the input, such as trimming control characters and removing tabs and newlines. The function is designed to be robust and returns an invalid URL object if parsing fails, rather than crashing. The validity of the parsed URL can be checked via the `is_valid` member of the returned `ada::url` object.
</description>
