
	
<description>
The function `GetUsedVar` returns a map of the variables used in the expression that has been set in the parser. The function first sets the parser to ignore undefined variables, then it creates the Reverse Polish Notation (RPN) of the expression. Finally, it returns the map of used variables from the token reader. The function is designed to be called after an expression has been set in the parser using `SetExpr`.
</description>
<requirements>
<requirement>
The `SetExpr` method must be called on the `ParserBase` object before calling `GetUsedVar`. This is because `GetUsedVar` internally calls `CreateRPN`, which processes the expression previously set by `SetExpr` to identify the variables used.
</requirement>
</requirements>
