
	
<description>
The `opus_decode` function decodes an Opus packet. It takes an OpusDecoder state, the encoded packet data, the data length, a buffer for the decoded PCM data, the frame size, and a flag to indicate whether to use forward error correction (FEC). The function returns the number of decoded samples per channel on success, or an error code on failure. Callers typically create a decoder object first, then repeatedly call `opus_decode` for each packet. The fuzzer shows a typical usage pattern where it reads packets from a stream and decodes them sequentially.
</description>
<requirements>

<requirement>
The `OpusDecoder` state `st` must be initialized by `opus_decoder_create`. This is necessary to set up the internal state required for decoding, such as the number of channels.
</requirement>
<requirement>
The `pcm` buffer must be allocated to be at least `frame_size * st->channels * sizeof(opus_int16)`. This is to prevent a buffer overflow when writing the decoded samples.
</requirement>
<requirement>
The `frame_size` argument must be a positive integer. The function will return `OPUS_BAD_ARG` if `frame_size` is zero or negative.
</requirement>
<requirement>
If the `data` pointer is NULL, the `len` argument must be 0 to signal a lost packet. This is because the function interprets a non-NULL data pointer with a zero length as a valid empty packet.
</requirement>
<requirement>
The `decode_fec` argument should be either 0 or 1. This argument is treated as a boolean flag, and other values may lead to unexpected behavior.
</requirement>
<requirement>
The `OpusDecoder` state `st` should be destroyed using `opus_decoder_destroy` after use. This is to free the memory and resources allocated for the decoder.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstddef>
#include <cstdint>
#include <vector>

#include "/src/opus/include/opus.h"

// Define a reasonable maximum frame size based on Opus documentation/examples.
#define MAX_FRAME_SAMP 5760

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider fdp(data, size);

  // 1. Create the decoder with fuzzed parameters.
  const opus_int32 sample_rates[] = {8000, 12000, 16000, 24000, 48000};
  opus_int32 fs = fdp.PickValueInArray(sample_rates);
  int channels = fdp.ConsumeIntegralInRange(1, 2);

  int err;
  OpusDecoder *dec = opus_decoder_create(fs, channels, &err);
  if (err != OPUS_OK || dec == nullptr) {
    return 0;
  }

  // 2. Prepare parameters for opus_decode.
  const int decode_fec = fdp.ConsumeBool();

  // Fuzz the frame_size, which is the size of the output pcm buffer
  // in samples per channel.
  const int frame_size = fdp.ConsumeIntegralInRange(0, MAX_FRAME_SAMP);

  // Allocate the output buffer.
  std::vector<opus_int16> pcm(frame_size * channels);

  // Use the rest of the data as the input packet.
  std::vector<uint8_t> packet_data = fdp.ConsumeRemainingBytes<uint8_t>();
  const opus_int32 len = packet_data.size();

  // 3. Call the function under test.
  // A null packet can be used to indicate a lost packet.
  if (packet_data.empty()) {
    opus_decode(dec, nullptr, 0, pcm.data(), frame_size, decode_fec);
  } else {
    opus_decode(dec, packet_data.data(), len, pcm.data(), frame_size,
                decode_fec);
  }

  // 4. Cleanup.
  opus_decoder_destroy(dec);

  return 0;
}
