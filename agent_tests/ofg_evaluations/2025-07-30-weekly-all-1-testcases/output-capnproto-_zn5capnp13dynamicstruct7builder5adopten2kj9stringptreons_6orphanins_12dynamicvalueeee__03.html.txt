
	
<description>
The `capnp::DynamicStruct::Builder::adopt` function is an overload that takes a field name as a string and an orphan object. It resolves the field name to a `StructSchema::Field` object by calling `schema.getFieldByName()` and then calls another `adopt` overload to perform the actual adoption of the orphan. The main purpose of this function is to transfer ownership of the memory and resources held by the orphan to a specific field within the struct being built.
</description>
<requirements>
<requirement>
The `name` argument must be a string representing a valid field name within the struct's schema. This is because the underlying call to `schema.getFieldByName(name)` will trigger a fatal assertion (`KJ_FAIL_REQUIRE`) if the name does not exist.
</requirement>
<requirement>
The `orphan` argument must be a valid, movable `Orphan<DynamicValue>` object. This is typically created via an `Orphanage` (e.g., from a `MessageBuilder`) and ensures that valid memory is being adopted by the struct builder.
</requirement>
<requirement>
The `DynamicStruct::Builder` object on which `adopt` is called must be properly initialized and associated with a valid `StructSchema`. An uninitialized builder will not have a schema, causing a crash when `getFieldByName` is called on a null or invalid schema object.
</requirement>
<requirement>
The type of the value contained within the `orphan` should be compatible with the type of the field specified by the `name` argument. Type mismatches can lead to undefined behavior or crashes inside the lower-level `adopt` implementation which handles the raw data based on the field's type information.
</requirement>
</requirements>

#include <capnp/message.h>
#include <capnp/schema.h>
#include <capnp/dynamic.h>
#include <capnp/test.capnp.h>
#include <kj/main.h>
#include <fuzzer/FuzzedDataProvider.h>
#include "test-util.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size < 1) {
    return 0;
  }

  kj::runCatchingExceptions([&]() {
    FuzzedDataProvider provider(data, size);
    capnp::Schema schema = capnp::Schema::from<capnp::_::TestAllTypes>();
    auto structSchema = schema.asStruct();
    auto fields = structSchema.getFields();
    if (fields.size() == 0) {
      return;
    }

    // 1. Create a message and initialize it with test data to get a source for orphans.
    capnp::MallocMessageBuilder message1;
    auto root1 = message1.initRoot<capnp::DynamicStruct>(structSchema);
    capnp::_::initDynamicTestMessage(root1);

    // 2. Pick a field from the initialized message and disown it to create an orphan.
    // The type of the orphan will depend on the chosen field.
    auto fieldToDisown = fields[provider.ConsumeIntegralInRange<uint16_t>(0, fields.size() - 1)];
    auto orphan = root1.disown(fieldToDisown);

    // 3. Create a second, empty message to adopt the orphan into.
    capnp::MallocMessageBuilder message2;
    auto root2 = message2.initRoot<capnp::DynamicStruct>(structSchema);

    // 4. Pick a field name to adopt into. This can be a valid field name or a random string.
    kj::String adoptFieldName;
    if (provider.ConsumeBool()) {
      // Pick a valid field name
      auto fieldToAdopt = fields[provider.ConsumeIntegralInRange<uint16_t>(0, fields.size() - 1)];
      adoptFieldName = kj::str(fieldToAdopt.getProto().getName());
    } else {
      // Use a random string
      adoptFieldName = kj::str(provider.ConsumeRandomLengthString());
    }
    
    // 5. Call the target function.
    root2.adopt(adoptFieldName, kj::mv(orphan));
  });

  return 0;
}
