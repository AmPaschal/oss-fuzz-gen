The function combines these three unsigned integer values into a single 32-bit unsigned integer, which is then used in a switch statement to check against a set of hard-coded valid combinations. It is called from `validate_block_size`, which in turn is called during the initialization of the `astcenc_config` object. The caller, `validate_block_size`, ensures that `zdim` is at least 2 before calling this function.
</description>
