
	
<description>
The function `XML_ExternalEntityParserCreate` creates a new parser for an external entity. It inherits most of the settings from the existing parser `oldParser`, but it can have a different encoding and context. The function is used to handle external entities encountered during parsing. It is called by the `externalEntityRefProcessor` function, which is a processor for handling external entity references.
</description>
<requirements>

<requirement>
The `oldParser` argument must be a valid, non-NULL `XML_Parser` object. This is because the function dereferences this pointer to create the new parser, and a NULL pointer would lead to a crash.
</requirement>
<requirement>
The `oldParser` should be initialized by calling `XML_ParserCreate` with a NULL argument. This is the standard way to create a new parser instance that can be used and modified.
</requirement>
<requirement>
The `context` argument can be a NULL or non-NULL, null-terminated string. The function has different control flows based on whether `context` is NULL, so both paths should be tested.
</requirement>
<requirement>
The `encodingName` argument can be a NULL or non-NULL, null-terminated string. `parserCreate` which is called by the target function, can handle both NULL and non-NULL `encodingName`.
</requirement>

</requirements>
