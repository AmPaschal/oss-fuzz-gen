
	
<description>
The function `mz_zip_locate_first_entry` iterates through entries in a zip archive, starting from the first one. It uses a callback function (`cb`) to determine if an entry matches a user-defined criteria. The `userdata` parameter is passed to this callback, allowing the callback to access custom data. The iteration stops and the function returns `MZ_OK` when the callback returns `MZ_OK`. Otherwise, it continues to the next entry.
</description>
<requirements>
<requirement>
The first argument, `handle`, must be a valid pointer to a `mz_zip` structure. This handle should be initialized by successfully opening a zip archive using `mz_zip_open` and a stream created with `mz_stream_mem_create` and `mz_stream_mem_open`.
</requirement>
<requirement>
The third argument, `cb`, must be a valid, non-null function pointer. This callback function is responsible for the matching logic and its return value controls the flow of the locate operation.
</requirement>
<requirement>
The callback function `cb` must have the signature `int32_t cb(void *handle, void *userdata, mz_zip_file *file_info)`. It should return `MZ_OK` (0) for a matching entry and a different value for a non-match.
</requirement>
<requirement>
The second argument, `userdata`, is passed to the callback function and can be used to provide context. The fuzzer can point this to a buffer of fuzzing data to be used within the callback to influence its behavior.
</requirement>
<requirement>
A zip archive with at least one entry should be opened before calling the target function. This ensures that the function has entries to iterate through.
</requirement>
</requirements>
