The function `wxFontMapperBase::CharsetToEncoding` takes a charset string and returns the corresponding font encoding. It first calls `NonInteractiveCharsetToEncoding` to perform the conversion. If the encoding is not found, it returns `wxFONTENCODING_SYSTEM`. The `NonInteractiveCharsetToEncoding` function has a complex logic to determine the encoding from the given charset string. It first looks up the charset in the user-defined configuration. If not found, it tries to recognize it by comparing it against a list of known encoding names. It also has specific parsing logic for different charset families like ISO-8859, Windows, KOI8, EUC, etc. The function is robust against different string formats, as it trims whitespaces and removes quotes from the input string before processing.
</description>
