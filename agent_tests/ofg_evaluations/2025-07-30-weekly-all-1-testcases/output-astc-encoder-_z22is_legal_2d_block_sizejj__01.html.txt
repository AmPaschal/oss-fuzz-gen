
	
<description>
The function `is_legal_2d_block_size` validates if the input dimensions `xdim` and `ydim` correspond to a supported 2D block size in the ASTC encoder. It combines the dimensions into a 16-bit value and checks it against a list of hardcoded valid sizes. It returns true for a legal size and false otherwise. This function is a preliminary check in the image compression pipeline to ensure valid configuration.
</description>
<requirements>

<requirement>
The `xdim` and `ydim` arguments must be one of the following pairs: (4,4), (5,4), (5,5), (6,5), (6,6), (8,5), (8,6), (8,8), (10,5), (10,6), (10,8), (10,10), (12,10), (12,12). This is because the function specifically checks for these combinations to consider the block size legal, and any other pair will cause the function to return false, likely halting further processing.
</requirement>
