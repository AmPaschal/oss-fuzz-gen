
	
<description>
The `tidyParseStdin` function parses HTML content from standard input. It acts as a wrapper for the `tidyDocParseStdin` function, which performs the core parsing logic. The function requires a `TidyDoc` object, which encapsulates the configuration and state for the parsing operation. This object is created using the `tidyCreate` function. The caller in `console/tidy.c` also sets a message callback using `tidySetMessageCallback` after creating the `TidyDoc` object. The function's primary purpose is to read from standard input, so it's essential to provide input through stdin for fuzzing.
</description>
<requirements>
<requirement>
The `TidyDoc` argument `tdoc` must be created by calling `tidyCreate()`. This is because `tidyCreate()` allocates and initializes the internal `TidyDocImpl` structure that is required by the parsing functions.
</requirement>
<requirement>
It is recommended to call `tidySetMessageCallback()` after `tidyCreate()`. This is because the callback is used for reporting errors and warnings found during parsing.
</requirement>
<requirement>
Input should be provided via standard input (stdin). This is because `tidyParseStdin` internally reads from `stdin` to get the content to be parsed.
</requirement>
</requirements>

#include <stdint.h>
#include <stdio.h>
#include <unistd.h>

#include "/src/tidy-html5/include/tidy.h"
#include "fuzzer_temp_file.h"

int tidyParseStdin(TidyDoc);

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  // Create a temporary file to act as stdin.
  char *tmpfile = fuzzer_get_tmpfile(data, size);
  if (!tmpfile) {
    return 0;
  }

  // Save the real stdin file descriptor.
  int stdin_fileno = fileno(stdin);
  int saved_stdin_fd = dup(stdin_fileno);
  if (saved_stdin_fd == -1) {
    fuzzer_release_tmpfile(tmpfile);
    return 0;
  }

  // Redirect stdin to the temporary file.
  if (!freopen(tmpfile, "rb", stdin)) {
    close(saved_stdin_fd);
    fuzzer_release_tmpfile(tmpfile);
    return 0;
  }

  TidyDoc tdoc = tidyCreate();
  if (tdoc) {
    // Call the function under test.
    tidyParseStdin(tdoc);
    tidyRelease(tdoc);
  }

  // Restore stdin.
  fflush(stdin);
  if (dup2(saved_stdin_fd, stdin_fileno) == -1) {
    // Error restoring stdin. The fuzzer process will terminate,
    // so we can ignore this in this context.
  }
  close(saved_stdin_fd);

  // Clean up the temporary file.
  fuzzer_release_tmpfile(tmpfile);

  return 0;
}
