
	
<description>
The function `SafeUint32Mult` safely multiplies three 32-bit unsigned integers (`arg1`, `arg2`, `arg3`). It checks for arithmetic overflow at each step of the multiplication. If the product of the three numbers fits within a `uint32_t`, it stores the result in the location pointed to by the `result` parameter and returns `true`. If an overflow occurs during the multiplication, the function catches an internal `dng_exception` and returns `false`, leaving the content of `result` untouched. The core logic is implemented in a series of chained calls, ultimately relying on a template function `SafeUnsignedMult` which performs the overflow check.
</description>
<requirements>

<requirement>
The 'result' argument must be a non-null pointer to a uint32_t. The function writes the multiplication result to this memory location, so a null pointer would lead to a crash from dereferencing.
</requirement>
<requirement>
The mathematical product of `arg1`, `arg2`, and `arg3` must be less than or equal to `UINT32_MAX` (4294967295). If the product exceeds this value, an arithmetic overflow occurs, causing the function to return `false` and preventing full code coverage.
</requirement>

</requirements>

#include <cstdint>
#include <fuzzer/FuzzedDataProvider.h>

#include "/src/dng_sdk/source/dng_hue_sat_map.h"

// Forward declaration as requested, although the header provides it.
bool SafeUint32Mult(uint32_t, uint32_t, uint32_t, uint32_t *);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  uint32_t arg1 = provider.ConsumeIntegral<uint32_t>();
  uint32_t arg2 = provider.ConsumeIntegral<uint32_t>();
  uint32_t arg3 = provider.ConsumeIntegral<uint32_t>();

  uint32_t result;

  SafeUint32Mult(arg1, arg2, arg3, &result);

  return 0;
}
