
	
<description>
The `crxLoadDecodeLoop` function decodes image data from a CRX file. It iterates through the image planes, decoding each one. The first argument is a pointer to a `CrxImage` struct which contains information about the image and the planes to be decoded. The second argument specifies the number of planes to decode.
</description>
<requirements>

<requirement>
The first argument, a void pointer, must be a pointer to a valid `CrxImage` struct. This struct should be initialized by calling the `crxSetupImageData` function before calling `crxLoadDecodeLoop`.
</requirement>
<requirement>
The `input` member of the `CrxImage` struct must be a valid, initialized `LibRaw_abstract_datastream` object. This is because the `crxDecodePlane` function, called by `crxLoadDecodeLoop`, will read from this stream.
</requirement>
<requirement>
The second argument, `nPlanes`, must be an integer between 1 and 4, inclusive. This is because the function uses this value to iterate over an array of size 4, and a value outside this range will cause an out-of-bounds access.
</requirement>

</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>
#include <vector>

// Make private and protected members public for fuzzing.
#define private public
#define protected public

#include <libraw.h>

#undef private
#undef protected

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  LibRaw libraw;

#if LIBRAW_VERSION >= LIBRAW_MAKE_VERSION(0, 21, 0)
  // Set a memory limit to avoid OOM errors.
  libraw.imgdata.rawparams.max_raw_memory_mb = 1;
#endif

  // Consume a portion of the data to initialize the LibRaw object state.
  // This simulates opening a file and prepares internal buffers.
  size_t init_data_size = provider.ConsumeIntegralInRange<size_t>(0, 8192);
  std::vector<uint8_t> init_data = provider.ConsumeBytes<uint8_t>(init_data_size);

  if (libraw.open_buffer(init_data.data(), init_data.size()) == LIBRAW_SUCCESS) {
    // Unpacking allocates buffers that crxLoadDecodeLoop writes to.
    libraw.unpack();
  }

  // Consume the remaining data to be used as input for the target function.
  std::vector<uint8_t> jpeg_data = provider.ConsumeRemainingBytes<uint8_t>();

  if (!jpeg_data.empty()) {
    // Call the target function directly with fuzzed data.
    // The object state has been prepared by open_buffer and unpack.
    libraw.crxLoadDecodeLoop(jpeg_data.data(), jpeg_data.size());
  }

  return 0;
}
