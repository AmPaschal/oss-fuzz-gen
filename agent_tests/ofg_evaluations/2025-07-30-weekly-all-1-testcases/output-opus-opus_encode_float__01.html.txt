The opus_encode_float function encodes a frame of floating-point PCM audio data into the Opus format. It takes an initialized `OpusEncoder` state, a buffer of PCM audio data, the frame size, an output buffer for the encoded data, and the maximum size of the output buffer. The function first determines the internal frame size to use based on the input `analysis_frame_size` and the encoder's configuration. It then converts the floating-point PCM data to an internal fixed-point representation. Finally, it calls the internal `opus_encode_native` function to perform the actual encoding. The encoded data is written to the output buffer, and the number of bytes written is returned. For the function to execute correctly, the `OpusEncoder` must be properly initialized, and the input and output buffers must be allocated with sufficient size. The `analysis_frame_size` must also be a valid value that is supported by the encoder's current configuration.

The `Fs` argument of `opus_encoder_create` must be one of 8000, 12000, 16000, 24000, or 48000. These are the only sample rates supported by the Opus encoder.
</requirement>
<requirement>
The `channels` argument of `opus_encoder_create` must be 1 or 2. The Opus encoder only supports mono and stereo channels.
</requirement>
<requirement>
The `application` argument of `opus_encoder_create` must be one of `OPUS_APPLICATION_VOIP` (2048), `OPUS_APPLICATION_AUDIO` (2049), or `OPUS_APPLICATION_RESTRICTED_LOWDELAY` (2051). These are the only supported application modes.
</requirement>
<requirement>
The `analysis_frame_size` argument must be greater than or equal to `st->Fs / 400`. This is to prevent a negative return value from `frame_size_select`, which would cause `opus_encode_float` to return an error.
</requirement>
<requirement>
The `pcm` buffer must have a size of at least `frame_size * st->channels`, where `frame_size` is the value returned by `frame_size_select`. This is to prevent out-of-bounds reads when accessing the `pcm` buffer.
</requirement>
<requirement>
The `data` buffer must be allocated with a size of at least `max_data_bytes`. This is to prevent a buffer overflow when writing the encoded data.
</requirement>
<requirement>
The `max_data_bytes` argument should be a non-negative value. A negative value can lead to unexpected behavior in the underlying `opus_encode_native` function.
</requirement>
<requirement>
After using the encoder, `opus_encoder_destroy` should be called on the `OpusEncoder*` to free the allocated memory. This is to prevent memory leaks.
</requirement>
</requirements>

  const opus_int32 Fs = 48000;
  const int application = provider.PickValueInArray({OPUS_APPLICATION_VOIP, OPUS_APPLICATION_AUDIO, OPUS_APPLICATION_RESTRICTED_LOWDELAY});

  int error;
  OpusEncoder *encoder = opus_encoder_create(Fs, channels, application, &error);
  if (error != OPUS_OK || encoder == nullptr) {
    return 0;
  }

  opus_encoder_ctl(encoder, OPUS_SET_BITRATE_REQUEST, provider.ConsumeIntegralInRange(500, 512000));
  opus_encoder_ctl(encoder, OPUS_SET_COMPLEXITY_REQUEST, provider.ConsumeIntegralInRange(0, 10));
  opus_encoder_ctl(encoder, OPUS_SET_VBR_REQUEST, provider.ConsumeBool());
  opus_encoder_ctl(encoder, OPUS_SET_PACKET_LOSS_PERC_REQUEST, provider.ConsumeIntegralInRange(0, 100));
  opus_encoder_ctl(encoder, OPUS_SET_SIGNAL_REQUEST, provider.PickValueInArray({OPUS_AUTO, OPUS_SIGNAL_VOICE, OPUS_SIGNAL_MUSIC}));

  const int frame_size = provider.PickValueInArray({120, 240, 480, 960, 1920, 2880});
  const size_t pcm_count = frame_size * channels;
  std::vector<float> pcm(pcm_count);

  size_t consumed_bytes = provider.ConsumeData(pcm.data(), pcm_count * sizeof(float));
  if (consumed_bytes < pcm_count * sizeof(float)) {
    opus_encoder_destroy(encoder);
    return 0;
  }

  const opus_int32 max_data_bytes = 4000;
  unsigned char output_buffer[max_data_bytes];

  opus_encode_float(encoder, pcm.data(), frame_size, output_buffer, max_data_bytes);

  opus_encoder_destroy(encoder);
