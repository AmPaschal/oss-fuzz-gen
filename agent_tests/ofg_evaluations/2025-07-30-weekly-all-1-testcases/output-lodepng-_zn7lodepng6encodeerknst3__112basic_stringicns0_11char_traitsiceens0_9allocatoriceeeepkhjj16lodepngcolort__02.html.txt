
	
<description>
This function encodes a raw image to a PNG file. It takes the image data, dimensions, color type, and bit depth as input, and writes the resulting PNG to the specified filename. The function first calls another `encode` function to perform the in-memory PNG encoding, and then uses `save_file` to write the encoded data to disk. The core logic resides in the `lodepng_encode` function, which is called indirectly. This function has several constraints on its inputs, particularly on the color type, bit depth, and their relationship with the input buffer size. It is important to provide valid combinations of these parameters to avoid errors. The `filename` must be a path to a writable file.
</description>
<requirements>

<requirement>
The `filename` parameter must be a valid path to a writable file. This is because the function uses `fopen` with the "wb" mode to write the encoded PNG data.
</requirement>
<requirement>
The `in` buffer must have a size of at least `lodepng_get_raw_size_lct(w, h, colortype, bitdepth)`. This is to prevent buffer overflows when the function reads the raw image data.
</requirement>
<requirement>
The `colortype` parameter must be one of the following values: `LCT_GREY`, `LCT_RGB`, `LCT_PALETTE`, `LCT_GREY_ALPHA`, or `LCT_RGBA`. These are the only color types supported by the encoder.
</requirement>
<requirement>
The `bitdepth` parameter must be a valid bit depth for the given `colortype`. The valid bit depths are: 1, 2, 4, 8, or 16 for `LCT_GREY`; 8 or 16 for `LCT_RGB`; 1, 2, 4, or 8 for `LCT_PALETTE`; and 8 or 16 for `LCT_GREY_ALPHA` and `LCT_RGBA`.
</requirement>
<requirement>
If the `colortype` is `LCT_PALETTE`, a valid palette must be set in the `LodePNGState`. The palette size must be between 1 and 256, otherwise, the encoder will return an error.
</requirement>

</requirements>

#include "/src/lodepng/lodepng.h"
#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>

// Re-use the color type and bit depth combinations from the existing fuzzer
// to provide valid inputs to the encode function.
namespace {
const size_t num_combinations = 15;

LodePNGColorType colortypes[num_combinations] = {
    LCT_GREY,       LCT_GREY,       LCT_GREY,    LCT_GREY,    LCT_GREY,
    LCT_RGB,        LCT_RGB,
    LCT_PALETTE,    LCT_PALETTE,    LCT_PALETTE, LCT_PALETTE,
    LCT_GREY_ALPHA, LCT_GREY_ALPHA,
    LCT_RGBA,       LCT_RGBA,
};

unsigned bitdepths[num_combinations] = {
    1, 2,  4, 8, 16, // gray
    8, 16,           // rgb
    1, 2,  4, 8,     // palette
    8, 16,           // gray+alpha
    8, 16,           // rgb+alpha
};
} // namespace

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  // The function under test writes to a file. Provide a dummy filename.
  const std::string filename = "fuzz_output.png";

  // Consume image dimensions. Keep them reasonably small to avoid OOMs.
  unsigned w = provider.ConsumeIntegralInRange<unsigned int>(1, 512);
  unsigned h = provider.ConsumeIntegralInRange<unsigned int>(1, 512);

  // Consume a valid color type and bit depth combination.
  size_t combination_index =
      provider.ConsumeIntegralInRange<size_t>(0, num_combinations - 1);
  LodePNGColorType colortype = colortypes[combination_index];
  unsigned bitdepth = bitdepths[combination_index];

  // Create and initialize a LodePNGColorMode struct.
  LodePNGColorMode color_mode;
  lodepng_color_mode_init(&color_mode);
  color_mode.colortype = colortype;
  color_mode.bitdepth = bitdepth;

  // Calculate the required size for the raw pixel data using the correct function.
  size_t image_size = lodepng_get_raw_size(w, h, &color_mode);

  // Check for invalid size (e.g., from overflow) or if we don't have
  // enough fuzz data.
  if (image_size == 0 || image_size > provider.remaining_bytes()) {
    return 0;
  }

  // Consume the raw pixel data.
  std::vector<uint8_t> in_data = provider.ConsumeBytes<uint8_t>(image_size);
  if (in_data.size() != image_size) {
    return 0;
  }

  // Call the function to be fuzzed.
  lodepng::encode(filename, in_data.data(), w, h, colortype, bitdepth);

  return 0;
}
