
	
<description>
The function `zip_file_replace` replaces a file in a zip archive at a given index with new data from a zip source. It takes the zip archive, the index of the file to be replaced, the new data source, and flags as input. The function first validates the index and source, and then calls `_zip_file_replace` to perform the actual replacement. It returns 0 on success and -1 on failure. Callers of this function first open a zip archive using `zip_open()`, then get the index of the file to replace using `zip_name_locate()`, and create a new data source using `zip_source_buffer()`.
</description>
<requirements>

<requirement>
The first argument `za` must be a valid `zip_t` pointer returned by `zip_open()` or a similar function. This is because the function operates on a zip archive structure.
</requirement>
<requirement>
The second argument `idx` must be a valid index of a file within the archive, i.e., `idx` must be less than the total number of files in the archive. This is to prevent out-of-bounds access.
</requirement>
<requirement>
The third argument `source` must be a valid `zip_source_t` pointer and not NULL. It should be created using a function like `zip_source_buffer()` to provide the new data for the file.
</requirement>
<requirement>
The fourth argument `flags` can be 0. The existing callers of this function pass 0 for the flags.
</requirement>

</requirements>

int
LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
    if (size < 2) {
        /* We need at least 1 byte for flags and 1 for the index selector. */
        return 0;
    }

    /* Use first byte for flags */
    zip_flags_t flags = data[0];
    /* Use second byte to select the index to test */
    zip_uint64_t idx_selector = data[1];
    const uint8_t *content_data = data + 2;
    const size_t content_size = size - 2;

    const char *path = "fuzz_replace.zip";
    int error = 0;
    zip_t *za;

    (void)remove(path);
    if ((za = zip_open(path, ZIP_CREATE | ZIP_TRUNCATE, &error)) == NULL) {
        return 0;
    }

    /* Add an initial file to the archive, so we have something to replace. */
    zip_source_t *source_initial = zip_source_buffer(za, content_data, content_size, 0);
    if (source_initial == NULL) {
        zip_discard(za);
        (void)remove(path);
        return 0;
    }

    /* The index of the newly added file will be 0. */
    zip_int64_t idx = zip_file_add(za, "file_to_replace", source_initial, ZIP_FL_OVERWRITE);
    if (idx < 0) {
        zip_discard(za);
        (void)remove(path);
        return 0;
    }

    /* Create a new source for the replacement. */
    zip_source_t *source_replace = zip_source_buffer(za, content_data, content_size, 0);
    if (source_replace == NULL) {
        zip_discard(za);
        (void)remove(path);
        return 0;
    }

    /* Fuzz the index. We have one entry, so index 0 is valid.
     * We test both the valid index and an invalid one. */
    zip_uint64_t replace_idx = idx_selector % 2;

    /* Call the function under test. */
    zip_file_replace(za, replace_idx, source_replace, flags);

    /* Close the archive to write changes and discover related bugs. */
    if (zip_close(za) < 0) {
        zip_discard(za);
    }
    (void)remove(path);

    return 0;
}
