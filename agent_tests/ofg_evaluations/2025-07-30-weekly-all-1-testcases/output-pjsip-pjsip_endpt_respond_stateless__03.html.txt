
	
<description>
The function `pjsip_endpt_respond_stateless` sends a SIP response message without associating it with a transaction. It is used to reply to requests when a transaction is not needed or has already been terminated. The function constructs a response message based on the received request data (`rdata`), a status code (`st_code`), and optional status text (`st_text`), headers (`hdr_list`), and message body (`body`). It then sends the response to the address from which the request was received.
</description>
<requirements>
<requirement>
The `endpt` argument must be a valid pointer to a `pjsip_endpoint` structure, which can be created using `pjsip_endpt_create`. This is because the function dereferences this pointer to access the memory pool for creating the response message and a NULL pointer will cause a crash.
</requirement>
<requirement>
The `rdata` argument must be a valid pointer to a `pjsip_rx_data` structure. The function accesses members of `rdata` extensively, and a NULL pointer will cause a crash.
</requirement>
<requirement>
The `rdata->msg_info.msg` field must be a valid pointer to a `pjsip_msg` structure, and its `type` field must be `PJSIP_REQUEST_MSG`. An assertion in the function checks for this condition, and the internal function `pjsip_endpt_create_response` expects a request message to correctly create a response.
</requirement>
<requirement>
The `rdata->msg_info.msg` must contain `To`, `From`, `CSeq`, `Call-ID`, and `Via` headers. The internal function `pjsip_msg_create_response` requires these headers from the request to build a valid response, and missing them can lead to errors or malformed responses.
</requirement>
<requirement>
If `rdata->tsx_grp.tsx` is not NULL, its `state` must be `PJSIP_TSX_STATE_TERMINATED` or a greater value. The function is designed for stateless responses, and if a transaction exists and is active, a stateful response should be sent instead. The function explicitly checks for this and returns an error if the condition is not met.
</requirement>
<requirement>
If the `hdr_list` argument is not NULL, it must point to a valid, circularly-linked list of `pjsip_hdr` structures. The function traverses this list to add headers to the response message, and an invalid list structure will lead to an infinite loop or a crash.
</requirement>
<requirement>
The functions `pj_init`, `pj_caching_pool_init`, and `pjsip_endpt_create` must be called in sequence before calling the target function. These functions are necessary to set up the memory pool and create the endpoint required by the target function.
</requirement>
</requirements>

static pj_caching_pool cp;
static pjsip_endpoint *sip_endpt;

/* For logging */
static void cb(int level, const char *data, int len)
{
    PJ_UNUSED_ARG(level);
    PJ_UNUSED_ARG(data);
    PJ_UNUSED_ARG(len);
}

extern int LLVMFuzzerInitialize(int *argc, char ***argv)
{
    PJ_UNUSED_ARG(argc);
    PJ_UNUSED_ARG(argv);

    pj_init();
    pj_log_set_level(0);
    pj_log_set_log_func(&cb);

    pj_caching_pool_init(&cp, &pj_pool_factory_default_policy, 0);

    pjsip_endpt_create(&cp.factory, "fuzzer", &sip_endpt);

    pjsip_ua_init_module(sip_endpt, NULL);

    return 0;
}

extern int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size)
{
    pj_pool_t *pool;
    pjsip_msg *msg;
    pjsip_rx_data *rdata = NULL;
    char *data_str;

    if (size < 4) {
        return 0;
    }

    pool = pj_pool_create(&cp.factory, "fuzzer-pool", 4000, 4000, NULL);
    if (!pool) {
        return 0;
    }

    data_str = (char*)pj_pool_alloc(pool, size + 1);
    pj_memcpy(data_str, data, size);
    data_str[size] = '\0';

    msg = pjsip_parse_msg(pool, data_str, size, NULL);
    if (msg == NULL) {
        pj_pool_release(pool);
        return 0;
    }

    if (msg->type != PJSIP_REQUEST_MSG) {
        pj_pool_release(pool);
        return 0;
    }

    /* Manually create rdata to avoid linker errors with library creation functions */
    rdata = (pjsip_rx_data*)pj_pool_calloc(pool, 1, sizeof(pjsip_rx_data));
    if (rdata) {
        /* Initialize the structure to zero */
        pj_bzero(rdata, sizeof(pjsip_rx_data));
        
        /* Set the only member we need and can safely access */
        rdata->msg_info.msg = msg;

        int st_code = (data[0] | (data[1] << 8)) % 600 + 100;
        pjsip_endpt_respond_stateless(sip_endpt, rdata, st_code, NULL, NULL, NULL);
    }
    
    pj_pool_release(pool);

    return 0;
}
