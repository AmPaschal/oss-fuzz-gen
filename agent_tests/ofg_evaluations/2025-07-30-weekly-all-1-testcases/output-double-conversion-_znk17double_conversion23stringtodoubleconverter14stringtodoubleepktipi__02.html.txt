
	
<description>
The function `StringToDouble` converts a string of 16-bit characters to a double-precision floating-point number. It is a wrapper around the `StringToIeee` function, which performs the actual conversion. The behavior of the conversion is highly configurable through the `StringToDoubleConverter` object's flags and other settings, such as custom symbols for infinity and NaN. The function can handle decimal, hexadecimal, and octal numbers, as well as leading/trailing whitespace and case-insensitive matching for special values, depending on the flags provided during the converter's construction.
</description>
<requirements>
<requirement>
The `length` argument must be less than or equal to the actual size of the `buffer`. This is to prevent out-of-bounds memory access when the function iterates through the buffer.
</requirement>
<requirement>
The `processed_characters_count` argument must be a valid pointer to an integer. The function writes the number of processed characters to this address, and a NULL pointer would cause a crash.
</requirement>
<requirement>
The `StringToDoubleConverter` object must be initialized before calling the target function. The constructor's arguments, particularly the `flags`, `infinity_symbol`, and `nan_symbol`, should be fuzzed to test different parsing paths.
</requirement>
<requirement>
The `infinity_symbol` and `nan_symbol` strings, if provided during the `StringToDoubleConverter`'s construction, must not start with a sign ('+' or '-'), a digit, or have the same first character. This is to avoid ambiguity and ensure correct parsing of special floating-point values.
</requirement>
<requirement>
The `buffer` argument, which contains the string to be converted, should be fuzzed. This will test the core parsing logic of the function with a wide variety of inputs.
</requirement>
</requirements>

  StringToDoubleConverter converter(
      StringToDoubleConverter::ALLOW_HEX |
          StringToDoubleConverter::ALLOW_OCTALS |
          StringToDoubleConverter::ALLOW_TRAILING_JUNK |
          StringToDoubleConverter::ALLOW_LEADING_SPACES |
          StringToDoubleConverter::ALLOW_TRAILING_SPACES |
          StringToDoubleConverter::ALLOW_SPACES_AFTER_SIGN |
          StringToDoubleConverter::ALLOW_CASE_INSENSIBILITY |
          StringToDoubleConverter::ALLOW_HEX_FLOATS,
      /*empty_string_value=*/0.0,
      /*junk_string_value=*/0.0, "inf", "nan");

  FuzzedDataProvider provider(data, size);
  std::vector<uint8_t> byte_buffer = provider.ConsumeRemainingBytes<uint8_t>();
  
  const uc16* buffer = reinterpret_cast<const uc16*>(byte_buffer.data());
  int length = byte_buffer.size() / sizeof(uc16);

  int processed_characters_count;
  converter.StringToDouble(buffer, length,
                           &processed_characters_count);
  return 0;
}
