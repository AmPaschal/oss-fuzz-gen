The function `Pistache::Tcp::Transport::onReady` is a central component of the Pistache network library's event loop. It's responsible for handling I/O events on a set of file descriptors. The function takes a reference to an `Aio::FdSet` object, which contains a collection of events that have occurred on file descriptors monitored by the reactor. For each event, `onReady` determines the type of event by examining its associated tag and whether the file descriptor is readable or writable. Based on this, it dispatches the event to the appropriate handler. These handlers manage different aspects of the transport layer, such as writing data to sockets, processing timers, handling peer connections, and responding to notifications.
</description>

void fuzz_request_parser(const std::string &input) {
  constexpr size_t maxDataSize = 4096;
  Pistache::Http::RequestParser rparser(maxDataSize);

  if (rparser.feed(input.data(), input.size())) {
    auto state = Pistache::Http::Private::State::Done;
    ignoreExceptions([&] { state = rparser.parse(); });

    if (state == Pistache::Http::Private::State::Again)
      ignoreExceptions([&] { rparser.parse(); });
  }
}
