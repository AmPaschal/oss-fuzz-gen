
	
<description>
The `YaHTTP::operator<<` function for `Response` objects writes a formatted HTTP response to an output stream. The function itself is a simple wrapper around the `HTTPBase::write` method, which is inherited by the `Response` class. The `write` method constructs the HTTP response by writing the status line, headers, and body to the provided ostream. The content of the response is determined by the member variables of the `Response` object.
</description>
<requirements>
<requirement>
The `Response.version` must be set to 9, 10, or 11. This is because these are the only supported HTTP versions, and any other value will cause a `YaHTTP::Error` to be thrown.
</requirement>
<requirement>
If `Response.statusText` is empty, `Response.status` must be one of the recognized status codes. Otherwise, the `Utility::status2text` function will return "Unknown Status", which may not be desired.
</requirement>
<requirement>
If `Response.version` is greater than 10 and the `content-length` header is not present, the `transfer-encoding` header must be set to `chunked`. Failure to do so will result in a `YaHTTP::Error`.
</requirement>
<requirement>
The `Response.renderer` should be initialized with a valid function. If not, a segmentation fault will occur when it is called in `HTTPBase::write`.
</requirement>
</requirements>

#include <fuzzer/FuzzedDataProvider.h>
#include <sstream>
#include <string>
#include <vector>

#include "yahttp/yahttp.hpp"

// The function signature to be fuzzed is brought in by yahttp.hpp
// No need for a forward declaration.

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  FuzzedDataProvider provider(data, size);

  try {
    YaHTTP::Response resp;

    // Populate the Response object with fuzzed data
    resp.status = provider.ConsumeIntegral<int>();
    resp.version = provider.PickValueInArray<int>({9, 10, 11});
    resp.statusText = provider.ConsumeRandomLengthString(128);

    // Populate headers
    uint8_t num_headers = provider.ConsumeIntegralInRange<uint8_t>(0, 15);
    for (uint8_t i = 0; i < num_headers; ++i) {
      std::string key = provider.ConsumeRandomLengthString(64);
      std::string value = provider.ConsumeRandomLengthString(256);
      if (provider.remaining_bytes() < 16) {
        break;
      }
      resp.headers[key] = value;
    }

    // The body will be the rest of the fuzzed data
    resp.body = provider.ConsumeRemainingBytesAsString();

    std::ostringstream oss;

    // Call the function under test via operator overloading
    oss << resp;
  } catch (const YaHTTP::Error &e) {
    // Catch specific library exceptions
  } catch (const std::exception &e) {
    // Catch any other standard exceptions
  } catch (...) {
    // Catch anything else that might be thrown
  }

  return 0;
}
