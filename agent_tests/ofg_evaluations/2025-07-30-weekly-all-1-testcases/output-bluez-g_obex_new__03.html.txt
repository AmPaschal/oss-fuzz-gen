
	
<description>
The `g_obex_new` function creates a new GObex object, which represents an OBEX session. It takes a GIOChannel for communication, a transport type, and receive/transmit MTU values. The function allocates and initializes a GObex struct, sets up read and write handlers based on the transport type, and registers a watch on the GIOChannel for incoming data. Callers typically create a GIOChannel from a socket (Unix or Bluetooth) and then pass it to this function. The MTU values can be specified, or a negative value can be used to select default values.
</description>
<requirements>
<requirement>
The first argument, `io`, must not be NULL. The function returns NULL if this argument is NULL.
</requirement>
<requirement>
The second argument, `transport_type`, must be one of the values from the `GObexTransportType` enum (`G_OBEX_TRANSPORT_STREAM` or `G_OBEX_TRANSPORT_PACKET`). Other values will cause the function to return NULL.
</requirement>
<requirement>
The third argument, `io_rx_mtu`, if not negative, must be greater than or equal to G_OBEX_MINIMUM_MTU (255). A value less than this will cause the function to return NULL.
</requirement>
<requirement>
The fourth argument, `io_tx_mtu`, if not negative, must be greater than or equal to G_OBEX_MINIMUM_MTU (255). A value less than this will cause the function to return NULL.
</requirement>
<requirement>
The `io` GIOChannel should be created from a valid socket file descriptor. In the callers, this is done using `g_io_channel_unix_new()` for Unix sockets or `bt_io_connect()` for Bluetooth sockets.
</requirement>
</requirements>
