
	
<description>
The `tidyParseSource` function parses input from a `TidyInputSource` and attaches it to a `TidyDoc` document. It's a wrapper around the internal `tidyDocParseSource` function. To use it, one must first create a `TidyDoc` using `tidyCreate()`. Then, a `TidyInputSource` must be prepared. A common way to do this for in-memory strings is to use a `TidyBuffer`. A `TidyBuffer` can be created and populated with the string to be parsed. Then, `tidyInitInputBuffer` is used to associate this buffer with a `TidyInputSource`. Finally, `tidyParseSource` can be called. After the parsing is done, both the `TidyDoc` and the `TidyBuffer` must be freed to avoid memory leaks.
</description>
<requirements>

<requirement>
The `TidyDoc` argument `tdoc` must be a valid pointer returned by `tidyCreate()`. The `tidyParseSource` function internally converts this to a `TidyDocImpl` pointer, so it must be a valid, initialized document handle.
</requirement>
<requirement>
The `TidyInputSource` argument `source` must be initialized, for example by using `tidyInitInputBuffer`. This ensures that the function pointers `getByte`, `eof`, and `ungetByte` within the `TidyInputSource` struct are valid and point to functions that can read from the provided source.
</requirement>
<requirement>
Before calling `tidyParseSource`, a `TidyBuffer` should be created and populated with the data to be parsed. This can be done using `tidyBufInit` or `tidyBufAlloc` and `tidyBufAppend`. The `sourceData` member of the `TidyInputSource` should point to this buffer. The contents of this buffer should be fuzzed.
</requirement>
<requirement>
After parsing, the `TidyDoc` object should be released using `tidyRelease()`. This is necessary to free the memory allocated for the document and prevent memory leaks.
</requirement>
<requirement>
After parsing, the `TidyBuffer` should be freed using `tidyBufFree()`. This is necessary to release the memory used to hold the input data and avoid memory leaks.
</requirement>

</requirements>
