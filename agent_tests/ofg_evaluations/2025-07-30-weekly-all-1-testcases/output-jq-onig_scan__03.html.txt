
	
<description>
The `onig_scan` function repeatedly searches for a regular expression pattern in a string. For each match found, it invokes a callback function. The function starts scanning from the `start` position and continues until the end of the string is reached. The `scan_callback` function is called for each successful match, and its return value determines whether the scan should continue.
</description>
<requirements>

<requirement>
The `reg` argument, a pointer to a `regex_t` struct, must be initialized by calling `onig_new`. This is because `onig_new` allocates and initializes the regex object required for matching.
</requirement>
<requirement>
The `str` and `end` arguments must be valid pointers to a character buffer. The memory region between `str` and `end` must be readable, and `end` must be greater than or equal to `str`.
</requirement>
<requirement>
The `region` argument, a pointer to an `OnigRegion` struct, must be initialized by calling `onig_region_new`. This is because `onig_region_new` allocates the necessary memory for storing capture group information.
</requirement>
<requirement>
The `scan_callback` argument must be a valid function pointer with the signature `int (*)(int, int, OnigRegion*, void*)`. This is because a `NULL` pointer will cause a crash when the callback is invoked. The callback should return 0 to continue scanning, or a non-zero value to stop.
</requirement>
<requirement>
The `onig_initialize` function must be called before `onig_scan`. This is because it sets up the necessary internal structures for the Oniguruma library to function correctly.
</requirement>
<requirement>
After using `onig_scan`, the `onig_free` function should be called on the `regex_t` pointer and `onig_region_free` on the `OnigRegion` pointer. Finally, `onig_end` should be called to release all resources used by the library.
</requirement>
