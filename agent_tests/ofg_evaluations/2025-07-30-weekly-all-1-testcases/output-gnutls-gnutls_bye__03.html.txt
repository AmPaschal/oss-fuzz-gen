
	
<description>
The gnutls_bye function is used to close a TLS session. It sends a close alert to the peer and terminates the connection. The function takes a gnutls_session_t object and a gnutls_close_request_t enum as input. The session object must be fully initialized and a TLS handshake must have been completed before calling this function. The 'how' parameter determines whether to shut down the writing part of the connection (GNUTLS_SHUT_WR) or both reading and writing (GNUTLS_SHUT_RDWR).
</description>
