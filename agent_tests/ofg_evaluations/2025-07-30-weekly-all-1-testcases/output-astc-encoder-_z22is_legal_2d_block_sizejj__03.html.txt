
	
<description>
The function `is_legal_2d_block_size` checks if a given 2D block size, defined by its x and y dimensions, is supported. It works by combining the x and y dimensions into a single 16-bit integer and using a switch statement to check against a hardcoded list of valid composite values. The function is called as part of the block size validation process when initializing the ASTC encoder configuration. If the provided block size is not one of the legal combinations, the configuration will be considered invalid, and an error will be returned, preventing further processing.
</description>
<requirements>
<requirement>
The input parameters `xdim` and `ydim` must be a pair of values that are valid block dimensions. This is because the function constructs a 16-bit value from these parameters and compares it against a fixed set of allowed values, and an invalid pair will cause the calling function to return an error.
</requirement>
<requirement>
The fuzzer should generate `xdim` and `ydim` from the following list of valid pairs: (4, 4), (5, 4), (5, 5), (6, 5), (6, 6), (8, 5), (8, 6), (8, 8), (10, 5), (10, 6), (10, 8), (10, 10), (12, 10), (12, 12). Using these specific pairs is necessary to ensure the function returns `true`, which is required for the `validate_block_size` function to succeed and allow fuzzing of subsequent code paths.
</requirement>
</requirements>

#include "/src/astc-encoder/Source/astcenc_internal.h"
#include <fuzzer/FuzzedDataProvider.h>
#include <cstdint>

bool is_legal_2d_block_size(unsigned int, unsigned int);

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
	// We need 2 unsigned integers.
	if (size < sizeof(unsigned int) * 2) {
		return 0;
	}

	FuzzedDataProvider stream(data, size);

	unsigned int xdim = stream.ConsumeIntegral<unsigned int>();
	unsigned int ydim = stream.ConsumeIntegral<unsigned int>();

	is_legal_2d_block_size(xdim, ydim);

	return 0;
}
