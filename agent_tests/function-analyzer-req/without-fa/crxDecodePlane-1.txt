<description>
The function `LibRaw::crxDecodePlane` decodes a single plane of a CRX image. It iterates through all the tiles of the image plane, and for each tile, it sets up the subband data, performs wavelet transformation and inverse quantization, and converts the decoded data into the output buffer. The function takes a pointer to a `CrxImage` object and a plane number as input. The `CrxImage` object contains all the necessary information about the image, such as its dimensions, number of planes, tile information, and subband data. The plane number specifies which color plane to decode.
</description>
<requirements>
<requirement>
The first argument `p` must be a valid pointer to a `CrxImage` object. This pointer is cast to a `CrxImage*` and dereferenced throughout the function, so a NULL pointer would lead to a crash.
</requirement>
<requirement>
The `CrxImage` object pointed to by `p` must be initialized by calling `crxSetupImageData` before calling this function. `crxDecodePlane` depends on the fields of the `CrxImage` object being correctly populated by `crxSetupImageData`.
</requirement>
<requirement>
The second argument `planeNumber` must be less than the number of planes in the image, which is stored in `img->nPlanes`. This is because `planeNumber` is used as an index into the `tile->comps` array.
</requirement>
<requirement>
After decoding is complete, the `crxFreeImageData` function should be called with the `CrxImage` object. This is necessary to free the memory allocated during the setup and decoding process to prevent memory leaks.
</requirement>
</requirements>

#include <stddef.h>

#include "libraw.h"

extern "C" int LLVMFuzzerTestOneInput(const uint8_t* data, size_t size) {
  // Limit from original fuzzer to avoid excessive memory usage.
  if (size > 15000000) {
    return 0;
  }

  LibRaw lib_raw;

  // open_buffer uses the provided data without copying it.
  if (lib_raw.open_buffer(data, size) != LIBRAW_SUCCESS) {
    return 0;
  }

  // unpack() is the main function that will parse the raw file and call
  // the appropriate decoder. For CRX/CR3 files, this will lead to
  // crxLoadRaw() and subsequently the target function crxDecodePlane().
  // By fuzzing unpack(), we effectively fuzz all internal decoders,
  // including the one containing crxDecodePlane.
  lib_raw.unpack();

  // The LibRaw object's destructor will call recycle() to free resources.
  return 0;
}
