<description>
The function `gnutls_record_recv_packet` is a low-level function for receiving a single, decrypted TLS/DTLS record from a peer. It is intended for high-performance applications that want to avoid extra memory copies by directly accessing the internal packet buffer. The function takes an initialized `gnutls_session_t` and a pointer to a `gnutls_packet_t`. Upon a successful return, the `packet` variable will point to a structure containing the decrypted application data, which must be deallocated by the caller using `gnutls_packet_deinit`. Callers, such as the test program `anonself.c` and the `benchmark-tls.c` utility, use this function within a loop to process incoming data after a successful TLS handshake has been established. The function handles reading the encrypted record from the underlying transport, decrypting it, verifying its integrity, and making the plaintext payload available to the application.
</description>
<requirements>
<requirement>
The `gnutls_session_t` object must be initialized via `gnutls_init` and a successful handshake must be performed using `gnutls_handshake`. This is necessary to establish the cryptographic keys and security parameters required to decrypt incoming records.
</requirement>
<requirement>
The second argument, `packet`, must be a valid pointer to a `gnutls_packet_t` variable. The function will fail with `GNUTLS_E_INVALID_REQUEST` if a NULL pointer is provided.
</requirement>
<requirement>
The transport functions must be set for the session using `gnutls_transport_set_int` or `gnutls_transport_set_ptr`. This is essential for the function to read encrypted record data from the peer.
</requirement>
<requirement>
After successfully receiving a packet (return value > 0), the `gnutls_packet_deinit` function must be called on the received packet. This is required to free the memory and resources allocated for the packet by the GnuTLS library.
</requirement>
<requirement>
The input fuzz data should be provided through the transport layer, specifically via the pull function set by `gnutls_transport_set_pull_function`. This allows the fuzzer to control the encrypted data stream that `gnutls_record_recv_packet` processes.
</requirement>
</requirements>

#include <assert.h>
#include <stdint.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

#include <gnutls/gnutls.h>
#include <gnutls/x509.h>

#include "fuzzer.h"
#include "mem.h"

int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  int res;
  gnutls_session_t session;
  gnutls_certificate_credentials_t xcred;
  struct mem_st memdata;
  gnutls_packet_t packet;

  res = gnutls_init(&session, GNUTLS_CLIENT);
  assert(res >= 0);

  res = gnutls_certificate_allocate_credentials(&xcred);
  assert(res >= 0);
  res = gnutls_credentials_set(session, GNUTLS_CRD_CERTIFICATE, xcred);
  assert(res >= 0);

  res = gnutls_priority_set_direct(session, "NORMAL", NULL);
  assert(res >= 0);

  memdata.data = data;
  memdata.size = size;

  gnutls_transport_set_push_function(session, mem_push);
  gnutls_transport_set_pull_function(session, mem_pull);
  gnutls_transport_set_pull_timeout_function(session, mem_pull_timeout);
  gnutls_transport_set_ptr(session, &memdata);

  do {
    res = gnutls_handshake(session);
  } while (res < 0 && gnutls_error_is_fatal(res) == 0);

  if (res >= 0) {
    while (true) {
      res = gnutls_record_recv_packet(session, &packet);
      if (res > 0) {
        gnutls_packet_deinit(packet);
      } else {
        break;
      }
    }
  }

  gnutls_deinit(session);
  gnutls_certificate_free_credentials(xcred);
  return 0;
}
