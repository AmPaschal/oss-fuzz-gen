<description>
The `crxDecodePlane` function decodes a single plane of a CRX image. It takes a pointer to a `CrxImage` structure and a plane number as input. The `CrxImage` structure contains all the necessary information about the image, including tiling information, number of planes, and data from the CRX file. The function iterates through all the tiles in the specified plane, and for each tile, it sets up the subband data by calling `crxSetupSubbandData`, and then decodes the tile data. The decoded data is then converted and stored in the output buffers within the `CrxImage` structure.
</description>
<requirements>

<requirement>
The first argument `p` must be a pointer to a valid `CrxImage` structure initialized by `crxSetupImageData`. This is because the function relies on the `CrxImage` structure for image parameters and data buffers.
</requirement>
<requirement>
The `planeNumber` argument must be less than the `nPlanes` field of the `CrxImage` structure. This is to prevent an out-of-bounds access to the `tile->comps` array.
</requirement>
<requirement>
The `CrxImage` structure's `input` field must point to a valid and open `LibRaw_abstract_datastream` object. This is because the function reads data from this stream during the decoding process.
</requirement>

</requirements>

extern "C" int LLVMFuzzerTestOneInput(const uint8_t *data, size_t size) {
  if (size < 128) {
    return 0;
  }

  FuzzedDataProvider fdp(data, size);
  FuzzLibRaw libraw;
  CrxImage img = {};
  crx_data_header_t hdr = {};

  LibRaw_buffer_datastream stream(data, size);
  img.input = &stream;

  hdr.f_width = fdp.ConsumeIntegralInRange<uint16_t>(32, 1024);
  hdr.f_height = fdp.ConsumeIntegralInRange<uint16_t>(32, 1024);
  hdr.tileWidth = fdp.ConsumeIntegralInRange<uint16_t>(16, hdr.f_width);
  hdr.tileHeight = fdp.ConsumeIntegralInRange<uint16_t>(16, hdr.f_height);
  hdr.nPlanes = fdp.PickValueInArray<uint8_t>({1, 4});
  hdr.nBits = fdp.ConsumeIntegralInRange<uint8_t>(9, 16);
  hdr.imageLevels = fdp.ConsumeIntegralInRange<uint8_t>(0, 3);
  hdr.encType = fdp.PickValueInArray<uint8_t>({0, 1, 3});
  hdr.version = fdp.PickValueInArray<int32_t>({0x100, 0x200});

  if (hdr.nPlanes == 1) {
    hdr.encType = 0;
    hdr.nBits = 8;
  } else {
    hdr.f_width &= ~1;
    hdr.f_height &= ~1;
    hdr.tileWidth &= ~1;
    hdr.tileHeight &= ~1;
  }

  if (hdr.tileWidth > 0 && hdr.f_width > hdr.tileWidth &&
      hdr.f_width % hdr.tileWidth < 16) {
    hdr.tileWidth = hdr.f_width;
  }
  if (hdr.tileHeight > 0 && hdr.f_height > hdr.tileHeight &&
      hdr.f_height % hdr.tileHeight < 16) {
    hdr.tileHeight = hdr.f_height;
  }

  std::vector<uint8_t> mdatHdrBuf =
      fdp.ConsumeBytes<uint8_t>(fdp.ConsumeIntegralInRange<size_t>(0, 64));
  hdr.mdatHdrSize = mdatHdrBuf.size();

  std::vector<int16_t> outBuf(hdr.f_width * hdr.f_height * 2, 0);

  if (crxSetupImageData(&hdr, &img, outBuf.data(), 0, size,
                        mdatHdrBuf.data(), mdatHdrBuf.size()) == 0) {
    if (img.nPlanes > 0) {
      uint32_t planeNumber =
          fdp.ConsumeIntegralInRange<uint32_t>(0, img.nPlanes - 1);
      libraw.public_crxDecodePlane(&img, planeNumber);
    }
  }

  crxFreeImageData(&img);

  return 0;
}
