<description>
The function `lou_getTypeformForEmphClass` takes a table list and an emphasis class name as input. It retrieves the corresponding translation table and searches for the provided emphasis class name within the table's `emphClassNames` array. If a match is found, it returns a typeform value calculated based on the index of the matched emphasis class. If no table can be found or the emphasis class is not in the table, it returns 0.
</description>
<requirements>
<requirement>
The `tableList` argument must be a path to a valid, compiled translation table. The function relies on `_lou_getTranslationTable` to load the table, and a valid path is necessary for this to succeed.
</requirement>
<requirement>
The `emphClass` argument should be a null-terminated string. This is because it's passed to `strcmp` for comparison, and a non-null-terminated string could lead to a read out-of-bounds.
</requirement>
<requirement>
The `lou_free()` function should be called after using `lou_getTypeformForEmphClass`. This is to free the memory allocated for the translation table by `_lou_getTranslationTable`, preventing memory leaks.
</requirement>
<requirement>
The `emphClass` argument should be fuzzed. This allows testing with various emphasis class names, including non-existent ones, to ensure the function behaves correctly in all scenarios.
</requirement>
</requirements>
